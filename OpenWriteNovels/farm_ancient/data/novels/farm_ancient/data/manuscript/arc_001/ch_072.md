# 火墙

天边泛起鱼肚白，西墙外的鞑子骑兵像闻到血腥味的狼群，开始躁动。

林小满蹲在墙垛后，右手掌心火辣辣地疼。刚才搬青石堵缺口时，一根木刺深深扎进肉里，她咬着牙用匕首尖挑出来，血珠子渗进泥土。

“林娘子，东边又来了一拨！”守在墙头的王二狗压低声音喊。

林小满抬头。东墙方向，沈青石的迎战号角撕裂晨雾。那声音短促有力，像刀劈在石头上。她的心揪了一下——昨夜他说左臂受伤，现在还能握刀吗？

“别慌。”林小满站起身，声音压得平，“按我说的，三拨人轮着来。第一拨守墙头扔石头，第二拨在缺口后等着，第三拨去搬火油草捆。”

西墙守卫三十人，全是镇上青壮。手里拿的不是锄头就是木棍，只有五把生锈的刀。但没人跑。昨夜鞑子游走时，有人想逃，被林小满拦住了：“跑出去死得更快。留在墙里，还有活路。”

这话实在。墙外是茫茫草原，马跑得比人快十倍。

“来了！”王二狗声音发颤。

缺口外，三匹马小跑过来。马上的鞑子骑兵穿着皮甲，手里弯刀在晨光里反着冷光。他们没直接冲缺口，而是绕着土墙走，像在试探。

林小满眯起眼。昨夜她让人在缺口前挖了浅沟，埋了麻绳套索，上面盖着草皮和湿泥。白天看不出来，但马蹄踩上去会陷住。

“放近点。”她低声说。

五十步。四十步。三十步。

领头的鞑子忽然勒马，指着缺口叽里咕噜说了句什么。另外两人大笑起来，其中一个从马鞍旁摘下弓。

“趴下！”林小满吼。

嗖——

箭矢擦着墙垛飞过，钉进后面的土墙里，箭尾还在颤。

“他们不敢直接冲。”林小满迅速判断，“在试探咱们有没有弓箭手。”

她抓起脚边一块石头，掂了掂。石头有拳头大，边角锋利。“扔！”

十几个石头同时飞出去。鞑子骑兵拨马躲开，石头砸在泥地上，溅起土沫。领头那人骂了句什么，调转马头往回跑。

“成了！”王二狗兴奋地捶墙。

林小满没松气。她盯着那三匹马，看它们跑回大队。鞑子骑兵分两股，一股在东墙外游走，一股在西墙外集结。现在天亮了，他们要动真格的。

“火油草捆呢？”她问。

“搬来了！”两个汉子抬着捆扎好的草捆跑过来。草捆有半人高，底部浸透了菜油，用破布包着。一共十二捆，分三堆放在缺口后二十步的地方。

林小满检查了火折子。老赵头征来的两罐菜油，一罐泼在草捆上，一罐留着备用。破布撕成条，缠在木棍上做火把。

“记住，”她对守在草捆旁的六个人说，“等马冲进缺口，再点火。火要扔在缺口正中间，形成火墙。马怕火，会往两边跑，正好撞上套索。”

“要是马跳过火墙呢？”有人问。

“跳不过。”林小满指了指缺口两侧的土墙，“缺口只有八尺宽，火墙烧起来有五尺高。马不是鸟，飞不过去。”

话音刚落，东墙方向传来震天的喊杀声。

林小满的心猛地一沉。她爬上墙垛，手搭凉棚往东看。晨雾散了，能看见东墙外黑压压一片鞑子骑兵，正潮水般往墙根涌。墙头上有滚木礌石砸下来，但稀稀拉拉的，明显快用完了。

“沈青石……”她喃喃道。

“林娘子！”老赵头的声音从墙下传来。

林小满回头。老赵头带着十几个人跑过来，个个气喘吁吁。他脸上有血，不知是自己的还是别人的。

“东墙顶不住了！”老赵头吼道，“箭射光了，滚木也快没了。鞑子架了云梯，沈将军带人往下推，自己胳膊又挨了一刀！”

林小满的手指抠进墙垛的泥土里。

“你带一半人去支援。”她说。

“那你这边——”

“我守得住。”林小满打断他，声音硬得像石头，“你告诉沈青石，西墙有火墙。鞑子要是从西边绕过去，我烧死他们。”

老赵头盯着她看了两秒，重重点头。“走！”他挥手，带着一半人往东墙跑。

西墙只剩下十五个人。

林小满跳下墙垛，走到缺口前。晨光里，她能看清缺口外鞑子骑兵的脸了。那些脸黝黑粗糙，眼睛里闪着贪婪的光。他们看见守军人少，开始往前挪。

“第一拨，上墙头！”林小满喊。

五个汉子爬上墙垛，手里握着石头。

“第二拨，缺口后待命！”

五个人退到缺口后十步，手里拿着削尖的木棍。

“第三拨，守火油草捆！”

剩下五个人蹲在草捆旁，火折子攥在手里。

鞑子骑兵开始冲锋了。

二十匹马小跑着过来，马蹄声闷雷似的。领头的鞑子举着弯刀，嘴里发出“嗬嗬”的怪叫。

“稳住！”林小满吼。

一百步。八十步。六十步。

墙头上的石头砸出去，砸中了两匹马。马嘶鸣着倒地，骑手滚下来，被后面的马踩过去。

但剩下的骑兵没停。他们冲得更快，直扑缺口。

四十步。三十步。

林小满看见领头鞑子的眼睛了。那是一双狼一样的眼睛，黄褐色，瞳孔缩成一条缝。

二十步。

“点火！”林小满吼。

五支火把同时点燃，扔进草捆。菜油轰地烧起来，火焰蹿起五尺高，橘红色的火舌舔着晨雾。热浪扑面而来，空气里弥漫着焦糊味。

领头鞑子的马猛地人立起来，前蹄乱蹬。骑手拼命勒缰绳，但马已经吓疯了，调头就往回跑。

后面的骑兵收不住，撞在一起。有两匹马直接冲进火墙，瞬间变成火球。骑手惨叫着摔下来，在地上打滚。

缺口前乱成一团。

“第二拨，上！”林小满喊。

五个汉子冲上去，用木棍捅那些没着火的马。马受惊乱跳，有两匹踩进浅沟，蹄子被麻绳套住，轰然倒地。

“扔石头！”

墙头上的石头雨点般砸下来。鞑子骑兵被火墙挡着，冲不过来，只能在外围转圈。有几个想绕到墙侧，但那里是荒地，马跑不快。

“他们要退了！”王二狗兴奋地喊。

林小满没放松。她盯着火墙。菜油烧得快，火焰开始变小。草捆里的草烧光了，只剩浸油的破布在烧。

“再加一罐油！”她喊。

有人抬来剩下的菜油，泼在燃烧的草捆上。火焰又蹿起来，比刚才还高。

鞑子骑兵终于退了。他们拖着伤员和死马，退回草原深处。墙外留下十几具尸体，还有三匹套在麻绳里哀鸣的伤马。

“赢了！”西墙守军欢呼起来。

林小满靠在墙上，腿有点软。她低头看自己的右手，掌心全是血和泥，木刺扎的伤口还在渗血。

“林娘子，东墙——”王二狗忽然指着东边。

林小满抬头。

东墙方向，喊杀声停了。晨雾散尽，能看见东墙外鞑子骑兵正在后撤。墙头上，沈青石的身影出现在墙垛间。他左臂缠着布条，右手握着刀，刀尖还在滴血。

他看见西墙的火光了。

隔着半里地，两人目光撞在一起。

沈青石举起刀，朝西墙方向挥了挥。

林小满的眼眶忽然有点热。她扯了扯嘴角，也抬起手，朝东墙挥了挥。

“鞑子退了！”东墙传来欢呼声。

西墙这边也跟着喊起来。两墙的欢呼声连成一片，在边关的晨光里回荡。

林小满滑坐在地上。她累坏了，从昨夜到现在，整整守了四个时辰。右手疼得发麻，腿肚子直打颤。

“林娘子，喝口水。”王二狗递过水囊。

林小满接过来，灌了两口。水是凉的，顺着喉咙流下去，浇灭了心里的火。

“鞑子还会来吗？”王二狗蹲在她旁边，小声问。

林小满摇头。“不知道。”她看着墙外草原，“但他们今天吃了亏，短时间内不敢再攻西墙。东墙那边……得看沈将军怎么安排。”

话音刚落，老赵头跑回来了。他浑身是血，自己的少，别人的多。

“沈将军让我来问，”老赵头喘着气说，“西墙的火油还有多少？”

林小满指了指剩下的半罐菜油。“就这些了。”

老赵头皱眉。“东墙的箭射光了，滚木礌石也用完了。鞑子要是再攻，只能拿人命填。”

林小满沉默片刻。“镇上还能征到油吗？”

“难。”老赵头摇头，“昨夜征了两罐，已经是全镇的存货。菜油金贵，谁家也没多少。”

林小满站起来，走到缺口前。晨光里，她能看清那些烧焦的草捆，还有鞑子留下的尸体。尸体穿着皮甲，手里还握着弯刀。

“那些皮甲……”她忽然说。

老赵头愣了下。“鞑子的皮甲？”

“对。”林小满转身，“皮甲是牛皮做的，牛皮能熬胶。胶能粘东西，也能燃烧。咱们把鞑子的皮甲扒下来，熬成胶，涂在草捆上，比菜油还耐烧。”

老赵头眼睛一亮。“这法子行！”

“还有弯刀。”林小满继续说，“弯刀是铁打的，铁能打箭头。咱们没有铁匠，但沈将军军营里肯定有。把弯刀融了，打成箭头，东墙就有箭了。”

老赵头重重一拍大腿。“林娘子，你这脑子咋长的！”

林小满没笑。她看着东墙方向，沈青石的身影还站在墙头。他在指挥人修补城墙，左臂的布条被血浸透了，红得刺眼。

“老赵头，”她说，“你带人去扒鞑子的皮甲，收弯刀。我去东墙找沈将军。”

“你去？”老赵头犹豫，“鞑子还没走远……”

“走不远。”林小满说，“他们今天吃了亏，得回去舔伤口。咱们得趁这时候，把防御做起来。”

她低头看自己的右手。伤口还在渗血，但已经不怎么疼了。疼过了头，就麻木了。

“走吧。”她说。

两人带着人，从西墙缺口出去。草原上弥漫着烧焦的味道，还有血腥味。鞑子的尸体东倒西歪，有的被马踩得变了形。

林小满没多看。她走到一具尸体旁，蹲下身，开始扒皮甲。皮甲是整张牛皮硝制的，硬邦邦的，带着膻味。她使劲拽，拽不下来。

“我来。”老赵头抽出匕首，割断皮甲的系带。

林小满接过皮甲，掂了掂。至少有十斤重。一张牛皮能熬出不少胶。

“多收点。”她说，“越多越好。”

镇民们开始扒皮甲，收弯刀。有人吐了，但没人停手。边关的人，见惯了死人。

林小满抱着两张皮甲，往东墙走。晨光把她的影子拉得很长，投在草原上，像一根细长的旗杆。

东墙下，沈青石正坐在石头上，军医给他换药。左臂的伤口很深，刀口从肩头划到肘子，肉翻卷着，白花花的骨头隐约可见。

林小满的心揪了一下。

“沈将军。”她开口。

沈青石抬头。他脸色苍白，额头上全是汗，但眼神还是亮的。看见林小满手里的皮甲，他愣了下。

“这是……”

“鞑子的皮甲。”林小满把皮甲放在他脚边，“能熬胶，涂在草捆上，比菜油耐烧。还能粘城墙裂缝。”

沈青石盯着她看了几秒，忽然笑了。他一笑，脸上的疤就皱起来，像一道扭曲的沟壑。

“林娘子，”他说，“你这脑子，该去当军师。”

林小满没接话。她看着他的伤口，血还在往外渗。“军医，”她对旁边的军医说，“伤口得缝起来。用鱼肠线，细针，密密地缝。”

军医愣住。“缝？”

“对。”林小满说，“伤口太长，不缝合好不了。我见过军医用马尾毛缝，但鱼肠线更细，愈合快。”

沈青石皱眉。“鱼肠线？”

“把鱼肠洗干净，刮去黏膜，用盐腌了，晾干，就是线。”林小满说，“边关没有鱼，但羊肠也行。羊肠衣薄，韧性好。”

军医听得目瞪口呆。“这……这法子从哪听来的？”

“书上看的。”林小满含糊道。总不能说她在现代见过兽医缝合伤口。

沈青石摆摆手。“按林娘子说的办。”他对军医说，“去找羊肠，要新鲜的。”

军医跑开了。

林小满在沈青石旁边坐下。两人之间隔着一臂距离。晨光晒在身上，暖洋洋的。

“西墙的火墙，是你弄的？”沈青石问。

“嗯。”林小满点头，“用菜油和草捆。油不多，只能烧一阵。”

“够了。”沈青石说，“鞑子没料到咱们有火，吓破了胆。今天不会再攻了。”

林小满看着东墙外。鞑子骑兵退到了草原深处，像一片黑压压的乌云。“他们还会来。”她说。

“会。”沈青石说，“但咱们也有时间准备了。”他低头看自己的左臂，血把布条浸透了，红得发黑。“你的法子，能救很多人的命。”

林小满没说话。她看着自己的右手，掌心的伤口结了层黑红色的血痂。忽然想起什么，从怀里掏出个小布包。

“这是草药。”她说，“止血的。我昨夜在墙根挖的，捣烂了敷上，能止血消炎。”

沈青石接过布包，打开。里面是深绿色的草药泥，带着苦涩的草腥味。

“你还会医术？”他问。

“不算会。”林小满说，“在家乡学过一点。边关缺医少药，总得想办法。”

沈青石看着她，眼神深了些。“你的家乡，在很远的地方？”

“很远。”林小满说，“远到回不去。”

这话是真的。现代，确实回不去了。

沈青石没再问。他把草药泥敷在伤口上，用布条重新包扎。草药凉丝丝的，伤口没那么疼了。

“林娘子，”他忽然说，“等打退鞑子，我请你喝酒。”

林小满愣了下，笑了。“好。”

两人坐在东墙下，看着晨光一点一点亮起来。草原上，鞑子骑兵开始后撤，马蹄扬起的尘土像一道灰色的幕布。

“他们走了。”沈青石说。

林小满点头。她站起来，拍了拍身上的土。“我去看看西墙的陷阱。套索得重新埋，火油草捆也得重新做。”

“我让老赵头帮你。”沈青石说。

“不用。”林小满摇头，“你受伤了，好好歇着。东墙这边，还得你守。”

她转身要走，沈青石忽然叫住她。

“林小满。”

林小满回头。

沈青石看着她，晨光里，他的眼睛像深潭。“小心点。”他说。

林小满的心跳漏了一拍。她点点头，快步往西墙走去。

身后，沈青石的目光一直跟着她，直到她的身影消失在墙角。

军医拿着羊肠跑回来，看见沈青石的表情，愣了下。“将军，羊肠找来了。”

沈青石收回目光，伸出手臂。“缝吧。”

军医开始清洗羊肠。沈青石看着西墙方向，想起林小满刚才说的话：“远到回不去。”

他忽然想，回不去也好。

边关苦寒，但有她在，好像也没那么苦了。
