# 血染西墙

西墙缺口处的火堆烧得正旺，火光把每个人的脸都映得忽明忽暗。林小满右手掌心火辣辣地疼，那根木刺还扎在肉里，她没空管它。

“石头！把那边那块大石头推过来！”她嗓子喊得发哑。

几个年轻后生喊着号子，把一块半人高的青石滚到缺口处。缺口不大，但足够让三五个鞑子兵并排冲进来。石头刚堵上，墙外就传来马蹄声。

“他们动了！”墙头放哨的猎户喊道。

林小满爬上缺口边的土堆往外看。月光下，黑压压的骑兵正在移动，不是冲过来，而是分成两股，像两条黑蛇一样绕着土墙游走。

“他们想把咱们围死。”老赵头蹲在她旁边，声音压得很低，“天一亮就强攻，或者等咱们自己乱。”

林小满回头看了看西墙这边的人。三十来个，都是镇上的百姓，有铁匠铺的学徒，有卖豆腐的老汉，还有几个妇人。他们手里拿着锄头、扁担、菜刀，眼神里全是恐惧。

“沈将军那边怎么样了？”她问。

“刚才传话过来，东墙还能守。”老赵头抹了把脸，“但箭矢用光了，滚木礌石也没多少。鞑子要是集中攻东墙，撑不过两个时辰。”

林小满咬了咬牙。她想起沈青石刚才在北门时的样子——左臂袖子湿透，血一滴一滴往下淌，可他还在指挥伤兵列队，声音稳得像块石头。

“咱们不能光守。”她突然说，“得让他们知道，西墙这边也不好啃。”

老赵头愣了一下：“咱们这点人……”

“人少有人少的办法。”林小满跳下土堆，在火堆边蹲下，捡起一根烧得半焦的木棍在地上画，“缺口堵上了，但墙头还能站人。咱们分三拨，一拨守缺口，一拨在墙头往下扔东西，一拨……”

她顿了顿，看向不远处堆着的柴草垛。

“一拨去准备火油。”

老赵头眼睛亮了：“你是说……”

“鞑子不是要围吗？咱们就让他们围得不安生。”林小满站起来，右手掌心一抽一抽地疼，“赵叔，你带几个人去镇里，把能找到的油都找来。菜油、桐油、猪油，什么油都行。再找些破布、旧棉花。”

“这大半夜的，上哪儿找……”

“去敲门！”林小满声音硬了，“跟大家说清楚，今晚要是守不住，明天鞑子破墙，谁都活不了。油能借多少借多少，打完仗我林小满双倍还！”

老赵头看着她，火光在她脸上跳动，那张年轻的脸此刻绷得紧紧的，可眼睛里没有慌。

“成。”他转身就要走。

“等等。”林小满叫住他，“再找些麻绳，要粗的。还有，把镇里那几口大水缸都搬来，装满水。”

老赵头点点头，带着两个后生跑了。

墙外马蹄声更近了。林小满爬上墙头，往外看。鞑子骑兵已经散开，每隔十几丈就有一骑，手里举着火把，把土墙外照得一片通明。

“他们在示威。”旁边的铁匠学徒小声说，“告诉咱们，他们看得见咱们的一举一动。”

林小满没说话。她盯着那些火把，脑子里飞快地转。

火把……

“去，把咱们的火堆都灭了。”她突然说。

“灭了？”几个镇民都愣了，“那咱们看不见……”

“墙外有他们的火把，咱们借光就行。”林小满已经跳下墙头，开始用脚踩火堆，“快！把火堆都踩灭！墙头留一两个小火堆，其他的全灭！”

大家虽然不明白，但还是照做了。很快，西墙这边暗了下来，只有墙头两个小火堆还亮着。

墙外的鞑子骑兵显然注意到了这个变化，有几骑开始往缺口方向靠近。

林小满蹲在墙根阴影里，心跳得很快。她在赌——赌鞑子不敢在夜里贸然冲缺口，赌他们会先试探。

果然，三匹马慢慢走到缺口外三十丈的地方，停住了。马上的骑兵举着火把，往缺口里照。

火光透进来，在地上拉出长长的影子。

林小满屏住呼吸，对墙头的人打了个手势。

两个后生悄悄抬起一块大石头，对准缺口外的地面。

“扔！”林小满低喝。

石头呼啸着飞出去，不是砸向骑兵，而是砸在他们马前的地面上。泥土飞溅，马匹受惊，嘶鸣着往后退。

墙头传来压低的喝彩声。

那三匹马退了几步，又停下来。骑兵们互相说了几句什么，调转马头回去了。

“他们不敢硬冲。”老赵头不知什么时候回来了，手里拎着两个陶罐，“油找来了，不多，就这两罐菜油。镇上人说，家里实在没多余的了。”

林小满接过陶罐，晃了晃。一罐大概三斤，两罐六斤。

“够不够？”她问。

“看怎么用。”老赵头从怀里掏出几块破布，“棉花没找到，倒是找了些旧衣裳，撕了能当引火物。”

林小满点点头。她走到柴草垛前，抓起一把干草，又看看陶罐里的油。

“赵叔，你以前打过猎吗？”

“年轻时跟爹进过山，打过兔子野鸡。”

“会用套索吗？”

老赵头愣了一下：“套索？”

“就是绳圈，能套住东西的那种。”林小满比划着，“咱们在缺口外设几个套索，鞑子要是冲过来，马腿踩进去，就能绊倒。”

老赵头眼睛又亮了：“这法子行！我去找绳子！”

“别急。”林小满叫住他，“套索要设在暗处，不能让他们看见。咱们得先挖几道浅沟。”

她蹲下来，用木棍在地上画：“缺口前这片空地，挖三道沟，半尺深就行。沟里埋套索，上面盖层浮土。鞑子冲过来，马蹄陷进去，套索就能套住。”

“可咱们人手不够……”

“不用全挖。”林小满站起来，“只挖缺口正前方这一小片。其他地方……”

她看了看墙外那些游走的火把。

“其他地方，咱们用别的法子。”

接下来的一个时辰，西墙这边忙得脚不沾地。老赵头带着几个人在缺口前挖沟，林小满则指挥其他人准备火油罐。

她把破布撕成条，塞进陶罐口，只留一截在外头当引信。又让人把柴草垛拆了，干草捆成一小捆一小捆的。

“这些草捆要浸油吗？”铁匠学徒问。

“不全浸。”林小满拿起一个草捆，只在底部沾了点油，“浸太多烧得快，浸太少点不着。这样就行，底下沾点油，上面干草，能烧一阵子。”

她试了试火折子，点燃草捆底部。火苗“腾”地窜起来，干草烧得噼啪作响，黑烟滚滚。

“成了。”林小满把火把插在地上，“鞑子要是冲过来，咱们就把这些草捆扔下去。不用砸人，就扔在缺口前，烧起一道火墙。”

老赵头那边也挖好了沟，正在埋套索。粗麻绳打成活结，埋在浅沟里，上面盖了层浮土。

“试试。”林小满牵过一匹不知从哪儿找来的瘦马，让它往沟里走。

马蹄刚踩进去，浮土塌陷，套索“唰”地收紧，一下套住了马腿。瘦马嘶鸣一声，差点摔倒。

“好！”周围的人压低声音喝彩。

林小满却皱起眉头：“套索太明显了。鞑子要是举着火把照一照，就能看见。”

她想了想，让人去挖几棵带根的草皮，盖在浮土上。又让人从墙根挖些湿泥，涂在绳子上，掩盖颜色。

等这一切都弄好，东边天际已经泛起一丝灰白。

天快亮了。

墙外的鞑子骑兵开始收拢，火把一支支熄灭。马蹄声变得整齐，像是在集结。

“他们要攻了。”老赵头声音发紧。

林小满爬上墙头，往外看。鞑子骑兵黑压压一片，至少两三百骑，在晨曦中列成阵势。马匪的队伍混在其中，穿着五花八门的衣裳，但手里的刀枪闪着寒光。

“东墙那边怎么样了？”她问。

话音刚落，东墙方向传来号角声。不是鞑子的号角，是沈青石的。

呜——呜呜——

两短一长，是准备迎战的信号。

“沈将军在调兵。”老赵头说，“东墙要硬扛了。”

林小满心跳得更快。她看看东墙方向，又看看西墙外的鞑子骑兵。如果鞑子集中兵力攻东墙，西墙这边压力会小些，但东墙能撑多久？

如果鞑子分兵，同时攻东西两墙呢？

“赵叔。”她突然说，“你带一半人去东墙支援。”

老赵头愣了：“那西墙……”

“西墙有我。”林小满声音平静，“缺口堵上了，套索也埋了，火油草捆都备好了。鞑子要是来，我守得住。”

“可你一个姑娘家……”

“姑娘怎么了？”林小满打断他，“昨晚砸石头、挖沟、准备火油，哪样不是我带头干的？赵叔，现在不是讲这些的时候。东墙是主战场，沈将军那边更需要人手。”

老赵头看着她，张了张嘴，最后重重叹了口气。

“成。我带十五个人过去。剩下的人留给你，你……你千万小心。”

林小满点点头。

老赵头很快点了十五个人，都是有点力气的后生。他们拿着锄头扁担，猫着腰往东墙方向跑。

西墙这边只剩下十五个人，还有几个妇人。林小满把他们分成三组，一组守缺口，一组在墙头准备扔石头草捆，一组负责递东西。

天色越来越亮。

墙外的鞑子骑兵开始移动，但不是冲向西墙，而是往东墙方向去了。只留下二三十骑在西墙外游弋，监视这边。

“他们主攻东墙。”铁匠学徒松了口气。

林小满却没松气。她盯着那二三十骑，总觉得不对劲。

如果鞑子真要主攻东墙，为什么还要留人看西墙？西墙缺口已经堵上，留人没用，除非……

除非他们知道西墙守军不多，留点人就能牵制住。

或者，除非他们还有别的招。

就在这时，东墙方向传来震天的喊杀声。

战鼓擂响，号角长鸣，马蹄声像闷雷一样滚过来。林小满爬上墙头，踮脚往东看，只见尘土飞扬，黑压压的骑兵潮水般涌向东墙。

“开始了。”她喃喃道。

西墙外的二三十骑也开始骚动，有几骑开始往缺口方向靠近，但只是靠近，不冲。

他们在试探。

林小满握紧手里的火折子，掌心的木刺扎得更深了，疼得她直抽气。

“娘，我怕。”一个妇人抱着孩子，蹲在墙根，声音发抖。

林小满走过去，蹲下来，看着那妇人的眼睛。

“别怕。”她说，“咱们准备了这么多，鞑子冲不进来。”

“可东墙那边……”

“沈将军守得住。”林小满声音很肯定，“他在边关守了这么多年，鞑子从来没攻破过。咱们只要守住西墙，别让他们抄后路就行。”

妇人看着她，慢慢点了点头。

墙外，那几骑鞑子骑兵又靠近了些，已经到了缺口外五十丈的地方。他们举着弓，但没射。

林小满盯着他们，突然发现不对。

那几骑的马背上，好像驮着什么东西。不是武器，是……布袋？

“那是什么？”她问。

没人答得上来。

那几骑突然加快速度，冲到缺口外三十丈的地方，把马背上的布袋往下一扔，调头就跑。

布袋落在地上，破了，里面滚出黑乎乎的东西。

“是石头？”铁匠学徒眯着眼看。

林小满心里一沉。

“不是石头。”她说，“是火油。”

话音未落，那几骑已经跑远了，但远处有一骑举起弓，箭头上绑着燃烧的布条。

火箭。

“躲开！”林小满大喊。

火箭划出一道弧线，精准地落在那堆布袋上。

轰！

火光冲天而起，黑烟滚滚。布袋里的火油溅开，瞬间烧成一片火海，正好堵在缺口前。

“他们想用火封住缺口！”老赵头留下的一个后生喊道。

林小满脑子嗡的一声。缺口被火封住，他们出不去，但鞑子也进不来——除非火灭了。

可火油烧起来，一时半会儿灭不了。

墙外的鞑子骑兵开始欢呼，用生硬的汉话喊着什么。

林小满听不懂，但能猜到意思：他们把西墙这边困死了。

火墙烧得正旺，热浪扑面而来。墙头的人都退了几步，脸色发白。

“怎么办？”铁匠学徒问。

林小满盯着那片火海，脑子飞快地转。火油烧得快，但这么多火油，至少能烧半个时辰。半个时辰后，火灭了，缺口前的地面烧得滚烫，马匹过不来，但人能过来。

而且，火灭的时候，往往是守军最松懈的时候。

“灭火。”她突然说。

“灭火？”大家都愣了，“怎么灭？咱们没水……”

“有水。”林小满指向墙根那几口大水缸，“那是我让赵叔搬来的，本来准备鞑子冲过来时泼他们，现在先灭火。”

“可火油烧着，泼水没用啊！”

“有用。”林小满已经跑到水缸边，舀起一桶水，“火油浮在水面上，但咱们不是要浇灭火油，是要把火油冲开，冲出一条道来。”

她拎着水桶，走到火墙前，深吸一口气，把水泼了出去。

水泼在火上，滋滋作响，蒸汽腾起。火被冲开一道口子，但很快又合拢了。

“不够。”林小满说，“得多泼，把火油冲到两边去，中间留出道。”

她回头：“都来帮忙！用水桶泼，把火油往两边冲！”

大家这才反应过来，纷纷去舀水。十几个人排成一排，一桶接一桶地往火墙上泼。

水汽蒸腾，热浪逼人。林小满被熏得眼泪直流，但手没停。

泼了二十多桶，火墙中间果然被冲开一道半人宽的口子。火油被冲到两边，还在烧，但中间露出焦黑的地面。

“成了！”铁匠学徒喊道。

林小满却摇摇头：“不够宽。鞑子要是冲过来，这么窄的道，一个堵住就完了。”

她看了看两边的火墙，又看看水缸里剩下的水。

“得再冲宽些。”她说，“但水不够了。”

就在这时，东墙方向传来一阵急促的锣声。

不是进攻的锣，是……收兵的锣？

林小满爬上墙头，往东看。只见鞑子骑兵潮水般退去，留下一片狼藉的战场。东墙的土墙上插满了箭，有些地方塌了，但没破。

沈青石守住了。

墙外的鞑子骑兵开始集结，往北边撤。西墙外那二三十骑也调转马头，跟着大部队走了。

“他们撤了？”有人不敢相信。

林小满却盯着那片还在烧的火墙，心里没松气。

鞑子撤了，但火墙还在。他们撤退前用火封住缺口，是想……

“他们想困住咱们。”她说，“等火灭了，再杀个回马枪。”

话音刚落，远处尘土又起。

不是鞑子的大部队，是一小队骑兵，二三十骑，正快速往西墙方向冲来。

“是马匪！”墙头有人认出来了，“秃鹫山的马匪！”

林小满心里一紧。马匪比鞑子更麻烦，他们熟悉地形，打仗没规矩，专门捡软柿子捏。

西墙这边只剩十五个人，火墙还没灭，缺口出不去。

马匪越来越近，已经能看清他们狰狞的脸和手里的弯刀。

“怎么办？”铁匠学徒声音发颤。

林小满看着那道半人宽的火墙缺口，又看看墙根剩下的半缸水，还有那几捆浸了油的草捆。

她脑子里突然冒出一个念头。

“点火。”她说。

“点火？点哪儿？”

“点草捆。”林小满已经抱起一捆浸油的干草，“往缺口外扔，扔在火墙前面，烧起一片，挡住他们的路。”

“可咱们只有几捆……”

“够了。”林小满点燃草捆，火苗“腾”地窜起来，“马匪要冲过来，得先过火墙。咱们把火烧旺些，让他们过不来。”

她抱着燃烧的草捆，冲到缺口前，用力扔了出去。

草捆落在火墙外，烧成一团火球。接着第二捆、第三捆……五捆草捆全扔出去，在缺口前烧起一片火海。

马匪冲到火海前，勒住马，不敢往前。

“放箭！”林小满喊。

墙头的人这才反应过来，拿起弓箭——虽然箭不多了——往火海外面射。箭矢稀稀拉拉，但马匪还是退了几步。

火墙、草捆火海、箭矢，三道防线，暂时把马匪挡在了外面。

但林小满知道，挡不了多久。草捆烧得快，箭矢也快用光了。等火烧完，箭射完，马匪就会冲过来。

她回头看了看东墙方向。沈青石那边刚打完，伤亡不知，能不能来支援？

就在这时，东墙方向传来马蹄声。

不是鞑子，是……镇子里的马？

林小满爬上墙头，只见一队骑兵从东墙方向冲过来，只有十几骑，但马壮人勇，为首那人左臂缠着绷带，右手举着长枪。

是沈青石。

他带着伤，来救西墙了。

马匪显然也看见了，开始骚动。沈青石那十几骑冲得很快，转眼就到了西墙外，和马匪撞在一起。

长枪挥舞，刀光闪烁。沈青石一枪挑翻一个马匪，调转马头又刺倒一个。他手下那些兵也是狠角色，虽然人少，但冲得猛，打得马匪连连后退。

林小满看着，心提到了嗓子眼。

沈青石左臂的绷带已经红透了，血一滴一滴往下淌，但他握枪的手稳得很。枪尖每一次刺出，都带着风声。

马匪撑不住了，开始溃逃。沈青石没追，勒住马，抬头看向墙头。

火光映在他脸上，那道疤格外显眼。

他看见了林小满。

两人隔着火墙和战场，对视了一眼。

沈青石点点头，调转马头，往东墙方向回去了。

马匪跑了，鞑子撤了，西墙的危机暂时解除了。

林小满瘫坐在墙根，右手掌心疼得钻心。她摊开手，那根木刺还扎在肉里，周围已经红肿发炎。

“得挑出来。”老赵头不知什么时候回来了，手里拿着根细针，“忍着点。”

林小满点点头。

针尖刺进肉里，找到木刺，一点点往外挑。疼得她直抽气，但没出声。

木刺挑出来，带出一点脓血。老赵头用布条给她包扎好，叹了口气。

“今天多亏了你。”他说，“要不是你准备了那些火油草捆，西墙早破了。”

林小满摇摇头：“多亏了沈将军。他要是不来，马匪就冲进来了。”

“沈将军伤得不轻。”老赵头压低声音，“左臂那一刀，深得见骨头。军医说，再偏一寸，胳膊就废了。”

林小满心里一紧。

她想起沈青石刚才在火光中看她的那一眼，想起他染血的绷带，想起他刺出长枪时稳得可怕的手。

“他现在在哪儿？”她问。

“回东墙了。鞑子虽然撤了，但没走远，还得守着。”

林小满站起来，往东墙方向看。尘土散去，晨光洒在土墙上，墙头插满的箭矢像刺猬的刺。

“赵叔。”她突然说，“咱们得修墙。”

“修墙？”

“西墙缺口堵上了，但只是用石头堆的，不结实。东墙也损坏了。”林小满声音平静，但带着不容置疑的坚决，“鞑子还会来，下次不一定能守住。得把墙修结实，修高，修厚。”

老赵头看着她，点了点头。

“成。你说怎么修，咱们就怎么修。”

林小满望向远处。鞑子骑兵退到了地平线，像一片乌云。马匪的残兵往秃鹫山方向逃，很快消失在山坳里。

边关的早晨，血腥味还没散，但新的战斗，已经开始了。

她低头看了看包扎好的右手，握了握拳。

还能动。

那就继续干。
