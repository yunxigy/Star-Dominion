# 第五十五章 雪中暖意

清晨的雪，下得又急又密。

林小满是被冻醒的。她裹紧了身上那件旧棉袄，指尖碰到粗糙的布料时，心里泛起一丝暖意。这件棉袄是昨天傍晚周副将送来的，说是沈将军旧衣，边关苦寒，让她先穿着御寒。

棉袄里子是厚实的棉花，虽然旧了，但针脚细密，一看就是正经军用的。林小满把脸埋进衣领里，深深吸了口气——有股淡淡的皂角味，还有一丝说不清道不明的气息，像是松木混着铁锈，又像是雪后清冽的空气。

她想起昨天傍晚，周副将把棉袄递给她时说的话：“将军说了，边关的冬天不好过，姑娘身子单薄，别冻着了。”

当时她问：“沈将军自己呢？他还有棉袄穿吗？”

周副将笑了笑：“将军的旧衣多着呢，姑娘放心穿。”

林小满当时没多想，现在却觉得不对劲。她掀开被子坐起来，借着窗户纸透进来的微光打量这件棉袄——衣襟处有几道细密的补丁，针脚和原衣不同，显然是后补的。袖口磨损得厉害，但领口却很干净，像是被人特意浆洗过。

这真的是旧衣吗？

她摇摇头，把这念头甩开。管它呢，先暖和了再说。

院子里的雪已经积了半尺厚。林小满踩着雪走到屋檐下，看见昨天堆在墙角的几捆柴火上也盖了层白。她深吸一口气，冷空气钻进鼻腔，激得她打了个寒颤。

“得去堆肥场看看。”她自言自语。

昨天傍晚，赵虎带着两个士兵，把三个坑的发酵肥全运到了东边荒地。那二十亩地已经翻好、起垄，就等着上底肥了。堆肥发酵成功的标志很明显——颜色从原来的黄褐色变成了深褐色，还泛着灰白，凑近了能闻到一股土腥味，不臭，反而有种雨后泥土的清新。林小满用树枝扒开表层，看见里面长满了褐色的菌丝，像细密的蛛网一样铺满整个肥堆。

这是好事。菌丝越多，说明微生物活动越旺盛，堆肥腐熟得越彻底。

她当时高兴坏了，抓了一把发酵肥在手里搓，颗粒松软，一捏就散。赵虎在旁边看得直咧嘴：“林姑娘，你咋跟捡了金元宝似的？”

“这比金元宝金贵。”林小满笑着说，“有了这些肥料，明年开春种小麦，亩产能翻一倍不止。”

赵虎将信将疑：“真有这么神？”

“等着瞧吧。”

现在雪下得这么大，林小满担心堆肥场那边的肥堆被雪水泡坏。她回屋拿了把旧扫帚，决定先去扫雪。

刚推开院门，就看见门外站着个人。

是沈青石。

他穿着一身玄色棉甲，肩头落了层薄雪，手里拎着个油纸包。看见林小满出来，他愣了一下，随即把油纸包递过来：“肉包子，刚出锅的。”

林小满没接：“沈将军怎么来了？”

“巡营路过。”沈青石说得轻描淡写，但林小满注意到他睫毛上挂着霜，鼻尖冻得发红。巡营会巡到村西头来？她心里嘀咕，但没拆穿。

“给赵虎他们的？”她问。

沈青石点头：“昨天他们帮你运肥料，辛苦了。”

林小满接过油纸包，打开一看，里面是四个拳头大的肉包子，还冒着热气。面皮雪白，褶子捏得整齐，一看就是军营伙夫的手艺。她掰开一个，肉香混着葱香扑鼻而来，馅儿是实实在在的猪肉白菜，油汪汪的。

“真香。”她忍不住说。

沈青石嘴角动了动，没说话。林小满抬头看他，发现他正盯着自己手背看。她下意识把手缩到袖子里——昨天搬石头时磨破了皮，手背上有一道红痕，已经结了痂。

“手怎么了？”沈青石问。

“没事，搬石头蹭的。”

沈青石皱了皱眉，从怀里掏出个小瓷瓶：“军用伤药，抹上好得快。”

林小满看着那个白瓷瓶，瓶口用红布塞着，系着根细麻绳。她忽然想起昨天周副将送棉袄时，也是这个表情——欲言又止，好像藏着什么话没说。

“沈将军，”她忍不住问，“你为什么对我这么好？”

沈青石一怔，随即移开视线：“边关将士，互相照应是应该的。”

“可我不是将士。”林小满盯着他，“我是种地的。”

沈青石沉默了片刻。雪下得更大了，雪花落在他肩头，很快积成薄薄一层。他忽然伸手，拍掉她肩上的雪：“你种的地，能养活边关的兵。”

说完，他转身就走，棉甲下摆扫过积雪，发出沙沙的声响。

林小满站在原地，看着他的背影消失在雪幕里。她低头看看手里的肉包子，又看看那个小瓷瓶，心里像被什么东西塞满了，胀胀的，暖暖的。

她先去了堆肥场。

雪确实下得大，但好在肥堆都用草帘子盖着，没被雪水泡坏。林小满掀开草帘检查，发酵肥还是昨天的样子，深褐色，松软，有菌丝。她松了口气，把草帘重新盖好，又用石头压住边角。

然后她去了东边荒地。

二十亩地，一眼望不到头。垄沟整整齐齐，像棋盘格子一样铺开。雪覆盖在黑土上，白茫茫一片。林小满蹲下来，抓了一把土——土块冻得硬邦邦的，但一捏就碎，说明土壤结构不错。

她想起昨天赵虎问的话：“林姑娘，这地真能种出粮食来？”

“能。”她当时肯定地说。

现在她更确定了。堆肥成功，底肥充足，只要明年开春天气正常，春小麦亩产二石半绝对不是梦。边关现在平均亩产才一石，要是能翻一倍半，整个镇子的粮食问题都能缓解大半。

她正想着，忽然听见身后有脚步声。

回头一看，是赵虎，带着两个士兵，扛着铁锹。

“林姑娘！”赵虎大步走过来，脸冻得通红，“我们来帮你干活！”

林小满愣了：“今天下这么大的雪，你们不用巡营？”

“将军放了我们半天假。”赵虎咧嘴笑，“说是昨天帮姑娘运肥料辛苦了，让我们今天来帮忙干活。”

林小满心里一动。她想起沈青石刚才说的话——“互相照应是应该的”。原来他是这个意思。

“那正好。”她指着地头那几堆冻硬的土块，“帮我把这些土块敲碎，越碎越好。开春前要把底肥翻进土里，土块太大，肥力渗不进去。”

赵虎二话不说，抡起铁锹就干。两个士兵也跟着忙活起来。林小满没闲着，她用扫帚把地头的雪扫开，露出下面的黑土。雪水渗进土里，能让土壤更松软。

四个人干到中午，才把地头的土块敲完。林小满把肉包子分给他们，赵虎咬了一大口，含糊不清地说：“真香！将军对我们都没这么大方过！”

林小满笑：“将军对你们不好吗？”

“好是好，”赵虎咽下包子，“但将军自己都舍不得吃肉，全紧着我们。上次伙房炖了只鸡，将军一口没尝，全分给伤兵了。”

林小满沉默了。她想起沈青石那件旧棉袄，想起他冻红的鼻尖，想起他说“互相照应是应该的”时的表情。

他明明可以不管她。

为什么呢？

下午雪小了些，但天还是阴沉沉的。林小满回到自家院子，发现院门口多了捆柴火，码得整整齐齐，用麻绳捆着。她问邻居王大娘，王大娘说：“晌午看见个兵扛来的，说是将军吩咐的。”

林小满看着那捆柴，忽然觉得眼眶发热。

她进屋，把小瓷瓶里的药膏抹在手背上。药膏是淡黄色的，有股草药味，抹上去凉丝丝的，很快就不疼了。她看着手背上的红痕，想起沈青石皱眉的样子。

他为什么皱眉呢？

是因为心疼她受伤，还是只是觉得她干活太不小心？

林小满摇摇头，把这些乱七八糟的念头甩开。她走到窗边，看着外面纷飞的雪花，心里忽然冒出一个念头——

明年开春，她要种出最好的粮食。

不光是为了边关的将士，也为了那个给她送棉袄、送肉包子、送伤药、送柴火的男人。

她要让他知道，她林小满，不是只会添麻烦的。

窗外的雪，越下越大了。
