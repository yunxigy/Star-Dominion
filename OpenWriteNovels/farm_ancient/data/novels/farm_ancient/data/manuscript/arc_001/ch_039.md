# 暗流涌动

晨光刚爬上破旧的窗棂，林小满就醒了。

她侧身看向床头那个粗陶坛子，坛口用麻布扎得严实，里面是昨夜配好的菌种。坛身还带着微温，那是发酵产生的热量。她伸手摸了摸坛壁，心里盘算着今天要做的事。

院子里传来王大娘扫地的声音，竹帚划过地面的沙沙声，规律又踏实。

“小满，醒了吗？”王大娘在窗外问。

“醒了，大娘。”林小满起身，推开吱呀作响的木门。

王大娘正弯腰扫着院子，晨光给她花白的头发镀了层金边。她直起身，捶了捶腰，打量着林小满：“昨晚又熬到很晚？看你眼底都有青黑了。”

“配药水呢。”林小满走到井边，摇起辘轳打水。冰凉的井水扑在脸上，激得她一个哆嗦，脑子却清醒了。

“那些虫子真能治住？”王大娘走过来，压低声音，“昨晚孙老汉他们走后，我听着动静，镇东头又有人哭了，说是菜地全毁了，今年冬天可怎么过。”

林小满拧干布巾，擦了把脸：“能治住。今天我在镇北空地教堆肥，顺便把配药水的法子也教给大家。”

王大娘张了张嘴，想说什么，又咽了回去。半晌才道：“你小心些。我听说……周主事家的管事昨天在镇上转悠，问了好些人，问你平时都做些什么。”

林小满动作一顿，随即若无其事地舀水漱口：“问就问，我又没做见不得人的事。”

“我不是那个意思。”王大娘急了，“我是怕他们使绊子。你上次让官田增产，已经得罪人了。现在又要教大家配药水，这不是断人家财路吗？”

林小满吐掉漱口水，看着王大娘满是皱纹的脸，忽然笑了：“大娘，您说得对。可要是怕得罪人，这日子就不用过了。”

她转身回屋，从床底下拖出个木箱。箱子里是她这些日子攒下的“家当”——几包种子，几捆麻绳，还有那本从现代带来的农学院笔记本。她小心地翻开笔记本，找到记录堆肥技术的那几页。

纸页已经泛黄，边角卷起，上面是她用钢笔写的字，还画了些示意图。堆肥的原理很简单：碳氮比、温度控制、翻堆时机。但在这个时代，这些知识就是金子。

她合上笔记本，塞回箱底，又从墙角拎起那个菌种坛子。坛子不重，但抱着它走在路上，总觉得沉甸甸的。

辰时刚过，林小满就出了门。

镇北空地原本是堆放杂物的地方，荒草长得半人高。昨天她让几个半大孩子帮忙清理出一片，现在看起来平整多了。空地中央已经堆了些材料：秸秆、枯叶、畜粪，还有几筐从官田运来的土。

孙老汉带着几个老农早到了，正蹲在材料堆旁抽烟。见林小满来了，孙老汉磕了磕烟斗站起来：“林姑娘，都按你说的备好了。”

“辛苦孙伯了。”林小满把菌种坛子放在一旁，环视一圈，“其他人呢？”

“在路上呢。”孙老汉朝镇子方向努努嘴，“听说你要教堆肥，都来了。连周主事家的佃户都来了几个，远远站着看。”

林小满顺着他的目光看去，果然见空地边缘站着些人，交头接耳，眼神闪烁。她心里明镜似的，面上却不动声色：“来就来，学东西又不挑人。”

人渐渐多了起来。有面朝黄土背朝天的老农，有围着灶台转的妇人，甚至还有几个半大孩子，好奇地张望。空地上嗡嗡的，像开了锅的粥。

林小满清了清嗓子，声音不大，却让所有人都静了下来。

“今天教堆肥，是为了治虫害。”她开门见山，“虫子吃菜，是因为菜弱。菜弱，是因为地瘦。地瘦，就要施肥。可光施畜粪不够，得用堆肥。”

她走到材料堆前，抓起一把秸秆：“秸秆、枯叶，这些是‘骨’。畜粪、烂菜叶，这些是‘肉’。骨肉要按比例配，才能发酵好。”

她边说边动手，把秸秆铺开一层，再撒上畜粪，又撒层土。动作不快，让所有人都能看清。

“一层骨，一层肉，一层土，像这样堆起来。”她堆了半人高，“堆好后要浇水，不能太湿，也不能太干。攥在手里，指缝见水，又滴不下来，就正好。”

孙老汉凑近看了看：“这得堆多久？”

“看天气。现在这季节，十天半个月。”林小满从坛子里舀出一勺菌种，灰白色的，带着股酸味，“这是菌种，撒进去能加快发酵。没有也行，就是慢些。”

她把菌种均匀撒在堆肥上，又浇了些水。做完这些，她直起身，拍了拍手上的土：“堆好后，每三天翻一次。翻的时候里外对调，让发酵均匀。等堆肥变成黑褐色，没有臭味，捏起来松软，就能用了。”

人群里有人问：“这堆肥真能治虫？”

“治不了虫，但能让菜长得壮。”林小满看向声音来处，“菜壮了，虫子啃不动，自然就少了。就像人，身子骨结实，病就找不上门。”

她顿了顿，提高声音：“今天还教配药水。烟叶水、苦楝树皮水、石灰硫磺合剂，这三种都能杀虫。材料我昨天已经说过，孙伯他们也配过，效果你们都看见了。”

“可我们上哪儿弄烟叶去？”一个妇人喊道，“镇上就周主事家种了烟叶，金贵着呢。”

林小满早料到有这一出。她转身，从带来的包袱里取出几个布包，一一打开。

“这是烟叶，军营送的。”她指着第一个布包，“这是苦楝树皮，孙伯他们找的。这是生石灰，也是孙伯他们弄的。”

她把布包推到前面：“材料我分给大家，每家一份。够配一缸药水，够喷半亩地。今天我在这儿教配，学会了自己配，往后就不用求人了。”

人群一阵骚动。有人挤上前来，眼睛盯着那些材料，又看看林小满，欲言又止。

孙老汉咳了一声：“林姑娘，这……这太贵重了。烟叶在镇上能换半袋粮食，你就这么分了？”

“治虫要紧。”林小满语气平淡，“粮食没了还能种，地毁了就什么都没了。”

她开始讲解配药水的步骤。烟叶要撕碎，用开水泡一天一夜，滤出渣子，兑水喷洒。苦楝树皮要捣碎，煮水，也是滤渣兑水。石灰硫磺合剂麻烦些，要生石灰、硫磺粉、水按比例熬煮，火候很关键。

她讲得细致，边讲边演示。人群渐渐围拢过来，伸长脖子看，有人还掏出随身带的炭笔，在破布上记。

日头渐高，空地上热起来。林小满讲得口干舌燥，后背汗湿了一片。她停下来喝水，目光扫过人群，忽然定在一处。

空地边缘，一个穿着绸衫的中年男人正负手而立，身后跟着两个家丁。男人身材微胖，留着山羊胡，眼睛细长，正冷冷地看着这边。

周主事。

林小满心里一紧，面上却没露出来。她放下水碗，继续讲解。

“石灰硫磺合剂熬好后，要放凉才能用。喷的时候要喷叶子背面，虫子爱趴在那儿。”她拿起一个竹筒做的简易喷壶，示范动作，“像这样，均匀喷，别漏了。”

人群里发出恍然大悟的“哦”声。

周主事忽然动了。他拨开人群，慢悠悠地走到堆肥前，用脚尖踢了踢：“这就是你说的堆肥？”

“是。”林小满迎上他的目光。

周主事嗤笑一声：“一堆烂草烂粪，也能叫肥料？我种了三十年地，没见过这么糟蹋东西的。”

“您没见过，不代表没用。”林小满声音平静，“官田的麦子，就是用了堆肥才增产的。”

周主事脸色一沉。他盯着林小满，眼神像刀子：“林姑娘，你一个外乡人，来我们这儿指手画脚，是不是太不把本地人放在眼里了？”

“我教大家种地，怎么是指手画脚？”林小满反问。

“你教？”周主事提高声音，“你凭什么教？凭你那点不知道哪儿来的野路子？我告诉你，种地是祖宗传下的手艺，轮不到你一个黄毛丫头来教！”

人群静了下来，所有人都看着他们。孙老汉想上前说话，被旁边的人拉住了。

林小满没动。她看着周主事，忽然笑了：“周主事，您说得对，种地是祖宗传下的手艺。可祖宗也说过，‘不违农时’，‘因地制宜’。现在虫害成灾，地里没收成，您有什么好法子？”

周主事噎住了。

林小满继续道：“您要是有法子，尽管使出来，我立马闭嘴。您要是没法子，就别拦着别人学法子。大家伙儿都要吃饭，都要活命。”

人群里响起低低的附和声。

周主事脸色铁青。他指着林小满，手指发抖：“你、你……好，好得很！我倒要看看，你这堆烂草烂粪，能种出什么花来！”

说完，他一甩袖子，带着家丁走了。

人群松了口气，又嗡嗡地议论起来。

孙老汉凑过来，忧心忡忡：“林姑娘，你得罪他了。这人心眼小，睚眦必报。”

“不得罪他，他也容不下我。”林小满看着周主事离去的方向，“孙伯，您昨天说，周家佃户往官田运土？”

孙老汉点头：“是，好几车呢。我亲眼看见的，土里掺着些黑乎乎的东西，当时没在意，现在想想，怕就是虫卵。”

林小满沉默片刻，低声问：“沈将军那边，有消息吗？”

“还没。”孙老汉摇头，“不过沈将军既然说了会查，就一定会查。他是个说到做到的人。”

林小满“嗯”了一声，没再问。她重新面向人群，声音恢复了清亮：“咱们继续。刚才讲了配药水，现在讲堆肥的翻堆……”

她讲了整整一个时辰。日头升到头顶，晒得人发晕。人群渐渐散去，有的拿着分到的材料，有的还在问问题。林小满一一解答，直到最后一个人离开。

空地上只剩下她和孙老汉几个老农。

“林姑娘，你今天这番话，说到大家心坎里了。”孙老汉感慨，“可也把周主事得罪狠了。那人手黑，你得小心。”

“我知道。”林小满蹲下身，检查堆肥的湿度，“孙伯，麻烦您和几位老伯，这几天多盯着点。要是看见有人鬼鬼祟祟往堆肥这儿来，立马告诉我。”

“放心，我们几个老骨头，别的本事没有，看家护院还行。”孙老汉拍拍胸脯。

林小满笑了笑，收拾东西准备回去。她抱起菌种坛子，坛子比早上轻了些——用掉了不少。

走到镇口，她看见沈青石牵着马，站在老槐树下。

他穿着便服，没佩刀，脸上的疤在树荫下显得没那么狰狞。见林小满过来，他松开缰绳，迎上两步。

“教完了？”

“教完了。”林小满在他面前站定，“周主事来了。”

“我知道。”沈青石点头，“我的人看见了。他没为难你？”

“嘴上说了几句，没动手。”林小满把坛子换了个手抱着，“你那边呢？查得怎么样？”

沈青石压低声音：“官田西边那块地，确实挖出掺虫卵的土块。我的人暗中跟着周家佃户，看见他们从周家后门运出几车土，半夜倒在官田里。”

“证据确凿？”

“土块还在，虫卵也还在。”沈青石眼神冷了冷，“但光凭这个，还动不了周主事。他是朝廷派来的，有品级，得有确凿的证据，证明是他指使的。”

林小满皱眉：“那怎么办？”

“等。”沈青石说，“他今天来探你的底，说明他急了。人一急，就会犯错。”

“可虫害等不了。”林小满看向远处的农田，“菜一天天在毁，再拖下去，今年真要绝收了。”

沈青石沉默片刻，忽然道：“你今天教堆肥，是故意引他出来？”

林小满一愣，随即点头：“堆肥要用到畜粪、秸秆，这些东西周家都有。他要是想继续破坏，就得从这些材料下手。我公开教，他的人一定会来学，也会来盯梢。”

“你这是把自己当诱饵。”沈青石眉头皱紧。

“不入虎穴，焉得虎子。”林小满笑了笑，“放心，我有分寸。倒是你，军营那边没事吧？”

“烟叶的事，我报上去了。”沈青石说，“军需官查了账，说军营的烟叶储备确实少了些，但不算大事。我暂时没提周主事，怕打草惊蛇。”

两人并肩往回走。夕阳把他们的影子拉得很长，一高一矮，几乎重叠。

走到林小满家门口，沈青石停下脚步：“今晚我安排人手在镇北空地附近盯着。你……早点休息。”

“好。”林小满点头，看着他转身离开，忽然开口，“沈将军。”

沈青石回头。

“谢谢你的烟叶。”她说。

沈青石脸上似乎闪过一丝笑意，但太快，林小满没看清。他摆摆手，牵着马走了。

林小满站在门口，直到他的背影消失在街角，才推门进院。

王大娘正在灶房忙活，听见动静探出头来：“回来了？饿了吧，饭快好了。”

“不饿。”林小满把菌种坛子放回屋，又出来打水洗手，“大娘，今天周主事来了。”

王大娘手一抖，勺子碰在锅沿上，叮当响：“他、他没把你怎么样吧？”

“没有。”林小满擦干手，“但他肯定记恨上我了。大娘，这几天您也小心些，少出门，少跟人嚼舌根。”

王大娘连连点头，脸色发白。

夜里，林小满躺在床上，睡不着。

月光从破窗漏进来，在地上画出歪歪扭扭的格子。她睁着眼，听着窗外的虫鸣，脑子转个不停。

周主事为什么要破坏官田？就为了削减军营粮饷？可粮饷是朝廷拨的，官田收成好，军营能多分些，但也不至于让周主事铤而走险。

除非……他贪的不止是粮饷。

林小满忽然想起孙老汉说过，周主事家在镇外有几百亩地，种的都是好田。那些田，用水方便，土质肥沃，跟官田的贫瘠形成鲜明对比。

如果官田一直没收成，那些好田的租子，是不是就能收得更高？

她越想越觉得可能。边关苦寒，田地有限。官田要是废了，佃户们只能去租周家的地。到时候，周主事就能漫天要价。

“真是打的好算盘。”林小满低声骂了一句。

可光猜没用，得有证据。

她翻了个身，看向床头的菌种坛子。坛子在月光下泛着微光，像只沉默的眼睛。

明天，堆肥就开始发酵了。周主事的人，会不会来动手脚？

她闭上眼，强迫自己睡去。明天还有一场硬仗要打。

鸡叫三遍，天刚蒙蒙亮，林小满就起了床。

她没惊动王大娘，轻手轻脚地出门，往镇北空地去。

晨雾很重，打湿了她的头发和衣襟。空地上静悄悄的，堆肥堆在晨雾里，像座小山。她走近，蹲下身，伸手探了探堆肥的温度。

温热，发酵已经开始了。

她绕着堆肥走了一圈，没发现异常。正要离开，忽然看见堆肥旁边的地上，有几个浅浅的脚印。

脚印不大，像是半大孩子留下的。但脚印的方向，直指堆肥。

林小满心里一紧。她顺着脚印往外找，在空地边缘的草丛里，发现了一小撮被踩倒的草。

草叶上沾着些灰白色的粉末。

她用手指沾了一点，凑近闻了闻。没味道，但触感粗糙，像是……石灰？

她猛地想起昨天配的石灰硫磺合剂。合剂里就有生石灰。

如果有人把生石灰撒进堆肥，会怎么样？

生石灰遇水发热，会烧死堆肥里的菌种，让发酵失败。堆肥废了，她教的法子就成了笑话，大家就不会再信她。

林小满捏紧了那撮粉末，眼神冷了下来。

动作真快。

她站起身，四下看了看。晨雾里，远处似乎有个人影一闪而过。

她没追。追也追不上。

她转身，快步往回走。得去找沈青石。

走到半路，就看见沈青石牵着马，从另一条巷子出来。他看见林小满，脚步顿了顿，迎上来。

“我正要去找你。”沈青石说，“我的人昨晚盯了一夜，天亮前看见个半大孩子，鬼鬼祟祟往堆肥那边去，手里拿着个布包。”

“布包里是生石灰。”林小满摊开手，露出掌心的粉末，“我在堆肥边发现的。”

沈青石眼神一沉：“他得手了？”

“不知道。”林小满摇头，“我检查了堆肥，温度正常，应该还没撒进去。可能被你的惊动了，没来得及。”

沈青石松了口气，随即又皱眉：“这是警告。他知道我们在盯，所以派个孩子来，就算抓住了，也问不出什么。”

“他还会再出手。”林小满说。

“会。”沈青石点头，“但下一次，就不会这么容易了。”

两人对视一眼，都从对方眼里看到了同样的意思：得加快速度。

“证据收集得怎么样了？”林小满问。

“还在查。”沈青石说，“周家管事的嘴很紧，佃户们也怕他，不敢多说。不过……”他顿了顿，“我查到一件事。周主事上个月，往京城送了封信，用的是八百里加急。”

“八百里加急？”林小满吃惊，“边关往京城送信，一般用普通驿递，除非是紧急军情。他一个主事，有什么急事要八百里加急？”

“这就是蹊跷的地方。”沈青石眼神幽深，“信是送给户部侍郎赵大人的。赵大人，是周主事的同乡，也是他的靠山。”

林小满心里咯噔一下：“他想干什么？”

“不知道。”沈青石摇头，“但肯定不是小事。我已经托人往京城打听了，最快也要十天才能有消息。”

十天。

林小满看向远处的农田。十天，虫害能毁掉多少菜？周主事又能使出多少绊子？

“等不了那么久。”她说。

沈青石看着她：“你有主意？”

林小满沉默片刻，忽然道：“周主事最怕什么？”

“怕东窗事发。”沈青石答。

“不，他最怕的是官田丰收。”林小满眼睛亮起来，“官田丰收，军营粮饷充足，他就没法借机敛财。如果我能证明，堆肥不仅能治虫害，还能让产量翻倍呢？”

沈青石明白了：“你想逼他狗急跳墙？”

“对。”林小满点头，“他现在还在暗处使绊子，就是因为觉得还有转圜余地。如果官田眼看着要大丰收，他就坐不住了。人一急，就会犯错。”

“太危险。”沈青石不赞同，“他现在已经对你下手了。”

“可这是最快的办法。”林小满坚持，“沈将军，你帮我个忙。”

沈青石看着她，没说话。

“今天，我要在官田里做实验。”林小满说，“用堆肥和药水，治理一块地的虫害。你帮我找块虫害最严重的地，再派几个人，名义上是帮我干活，实际上是盯着周家的人。”

“你想引蛇出洞。”

“对。”林小满笑了，那笑容在晨光里，亮得晃眼，“我要让全镇的人都看见，我的法子有用。周主事要是还坐得住，他就不是周主事了。”

沈青石盯着她看了很久，最后叹了口气：“好。但你要答应我，一旦有危险，立刻撤。”

“我答应。”林小满点头。

两人分头行动。沈青石回军营调人，林小满回家拿工具和材料。

日上三竿时，官田西边那块虫害最严重的地里，已经围了不少人。

林小满站在地头，身后是沈青石派来的四个士兵，还有闻讯赶来的孙老汉几个老农。地里的菜叶上，菜青虫密密麻麻，看得人头皮发麻。

“就这块地了。”孙老汉指着菜叶，“虫子最多，叶子都快吃光了。”

林小满蹲下身，仔细看了看。虫子是二代虫，个头大，食量惊人。她站起身，对围观的人说：“今天，我在这块地做实验。左边用堆肥和药水，右边什么都不用。七天后，大家来看结果。”

人群一阵骚动。

“七天？能行吗？”

“虫子这么多，药水管用吗？”

林小满没回答。她指挥士兵开始干活：一半地翻土，施堆肥；另一半地保持原样。然后，她拿出配好的药水，开始喷洒。

药水是烟叶水和苦楝树皮水的混合，气味刺鼻。她喷得很仔细，每片叶子背面都不放过。

围观的人越来越多。有老农，有妇人，还有孩子。他们看着林小满的动作，眼神里有好奇，有怀疑，也有期待。

日头偏西时，实验地终于弄好了。左边地里，堆肥的土黑黝黝的，药水的味道还没散尽。右边地里，虫子依旧猖獗。

“七天后，同一时间，同一地点。”林小满对人群说，“大家来看结果。如果我的法子没用，我林小满立马收拾东西，离开边关。”

人群静了静，然后爆发出嗡嗡的议论声。

孙老汉凑过来，低声道：“林姑娘，你这赌注下得太大了。”

“不下大注，钓不上大鱼。”林小满擦了把汗，看向人群边缘。

那里，周主事家的管事正站在那儿，脸色阴沉地盯着这边。

林小满对他笑了笑。

管事一愣，随即冷哼一声，转身走了。

林小满收回目光，对沈青石派来的士兵说：“接下来几天，麻烦几位轮流盯着这块地。不准任何人靠近，尤其是晚上。”

“是。”士兵们抱拳。

林小满收拾东西，准备回去。走到田埂上，沈青石不知何时出现在她身后。

“你今天这番话，全镇都会传开。”他说。

“我要的就是这个效果。”林小满回头看他，“沈将军，你觉得周主事会怎么做？”

沈青石沉吟片刻：“他会先观望。如果七天后菜真的活了，他就会动手。要么毁地，要么毁你。”

“所以这七天，是关键。”林小满说，“堆肥和药水，我已经教给大家了。就算我出事，法子还在。”

沈青石眉头紧皱：“别说这种话。”

林小满笑了笑，没接话。她看着远处的夕阳，忽然道：“沈将军，你脸上的疤，是怎么来的？”

沈青石一愣，下意识摸了摸脸：“三年前，北狄人偷袭，我带队去堵口子，被箭擦的。”

“疼吗？”

“早就不疼了。”

林小满点点头，转身继续走：“七天后见。”

沈青石站在原地，看着她的背影消失在暮色里。他摸了摸脸上的疤，那道疤已经三年了，早就没了知觉。

可今天，它忽然有点痒。

像是要长出新肉来。
