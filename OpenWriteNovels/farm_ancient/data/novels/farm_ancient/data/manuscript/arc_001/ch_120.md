# 京中来人

第三声号角落下，沈青石已经翻身上马。

“林姑娘，回屋。”

“西墙外有火。”林小满指着镇北，“风从那边往粮仓吹，若只是营房起火，火星不会越过两道栅栏。”

沈青石回头看了一眼。夜色压得很低，西墙上方的火光被风扯成长条，几片亮红的灰烬越过墙头，落在军营后侧的草垛上。

他的判断只用了片刻。

“跟紧亲兵，到了水渠边就停。”

“我能看水。”

“这不是田。”

“所以才要看得更快。”

沈青石没有再争。他对亲兵道：“把她带到蓄水坑，若有失火，先保粮仓。”

亲兵领命，牵来一匹空马。林小满翻身上去，刚出巷口，便听见城墙方向传来喊杀声。镇门没有打开，军营里的士兵正沿着内道向西墙增援。

水渠从院后通向军营外的蓄水坑，原本只供田地灌溉。夜里看不清沟底，马蹄踏过几处碎石，水声在黑暗里断断续续。

到了蓄水坑，林小满跳下马。坑里的水只剩一半，入口处还堵着前日冲来的泥沙。她蹲下去摸了摸，手指很快沾满冷泥。

“水进不来。”她说，“上游的分水石被人动过。”

亲兵借着火光看去，果然有两块石头歪在沟边。那不是风能吹动的重量。

“有人从水渠进来过。”

“先别追。”林小满抓起木铲，“把石头移开，水能过来一半就够。”

亲兵带人搬石。上游的水终于冲下来，混着泥沙灌进蓄水坑。林小满沿着沟渠跑到军营后侧，发现草垛已经烧了两排，火舌正往粮仓的屋檐舔。

军汉们提桶往返，水却总落不到火根上。有人把水泼到屋顶，屋檐上的火被压低，草垛里的火星又从另一边冒出来。

“别往屋顶泼！”林小满喊，“先断草垛，把烧着的往外拖！”

一个军汉回头骂道：“你一个姑娘懂什么！”

“粮仓在下风口，屋顶塌了，火还会沿粮袋烧进去。先拖出一条空带，水桶只浇火根！”

亲兵认出她，喝道：“照她说的做！”

几名军汉用长钩挑开草垛。最外层的干草一被拖走，里面果然露出两只浸了火油的陶罐，罐口已经烧裂。

林小满喉咙发紧。若再慢一刻，火就会顺着油流到粮仓门口。

她指挥人把陶罐推入泥坑，又让两队人从水渠两边取水。水渠不宽，队伍不能并行，她便让一队取水、一队回程，隔着三步交替换手。水桶一只接一只递过去，终于压住了草垛根部的火。

城墙上的喊杀声忽高忽低。沈青石带人守在西墙缺口，火把在墙头来回移动。北狄骑兵没有攻城器械，只趁夜色靠近，点火、射箭，逼守军分散。几轮冲杀后，他们退到黑暗里，又从另一处露头。

这是试探。

可对粮仓来说，一次试探也够要命。

火势压下去时，周文安带着书吏赶到了。他没有穿官袍，外面套着一件短褂，手里提着从驿站借来的灯。

“粮仓保住了吗？”他问。

“东侧屋檐烧穿一角，粮袋还没动。”亲兵答。

周文安看向林小满：“是她指挥的？”

“她先看出了火路。”

周文安没有夸奖，只让书吏记下：“粮仓、草垛、水渠，分别记损失和用水。再去问军需官，若西墙失守，存粮还能撑多久。”

书吏领命跑开。

林小满听见这句话，回头看他：“大人现在还要看我的水渠？”

“现在看得最清楚。”周文安指了指满地的泥水，“白日里只能看它能不能浇田，夜里才知道它能不能救粮。”

远处忽然传来一阵密集的马蹄声。沈青石的亲兵抬头：“敌骑退了。”

火光照在周文安脸上，他沉思片刻，对书吏喊：“把西墙这一段也记上。不是大举进攻，是来探粮道和水路。”

这一夜没有人再提赏钱和功劳。

天亮时，西墙下留下十几枚断箭，粮仓外烧掉两排草垛，三名军汉受了伤。镇上的百姓没有大规模伤亡，水渠里的泥却被踩得一塌糊涂。

林小满蹲在渠边，把手伸进淤泥里。泥里有一片被火烤黑的木屑，木屑上还留着新削的刀痕。

有人提前看过这里。

沈青石走到她身边，肩甲上沾着灰，眉骨旁多了一道浅浅的擦伤。

“伤口要洗。”林小满说。

“不深。”

“泥水进了伤口，过两天就会肿。”

沈青石看了看她沾泥的手：“你自己也一样。”

两人都没有动。最后还是林小满先站起来，把袖口的泥拍掉：“试验地不能放在军营西边了。”

“我也这么想。”沈青石说，“那里离水近，却太靠外。”

周文安从粮仓方向走来，手里拿着一页刚写好的记录：“试验地先改到镇南。水渠要重新开一道分口，军营用水和农田用水分开。至于西边那块地，等巡哨稳定后再看。”

林小满接过纸。上面写着昨夜损失、取水路线和需要的木料，没有一句夸大的话。

“大人要把这些上报？”她问。

“要报。”

“把水车也写上？”

周文安看她：“写它救粮了吗？”

“昨夜没有用水车，只用了水渠。”

“那就不写水车。”他把纸收回去，“朝廷要看真实的法子。能救粮的写，尚未验证的等验证以后再写。”

林小满第一次觉得这个从京城来的官员没有那么远。他仍然要功绩，却愿意把功绩绑在结果上。

周文安又道：“十亩试验地照旧，只是换到镇南。银子按账支取，种子由你保管，收成由镇里和军营各派一人核验。”

“谁来核验？”

“王大娘可以算镇里的人。”

林小满愣了一下。周文安竟然记得她的邻居。

“她不识多少字。”

“会数鸡蛋，也会看谁家的手伸进了菜地。”周文安说，“账本再让钱进记一份，两边对照。”

林小满低头看那张纸，忽然明白了周文安为什么能在户部待这么多年。他未必可信，却知道怎么让一件事留下证据。

“可以。”她说。

周文安将纸递回给她：“那就从今天开始。至于昨夜的事，林姑娘也写一份。你看见了水路，我看见了粮仓，沈将军看见了敌人的路。三份记录放在一起，才不会漏掉关键处。”

沈青石在旁边看着他：“周大人倒不怕折子写得太长。”

“粮食和人命的事，长一点总比少一句强。”

周文安说完，转身去找军需官。

林小满目送他的背影走远，才低声道：“他不是来拿走所有东西的。”

“他是来挑能带走的。”沈青石说，“区别在于，这次他愿意先问清楚。”

林小满看着镇南的方向。那里有一片还没开垦的荒地，石头多，土薄，正适合把每一步都记下来。

“那就让他看真正的结果。”她说。

沈青石点头：“先把手上的伤洗了。”

“你先去洗。”

“我不疼。”

“我也不疼。”

两个人对视片刻，同时移开目光。

天光照进烧黑的草垛，余烟贴着地面慢慢散开。林小满回到院子，取出真正的种子记录，在新的一页写下：

“周文安到访。夜袭。水渠保住粮仓。试验地改至镇南。”

写完，她把笔搁下，抬头看向墙角。

那架水车还在，木叶片被晨风推得轻轻转动。

今天要修水渠，清点木料，重新丈量十亩地。西域胡麻刚露白，真正的试验才刚开始。
