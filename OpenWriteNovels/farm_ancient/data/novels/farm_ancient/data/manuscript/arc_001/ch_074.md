# 血色黎明

西墙的火光在夜色中摇曳，映照着林小满苍白的脸。她右手掌心的伤口还在渗血，木刺扎得很深，每动一下都钻心地疼。但她顾不上这些，眼睛死死盯着墙外百步外那些黑压压的骑兵。

“林娘子，油罐只剩半罐了。”一个满脸烟灰的镇民压低声音说。

林小满深吸一口气，强迫自己冷静下来。“破布和麻绳还有多少？”

“破布撕了衣服还剩些，麻绳不多了。”

她蹲下身，借着火光查看墙根下堆着的物资。两罐菜油用了大半，破布条缠在木棍上做成火把，麻绳编成套索陷阱。水缸已经被推到缺口处，里面装着最后半缸水。

墙外传来马匹的嘶鸣声，鞑子骑兵在重新集结。

“他们要发动第二波进攻了。”老赵头的声音从东墙方向传来，他带着一半人刚支援过去，现在又跑回来报信，“东墙那边箭矢快用完了，滚木礌石也只剩七八块。李铁匠带人在拆门板，但撑不了多久。”

林小满站起身，伤口撕裂般地疼。她咬紧牙关，目光扫过身边这些伤痕累累的镇民——不到二十人，个个带伤，手中的武器是削尖的木棍、生锈的柴刀，还有几张猎弓。

“所有人听好。”她的声音在夜风中显得格外清晰，“鞑子下一波进攻，会比刚才更猛。他们知道我们没多少油了，会直接冲缺口。”

一个年轻镇民颤声问：“那、那我们怎么办？”

林小满指向墙根下那半罐菜油：“把油全部用上。破布撕成条，浸油后绑在箭头上。我们只有二十支箭，但每支都要点着。”

她蹲下身，用没受伤的左手在地上画出简图：“套索陷阱还剩三个，都设在缺口正前方。鞑子冲进来时，会先踩中陷阱，马匹受惊会乱。这时候，第一排人射火箭，第二排人用长矛捅，第三排人准备石头砸。”

“可石头只剩十几块了。”有人提醒。

“那就用砖。”林小满指向残破的墙垣，“拆墙砖，每块都有三四斤重，砸下去照样要命。”

她转身看向老赵头：“赵叔，你带五个人去拆东墙的破房子，把房梁木料都搬过来。鞑子要是从东墙突破，我们就用木料堵路。”

老赵头点头要走，林小满又叫住他：“等等，把水缸里的水分一半出来。每人喝两口，剩下的留着灭火。”

命令一道道下达，镇民们开始行动。林小满走到缺口处，借着火光查看地形。缺口约有两丈宽，是上一波进攻时被鞑子用撞车撞塌的。缺口前地面坑洼，正好适合设陷阱。

她蹲下身，检查那三个套索陷阱。麻绳编成的活套埋在浅土下，连着削尖的木桩。只要马蹄踩进去，套索收紧，马匹就会摔倒，骑手会被甩出去。

“林娘子，箭矢准备好了。”一个老猎户递过二十支箭，箭头都绑了浸油的布条。

林小满接过一支，用火把点燃。火焰“腾”地窜起，照亮了她坚毅的脸。

“记住，”她对弓箭手们说，“等鞑子冲到三十步内再射。射完箭立刻后退，让长矛手上。石头手在最后，听我口令砸。”

墙外传来号角声。

鞑子要进攻了。

林小满举起燃烧的箭，火焰在她眼中跳动。她深吸一口气，声音穿透夜色：

“点火！”

二十支火箭同时点燃，火光映红了西墙。

马蹄声如雷，鞑子骑兵开始冲锋。

百步、八十步、六十步——

林小满盯着那些黑影，心跳如擂鼓。她右手的伤口在流血，混着汗水滴落在地。

四十步。

“稳住——”她低吼。

三十步。

“放箭！”

二十支火箭呼啸而出，在夜空中划出火线。最前面的鞑子骑兵中箭，火焰瞬间点燃了他们的皮袍。惨叫声响起，但后面的骑兵毫不减速，继续猛冲。

二十步。

鞑子冲到了缺口前。

“陷阱！”林小满大喊。

最前面的三匹马同时踩中套索，麻绳猛地收紧，马腿被绊住。三匹战马轰然倒地，骑手被甩出丈远。后面的骑兵收势不及，撞在一起，人仰马翻。

“长矛手，上！”

十几个镇民冲上前，用削尖的木棍狠狠捅向落马的鞑子。惨叫声、怒骂声、兵器碰撞声混成一片。

但鞑子太多了。

后续的骑兵跳过倒地的同伴，继续涌入缺口。他们挥舞着弯刀，砍向镇民。一个年轻镇民被劈中肩膀，惨叫着倒下。

“石头！砸！”

林小满抓起一块墙砖，狠狠砸向一个鞑子骑兵的脸。砖块碎裂，那鞑子鼻梁塌陷，栽下马背。

镇民们纷纷效仿，砖块、石头雨点般砸下。但鞑子前赴后继，缺口处混战成一团。

“火油！”林小满喊道。

两个镇民抬着最后半罐菜油冲上来，将油泼向缺口处的人堆。林小满将手中的火把扔过去。

“轰——”

火焰腾起，缺口处变成一片火海。鞑子骑兵的皮袍、马匹的鬃毛瞬间被点燃，惨叫声撕心裂肺。

火光中，林小满看到一个鞑子头目骑着黑马，挥刀砍翻两个镇民，朝她冲来。

她抓起地上的长矛——那是从鞑子尸体上捡的——双手握紧，矛尖对准来敌。

黑马冲到近前，鞑子头目的弯刀劈下。

林小满侧身躲过，长矛刺出，扎进马腹。战马哀鸣倒地，将骑手甩出。那鞑子头目刚爬起身，就被三个镇民用木棍围住，乱棍打死。

缺口处的火焰渐渐熄灭，留下十几具鞑子尸体。剩下的鞑子骑兵开始后退，在百步外重新集结。

林小满喘着粗气，汗水混着血水从额头流下。她清点人数——又倒下了三个镇民，能站着的只剩十五人，个个带伤。

“林娘子，东墙告急！”老赵头浑身是血地跑来，“鞑子在撞门，木料快撑不住了！”

林小满看向西墙外那些重新集结的鞑子骑兵，又看向东墙方向。她知道，西墙这边暂时守住了，但鞑子随时可能发动第三波进攻。

“分兵。”她咬牙道，“赵叔，你带五个人去东墙。剩下的，跟我守西墙。”

“可你这边人太少了——”

“够了。”林小满捡起一把鞑子弯刀，刀刃上还滴着血，“鞑子刚才吃了亏，下一波会更谨慎。我们有时间准备。”

她指向墙根下那些鞑子尸体：“把他们的皮甲扒下来，能穿的穿上。弯刀、箭矢，全都收起来。还有，检查马匹，受伤不重的牵到后面。”

镇民们开始行动。林小满走到缺口处，蹲下身查看地形。火焰烧焦了土地，鞑子尸体横七竖八。她注意到，缺口左侧的墙根处，土壤特别松软。

一个念头闪过脑海。

“挖坑。”她突然说。

“什么？”

“在这里挖坑。”林小满比划着，“挖三尺深，一丈宽。坑底插削尖的木桩，上面用木板盖住，铺层薄土。”

一个镇民眼睛一亮：“陷阱！”

“对。”林小满站起身，“鞑子吃过亏，下一波会绕开套索陷阱，从侧面冲。我们在这里挖坑，让他们再栽一次。”

镇民们立刻动手，用鞑子的弯刀、用木棍、用手刨土。林小满也加入其中，右手的伤口被泥土糊住，疼得她直抽气，但她没停。

半个时辰后，坑挖好了。三尺深，坑底插满削尖的木桩。他们用拆下来的门板盖住坑口，铺上薄土，伪装得和周围地面一样。

“火油呢？”林小满问。

“没了，真的一滴都没了。”

林小满看向那些鞑子尸体：“马油呢？把马尸里的脂肪刮出来，熬油。”

镇民们愣住了，但很快明白过来。他们开始处理马尸，用弯刀刮取脂肪，在废铁锅里熬煮。腥臭味弥漫开来，但没人抱怨。

熬出的马油装在破瓦罐里，虽然只有小半罐，但足够用了。

“浸布条。”林小满指挥，“做成火把，插在坑边。鞑子掉进坑里，我们就点火扔下去。”

一切准备就绪时，东墙方向传来震天的撞门声。

鞑子对东墙发动了猛攻。

林小满看向西墙外——鞑子骑兵还在集结，但数量比之前更多了。远处尘土飞扬，显然援军到了。

“林娘子，”一个年轻镇民颤声说，“他们、他们人太多了……”

林小满握紧手中的弯刀，刀柄被汗水浸湿。她抬头看向东方，天际已经泛起鱼肚白。

黎明要来了。

“听着，”她的声音很轻，但每个人都听得清清楚楚，“天亮前，鞑子一定会发动总攻。他们不想让我们看到援军有多少，不想让我们知道东墙那边有多危急。”

她环视这些伤痕累累的镇民：“但我们守住了西墙，守了一整夜。鞑子没讨到便宜，他们怕了。所以他们才会调集更多人，才会这么急。”

一个老镇民哑着嗓子问：“那我们还能守住吗？”

林小满没有直接回答。她走到缺口处，捡起一块染血的墙砖，举起来让所有人都看见。

“这块砖，”她说，“是咱们镇的墙砖。一百多年前，咱们的祖辈用它砌起了这堵墙，挡住了鞑子。一百多年后，咱们用它砸碎了鞑子的脑壳。”

她将砖块重重砸在地上，碎成几块。

“墙会倒，砖会碎，但人不会垮。”林小满的声音陡然提高，“鞑子有马有刀，咱们有命有胆！今天就算死，也要拉几个垫背的！”

镇民们的眼睛亮了。恐惧还在，但某种更坚硬的东西从心底涌上来。

“对！死也要拉垫背的！”

“跟他们拼了！”

林小满举起弯刀：“准备迎敌——”

话音未落，西墙外响起震天的号角声。

鞑子总攻开始了。

黑压压的骑兵如潮水般涌来，马蹄声震得地面都在颤抖。这一次，他们没有分散冲锋，而是集中兵力，直扑缺口。

“稳住！”林小满吼道。

鞑子冲到五十步时，火箭射出。但这次鞑子学乖了，前排骑兵举着缴获的木板盾牌，箭矢大多被挡开。

三十步。

二十步。

前面的骑兵突然减速，显然记得套索陷阱的位置。他们绕向缺口左侧——正对着新挖的深坑。

“就是现在！”林小满大喊。

十几个鞑子骑兵冲上坑口，木板断裂，人马惨叫着跌入深坑。坑底的木桩刺穿马腹，骑手被甩出，摔在尖桩上。

后续的骑兵收势不及，又掉进去几个。坑里顿时堆满人马尸体，惨不忍睹。

“火把！扔！”

点燃的火把扔进坑里，马油遇火轰然燃烧。坑里变成一片火海，鞑子的惨叫声撕心裂肺。

但后面的骑兵跳过火坑，继续冲来。

“长矛手！顶上去！”

镇民们用缴获的鞑子长矛，结成简陋的阵型，堵在缺口处。刀矛相交，火星四溅。

林小满挥舞弯刀，砍翻一个冲进来的鞑子。另一个鞑子从侧面扑来，她躲闪不及，被撞倒在地。

弯刀脱手。

那鞑子狞笑着举刀劈下。

林小满抓起地上的碎砖，狠狠砸向他的眼睛。鞑子惨叫一声，刀势偏了，砍在她左肩上。

剧痛传来。

林小满咬紧牙关，用尽全身力气将鞑子推开，捡起弯刀，反手捅进他的腹部。

温热的血喷了她一脸。

她挣扎着爬起身，环顾四周——缺口处已成修罗场。镇民和鞑子混战在一起，不断有人倒下。

东墙方向，撞门声越来越响。

“轰——”

一声巨响，东墙的门被撞开了。

鞑子的欢呼声传来。

西墙的鞑子骑兵也发出兴奋的吼叫，攻势更猛。

林小满知道，完了。

东墙破了，鞑子会从两面夹击。他们这点人，守不住了。

但她没退。

她捡起另一把弯刀，双手各持一刀，站在缺口正中。

“来啊！”她吼道，声音嘶哑，“鞑子狗！你姑奶奶在这儿！”

一个鞑子骑兵冲来，她双刀交叉，架住劈下的弯刀。火星四溅，她被震得后退两步，肩上的伤口迸出血来。

但她没倒。

她反手一刀，砍断马腿，战马哀鸣倒地。另一刀捅进骑手的咽喉。

更多的鞑子涌上来。

林小满杀红了眼。她不知道自己砍了多少人，不知道身上添了多少伤口。她只知道不能退，退一步，身后的镇民就会被屠杀。

突然，东墙方向传来异样的声音。

不是鞑子的欢呼，而是——惊叫？

林小满百忙中瞥了一眼，只见东墙门口冲进来的鞑子骑兵，突然人仰马翻。地面塌陷，露出一个巨大的陷坑。

陷坑里插满了削尖的木桩，鞑子人马掉进去，当场毙命。

“这是……”林小满愣住了。

她没在东墙挖陷阱啊。

就在这时，东墙城头响起一个熟悉的声音：

“放箭！”

箭矢如雨，从东墙城头射向涌入的鞑子。箭法精准，箭箭致命。

林小满抬头，看见东墙城头站着一个高大的身影。

那人穿着破旧的皮甲，脸上有一道狰狞的疤，手中握着一张硬弓。

沈青石。

他回来了。

沈青石连发三箭，射倒三个鞑子骑兵，然后扔下弓，拔出腰刀，从城头一跃而下，落入鞑子群中。

刀光闪过，血花飞溅。

他身后，十几个穿着边军皮甲的士兵跟着跳下，杀入敌阵。

西墙的鞑子骑兵见状，攻势一顿。

林小满抓住机会，大吼：“援军到了！杀啊！”

镇民们士气大振，拼死反扑。

沈青石带人从东墙杀穿过来，与西墙守军汇合。他浑身浴血，脸上那道疤在火光下更显狰狞，但眼睛亮得吓人。

“撑住！”他吼道，声音盖过战场喧嚣。

边军士兵训练有素，很快稳住阵脚。他们用盾牌结成防线，长矛从盾牌缝隙刺出，将鞑子骑兵挡在缺口外。

沈青石杀到林小满身边，一刀砍翻偷袭她的鞑子。

“你受伤了。”他皱眉看着她肩上的伤口。

“死不了。”林小满喘着气，“你怎么回来了？不是在百里外……”

“收到烽火信号，连夜赶回。”沈青石简短地说，眼睛却盯着她流血的手，“手也伤了？”

“木刺扎的，小事。”

沈青石没再问，转身面对缺口外的鞑子。他举起染血的腰刀，声音传遍战场：

“边军听令！守住缺口，一个鞑子都不许放进来！”

“是！”

边军齐声应和，声震四野。

鞑子骑兵在缺口外徘徊，几次试探都被打退。天边渐渐发白，黎明终于来了。

当第一缕阳光照上城墙时，鞑子吹响了撤退的号角。

他们退了。

黑压压的骑兵如潮水般退去，留下满地尸体。

西墙上，幸存的镇民和士兵瘫坐在地，大口喘气。

林小满靠在残破的墙垣上，肩上的伤口还在流血。她看着鞑子退去的方向，又看向身边浑身浴血的沈青石。

“你怎么知道东墙有陷阱？”她问。

沈青石擦去脸上的血：“我在路上抓了个鞑子探子，逼问出来的。他们计划先破东墙，我就带人提前赶回，在东墙门口挖了坑。”

他顿了顿，看向林小满：“倒是你，西墙就这点人，怎么守了一夜？”

林小满扯了扯嘴角，想笑，却牵动了伤口，疼得直抽气。

“靠……靠这个。”她举起右手，掌心那个木刺伤口已经血肉模糊，“还有……靠命。”

沈青石看着她血肉模糊的手，又看向缺口处那些鞑子尸体，眼神复杂。

“你就不怕死？”他问。

林小满靠在墙上，看着东方渐亮的天空。

“怕啊，”她轻声说，“但更怕……怕守不住，怕镇子里的人被杀光。”

她转过头，看向沈青石：“你呢？你连夜赶回来，就不怕是陷阱？不怕鞑子埋伏？”

沈青石沉默片刻。

“怕，”他承认，“但更怕……怕回来晚了。”

两人对视一眼，都没再说话。

晨光照亮城墙，照着满地血污，照着这些劫后余生的人。

远处传来哭声——有人在找亲人，有人在收殓尸体。

林小满撑着墙站起来，腿一软，差点摔倒。沈青石伸手扶住她。

“先包扎伤口。”他说。

林小满点头，任由他扶着走下城墙。她回头看了眼缺口，那些鞑子尸体在晨光下显得格外狰狞。

但她知道，这只是开始。

鞑子退了，但还会再来。

而她，还有他们，必须活下去。

必须守住这堵墙。

守住这个家。
