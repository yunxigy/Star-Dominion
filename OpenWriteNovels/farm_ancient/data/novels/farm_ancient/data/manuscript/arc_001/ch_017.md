# 第17章

# 第十七章 土里的学问

天刚蒙蒙亮，林小满就醒了。

左肩的伤口在夜里隐隐作痛，像有根针扎在肉里。她坐起身，轻轻活动了几下肩膀，疼得倒抽一口冷气。昨天沈青石借来的那头黄牛正拴在院角的老槐树下，低头嚼着草料，两个兵卒裹着军毯睡在柴房门口。

她推开门，晨风带着凉意扑在脸上。

院子里已经堆好了昨天挖来的河底淤泥，黑褐色的泥块散发着淡淡的腥气。林小满蹲下身，用手捻开一块泥，指腹能感觉到细腻的颗粒感——这是好料，比她预想的还要肥。

“姑娘，这么早就起了？”

王大娘端着一盆热粥从隔壁过来，看见林小满蹲在泥堆前，忙放下盆子，“你这伤还没好利索，可别累着。”

“没事，活动活动反而舒服些。”林小满站起身，接过粥碗，“大娘，今天要麻烦您帮我看着点那两个兵卒，他们翻地的时候，我得盯着土层。”

王大娘点头：“放心，我让柱子也过来帮忙。对了，昨天统计的孩子名单我带来了，一共七个，都是六到十岁的。”

她从怀里掏出一张皱巴巴的纸，上面歪歪扭扭写着七个名字。

林小满接过来看了看：“等播种的事忙完，我就开始筹备学堂。纸笔沈将军已经送来了，够用一阵子。”

“姑娘真是咱们镇子的福星。”王大娘感慨道，“以前谁想过能在这种地方种出粮食来？现在好了，连将军都亲自派人来帮忙。”

林小满没接话，低头喝粥。

她心里清楚，沈青石这么支持她，不仅仅是因为她会种地。边军屯田的事一直是个难题，北境苦寒，将士们吃的粮食大半要从内地运，路途遥远损耗大。要是能就地解决一部分粮食问题，对边防的意义不言而喻。

吃过早饭，两个兵卒已经醒了。

他们一个叫赵大牛，一个叫李铁柱，都是二十出头的年纪，皮肤黝黑，手上全是老茧。看见林小满出来，两人立刻站直身子。

“林姑娘，今天怎么安排？”赵大牛问。

林小满指着屋后那片荒地：“先翻那五亩试验田。黄牛拉犁，你们扶着犁头，深度要一尺左右，不能太浅。”

“一尺？”李铁柱挠挠头，“姑娘，这地硬得跟石头似的，一尺怕是翻不动。”

“所以要先浇水。”林小满早就料到这一点，“昨天挖的引水沟正好用上，先引水泡地两个时辰，等土软了再翻。”

她带着两人来到荒地边。

这片地比她想象的还要荒凉，地面龟裂成一块块硬壳，脚踩上去咔咔作响。远处几棵枯死的胡杨歪斜着，枝干上连片叶子都没有。

林小满蹲下身，用随身带的木棍戳了戳地面，只留下一个浅浅的白印。

“碱性太重。”她皱眉。

王大娘跟过来：“姑娘，这地以前也有人试过种东西，种子下去不出苗，就算出了苗也活不过十天。”

“那是因为他们没改良土壤。”林小满站起身，拍了拍手上的土，“草木灰带碱性，但少量使用能中和土壤里的酸性物质。河底淤泥肥力足，能改善土质结构。两者配合，再加上合理的灌溉，就能种出东西来。”

她说得头头是道，王大娘听得半懂不懂，但看林小满一脸笃定，也就不再多问。

引水沟是昨天挖好的，从村东头的小河一直延伸到荒地边。林小满让赵大牛把沟口挖开，河水顺着沟渠缓缓流进来，慢慢渗进干硬的土地里。

“两个时辰后开始翻地。”林小满看了看日头，“你们先歇着，我去准备草木灰。”

她转身往村里走。

昨天她已经让柱子收集了镇上好几户人家的灶灰，堆在村口的老槐树下。这会儿柱子正蹲在灰堆边，用破麻袋装灰，看见林小满过来，连忙站起身。

“姐，灰够了吗？”

“够了，先拉三车过去。”林小满看了看灰堆，“剩下的留着，后面还要用。”

柱子点头，赶着借来的牛车开始运灰。

林小满站在村口，看着远处连绵的荒地，心里盘算着接下来的计划。五亩试验田分成四块，分别用不同的配比：一块纯淤泥，一块纯草木灰，一块混合，一块什么都不加作对照。这样十天后就能看出哪种方法最有效。

正想着，身后传来马蹄声。

她回头，看见沈青石骑着那匹黑马，带着两个亲兵从镇子方向过来。他今天没穿铠甲，一身青色布衣，脸上的疤痕在晨光里显得格外清晰。

“伤好些了？”他勒住马，目光落在林小满左肩。

林小满下意识摸了摸肩膀：“还行，不影响干活。”

沈青石皱眉，翻身下马：“孙草医说你这伤至少要养半个月，这才第三天。”

“地不等人。”林小满说，“再过半个月，就错过播种期了。”

沈青石没说话，走到荒地边看了看。河水已经渗进土里，地面颜色深了一块，但依然硬邦邦的。

“这地能种出东西？”他问。

“能。”林小满肯定地说，“给我一个月时间，我让它长出庄稼来。”

沈青石转头看她，眼神里带着审视。这个女人说话总是这么笃定，明明看起来弱不禁风，骨子里却硬得很。

“需要什么尽管开口。”他说，“边军屯田的事，我交给你了。”

林小满点头：“今天下午开始翻地，您借的黄牛和兵卒正好用上。”

“不够我再调人。”

“够了，五亩地用不了太多人。”

两人正说着，柱子赶着牛车过来了，车上堆着黑乎乎的草木灰。沈青石看了一眼，没多问，翻身上马。

“我下午再过来。”他说完，带着亲兵往镇子方向去了。

林小满看着他的背影消失在晨雾里，转身对柱子说：“把灰卸在地头，等土泡软了再撒。”

柱子应声，开始卸灰。

两个时辰后，荒地终于泡软了。

林小满赤脚踩进泥里，脚底能感觉到湿软的土层。她拿起木棍插进去，轻松插了一尺深。

“可以翻了。”她对赵大牛和李铁柱说。

黄牛被牵过来，套上犁头。赵大牛在前面牵牛，李铁柱扶犁，开始翻地。犁头切进土里，翻起一道道黑色的泥浪，带着河泥的腥气和湿气。

林小满跟在后面，不时蹲下身检查翻起的土层。

“再深一点。”她喊道，“至少一尺二。”

李铁柱调整犁头，牛走得慢了，但翻起的土层明显更深。林小满抓起一把土，在手里捻了捻，土块松散，能看见细小的根须——这是以前植物留下的。

“好土。”她轻声说。

王大娘端着水碗过来：“姑娘，喝口水歇歇。”

林小满接过碗，喝了几口，眼睛却一直盯着翻地的进度。五亩地，按这个速度，今天能翻完三亩，明天再翻两亩。

“大娘，草木灰准备好了吗？”

“准备好了，柱子在那边看着呢。”

林小满点头，走到地头。草木灰已经装在麻袋里，堆成小山。她让柱子打开一袋，抓出一把灰，撒在刚翻过的土上。

“均匀撒，一亩地两百斤左右。”她示范着，“不能太多，太多了碱性太强，烧苗。”

柱子学着她的样子开始撒灰。

林小满又检查了淤泥的情况。昨天运来的淤泥已经晒得半干，她让人把泥块敲碎，和草木灰混合在一起。

“这样混合撒，效果更好。”她对王大娘解释，“淤泥保水，草木灰中和碱性，两者配合，土质改良得更快。”

王大娘似懂非懂地点头。

下午，沈青石果然又来了。

他换了一身轻甲，带着五个兵卒，还拉来一车农具——锄头、铁锹、木耙，都是新的。

“这些先用着。”他说，“不够再去军械库拿。”

林小满看着那车农具，眼睛亮了。她正愁工具不够，这些来得正是时候。

“谢谢沈将军。”

沈青石摆手：“别客气，你把地种好，就是帮边军大忙。”

他走到翻过的地边，蹲下身抓起一把土。土里混着草木灰和淤泥，颜色深浅不一。

“这是在改良土壤？”他问。

林小满点头：“这片地碱性太重，不改良种不出东西。草木灰能中和碱性，淤泥能增肥，两者配合，土质会慢慢变好。”

沈青石若有所思：“北境这样的荒地很多，要是都能改良……”

“一步步来。”林小满说，“先做出样板，让大家看见效果，再推广不迟。”

沈青石站起身，拍了拍手上的土：“你说得对。”

他看着林小满，这个女人比他想象的还要懂农事。她说的那些话，听起来简单，但细想都有道理。边军屯田这么多年，一直没起色，就是因为没人懂这些。

“林姑娘。”他忽然开口，“你愿不愿意正式接管边军屯田？”

林小满一愣：“接管？”

“对。”沈青石说，“我任命你为农事顾问，专门负责屯田事宜。需要什么资源，直接找我。”

林小满看着他，心里飞快地盘算。接管屯田，意味着她能调动更多资源，推广农业技术会更方便。但同时，责任也更重了。

“我能行吗？”她问。

“你能。”沈青石肯定地说，“我看过你种的菜，比别人快一倍。这片荒地，你说能种出东西，我就信。”

林小满深吸一口气：“好，我接。”

沈青石点头：“明天我让军需官来找你，需要什么种子、农具，列个单子。”

“种子我有想法。”林小满说，“本地种子退化严重，我想试试改良。能不能从内地调一些新种子来？”

“可以。”沈青石说，“下个月有一批军粮要运来，我让押运官顺便带些种子。”

“太好了。”林小满眼睛发亮，“有了新种子，改良计划就能提前。”

两人正说着，赵大牛跑过来：“林姑娘，地翻完了，三亩。”

林小满回过神，看了看天色。太阳已经西斜，天边泛起红霞。

“今天先到这儿。”她说，“明天继续翻剩下的两亩，然后开始播种。”

沈青石看了看翻好的地，黑褐色的泥土在夕阳下泛着油光。他很难想象，一个月后这里会长出庄稼。

“需要多久能看见结果？”他问。

“十天出苗，一个月能看出长势。”林小满说，“如果顺利，秋天就能收第一茬。”

沈青石点头：“好，我等着看。”

他带着兵卒离开，林小满站在地头，看着翻好的土地。晚风吹过，带着泥土的腥气和草木灰的涩味。

王大娘走过来：“姑娘，回去吃饭吧，今天累坏了。”

林小满摇头：“再等等，我得把播种的计划写下来。”

她找来一块平整的木板，用炭笔在上面画图。五亩地分成四块，每块种不同的作物：一块种黍米，一块种豆子，一块种蔬菜，一块种她带来的那些种子。

“对照实验。”她喃喃自语，“这样就能看出哪种方法最有效。”

王大娘看不懂她在画什么，但看林小满一脸认真，也不打扰，转身去准备晚饭。

夜幕降临，林小满还在地头忙碌。

她点起火把，检查白天撒的草木灰和淤泥混合得是否均匀。有些地方撒多了，她用木耙摊开；有些地方撒少了，她又补上一些。

柱子蹲在旁边帮忙，小声问：“姐，真能种出来吗？”

“能。”林小满肯定地说，“只要按我说的做，一定能。”

柱子点头，继续干活。

月亮升起来，银色的光洒在翻过的土地上。林小满直起腰，左肩的伤口又开始疼了。她按了按肩膀，深吸一口气。

“明天还有硬仗要打。”她对自己说。

第二天，天还没亮，林小满就醒了。

她推开窗，看见院子里已经有人在干活。赵大牛和李铁柱正在整理农具，柱子在喂黄牛，王大娘在灶台边忙活。

“姑娘，粥好了。”王大娘喊道。

林小满匆匆洗漱，喝了碗粥，就往地里赶。

剩下的两亩地，今天必须翻完。她计划下午开始播种，时间很紧。

到了地头，赵大牛已经套好犁头，李铁柱在检查引水沟。昨天泡过的地今天更软了，脚踩进去能陷到脚踝。

“开始吧。”林小满说。

黄牛拉着犁头，慢慢往前走。犁头切进土里，翻起一道道泥浪。林小满跟在后面，不时调整犁头的深度。

“再深一点。”她喊道，“一尺二，不能浅了。”

李铁柱调整犁头，牛走得更慢了，但翻起的土层明显更深。林小满抓起一把土，在手里捻了捻，土块松散，能看见细小的颗粒。

“好。”她点头。

翻地进行到中午，剩下的两亩终于翻完了。五亩地全部翻好，黑褐色的泥土在阳光下泛着油光。

林小满让人把草木灰和淤泥混合物均匀撒上，然后用木耙把土块打碎，整平。

“下午播种。”她看了看天色，“先种黍米和豆子，蔬菜和试验田明天再说。”

柱子拿来种子，是林小满前几天准备好的。黍米种子是本地的，颗粒小，颜色暗；豆子种子也是本地的，干瘪，有些已经发霉。

“这些种子不行。”林小满皱眉，“发芽率太低。”

王大娘凑过来看：“姑娘，咱们这儿的种子都是这样的，能发芽就不错了。”

“不行，得改良。”林小满说，“我昨天跟沈将军说了，下个月从内地调新种子来。现在先用这些，但要筛选。”

她让人找来几个大木盆，把种子倒进去，加水浸泡。

“浮起来的都是瘪的，不要。”她示范着，“沉下去的才是好种子。”

柱子和王大娘学着她的样子开始筛选。一盆种子，能用的不到一半。

“就这么点？”柱子心疼地说。

“够了。”林小满说，“五亩地用不了太多种子。先种下去，等新种子来了再补种。”

筛选完种子，林小满开始教播种。

她用木棍在翻好的地上划出一条条浅沟，沟深两寸，行距一尺。

“种子撒进去，盖上土，轻轻压实。”她示范着，“不能太深，太深出不来；不能太浅，太浅被鸟吃。”

柱子和王大娘学着她的样子开始播种。黍米种一块，豆子种一块，另外两块留着种蔬菜和试验田。

播种进行到傍晚，五亩地终于种完了。

林小满站在地头，看着整齐的田垄，心里松了口气。第一步总算迈出去了。

“接下来就是浇水。”她说，“引水沟要一直开着，保持土壤湿润。但不能积水，积水会烂根。”

王大娘点头：“我让柱子每天来盯着。”

“好。”林小满说，“还有，鸟会来吃种子，得想办法防鸟。”

她想了想，让人找来一些破布条，绑在木棍上，插在田边。风吹过，布条飘动，能吓唬鸟。

“先这样，不行再想别的办法。”

忙完这些，天已经黑了。

林小满拖着疲惫的身体回到家，左肩的伤口疼得厉害。她解开衣服，看见伤口周围又红又肿，有些地方还渗出血水。

“得换药了。”她喃喃自语。

正要找药，门外传来敲门声。

“林姑娘，是我。”是沈青石的声音。

林小满一愣，赶紧整理好衣服，过去开门。

沈青石站在门外，手里拿着一个小瓷瓶。

“孙草医让我给你的。”他说，“说是新配的药膏，对刀伤特别有效。”

林小满接过瓷瓶，打开闻了闻，一股草药味冲鼻。

“谢谢。”她说。

沈青石看了看她，欲言又止。

“怎么了？”林小满问。

“今天……”沈青石顿了顿，“有人跟我说，你种地的方法，跟咱们这儿的不太一样。”

林小满心里一紧，面上不动声色：“哪里不一样？”

“他们说，你翻地太深，撒的灰太多，种子筛选太仔细。”沈青石说，“这些做法，他们没见过。”

林小满松了口气，还以为是什么大事。

“这是我娘教的。”她说，“我娘是南方人，那边的种法跟北境不一样。”

沈青石点头：“原来如此。”

他没再多问，转身要走。走到门口，又停下脚步。

“林姑娘。”他说，“不管你的方法从哪儿来，只要能种出粮食，我就支持你。”

林小满看着他，心里一暖。

“我会的。”她说。

沈青石点点头，消失在夜色里。

林小满关上门，靠在门板上，长长地舒了口气。今天总算过去了，明天开始，才是真正的考验。

她走到桌边，摊开那张画着田垄图的木板，开始写种植日记。

“第一天，翻地五亩，撒草木灰和淤泥混合物，播种黍米和豆子。预计十天出苗，一个月观察长势。”

写完，她吹熄油灯，躺在床上。

左肩的伤口还在疼，但她心里却踏实了许多。不管怎么说，第一步迈出去了，接下来就是等待和观察。

她闭上眼睛，脑子里却还在转着明天的计划。蔬菜田要翻，试验田要整理，学堂的事也要开始筹备……

迷迷糊糊间，她听见窗外传来鸟叫声。

天亮了。

新的一天开始了。
