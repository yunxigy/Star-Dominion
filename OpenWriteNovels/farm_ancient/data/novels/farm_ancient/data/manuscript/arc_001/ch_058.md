# 春耕之后

雪化了三天，日头终于舍得露脸。

林小满蹲在地头，手背上的冻疮裂口被阳光晒得发痒。她搓了搓手，掌心粗糙得像老树皮。沈青石给的药膏确实管用，裂口已经收拢，只留下几道红印子。

“这耧车比我想的还沉。”赵虎擦了把汗，把那个木制的播种机往地上一放，“林姑娘，这玩意儿真能比人手撒种快？”

林小满站起来，拍了拍膝盖上的土：“快不快，试了才知道。”

她走到耧车旁边，这东西是她画了图，找镇上木匠老刘做的。三个漏斗排成一排，底下有铁制的耧脚，后面跟着覆土的刮板。看着简陋，但原理和现代播种机差不多。

“来，我演示一遍。”林小满把小麦种子倒进漏斗，“推的时候要匀速，不能太快也不能太慢。太快种子撒不匀，太慢会堆在一块儿。”

她推着耧车往前走，铁耧脚划开刚翻过的土地，种子顺着管道滑进土里。走了十几步，她停下来，蹲下去扒开土层。

“看，种子间距差不多一掌宽，深度两指。”她指着土里的种子，“这样出苗后不会挤在一起，通风透光都好。”

赵虎凑过来看：“嘿，还真是。老法子撒种，一亩地得撒三四十斤种子，这耧车能省多少？”

“二十斤足够。”林小满站起来，“省种子是一方面，更重要的是出苗齐整。苗齐了，后期管理方便，产量自然上去。”

沈青石站在田埂上，没穿铠甲，一身深灰色棉袍。他脸上那道斜疤在阳光下泛着淡粉色，眼神却很专注。

“一亩能省十来斤种子。”他开口，声音低沉，“二十亩地，就是两百斤。这数字不小。”

林小满点头：“边关种子金贵，能省一点是一点。而且选种的事，我还没说完。”

她从怀里掏出两个布袋，一个鼓鼓囊囊，一个只有半袋。

“这袋是普通种子，”她举起鼓的那袋，“这袋是我挑过的。”她晃了晃半袋的，“挑颗粒大、饱满、无虫眼的，单独存放。去年试过，挑过的种子一亩能多收半石。”

赵虎瞪大眼睛：“半石？那二十亩就是十石！”

“不止。”林小满说，“今年我打算在二十亩地里分四块种。五亩纯小麦，五亩小麦套种芥菜，五亩萝卜，五亩土豆。”

沈青石皱眉：“为什么分开种？”

“防风险。”林小满蹲下来，用树枝在地上画，“边关天气说变就变。要是小麦抽穗时来场冰雹，五亩就全完了。但萝卜土豆不怕冰雹，还能保收成。芥菜生长期短，小麦收了还能再种一茬晚豆。”

她抬起头：“这样算下来，二十亩地，最差的情况也能收四十石粮食。好的话，八十石也有可能。”

沈青石沉默片刻：“八十石够五百将士吃多久？”

“一个月。”林小满说，“如果再种一茬晚豆，多出二十石豆子，能顶半个月。加上军营原来的存粮，撑到夏收没问题。”

“夏收之后呢？”沈青石问，“开春后北边部落肯定要南下抢粮。我们种地，他们来抢，怎么办？”

林小满站起来，拍了拍手上的土：“所以得抢时间。春耕早一天，夏收就早一天。粮食进仓，心里才不慌。”

她看向沈青石：“将军，你担心的不是粮食够不够吃，是粮食够不够打仗，对吧？”

沈青石没说话，但眼神已经回答了。

“打仗要粮草先行，这个我懂。”林小满说，“但边关的情况，不能等粮草充足了再打。我们得一边种一边防，种出来的粮食，一半吃，一半存，存的那部分就是军粮。”

赵虎插嘴：“可要是鞑子来得太快，地里的庄稼还没熟……”

“那就提前收。”林小满打断他，“没熟的麦子也能吃，磨成粉做饼子，顶饿。萝卜土豆更简单，挖出来就能存。我们种地，不是为了好看，是为了活下去。”

沈青石看着她，眼神复杂。这个女人，说起种地头头是道，说起打仗也不含糊。她手上的冻疮还没好利索，可眼里那股劲儿，比边关的风还硬。

“行。”他终于开口，“春耕的事你说了算。需要人手，从军营调。需要东西，列个单子给我。”

林小满笑了，露出一口白牙：“那我就不客气了。首先，得再打二十把锄头，十把铁锹。翻地的人手不够，光靠我们几个，二十亩地得翻到明年。”

“明天就让铁匠铺开工。”沈青石说，“还要什么？”

“粪肥。”林小满说，“镇上的茅厕、马厩、猪圈，所有能沤肥的地方，都得收集起来。边关地薄，不施肥根本长不出东西。”

赵虎咧嘴：“这活儿可够臭的。”

“臭是臭，但肥田。”林小满认真地说，“一亩地至少要施二十担肥，二十亩就是四百担。得组织人专门收肥、沤肥、运肥。这事我来安排，将军您帮着协调镇上的人就行。”

沈青石点头：“没问题。”

太阳已经升到头顶，晒得人后背发烫。林小满抹了把汗，看着眼前这片刚播下种子的土地。二十亩，说大不大，说小不小。这是边关的希望，也是她的战场。

“今天先这样。”她说，“明天开始，分组干活。一组翻地，一组运肥，一组播种。赵虎，你带两个人负责翻地，深度一掌半，不能浅了。”

“一掌半？”赵虎比划了一下，“那得使大劲儿。”

“使劲儿也得翻。”林小满说，“边关的土地板结，不深翻，种子扎不下根。翻完之后要耙两遍，把土块打碎，不然影响出苗。”

她转向沈青石：“将军，您今天有空的话，能不能带人把东边那五亩地先翻出来？那块地向阳，适合种芥菜，我想早点种下去。”

沈青石看了她一眼，没说话，转身往军营方向走去。赵虎小声说：“林姑娘，将军这是答应了还是没答应啊？”

林小满笑了笑：“他要是不答应，早就说‘不行’了。”

果然，半个时辰后，沈青石带着二十个士兵来了。每个人手里都拿着锄头，沉默地走到东边那块地，开始翻土。

林小满看着那些士兵，动作生疏但卖力。他们平时拿刀枪的手，现在握着锄头，一锄一锄地刨着土地。阳光照在他们汗湿的背上，反射出光亮。

“将军带兵，真是有一套。”她对赵虎说。

赵虎嘿嘿笑：“那是。将军说了，种地也是练兵。手上有劲儿，打仗时才能挥得动刀。”

沈青石走到林小满身边，递给她一个水囊：“喝点水。”

林小满接过，喝了一口，是温的。她愣了一下，看向沈青石。

“军医说冻疮不能喝凉水。”沈青石说完，转身走了。

林小满握着水囊，心里有点暖。这个男人，话不多，但事事都记在心里。

下午的时候，镇上陆续来了人。王大娘带着几个妇人，拎着篮子，里面是蒸好的杂粮饼子。

“林姑娘，听说你们在种地，老婆子们来送点吃的。”王大娘笑着说，“吃饱了才有力气干活。”

林小满赶紧迎上去：“大娘，您太客气了。”

“客气啥。”王大娘压低声音，“姑娘，我跟你说，镇上好些人都在看呢。有人说你瞎折腾，有人说你能成事。老婆子我信你，你种的菜，比别人家的都好。”

林小满心里一热：“大娘，您放心，我一定把地种好。”

王大娘拍拍她的手：“好，好。需要帮忙就说，老婆子别的不行，收粪沤肥还是会的。”

林小满眼睛一亮：“大娘，您真愿意帮忙？”

“愿意。”王大娘说，“不就是臭点嘛，捂住鼻子干就行。姑娘你教教我们，怎么沤肥最快。”

林小满立刻来了精神，拉着王大娘到一边，细细说起来。沤肥要分层，底下铺秸秆，上面盖粪肥，再撒一层草木灰，最后用泥封住。发酵半个月，翻一次，再发酵一个月就能用。

“关键是温度。”林小满说，“现在天还冷，得用草帘子盖住保温。等开春暖和了，就能快不少。”

王大娘听得认真，连连点头：“姑娘懂得真多。老婆子活了五十年，头回听说种地还有这么多讲究。”

“讲究多着呢。”林小满笑着说，“等夏天，我教您做堆肥，用烂菜叶、草根、畜粪一起沤，肥力更足。”

两人正说着，一个尖利的声音插进来：“哟，这不是咱们边关的大能人嘛，又在教人种地呢？”

林小满转头，看见一个穿着绸缎袍子的中年男人，摇着扇子走过来。是镇上的粮商，姓钱，人称钱扒皮。

钱扒皮走到地头，看了看正在翻地的士兵，又看了看林小满，阴阳怪气地说：“林姑娘好本事啊，连将军的兵都使唤得动。这地种出来，是归你呢，还是归将军呢？”

林小满脸色不变：“钱老板有话直说。”

“直说？”钱扒皮冷笑，“我就是好奇，你一个外来户，凭什么占这么大块地？这地以前可是荒地，但荒地也是官地，你跟官府报备了吗？”

赵虎走过来，瞪着眼睛：“钱扒皮，你少在这儿阴阳怪气。这地是将军批给林姑娘种的，有文书为证。”

“文书？”钱扒皮摇着扇子，“文书我看看？”

沈青石的声音从后面传来：“钱老板想看文书，去军营看。”

钱扒皮脸色一变，转身看见沈青石站在不远处，眼神冷得像冰。他干笑两声：“沈将军说笑了，我就是随便问问。种地是好事，好事。”

他说着，往后退了几步，转身溜了。

王大娘呸了一口：“这个钱扒皮，专干缺德事。去年粮价飞涨，他囤积居奇，害得好些人家吃不上饭。”

林小满看着钱扒皮的背影，眼神沉了沉。这种人，见不得别人好，以后肯定还会找麻烦。

沈青石走过来：“别理他。地的事，我担着。”

林小满点头：“我知道。但粮食种出来，总要卖一部分。他要是从中作梗……”

“他不敢。”沈青石说，“边关的粮食，优先供应军营。剩下的，按市价卖给镇民。谁敢抬价，军法处置。”

林小满松了口气：“有将军这句话，我就放心了。”

太阳西斜的时候，二十亩地已经翻完了一半。士兵们收工回营，林小满蹲在地头，看着新翻的土地，黑黝黝的，带着泥土的腥气。

沈青石还没走，站在她旁边。

“今天多谢将军。”林小满说，“要不是您带人来，光靠我们几个，得翻好几天。”

“分内之事。”沈青石说，“将士们吃饱了，才有力气守边关。”

林小满抬头看他：“将军，您觉得，这地真能种出粮食吗？”

沈青石看着远处的山，那里还覆着残雪，但山脚下的土地已经露出了本色。

“不知道。”他说，“但总得试试。边关苦寒，年年缺粮，朝廷的粮饷十次有八次迟发。不自己想办法，难道等着饿死？”

林小满笑了：“将军这话，说到我心坎里了。”

她站起来，伸了个懒腰：“明天开始沤肥。将军，您能不能让军营的马厩、猪圈，都把粪肥攒着？我派人去收。”

“可以。”沈青石说，“还有伙房的泔水，也能沤肥。”

“对！”林小满眼睛发亮，“我怎么没想到。泔水里有油水，沤出来的肥更肥。将军，您真是……”

她话没说完，沈青石突然转身：“走了。”

林小满愣住，看着他大步离开的背影，有点摸不着头脑。刚才不是聊得好好的吗？

赵虎凑过来，小声说：“林姑娘，将军这是害羞了。”

“害羞？”林小满更懵了，“为啥害羞？”

“您刚才夸他，他不好意思了。”赵虎嘿嘿笑，“将军脸皮薄，您别当面夸，他受不了。”

林小满哭笑不得：“我夸他啥了？我就说他想到泔水沤肥……”

“那就是夸。”赵虎认真地说，“将军平时不怎么说话，您突然夸他，他肯定不自在。”

林小满摇摇头，不再多想。她蹲下来，抓起一把土，在手里捏了捏。土质松软，湿度适中，正是播种的好时候。

“明天，”她对赵虎说，“把剩下的地翻完，后天开始运肥。大娘那边已经组织人手收粪了，我们得准备好地方沤肥。”

“地方我看了，”赵虎说，“地头东边有个洼地，围起来正好沤肥。就是离水源有点远，浇水不方便。”

林小满想了想：“挖条小渠，从河边引水过来。这事让老刘带人干，他木工好，做水渠的闸门没问题。”

“行。”赵虎记下，“还有啥？”

“种子。”林小满说，“我挑的那些种子，得单独存放，不能受潮。你找个干燥的屋子，铺上草席，把种子摊开晾着。每天翻一遍，防止发霉。”

赵虎一一记下。两人又商量了些细节，直到天快黑了，才收工回镇。

林小满回到自己的小屋，点上油灯，摊开本子，把今天的进度和明天的计划写下来。手背上的冻疮又开始痒了，她抹了点药膏，继续写。

窗外，月亮升起来了，清冷的光洒在院子里。远处传来军营的号角声，悠长而苍凉。

林小满停下笔，看着窗外的月亮。边关的夜晚，总是这么安静，安静得能听见风声。

她想起沈青石的话：“总得试试。”

是啊，总得试试。不试，怎么知道行不行？

她吹灭油灯，躺在床上，闭上眼睛。明天，还有很多事要做。

沤肥、翻地、播种、挖渠……每一件，都不能马虎。

边关的春天，才刚刚开始。
