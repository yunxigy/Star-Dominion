# 第六十一章 大旱之兆

林小满蹲在地头，手指插进土里，脸色越来越难看。

土是干的。

不是那种春耕时湿润的干，而是从里到外、结成硬块的干。她使劲往下挖了挖，指甲缝里全是灰白色的土粉，一点潮气都没有。

“不对劲。”她喃喃自语，抬头望向天空。

六月的边关本该是雨季，可这半个月来，天上连一片像样的云都没飘过。日头毒得能把人晒脱层皮，风一吹，地里的土就扬起来，呛得人直咳嗽。

王大娘端着碗水走过来，见她这副模样，叹了口气：“小满，别挖了，喝口水歇歇。”

林小满接过碗，没喝，反而问：“大娘，往年这时候，是不是该下大雨了？”

“可不是嘛。”王大娘抹了把额头的汗，“往年这时候，雨下得勤，河里的水都能漫到田埂边。可你看今年——”她指了指远处干裂的河道，“河底都露出来了，石头晒得发白。”

林小满心里一沉。

她是农学硕士，对气候敏感。边关地处西北，本就干旱，但往年六月总有几场透雨，勉强够庄稼生长。可今年这架势……

她站起身，环顾四周。

她开垦的这片地，因为用了深翻晾晒、秸秆还田的法子，土壤比别家的松软，保水性也好些。但再好的土壤，也扛不住持续干旱。地里的土豆苗已经开始打蔫，叶子边缘发黄卷曲。小麦更是惨，抽穗期遇上这种天，减产是板上钉钉的事。

“得想办法。”林小满咬了咬牙。

她转身往家走，脑子里飞快地转着。

灌溉系统她早就设计好了，引的是上游山泉水。可今年山泉水也明显少了，细细的一股，勉强够镇上人吃喝，根本不够浇地。

打井？边关地下水位深，打一口井要费老大劲，而且不一定能打出水。

储水？现在挖蓄水池已经来不及了，等挖好，庄稼早旱死了。

林小满越想越焦躁，推开院门时，差点撞上一个人。

“沈将军？”

沈青石站在院子里，一身便装，手里拎着个布包。见她回来，眉头微皱：“你去地里了？”

“嗯。”林小满点点头，顾不上寒暄，直接说，“将军，今年旱得厉害，地里的庄稼快撑不住了。”

沈青石脸色凝重：“我知道。军营里的水井水位也降了，再这么下去，别说浇地，人喝的水都成问题。”

两人对视一眼，都从对方眼里看到了担忧。

沈青石把手里的布包递过来：“这是军医配的防暑药，你拿着，天热别中暑了。”

林小满接过，心里一暖，但眼下实在没心思道谢。她急切地说：“将军，我有个想法，但需要人手，也需要一些东西。”

“你说。”

“我想试试滴灌。”

“滴灌？”沈青石没听过这词。

林小满比划着解释：“就是用竹管或者陶管，把水一滴一滴送到庄稼根部。这样既省水，又能保证庄稼喝到水。”

沈青石眼睛一亮：“这法子好！但……竹管陶管从哪儿来？镇上没那么多匠人。”

“不用那么精细。”林小满说，“我看过古书，古人用埋了破瓦罐的土法子也能凑合。咱们可以挖沟，铺上碎石和秸秆，让水慢慢渗下去。或者……”她顿了顿，“用羊肠。”

“羊肠？”

“对，羊肠洗干净，灌上水，埋在地里，水会慢慢渗出来。”林小满越说越觉得可行，“边关羊多，羊肠不值钱。咱们可以发动镇上的人，家家户户收集羊肠，我来教他们怎么弄。”

沈青石沉吟片刻：“这法子听着不难，但工程量不小。镇上几百户人家，地加起来几千亩，光靠你一个人教，得教到什么时候？”

“所以我需要帮手。”林小满看着他，“将军能不能派些兵来帮忙？不用多，二三十人就行，主要是帮忙挖沟、铺管。剩下的，我自己来教镇上的人。”

沈青石没立刻答应，反而问：“你有几成把握？”

林小满老实说：“没试过，不敢打包票。但总比眼睁睁看着庄稼旱死强。”

沈青石盯着她看了几秒，忽然笑了：“行，我给你三十人。明天一早，让他们去你地里集合。”

林小满松了口气：“多谢将军！”

“先别谢。”沈青石说，“这法子要是管用，算你功劳。要是不管用……”他故意顿了顿，“你得请我吃顿好的。”

林小满一愣，随即也笑了：“行！要是不管用，我把我存的那点腊肉全炖了，请将军吃！”

沈青石摇摇头：“腊肉太柴，我要吃你种的土豆炖鸡。”

“没问题！”

两人又商量了些细节，沈青石才离开。他走后，林小满立刻行动起来。

她找出之前记农事的本子，开始画图。滴灌系统的核心是“少食多餐”，把水精准送到根部。边关条件有限，只能土法上马。

羊肠管是最简单的方案。把羊肠洗净，用盐和草木灰反复搓洗去腥，晾干后就成了天然的“软管”。一头扎紧，另一头接上水源，水就会慢慢渗出来。

但羊肠管怕晒，埋在土里又容易腐烂，撑不了多久。所以得配合沟渠，把羊肠管铺在沟底，上面盖上碎石和土，既防晒又延长寿命。

林小满画了一夜，天亮时终于把图纸画完。她揉了揉酸涩的眼睛，出门打了盆冷水洗了把脸，清醒了些。

刚擦干脸，院门被敲响了。

“林姑娘，在家吗？”是赵铁匠的声音。

林小满打开门，赵铁匠站在门外，一脸愁容。他身后还跟着几个人，都是镇上的农户。

“赵叔，怎么了？”

赵铁匠叹了口气：“林姑娘，我们是来求你帮忙的。你看这天，再不下雨，地里的庄稼全得完蛋。我们听说你有法子，能不能……教教我们？”

林小满心里一酸。这些农户，靠天吃饭，一年到头就指着这点收成。要是旱灾真来了，日子就难过了。

“赵叔，你们来得正好。”林小满把他们让进院子，“我正要去找你们呢。我有个土法子，能省水，要不要听听？”

农户们立刻围上来，眼睛里全是期盼。

林小满把滴灌的原理讲了一遍，又拿出图纸给他们看。农户们听得似懂非懂，但“省水”两个字他们听懂了。

“林姑娘，这法子真管用？”一个老农问。

“管不管用，得试了才知道。”林小满实话实说，“但总比干等着强。你们要是愿意，今天就开始准备材料。羊肠、碎石、秸秆，能收集多少是多少。明天一早，将军会派兵来帮忙挖沟。”

“将军也帮忙？”农户们更惊讶了。

“对。”林小满点头，“咱们一起想办法，总能扛过去。”

农户们互相看看，眼里有了光。赵铁匠一拍大腿：“行！我们这就回去准备！林姑娘，你说怎么弄，我们就怎么弄！”

送走农户们，林小满长舒一口气。第一步迈出去了，接下来就是硬仗。

她回到屋里，拿出沈青石给的防暑药，倒出一粒吞下。药丸苦得她直皱眉，但脑子确实清醒了些。

这时，院门又被敲响了。

林小满以为是农户还有问题，打开门一看，却愣住了。

门外站着一个锦衣华服的中年男人，身后跟着两个小厮。男人手里摇着折扇，一脸嫌弃地打量着林小满的院子。

“你就是林小满？”男人开口，语气倨傲。

林小满皱眉：“你是……”

“我是赵员外府上的管事，姓钱。”男人说，“员外让我来传个话。”

林小满心里咯噔一下。赵员外，就是之前逼她交押金、涨地租的那个地主。她当时靠沈青石借的十两银子才渡过难关，但心里一直记着这笔账。

“钱管事请说。”林小满语气平淡。

钱管事清了清嗓子：“员外说了，今年旱情严重，地租得再涨一成。另外，你那片地，员外看上了，想收回去。”

林小满脸色一变：“地租不是说好三成吗？怎么又要涨？”

“旱情严重，员外也没办法。”钱管事耸耸肩，“至于收地，员外觉得你种地的法子不错，想收回去自己种。你放心，员外不会亏待你，会给你一笔补偿。”

林小满气得手发抖。赵员外这是趁火打劫！旱情一来，他就想吞并土地，还要涨租子，简直是吃人不吐骨头。

“地我不卖，租子也不会涨。”林小满一字一句地说，“钱管事请回吧。”

钱管事脸色一沉：“林姑娘，我劝你想清楚。员外可不是好说话的人。你要是不识抬举，别怪我们不客气。”

“怎么个不客气法？”一个冷硬的声音从身后传来。

林小满回头，看见沈青石大步走来，脸色阴沉得能滴出水。他身后跟着两个亲兵，手按刀柄，眼神锐利。

钱管事脸色一变，显然认得沈青石，语气立刻软了：“沈、沈将军……小的只是传话……”

“回去告诉赵员外。”沈青石走到林小满身边，站定，“边关军民一体，抗旱是头等大事。谁要是这时候捣乱，别怪军法无情。”

钱管事额头冒汗，连连点头：“是是是，小的一定带到。”说完，带着小厮灰溜溜地跑了。

林小满松了口气，转头看向沈青石：“多谢将军。”

沈青石脸色依旧不好看：“赵员外越来越放肆了。你放心，有我在，他不敢动你。”

林小满点点头，心里却沉甸甸的。赵员外不会善罢甘休，旱情又迫在眉睫，真是屋漏偏逢连夜雨。

沈青石看出她的心思，说：“别想太多，先解决眼前的旱情。人我已经安排好了，明天一早准到。你图纸画好了吗？”

“画好了。”林小满回屋拿出图纸递给他。

沈青石仔细看了看，指着一处问：“这里为什么要挖深些？”

“这里是低洼处，容易积水。挖深些，铺上碎石，能起到蓄水的作用。”林小满解释，“水先存在这里，再慢慢渗到地里，比直接浇更省水。”

沈青石点点头：“你考虑得周全。还有什么需要我帮忙的？”

林小满想了想：“将军能不能帮忙收集羊肠？军营里羊肠应该不少。”

“这个容易。”沈青石说，“我让伙房把羊肠都留着，洗干净给你送过来。”

“太好了！”林小满眼睛一亮，“还有，我需要一些陶罐，不用太好，有裂缝的也行。用来做简易的滴灌头。”

“陶罐……”沈青石沉吟，“镇上瓦窑应该有破损的，我去问问。”

“那就麻烦将军了。”

两人又商量了一会儿，沈青石才离开。他走后，林小满立刻开始准备。

她先去地里查看情况。土豆苗蔫得更厉害了，叶子耷拉着，有的已经开始枯黄。小麦穗子干瘪，一看就是灌浆不足。

林小满心疼得直抽气。这些庄稼，是她和镇上农户们几个月的心血，要是就这么旱死了，她不甘心。

她蹲下来，仔细检查土壤。表层已经干透，但往下挖一尺，还有点潮气。这说明地下水还没完全枯竭，滴灌还有希望。

回到家，她开始处理羊肠。军营送来的羊肠又多又新鲜，她烧了一大锅热水，把羊肠放进去烫，然后刮去油脂，用盐和草木灰反复搓洗。

洗羊肠是个脏活累活，腥臭味熏得人直反胃。林小满干了一下午，洗了上百根羊肠，手都搓红了，指甲缝里全是黑泥。

王大娘过来帮忙，一边洗一边叹气：“小满啊，你这姑娘，咋这么能折腾呢？这羊肠子洗得，比伺候月子还仔细。”

林小满苦笑：“大娘，这可是救命的东西，马虎不得。”

“我知道，我知道。”王大娘说，“我就是心疼你。你看你这手，都裂口子了。”

林小满低头看看自己的手，确实，洗羊肠洗得皮肤发红，有些地方裂开了小口子，一碰就疼。

“没事，抹点药膏就好了。”她想起沈青石给的药膏，回去抹了些，凉丝丝的，舒服多了。

晚上，她又画了会儿图，把滴灌系统的细节又完善了些。快睡着时，忽然想起一件事——沈青石说土豆七月底能收，可现在才六月中旬，要是旱情持续到七月底，土豆能不能撑住？

她心里没底，翻来覆去睡不着，索性爬起来，提着油灯去了地里。

月光下，土豆苗影影绰绰，叶子在夜风里微微晃动。林小满蹲下来，摸了摸土，还是干。

她叹了口气，正要离开，忽然看见地头有个黑影。

“谁？”她厉声问。

黑影动了动，传来一个熟悉的声音：“是我。”

林小满松了口气：“将军？你怎么在这儿？”

沈青石从阴影里走出来，月光照在他脸上，那道疤痕显得格外清晰。他手里拎着个水囊，递过来：“睡不着，过来看看。你呢？”

“我也睡不着。”林小满接过水囊，喝了一口，是凉茶，“担心庄稼撑不住。”

沈青石走到她身边，看着地里的土豆苗：“我问过老农，这种旱情，边关十年能遇上一次。上一次是十二年前，饿死了不少人。”

林小满心里一紧：“那这次……”

“这次有你。”沈青石转头看她，眼神在月光下显得格外亮，“你的滴灌法子，要是管用，能救很多人。”

林小满被他看得有些不自在，低下头：“我也不知道能不能管用……”

“管不管用，总得试。”沈青石说，“明天开始，我陪你一起弄。军营那边，我交给副将盯着。”

林小满惊讶地抬头：“将军亲自来？”

“嗯。”沈青石点头，“旱情是大事，我不能只在军营里等消息。再说……”他顿了顿，“我也想学学你的法子。”

林小满心里一暖，点点头：“好。”

两人在地头站了一会儿，谁也没说话。夜风吹过，带来一丝凉意，也带来远处隐约的狼嚎。

“回去吧。”沈青石说，“明天还有硬仗要打。”

林小满嗯了一声，跟着他往回走。走到村口时，沈青石忽然停下脚步。

“林小满。”

“嗯？”

“不管结果如何，你已经尽力了。”沈青石声音低沉，“边关百姓会记得你的。”

林小满鼻子一酸，差点掉下眼泪。她深吸一口气，把情绪压下去，说：“将军也是。有你在，边关百姓才能安心种地。”

沈青石笑了笑，没再说什么，转身走进了夜色里。

林小满看着他的背影，心里忽然踏实了些。不管旱情多严重，不管赵员外怎么捣乱，至少她不是一个人。

她握紧拳头，转身回家。

明天，就是背水一战的时候了。
