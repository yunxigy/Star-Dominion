# 豆种试验

林小满蹲在自家地头，手指捏着一颗豆子，对着西斜的日头仔细端详。

豆子颗粒饱满，表皮泛着健康的淡黄色光泽，捏在手里沉甸甸的。这是赵老四给的那包豆种里的一颗。

“发芽率、抗病性、耐寒程度……”她嘴里念念有词，手指无意识地在泥地上划拉着，“还得做个对比试验。”

沈青石站在她身后几步远的地方，抱臂看着她。夕阳把她的影子拉得很长，落在刚翻过的黑土上。

“你说什么试验？”他开口问。

林小满回过神，转头看他。沈青石今天没穿盔甲，一身灰布短打，袖子挽到小臂，露出结实的肌肉线条。脸上的疤痕在夕阳下显得没那么狰狞了。

“就是把这豆子种下去，跟咱们本地豆子比一比。”她站起身，拍了拍手上的土，“看看哪个长得好，哪个收成多。”

“光看收成？”沈青石走过来，也蹲下身，捡起一颗豆子，“赵老四说他家这豆子用了七八年，每年都能留种。本地豆子种一年，第二年就退化得厉害。”

林小满眼睛一亮：“你也注意到这个了？”

“打仗的人，粮食的事总要多留心。”沈青石把豆子扔回布袋里，“北狄那边，他们的马比咱们的壮，牛羊比咱们的肥。我问过俘虏，说是他们有种法子，能让牧草长得更好。”

“什么法子？”

“轮牧。”沈青石站起身，“今年这片草场放马，明年就空着，让草长一年。后年再放羊。”

林小满愣了愣，随即笑起来：“这不就是轮作嘛！咱们种地也讲究这个，一块地今年种豆子，明年种麦子，后年种粟米。豆子能养地，麦子耗地，轮着来，地力才不会衰竭。”

她说着，眼睛越来越亮，转身就往屋里跑：“我得记下来！”

沈青石看着她风风火火的背影，嘴角不自觉地弯了弯。

屋子里，林小满翻出那本用草纸装订的册子，这是她穿越过来后自己做的记录本。她用炭笔飞快地写着：

“豆种对比试验计划：
1. 试验田：屋后东边那块地，约二分。
2. 分区：东半种赵老四豆种，西半种本地豆种。
3. 播种时间：三日后。
4. 记录指标：出苗率、株高、结荚数、单荚粒数、千粒重。
5. 特别注意：抗病性、耐旱性、耐寒性。
6. 对照组：本地豆种普通种植法。”

写到一半，她突然停笔。

“糟了，忘了问赵老四他家豆子怎么种的。”

她抓起册子就往外跑，差点撞上端着碗进来的王大娘。

“冒冒失失的，又要去哪儿？”王大娘把碗放在桌上，“先吃饭，我给你熬了粟米粥，还卧了个鸡蛋。”

林小满肚子确实饿了，但心里有事，吃得飞快。

“大娘，您知道赵老四家豆子怎么种的吗？”

王大娘想了想：“他家种豆子跟别人不一样。别人都是清明前后下种，他家要等到谷雨。别人种豆子喜欢密，他家种得稀，一尺远才下一窝。”

“谷雨下种？一尺一窝？”林小满眼睛更亮了，“还有呢？”

“他家还喜欢在豆子地里套种点高粱，说是能挡风。”王大娘说着，压低声音，“不过这些都是他家祖传的法子，从来不外传。要不是沈将军亲自去说，他才不会把豆种给你。”

林小满点点头，心里有了数。

吃完饭，她又蹲回地头，把试验计划改了改。

“播种时间：谷雨前后。
种植密度：本地豆种按常规密度（六寸一窝），赵老四豆种按一尺一窝。
套种：赵老四豆种区套种高粱，本地豆种区不套种。
观察记录：每五天记录一次生长情况。”

沈青石不知何时又站到了她身后。

“你打算自己种？”

“当然自己种，试验田得我自己看着才放心。”林小满头也不抬，“不过我得找几个人帮忙，翻地、播种这些力气活我一个人干不完。”

“我让几个兵来帮你。”

“不用。”林小满摆摆手，“镇上好多人想跟我学种地，正好趁这个机会，让他们也参与进来。试验嘛，人多看得才仔细。”

沈青石没说话，只是看着她蹲在地上的背影。夕阳已经完全落下，天边还剩最后一抹暗红色的光。

“天黑了，回去吧。”他说。

林小满这才发现天色已晚，站起身时腿都有些麻了。她踉跄了一下，沈青石伸手扶了一把。

他的手很热，手掌有厚厚的茧子，握着她胳膊的力道恰到好处。

林小满心跳快了一拍，赶紧站稳：“谢谢。”

沈青石松开手，没说话。

两人一前一后往回走，谁都没提刚才那一扶。

第二天一早，林小满就去了镇上。

她先找刘老根，这老头种了一辈子地，是镇上有名的庄稼把式。

“刘爷爷，我想请您帮个忙。”

刘老根正在院里编筐，抬头看她：“林丫头啊，啥事？”

林小满把试验计划说了一遍，刘老根听完，眼睛瞪得溜圆。

“你要同时种两种豆子，还要记它们长多高、结多少荚？”

“对，还得记有没有生虫、叶子黄不黄这些。”

刘老根放下手里的柳条，站起来绕着林小满转了两圈：“你这丫头，种个地还跟做学问似的。”

“种地本来就是学问。”林小满认真道，“咱们这儿的豆子亩产五六十斤，赵老四家能有一百二三十斤，差了一倍多。要是能弄明白他家豆子为啥产量高，咱们全镇的豆子都能增产。”

刘老根眼睛亮了：“这话在理。行，我帮你。不过我有个条件。”

“您说。”

“你得把研究出来的法子教给我。”刘老根搓着手，“我种了四十年地，就知道埋头苦干，从来不知道种地还能这么讲究。”

林小满笑了：“没问题，我本来就想教给大家。”

从刘老根家出来，她又找了三个年轻后生——李二狗、张铁柱、王小石。这三人都是地里干活的好手，脑子也灵光，之前跟她学过堆肥的法子，对她很信服。

“林姐，你说咋干我们就咋干！”李二狗拍着胸脯保证。

“对，我们都听你的！”张铁柱和王小石也跟着点头。

林小满把任务分派下去：刘老根负责翻地、起垄，三个后生负责挑水、运肥，她自己负责播种和记录。

谷雨前三天，试验田准备就绪。

东边二分地被分成四垄，每垄长约五丈，宽四尺。垄与垄之间挖了排水沟，垄面整得平平整整。

林小满蹲在地头，手里拿着两个小布袋。左边袋子里是赵老四给的豆种，右边是本地豆种。

“开始吧。”她深吸一口气。

刘老根带着三个后生已经等在一旁。按照计划，东边两垄种赵老四豆种，西边两垄种本地豆种。

林小满先种赵老四的豆种。

她用小铲子挖坑，坑深约一寸，每个坑里放三颗豆子，然后覆土，轻轻压实。坑与坑之间相距一尺。

“林姐，这也太稀了吧？”李二狗看着直皱眉，“咱们种豆子，巴掌大的地方就能下五六颗种子。”

“稀了才好。”林小满一边下种一边说，“豆子长得壮，根系就扎得深，结的荚才多。种得太密，豆子争养分，长得又细又弱，反而减产。”

刘老根蹲在旁边看，若有所思：“赵老四家的豆子确实比别人的壮，原来根子在这儿。”

种完东边两垄，林小满在垄边插了根木棍，系上红布条做标记。然后开始种西边的本地豆种。

这次她用的是常规密度：六寸一窝，每窝放五六颗种子。

种完后，她又在两块地中间立了块木牌，用炭笔写上：“谷雨试验田，东：赵老四豆种，西：本地豆种。”

“好了，从今天开始，每五天来记录一次。”林小满拍拍手，“刘爷爷，您眼神好，帮我看着点，要是有虫子或者叶子发黄，立刻告诉我。”

刘老根点头：“放心，我天天来瞅两眼。”

接下来几天，林小满每天都要去地头看一圈。

谷雨那天，下了一场小雨。雨后第二天，东边的豆子就冒出了嫩芽。

林小满蹲在地头，用小尺子量了量：“芽高一寸二分，两片子叶展开，颜色翠绿。”

她在册子上记下数据，又跑到西边看。

西边的豆子还没出苗。

“别急，再等等。”刘老根安慰她，“本地豆子出苗慢，得等个三五天。”

林小满点点头，但心里已经开始打鼓。

又过了两天，西边的豆子终于出苗了。但芽明显比东边的细弱，颜色也偏黄。

林小满蹲在地头，眉头皱得紧紧的。

“林姐，咋了？”李二狗凑过来问。

“出苗率。”林小满指着西边的地，“你看，这一窝应该有五六棵苗，现在只出了三四棵。东边那边，每窝都出了三棵，一棵不少。”

李二狗挠挠头：“是不是种子不好？”

“种子是一方面，但更重要的是下种的方法。”林小满站起身，“你看东边，每窝只下三颗种子，间距一尺。豆子出苗后，有足够的空间生长，根系能扎得开。西边下种太密，豆子挤在一起，养分不够，弱苗就出不来。”

刘老根蹲在旁边，听得连连点头：“有道理，有道理。我以前种豆子，总怕出苗少，使劲往地里撒种子，原来反而是害了它们。”

林小满没说话，心里却在想另一件事。

赵老四的豆种，出苗率百分之百，本地豆种只有百分之七十左右。这个差距，除了种植方法，种子本身的质量也是关键。

她得想办法改良本地豆种。

这个念头一冒出来，就像野草一样疯长。

当天晚上，她点着油灯，在册子上写了整整三页纸。

“本地豆种改良方案：
1. 选种：从现有豆种中挑选颗粒饱满、颜色均匀的作为育种材料。
2. 杂交：用赵老四豆种做父本，本地豆种做母本，人工授粉。
3. 筛选：连续种植三年，选出性状稳定的优良单株。
4. 推广：将改良后的豆种分发给农户种植。”

写完后，她盯着“杂交”两个字看了很久。

人工授粉，这在现代农业里是常规操作。但在古代，没有镊子，没有放大镜，甚至没有杂交的概念。

她得自己做工具。

第二天，林小满去了李铁匠家。

“李叔，我想请您打几样东西。”

李铁匠正在打铁，闻言抬起头：“林丫头啊，要啥？”

林小满比划着：“我要一把小镊子，头要尖，能夹住豆花。还要一个放大镜，就是……能把小东西看大的镜片。”

李铁匠听得一头雾水：“啥叫放大镜？”

林小满想了想，从怀里掏出几文钱：“这样，您帮我打镊子，放大镜我再想办法。”

镊子好办，李铁匠用细铁条敲敲打打，半天就做出来了。头确实很尖，能稳稳夹住一粒豆子。

放大镜就难了。

林小满跑遍了整个镇子，也没找到能用的镜片。最后还是王大娘给了她个主意：“你去问问赵老四，他家祖上是做琉璃的，说不定有琉璃片。”

林小满眼睛一亮，立刻往赵老四家跑。

赵老四听完她的来意，从屋里翻出个布包，打开一看，里面是几块巴掌大的琉璃片，厚薄不一，颜色泛青。

“这是我爷爷那辈留下来的，本来是想做琉璃灯，后来家道中落，就剩这几块了。”赵老四递给她，“你要能用上，就拿去。”

林小满千恩万谢地捧着琉璃片回家，挑了一块最厚的，用砂石慢慢磨。磨了整整两天，终于磨出一块中间厚、边缘薄的凸透镜。

她试着透过镜片看豆子，豆子瞬间放大了好几倍，连表皮上的纹路都看得清清楚楚。

“成了！”她激动得差点跳起来。

有了工具，杂交试验就能开始了。

谷雨后第十天，东边的赵老四豆种开始开花。

豆花很小，淡紫色，藏在叶片下面。林小满蹲在地头，用自制的放大镜仔细观察。

“雄蕊十枚，九枚合生，一枚分离……雌蕊一枚，子房上位……”她一边看一边在册子上记录。

记录完，她开始人工授粉。

先用镊子把母本的雄蕊摘掉，然后取父本的花粉，轻轻涂在母本的柱头上。一朵花授粉完，再用细线在花梗上做个标记。

这个活需要极强的耐心和细心。一朵花授粉就要五六分钟，她蹲在地头，一干就是一整天。

刘老根和三个后生在旁边看着，大气都不敢出。

“林姐，你这是在干啥？”李二狗忍不住问。

“杂交育种。”林小满头也不抬，“把两种豆子的优点结合在一起，培育出更好的新品种。”

“啥叫杂交？”

“就是……”林小满想了想，“比如你爹个子高，你娘干活利索，生出来的你，既高又能干。豆子也一样，把两种好的豆子配在一起，生出来的豆子就能又高产又抗病。”

李二狗挠挠头：“豆子还能配对？”

“能，不过得人工帮忙。”林小满指着那些做了标记的花，“等这些花谢了，结出豆荚，里面的种子就是杂交种。明年种下去，再选最好的留种，连续选三年，就能选出稳定的好品种。”

刘老根听得眼睛发直：“我的老天爷，种个豆子还有这么多门道。”

林小满笑了笑，继续干活。

杂交授粉进行了五天，总共授了三十朵花。最后只结了十二个豆荚，每个豆荚里有两三粒种子。

“成功率百分之四十。”林小满在册子上记下，“比预期低，可能是技术还不熟练。”

她把这十二个豆荚小心地摘下来，放在布袋里，挂在房梁上阴干。

与此同时，东边的赵老四豆种和西边的本地豆种也在生长。

五天后，林小满再次记录数据：

东边：株高一尺二寸，叶片浓绿，无病虫害。
西边：株高八寸，叶片偏黄，有少量蚜虫。

“差距越来越大了。”刘老根蹲在地头，眉头紧锁，“林丫头，你说这是为啥？”

林小满指着两块地：“您看东边，豆子间距一尺，通风透光好，豆子长得壮，抗病虫害的能力就强。西边太密，豆子挤在一起，通风不好，就容易生虫。”

“那咱们现在把西边的豆子拔掉一些？”李二狗问。

“晚了。”林小满摇头，“豆子已经长起来了，现在拔掉反而伤根。明年吧，明年咱们按新法子种。”

刘老根叹了口气：“一年的收成就这么耽误了。”

“不算耽误。”林小满站起身，“这是试验，试验就是要找出问题。咱们知道了问题出在哪儿，明年就能改进。”

她说着，眼睛看向远方。

边关的天很高，云很淡，远处的山峦连绵起伏。这片土地虽然贫瘠，但只要用心经营，一定能长出好庄稼。

“林姐，你看啥呢？”王小石问。

“看地。”林小满说，“我在想，要是全镇的地都能像东边这块一样，咱们的粮食产量能翻一倍。”

“翻一倍？”三个后生同时惊呼。

“对，翻一倍。”林小满转过身，看着他们，“现在咱们镇的豆子亩产五六十斤，要是能种出赵老四家那样的豆子，亩产能到一百二三十斤。全镇要是都种上，一年能多收多少粮食？”

刘老根掰着手指头算：“咱们镇有三百多户，每户种两亩豆子，一年就是六百亩。现在亩产六十斤，总共三万六千斤。要是能到一百二十斤，就是七万两千斤，整整多出三万六千斤！”

“三万六千斤……”李二狗咽了口唾沫，“够全镇人吃两个月的。”

“所以啊，”林小满看着他们，“咱们现在费这些功夫，值不值？”

“值！”三个后生异口同声。

刘老根也重重点头：“值，太值了！林丫头，你说咋干，我们都跟着你干！”

林小满笑了，笑容在夕阳下格外明亮。

她知道，这才只是开始。

真正的考验，还在后头。
