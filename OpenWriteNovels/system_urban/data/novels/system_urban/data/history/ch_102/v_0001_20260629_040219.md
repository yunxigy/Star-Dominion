# 不理会的艺术

甜。

真甜。

他边走边剥栗子吃。

栗子壳很脆，一捏就开，栗子肉粉糯香甜。陈默吃了好几个，手指被染得黑乎乎的。

走到小区门口，保安老张正在岗亭里看手机，看见陈默，探出头来打招呼：“小陈，今天回来挺早啊。”

“嗯，今天没加班。”

“好事好事，年轻人就该多休息。”老张笑呵呵的，“你妈今天来了，拎着一兜子菜，说要给你做饭。”

陈默愣了一下：“我妈来了？”

“是啊，下午三点多来的，我帮她开的门禁。”老张指了指楼上，“估计现在饭都做好了。”

陈默心里一暖。

他加快脚步往单元楼走，电梯等了两分钟才下来。进了电梯，按下楼层按钮，看着数字一层层往上跳。

【系统提示：限时任务“不要理会”进度更新：2/？】
