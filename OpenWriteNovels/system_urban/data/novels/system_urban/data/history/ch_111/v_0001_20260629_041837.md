# 系统升级

会议室里安静得能听见空调出风的声音。

七位新入职的技术副总裁坐在长桌两侧，加上技术总监老张，八个人的目光全落在陈默身上。这是他们入职后第一次全体会议，气氛有些微妙。

陈默靠在椅背上，手指轻轻敲着桌面。

“今天叫大家来，就是互相认识一下。”他开口，语气轻松得像在聊天气，“公司情况你们都了解了，我就不多废话。咱们公司最大的特点就一个——不加班。”

赵明推了推眼镜，欲言又止。

李薇低头看着自己带来的笔记本，笔尖在纸上点了两下。

老张倒是直接：“陈总，我有个问题。”

“问。”

“如果不加班，项目进度怎么保证？我们之前在原公司，关键时期都是靠加班赶出来的。”

陈默笑了：“老张，你在原公司加班赶出来的项目，最后效果怎么样？”

老张愣了一下，没接话。

“我猜猜，上线后bug不断，用户投诉一堆，然后继续加班修复，恶性循环对吧？”陈默站起身，走到白板前，“咱们公司不一样。上班时间高效工作，下班时间准时走人。谁要是敢在晚上七点后还在公司，我亲自把他赶出去。”

会议室里响起几声低笑。

李薇抬起头：“陈总，这样的话，我们怎么和其他公司竞争？他们的程序员都在拼命。”

“拼命？”陈默转过身，“拼命拼出来的代码质量怎么样？你们心里没数吗？”

八个人都沉默了。

陈默敲了敲白板：“从今天开始，公司实行新的工作制度。第一，禁止任何形式的加班申请。第二，下班后工作群禁言。第三，周末和节假日，除非天塌下来，否则别想找到人。”

赵明终于忍不住了：“陈总，这样真的能行吗？”

“能不能行，试了才知道。”陈默回到座位上，“你们七位都是技术大牛，我花大价钱请你们来，不是让你们来加班的。我要的是效率，是质量，是你们在清醒状态下的创造力。”

他顿了顿，语气加重：“谁要是觉得做不到，现在可以提出来。门在那边，我不拦着。”

没有人动。

陈默点点头：“很好。那就这么定了。散会。”

众人起身往外走，陈默叫住了老张。

“老张，留一下。”

等会议室里只剩他们两人，陈默才开口：“老张，我知道你在想什么。”

老张苦笑：“陈总，我干了十五年技术，从来没见过这么干的。”

“所以你才来了我这儿。”陈默走到窗边，看着楼下熙熙攘攘的街道，“你知道为什么吗？”

“为什么？”

“因为你在原公司待不下去了。”陈默转过身，“你手下的人离职率最高，不是因为你管理不行，是因为你没法改变那种加班文化。你心疼手下人，但你无能为力。”

老张的喉结动了动，没说话。

“现在我给你这个权力。”陈默走到他面前，“从今天起，技术部的工作安排你说了算。谁要是敢带头加班，你直接来找我。我帮你处理。”

老张深吸一口气：“陈总，我……”

“别急着表态。”陈默打断他，“我给你一个月时间。一个月后，如果你觉得这套制度行不通，你可以走。我不拦你。但如果你留下来，就得全力执行。”

老张重重地点了点头：“我明白了。”

“去吧。”陈默拍拍他的肩膀，“对了，晚上六点准时下班，别让我看见你在公司。”

老张离开后，陈默一个人坐在会议室里。

【系统提示：检测到宿主正在推行新的工作制度，触发隐藏任务“制度的种子”。】

【任务内容：在接下来的一个月内，确保公司没有一人主动加班超过10分钟。】

【任务奖励：员工工作效率提升卡（永久生效）x1，现金奖励200万。】

【失败惩罚：公司所有电脑集体蓝屏三天。】

陈默看着系统面板，嘴角抽了抽。

“集体蓝屏三天？这惩罚也太狠了。”

【系统：这叫激励措施。】

“行行行，你说得对。”陈默关掉面板，起身离开会议室。

刚走到办公室门口，助理小林急匆匆跑过来。

“陈总，出事了！”

“什么事？”

“技术部那边，新来的几个程序员在争论要不要加班赶一个紧急需求。”

陈默眉头一皱：“谁带的头？”

“是……是赵明副总裁。”

陈默转身就往技术部走。

技术部的大办公区里，十几个程序员围在一起，赵明站在白板前，手里拿着记号笔。

“这个需求明天就要上线，如果不加班，根本完不成。”赵明的声音有些急，“我知道公司的规定，但这是特殊情况。”

一个年轻程序员举手：“赵总，陈总说了，任何情况都不能加班。”

“但这是客户紧急需求！”赵明提高了声音，“如果我们不按时交付，客户会流失的！”

“那就流失。”陈默的声音从门口传来。

所有人齐刷刷转头。

陈默走进办公区，站到赵明面前：“赵明，我刚才在会上说的话，你没听进去？”

赵明脸色有些难看：“陈总，我理解公司的理念，但现实是——”

“现实是什么？”陈默打断他，“现实是，如果我们今天加班赶出来，明天上线后出了问题，是不是还要继续加班修复？然后恶性循环，最后所有人都累垮了？”

赵明张了张嘴，没说出话来。

陈默环视四周：“在座的各位，谁以前没经历过这种情况？加班赶出来的项目，质量怎么样，你们心里没数吗？”

几个程序员低下了头。

陈默走到白板前，拿起板擦把赵明写的计划擦掉。

“这个需求，明天上线不了，那就后天上。后天上不了，那就大后天。但有一条底线——今天，现在，所有人都给我准时下班。”

他看向赵明：“赵明，你是技术副总裁，你的职责是保证项目质量，而不是保证项目速度。明白吗？”

赵明沉默了几秒，点了点头：“我明白了。”

“很好。”陈默拍拍手，“都散了，收拾东西准备下班。谁要是敢多待一分钟，这个月的奖金别想要了。”

人群很快散去。

陈默站在空荡荡的办公区里，看着窗外渐暗的天色。

【系统提示：隐藏任务“制度的种子”进度更新。当前加班人数：0。】

【宿主做得不错，但别高兴太早。真正的考验在后面。】

陈默关掉系统面板，回到自己的办公室。

刚坐下，手机就响了。

是老同学王浩打来的。

“喂，老陈，听说你公司最近搞得风生水起啊？”王浩的声音里带着调侃。

“还行吧，怎么了？”

“我这边有个项目，想问问你有没有兴趣合作。”

陈默靠在椅背上：“什么项目？”

“一个企业管理系统，客户是家大公司，预算很足。”王浩压低声音，“但他们要求很紧，一个月内必须上线。”

“一个月？”陈默笑了，“王浩，你又不是不知道我的规矩。”

“我知道，但这次真的不一样。”王浩急切地说，“这个客户很重要，如果我们能拿下来，后续还有很多合作机会。”

“那就让他们等。”陈默语气轻松，“等不了就找别人。”

“老陈，你这——”

“王浩。”陈默打断他，“我问你，你上次接的那个紧急项目，最后怎么样了？”

电话那头沉默了。

陈默继续说：“我记得你为了赶进度，带着团队连续加班两周，最后上线那天，核心程序员累倒进了医院。项目是交付了，但后续维护呢？bug修了三个月，客户投诉不断，最后尾款都没结清。”

王浩叹了口气：“那不一样，这次——”

“有什么不一样？”陈默反问，“客户要求紧，我们就得妥协？那我们和那些996的公司有什么区别？”

电话那头又沉默了。

陈默放缓语气：“王浩，我不是不想帮你。但我的原则不能破。如果你能找到一个客户，愿意给我们合理的时间，保证质量，我可以考虑合作。但这种要求一个月上线的项目，免谈。”

“好吧，我明白了。”王浩的声音有些失落，“那就这样吧。”

挂掉电话，陈默靠在椅背上，看着天花板。

手机又响了，这次是李薇发来的消息。

【李薇：陈总，我有个想法想和您聊聊，现在方便吗？】

【陈默：来我办公室。】

五分钟后，李薇敲门进来。

她手里拿着一份文件，走到陈默桌前：“陈总，这是我整理的技术部改进建议。”

陈默接过文件，快速翻看。

“你想推行代码审查制度？”他抬头问。

李薇点头：“是的。我在原公司就一直想推行，但领导觉得太浪费时间，没同意。”

“为什么觉得浪费时间？”

“因为代码审查需要花时间，领导觉得不如让程序员多写代码。”李薇苦笑，“但结果就是，代码质量越来越差，后期维护成本越来越高。”

陈默合上文件：“这个想法很好。你需要什么支持？”

李薇眼睛一亮：“我需要您授权，让技术部所有人都参与代码审查，包括各位副总裁。”

“没问题。”陈默爽快答应，“还有什么？”

“还有……”李薇犹豫了一下，“我想建议，把代码审查的时间算在正常工作时间内，不能占用下班时间。”

陈默笑了：“这是当然。你写个详细方案，明天给我。”

“好的，谢谢陈总！”李薇拿着文件，脚步轻快地离开了。

陈默看着她的背影，摇了摇头。

这些技术大牛，其实都有很多好想法，只是以前没有施展的空间。

【系统提示：检测到宿主正在推动技术部改革，触发支线任务“代码质量”。】

【任务内容：在接下来的三个月内，将公司代码质量评分提升至行业前10%。】

【任务奖励：技术人才吸引力卡（永久生效）x1，现金奖励500万。】

【失败惩罚：公司所有项目代码自动变成屎山。】

陈默看着系统面板，无奈地笑了。

“又是这种惩罚。”

【系统：这叫成长的代价。】

“行吧。”陈默关掉面板，开始收拾东西准备下班。

走出公司大楼时，天已经完全黑了。

陈默站在门口，看着街道上匆匆的行人，突然有种恍如隔世的感觉。

就在几个月前，他还是这些行人中的一员，每天加班到深夜，挤最后一班地铁回家。

而现在，他成了这家公司的老板，每天准时六点下班。

“陈总，您还没走啊？”身后传来声音。

陈默回头，看见老张正从大楼里出来。

“刚准备走。”陈默笑了笑，“你呢？”

“我也下班了。”老张走到他身边，“说实话，这么多年，我第一次这么准时下班，还有点不习惯。”

“慢慢就习惯了。”陈默拍拍他的肩膀，“走吧，一起吃个饭？”

老张愣了一下，随即笑了：“好啊。”

两人找了家附近的餐馆，点了几个菜。

等菜的时候，老张开口：“陈总，我今天观察了一下，技术部的那些年轻人，其实都很有能力。”

“我知道。”陈默点头，“不然我也不会花大价钱请他们来。”

“但他们以前在原公司，都被埋没了。”老张叹了口气，“每天就是加班、加班、再加班，根本没时间学习新技术，没时间思考怎么改进。”

“所以我们要改变这种现状。”陈默看着老张，“老张，你在技术圈干了这么多年，应该知道，真正厉害的程序员，都不是靠加班堆出来的。”

老张重重地点头：“我明白。以前我们总说，程序员要靠灵感，要靠创造力。但现实是，很多公司把程序员当流水线工人用，每天就是写代码、写代码、写代码。”

“所以我们要不一样。”陈默端起茶杯，“我们要让程序员有时间思考，有时间学习，有时间生活。只有这样，他们才能写出真正好的代码。”

老张看着陈默，眼神复杂：“陈总，您真的觉得这样能行吗？”

“能不能行，试了才知道。”陈默喝了一口茶，“但至少，我们要试一试。”

菜上来了，两人边吃边聊。

聊到一半，陈默的手机又响了。

是启明资本的赵总。

陈默皱了皱眉，接起电话。

“陈总，我是赵明。”赵总的声音很热情，“上次的事情，我想再和您聊聊。”

“赵总，我记得我已经说得很清楚了。”陈默语气平淡，“我不需要融资。”

“陈总，您先别急着拒绝。”赵总急忙说，“我这次不是来谈投资的，是想和您聊聊行业趋势。”

陈默看了看对面的老张，起身走到餐馆外面。

“赵总，您有什么话就直说吧。”

“陈总，您最近在业界的名声很大。”赵总的声音压低了，“很多人在讨论您的公司，讨论您的管理方式。”

“讨论什么？讨论我不加班？”陈默笑了，“还是讨论我给员工放假？”

“都有。”赵总顿了顿，“陈总，我直说吧。有些人对您的做法很不满，他们觉得您在破坏行业规矩。”

“行业规矩？”陈默冷哼一声，“什么行业规矩？让员工每天工作12小时以上，这就是行业规矩？”

“陈总，您别激动。”赵总急忙说，“我只是提醒您，小心一点。有些人可能会对您不利。”

“怎么不利？挖我的人？还是给我使绊子？”陈默语气轻松，“赵总，谢谢您的提醒。但我做事，问心无愧。”

“好吧，那您多保重。”赵总叹了口气，“如果有什么需要帮忙的，随时联系我。”

挂掉电话，陈默站在餐馆门口，看着夜色中的街道。

【系统提示：检测到外部威胁，触发紧急任务“应对危机”。】

【任务内容：在接下来的一周内，应对来自竞争对手的恶意挖角。】

【任务奖励：核心员工忠诚度锁（永久生效）x1，现金奖励300万。】

【失败惩罚：公司核心团队集体跳槽。】

陈默看着系统面板，眉头紧锁。

“看来，麻烦要来了。”

他转身回到餐馆，坐回座位。

老张看出他的异样：“陈总，怎么了？”

“没什么。”陈默笑了笑，“老张，我问你个问题。”

“您说。”

“如果有人出高薪挖你，你会走吗？”

老张愣了一下，随即坚定地摇头：“不会。”

“为什么？”

“因为在这里，我找到了久违的尊重。”老张认真地说，“陈总，钱很重要，但不是最重要的。在这里，我能做自己想做的事情，能实现自己的价值。这比多给几万块钱重要多了。”

陈默点点头，没再说话。

但他知道，不是所有人都像老张这样想。

【系统：宿主，危机即将来临，你准备好了吗？】

陈默在心里回答：“准备好了。”

【系统：很好。那么，游戏开始。】

陈默放下筷子，看着窗外的夜色。

他知道，真正的挑战，现在才刚刚开始。
