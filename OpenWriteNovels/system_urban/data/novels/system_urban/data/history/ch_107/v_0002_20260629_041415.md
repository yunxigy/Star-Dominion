# 行业风暴

青云科技总部，顶层会议室。

落地窗外是灰蒙蒙的城市天际线，陈默站在窗前，手指无意识地敲击着玻璃。林远坐在他身后的沙发上，正用笔记本电脑整理着什么。

“王总还有十分钟到。”林远抬头看了一眼时间。

陈默转过身，深吸一口气。他手里捏着那份《关于推动行业健康发展的自律公约（草案）》，纸张边缘已经被他捏得微微发皱。

【系统提示：距离国际技术峰会还剩6天23小时32分钟。隐藏任务“以彼之道，还施彼身”进行中。请宿主注意，本次任务失败惩罚为摆烂值-30，随机失去一项已获得能力。】

陈默在心里翻了个白眼。这系统，每次提醒都跟催命似的。

“你紧张？”林远合上电脑，走到他身边。

“有点。”陈默坦白道，“星耀科技那边已经拉了七家公司，行业协会表决需要九票。我们这边……”

“王总这边是关键。”林远接话，“青云科技在行业里分量不轻，如果他们能支持我们，至少能争取到观望的公司。”

会议室的门被推开。

王总走进来时，脸上带着职业化的笑容。他四十出头，头发梳得一丝不苟，西装笔挺，但眼下的乌青暴露了长期睡眠不足的事实。

“陈总，林总，久等了。”王总和两人握了握手，示意他们坐下，“听说你们有个提案想和我聊聊？”

陈默将草案递过去：“王总，这是我们草拟的《行业自律公约》，想听听青云科技的意见。”

王总接过文件，快速浏览起来。会议室里只剩下纸张翻动的沙沙声。

陈默观察着王总的表情。当看到“禁止使用工时监控系统侵犯员工隐私”这一条时，王总的眉头明显皱了一下。看到“禁止将‘工时’作为绩效考核唯一标准”时，他的嘴角抽动了一下。

五分钟后，王总放下文件，靠回椅背。

“陈总，”他缓缓开口，“这份公约……很大胆。”

“是务实。”陈默纠正道，“王总，您应该比我们更清楚，现在行业里‘加班文化’已经到了什么程度。员工健康出问题，效率反而下降，这是恶性循环。”

王总笑了，但笑容里没什么温度：“陈总，道理我都懂。但现实是，星耀科技牵头的那个公约已经进入表决阶段了。他们那边七票，我们这边……说实话，除了你们公司，明确表态支持你们的，目前还没有。”

“所以才来找您。”林远插话，“青云科技如果支持我们，至少能打破星耀的垄断局面。”

王总沉默了几秒，手指在桌面上轻轻敲击。

“陈总，我问你一个问题。”他突然说，“你们公司，真的能做到完全不加班吗？项目紧的时候怎么办？客户需求突然变更怎么办？”

陈默早料到会有这个问题：“我们有科学的项目管理系统，合理评估工作量，预留缓冲时间。更重要的是——”

他顿了顿，直视王总的眼睛：“我们相信，尊重员工的时间，才能换来真正的效率。上个月我们公司人均产出比行业平均水平高15%，但人均工时少了20%。”

王总挑眉：“数据有支撑吗？”

“有。”陈默从公文包里拿出另一份文件，“这是我们过去半年的运营数据，第三方审计过的。另外——”

他又拿出一个U盘：“这是苏晴记者做的行业调查报告，关于程序员健康状况的。王总可以看看。”

王总接过U盘，插进电脑。屏幕上很快跳出图表和数据。

会议室里再次陷入沉默。只有鼠标点击的声音。

陈默看着王总的脸色。从最初的质疑，到惊讶，再到若有所思。

“这些数据……”王总终于开口，“是真的？”

“每一份都有来源标注。”陈默说，“王总，我知道青云科技内部也有类似的问题。去年你们有个项目经理猝死，对吧？”

王总的脸色瞬间变了。

“你怎么知道——”

“行业里传过一阵。”陈默平静地说，“但很快被压下去了。王总，这样的事情，还要发生多少次，我们才能真正改变？”

王总靠回椅背，闭上眼睛。会议室里安静得能听到空调出风的声音。

良久，他睁开眼睛：“陈总，你想让我怎么做？”

“在峰会上支持我们的公约。”陈默说，“至少投一票赞成。如果可能的话，帮我们争取其他公司。”

王总苦笑：“你知道这意味着什么吗？星耀科技那边会怎么想？我们和他们还有三个合作项目……”

“王总，”陈默打断他，“如果连您都不敢站出来，那这个行业就真的没救了。”

这句话说得有点重。林远在旁边轻轻咳了一声。

但王总没有生气。他盯着陈默看了很久，突然笑了。

“你和以前不一样了，陈默。”

“人总会变的。”

王总点点头，站起身走到窗边。背对着他们，声音有些飘忽：“我儿子今年大三，计算机专业。上次他问我，爸，你们公司是不是天天加班？我说是。他说，那我毕业绝对不进你这行。”

陈默没说话。

“我做了二十年互联网，”王总继续说，“从程序员做到CEO。年轻的时候觉得加班是奋斗，现在……”

他转过身：“现在觉得，是该做点改变了。”

陈默心里一动。

【系统提示：检测到关键人物态度转变。摆烂值+1。】

王总走回座位，重新拿起那份公约：“这份草案，有些条款需要修改。比如这个‘禁止使用工时监控系统’，表述太绝对了。可以改成‘合理使用工时管理系统，禁止用于侵犯员工隐私’。”

陈默眼睛一亮：“您愿意帮我们修改？”

“不只是修改。”王总说，“我愿意联署。但有一个条件。”

“您说。”

“公约通过后，成立一个行业监督委员会。”王总说，“青云科技要有一个席位。而且这个委员会要有实权，能对违规公司进行公示。”

陈默和林远对视一眼。

“没问题。”陈默说，“我们本来就想设立这样的机构。”

王总点点头，伸出手：“那就合作愉快。”

陈默握住他的手，感觉到对方手掌的力度。

【系统提示：获得青云科技支持。隐藏任务进度更新：已获得支持公司数量1/3。】

离开青云科技总部时，天色已经暗了。

林远开着车，陈默坐在副驾驶，看着窗外流动的霓虹灯光。

“王总最后那番话，是真心的吗？”林远问。

陈默想了想：“七分真，三分利。他儿子那段可能是真的，但更重要的是，他也看到了行业的问题。青云科技去年离职率35%，再这么下去，公司也撑不住。”

“那星耀科技那边呢？他们肯定不会坐视不管。”

“当然不会。”陈默说，“所以我们要快。明天联系其他几家公司，能争取一票是一票。”

手机震动起来。陈默看了一眼，是苏晴发来的消息。

“数据已经整理好了，深度报道初稿完成。另外，我听到风声，星耀科技那边准备在峰会上搞突然袭击，可能会提出更激进的提案。”

陈默皱眉，回复：“什么提案？”

“具体内容不清楚，但据说和‘灵活用工’有关。可能是想把加班包装成‘自愿奋斗’。”

陈默冷笑一声。这招他们太熟了。

“继续跟进，有消息随时联系我。”

“好。对了，陈默，”苏晴又发来一条，“你们公司还招人吗？我有个学弟，技术很强，但在原公司被排挤，因为不愿意加班。”

陈默笑了：“让他投简历。我们公司，欢迎所有‘不愿意加班’的人。”

【系统提示：触发支线任务“人才引进”。任务要求：在峰会前招募至少三名因拒绝过度加班而离职的优秀人才。奖励：摆烂值+5，随机技能卡一张。】

陈默收起手机，看向窗外。

城市灯火通明，无数写字楼里还亮着灯。那些灯光背后，是无数个还在加班的人。

“林远，”陈默突然说，“你说，我们真的能改变这个行业吗？”

林远沉默了几秒：“不知道。但至少，得有人先站出来。”

陈默点点头。

是啊，得有人先站出来。

第二天上午，陈默的办公室里堆满了文件。

他正在打电话，声音有些沙哑：“李总，您再考虑一下。这份公约不是要和谁作对，是为了整个行业的健康发展……”

电话那头传来犹豫的声音：“陈总，道理我都懂。但星耀科技那边已经找过我了，他们承诺，如果支持他们的提案，会给我们三个项目……”

“李总，”陈默打断他，“三个项目能做多久？一年？两年？如果行业环境恶化，优秀人才都流失了，您拿什么做项目？”

电话那头沉默了。

“我再想想。”对方最后说。

挂断电话，陈默揉了揉太阳穴。这已经是今天第五个了，每一个都顾虑重重。

【系统提示：检测到宿主情绪波动。建议进行十分钟“摆烂式休息”——即什么都不做，发呆放空。】

陈默差点被气笑。这系统，真是随时随地都在推销它的摆烂哲学。

不过他还是照做了。靠在椅背上，闭上眼睛，什么都不想。

五分钟后，他睁开眼，感觉脑子清醒了不少。

手机又响了。这次是陌生号码。

“陈总？”电话那头是个年轻的声音，“我是张涛，苏晴学姐介绍的。听说您在找人？”

陈默坐直身体：“是的。你现在方便聊聊吗？”

“方便。我刚从上家公司离职，原因是……拒绝加班。”

陈默笑了：“欢迎。明天来公司面试吧。”

【系统提示：支线任务进度更新：已招募人才1/3。】

挂断电话，陈默看了看时间。下午两点，距离峰会还有六天。

他打开电脑，开始修改公约草案。王总提的那些建议很有道理，需要逐条落实。

敲门声响起。

“进。”

林远推门进来，脸色有些凝重：“陈默，星耀科技那边有动作了。”

“什么动作？”

“他们刚发了公告，宣布成立‘行业创新联盟’。”林远把平板电脑递过来，“你看这个名单。”

陈默接过平板，快速浏览。联盟成员除了星耀科技和那七家公司，又多了四家。总共十一家。

“他们动作这么快？”陈默皱眉。

“不止如此。”林远说，“你看这个条款——‘联盟成员将共同探索灵活用工模式，鼓励员工自愿奋斗，实现个人价值与企业发展的双赢’。”

陈默冷笑：“自愿奋斗？说得真好听。”

“问题是，”林远说，“他们现在有十一家公司了。峰会上如果一起投票，我们的公约根本过不了。”

陈默沉默了几秒，突然问：“苏晴那边有消息吗？”

“刚发来一份资料。”林远调出另一个文件，“星耀科技过去三年的员工健康数据，以及……猝死案例。”

陈默快速浏览，脸色越来越沉。

“这些数据，能公开吗？”

“苏晴说，如果得到当事人或家属授权，可以。”林远说，“但她需要时间。”

“时间不多了。”陈默站起身，走到窗边。

楼下街道车水马龙，每个人都在匆忙赶路。这座城市就像一台永不停歇的机器，而每个人都是机器上的零件。

“林远，”陈默突然说，“你说，如果我们在峰会上，直接公布这些数据，会怎么样？”

林远一愣：“你是说……”

“星耀科技不是要搞‘自愿奋斗’吗？”陈默转过身，眼睛里闪着光，“那我们就让所有人看看，‘自愿奋斗’的代价是什么。”

“但这会彻底得罪星耀科技。”林远说，“而且可能引发行业震动。”

“行业需要震动。”陈默说，“一直温水煮青蛙，最后死的是所有人。”

【系统提示：检测到宿主计划采取激进策略。系统评估：风险系数高，但收益潜力大。建议宿主做好充分准备。】

陈默点点头。他拿起手机，给苏晴发了条消息：“那些数据，我需要最完整的版本。另外，如果有家属愿意发声，联系我。”

发完消息，他看向林远：“继续联系其他公司。能争取一票是一票。另外，准备一份新闻稿，以备不时之需。”

“什么内容？”

“关于行业健康危机的。”陈默说，“用数据说话，不要带情绪。”

林远点点头，转身离开。

办公室里又只剩下陈默一个人。他重新坐回电脑前，继续修改公约草案。

但脑子里却在想另一件事。

系统给他的任务是获得至少三家公司支持。现在只有一家。剩下两家，从哪里来？

他打开通讯录，一个个名字看过去。大部分都是顾虑重重的，真正敢站出来的，少之又少。

手机震动。是苏晴的回复。

“数据完整版已发你邮箱。有两位家属愿意匿名发声，但需要你保证他们的隐私安全。”

陈默回复：“保证。峰会前我会和他们详细沟通。”

放下手机，他继续工作。

时间一分一秒过去。窗外的天色从亮到暗，又从暗到亮。

第二天下午，陈默终于修改完了公约草案的最终版本。他伸了个懒腰，感觉骨头都在响。

【系统提示：宿主已连续工作18小时。根据摆烂系统健康指南，建议立即休息。】

陈默笑了笑。这系统，有时候还挺贴心的。

他正准备去休息室躺一会儿，手机又响了。这次是王总。

“陈总，有个消息。”王总的声音有些急促，“星耀科技那边，准备在峰会上提出‘行业人才共享计划’。”

“什么内容？”

“简单说，就是联盟内公司可以共享员工资源。”王总说，“听起来是优化资源配置，但实际上……”

“实际上是变相的劳务派遣，规避劳动法。”陈默接话。

“没错。”王总说，“而且这个计划一旦通过，员工就更没有议价能力了。今天在这家公司加班，明天被调到那家公司加班，连反抗的机会都没有。”

陈默握紧了手机：“王总，您那边能争取到多少票？”

“我试了几家公司，有两家松口了。”王总说，“但他们都要求匿名支持，不想公开得罪星耀科技。”

“匿名也行。”陈默说，“只要投票的时候站我们这边。”

“我尽力。”王总说，“陈默，这次峰会，可能会很激烈。”

“我知道。”陈默说，“但我们没有退路。”

挂断电话，陈默深吸一口气。

两家匿名支持，加上青云科技，就是三家。刚好完成任务。

但这还不够。星耀科技那边有十一家公司，如果他们全力推动那个“人才共享计划”，公约根本不可能通过。

必须想其他办法。

陈默打开电脑，开始搜索国际技术峰会的议程。当他看到“自由演讲环节”时，眼睛亮了。

每个参会公司都有十分钟的自由演讲时间。通常大家都会用来宣传自家产品，但……

如果用这个时间，来公布那些数据呢？

陈默的心跳开始加速。

他拿起手机，给苏晴发了条消息：“峰会上的自由演讲环节，我能用吗？”

苏晴很快回复：“理论上可以，但需要提前申请。而且内容要审核。”

“如果我说，我要公布行业健康数据呢？”

电话那头沉默了几秒，然后苏晴的声音传来：“陈默，你疯了吗？”

“可能吧。”陈默说，“但这是唯一的机会。”

又是一阵沉默。然后苏晴说：“我帮你申请。但你要想清楚，一旦公开，就再也没有回头路了。”

“我想清楚了。”陈默说。

挂断电话，陈默靠在椅背上，看着天花板。

【系统提示：检测到宿主计划采取高风险行动。系统评估：此行动可能导致宿主成为行业公敌，但同时也可能彻底改变行业格局。奖励预估：摆烂值+50，特殊成就“行业颠覆者”。】

陈默笑了。

行业公敌？他早就习惯了。

从绑定摆烂系统的那天起，他就注定要走上一条与众不同的路。

手机又响了。这次是林远。

“陈默，又有两家公司松口了。”林远的声音里带着兴奋，“他们愿意在峰会上支持我们的公约！”

陈默坐直身体：“哪两家？”

“一家是做云计算的，另一家是做人工智能的。”林远说，“他们之前也被星耀科技拉拢过，但看完我们的公约草案和数据后，改变了主意。”

“太好了。”陈默说，“现在我们有五家支持了。超过三家，任务完成。”

【系统提示：隐藏任务“以彼之道，还施彼身”进度更新：已获得支持公司数量5/3。任务完成！奖励摆烂值+20。】

陈默长舒一口气。

但紧接着，系统提示又响了。

【系统提示：检测到任务已完成，但宿主计划采取进一步行动。系统建议：谨慎行事。摆烂不是送死。】

陈默笑了笑。

放心，他还没活够呢。

他站起身，走到窗边。夕阳正在西沉，把整座城市染成金色。

六天后，就是峰会了。

那时候，一切都会不一样。

陈默转身，回到电脑前，开始准备演讲稿。

这一次，他要让所有人听到真相。

哪怕真相很刺耳。

哪怕真相会得罪很多人。

但总得有人说出来。

而他，愿意当这个出头鸟。

毕竟，他是陈默。

一个绑定了摆烂系统，却偏偏要改变世界的男人。
