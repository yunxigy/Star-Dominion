# 第76章

# 第七十六章 反击

陈默走出公司大楼，晚风裹挟着初秋的凉意扑面而来。

他站在台阶上，掏出手机看了眼时间——晚上七点四十五分。往常这个时候，他还在工位上对着电脑屏幕发呆，或者被李明远叫去办公室听那些冠冕堂皇的“企业文化培训”。

现在，他刚刚把一封足以让整个公司地震的举报邮件，发送到了市经侦支队的邮箱。

【系统提示：隐藏任务“反击”已接受。任务要求：在李明远发现举报前，收集更多证据。风险等级：极高。】

陈默深吸一口气，手指在屏幕上滑动，调出系统面板。

【危机直觉+5：可提前0.5秒预感危险。当前状态：已激活。】

“0.5秒……”陈默喃喃自语，“够干什么的？够我躲一巴掌吗？”

他摇摇头，把手机揣回口袋。系统给的东西，向来是能用就用，不能用也得用——毕竟这是他现在唯一的依仗。

陈默拦了辆出租车，报出自己公寓的地址。车窗外，城市的霓虹灯流淌成河，他看着那些光影，脑子里却在飞速运转。

举报邮件已经发出去了，但李明远不是傻子。财务总监那个位置坐了这么多年，他肯定有自己的消息渠道。经侦支队接到举报，按照流程，至少需要三到五天才会正式立案调查。而这段时间，就是陈默的窗口期。

“师傅，麻烦绕一下路，去老城区那边。”陈默突然开口。

司机从后视镜里看了他一眼：“老城区？那边路窄，还堵。”

“没事，我多付二十块。”

出租车拐进另一条车道，朝着城市的另一端驶去。

陈默靠在座椅上，闭上眼睛。老周的脸又浮现在眼前——那个总是笑呵呵、喜欢在办公室养绿植的中年男人，最后留给他的，只有一个U盘，和一句“说真话的人”。

他睁开眼，眼神变得坚定。

二十分钟后，出租车停在一条老旧巷子口。陈默付了钱下车，巷子里的路灯坏了几盏，光线昏暗。他凭着记忆，走到一扇锈迹斑斑的铁门前，抬手敲了敲。

“谁啊？”里面传来警惕的声音。

“我，陈默。”

门开了一条缝，露出一张戴着黑框眼镜的脸。那人上下打量陈默，然后侧身让他进去。

屋里堆满了纸箱和旧电脑主机，空气中弥漫着灰尘和焊锡的味道。那人——网名“老黑”，真名不详，是陈默大学时认识的计算机系学长，现在是个自由职业的网络安全顾问。

“你小子，大晚上跑我这儿来，准没好事。”老黑推了推眼镜，“说吧，又惹上什么麻烦了？”

陈默没废话，从口袋里掏出一个U盘——这是他备份的证据副本。

“帮我查点东西。”

老黑接过U盘，插进旁边一台看起来像是古董的电脑里。屏幕亮起，代码飞快滚动。

“财务数据？公司内部文件？”老黑皱眉，“你这是……要举报？”

“嗯。”

“举报谁？”

“李明远，我们公司的财务总监。”

老黑的手指在键盘上停顿了一下，转头看向陈默：“你知道这意味着什么吗？这种级别的举报，一旦被对方察觉，你可能会……”

“可能会死。”陈默接过话头，“我知道。”

老黑沉默了几秒，然后叹了口气：“行，你要查什么？”

“这些证据里，有一部分是老周——我们公司之前的技术总监——留下的。但还不够，特别是资金流向那一块，中间有几笔转账记录很模糊。我需要你帮我挖深一点，看看能不能找到更多关联账户。”

老黑盯着屏幕，手指重新开始敲击键盘：“我试试。不过这种事，一旦开始查，就停不下来了。你确定要继续？”

“确定。”

“行。”老黑点头，“给我三天时间。这期间，你别联系我，也别用任何可能被追踪的通讯方式。三天后，老地方见。”

陈默站起身：“谢了。”

“别谢我。”老黑头也不抬，“我只是不想看到又一个‘老周’出现。”

陈默离开老黑的住处，已经是晚上九点多。他走到巷子口，正准备拦车，手机突然震动起来。

是系统提示。

【系统提示：检测到潜在威胁。建议宿主立即更换出行路线。】

陈默的心跳漏了一拍。危机直觉能力没有触发预警，说明威胁还不紧迫，但系统主动提示，意味着情况可能正在变化。

他收起手机，没有拦车，而是转身走进旁边一家24小时便利店。透过玻璃窗，他观察着外面的街道。

五分钟后，一辆黑色轿车缓缓驶过巷子口，车窗贴着深色膜，看不清里面。轿车在巷口停了十几秒，然后加速离开。

陈默的手心渗出冷汗。

那辆车……是巧合，还是有人在找他？

他等到轿车彻底消失在视线里，才走出便利店，拦了辆出租车，报了另一个地址——不是他的公寓，而是市中心的一家连锁酒店。

当晚，陈默在酒店房间里几乎没睡。他躺在床上，盯着天花板，脑子里反复推演各种可能性。

李明远如果察觉到举报，会怎么做？

第一，派人盯着他。第二，销毁证据。第三，直接动手。

陈默摸了摸口袋里的U盘——这是他最后的底牌，也是最危险的筹码。他必须确保，在经侦支队正式介入之前，这些证据不会落入李明远手中。

第二天早上，陈默照常去公司上班。

他走进办公室时，一切看起来和往常一样。同事们在工位上忙碌，有人抱怨昨晚加班太晚，有人在茶水间聊八卦。李明远的办公室门关着，透过玻璃能看到他坐在里面，正在打电话。

陈默坐到自己的工位上，打开电脑。屏幕亮起，他却盯着桌面图标发呆。

【系统提示：日常任务发布——今日摸鱼时长需达到4小时。奖励：随机技能点+1。】

陈默嘴角抽了抽。系统永远在这种时候给他发这种任务。

他深吸一口气，开始处理手头的工作——其实也没什么工作，自从他“摆烂”出名后，李明远几乎不给他安排重要任务了。

上午十点，陈默去茶水间倒水。路过李明远办公室时，他听到里面传来激烈的争吵声。

“……什么叫查不到？！我让你查那个人的行踪，你跟我说查不到？！”李明远的声音压得很低，但怒气清晰可闻。

陈默放慢脚步，耳朵竖了起来。

“……废物！继续查！我不管你用什么方法，明天之前，我要知道他昨晚去了哪里，见了谁！”

办公室门突然打开，李明远的秘书小王低着头走出来，差点撞上陈默。两人对视一眼，小王眼神躲闪，快步离开。

陈默端着水杯回到工位，心跳加速。

李明远在查谁？查他吗？

下午，陈默注意到公司里的气氛有些微妙。几个平时和李明远走得近的中层领导，频繁出入他的办公室，每次出来都脸色凝重。财务部那边更是安静得反常，所有人都埋头工作，连聊天的人都没有。

陈默知道，暴风雨要来了。

但他没想到，会来得这么快。

下午四点，陈默的手机收到一条陌生号码发来的短信：

“今晚八点，老地方见。有重要事情商量。”

没有署名，没有称呼。陈默盯着这条短信，手指悬在屏幕上方。

老地方？什么老地方？

他突然想起，大学时他和几个朋友常去学校后门的一家烧烤摊，他们私下里称那里为“老地方”。但毕业后，那些朋友各奔东西，已经很多年没联系了。

这是巧合，还是陷阱？

【系统提示：检测到可疑信息。建议宿主谨慎处理。】

陈默没有回复短信，而是把手机锁屏，塞进口袋。

晚上六点，下班时间。陈默收拾东西准备离开，李明远突然从办公室里走出来，叫住了他。

“陈默，留一下。”

办公室里其他人都抬头看过来，眼神复杂。陈默停下脚步，转身看向李明远。

李明远脸上挂着那种标志性的、虚伪的微笑：“来我办公室一趟，有点事想跟你聊聊。”

陈默跟着李明远走进办公室。门关上，隔绝了外面的视线。

李明远坐到办公桌后，指了指对面的椅子：“坐。”

陈默坐下，背脊挺直。

“最近工作怎么样？”李明远问，语气轻松得像是在闲聊。

“还行。”陈默回答。

“听说你最近……挺清闲的？”李明远笑了笑，“年轻人嘛，有想法是好事。但公司有公司的制度，该做的事情，还是要做好的。”

陈默没说话，等着他的下文。

李明远身体前倾，双手交叉放在桌上：“陈默，我直说了吧。公司最近在筹备一个新项目，很重要。我需要一个信得过的人来负责一部分工作。你有兴趣吗？”

陈默看着李明远的眼睛。那双眼睛里，没有真诚，只有试探。

“什么项目？”陈默问。

“一个技术升级项目。”李明远说，“具体内容，等你答应了，我再详细告诉你。不过我可以保证，这个项目做好了，你的职位和薪水，都会有大幅度的提升。”

陈默沉默了几秒，然后摇头：“李总，谢谢您的好意。但我最近身体不太好，可能没办法承担太大的工作量。”

李明远脸上的笑容僵了一下：“身体不好？要不要去医院看看？公司可以报销。”

“不用了，休息休息就好。”陈默站起身，“如果没其他事，我先下班了。”

李明远盯着他，眼神变得锐利：“陈默，你是不是……对我有什么意见？”

“没有。”陈默平静地说，“我只是觉得，现在的工作状态挺好的。”

两人对视了几秒，李明远突然笑了：“行，那你先回去休息。项目的事，你再考虑考虑。”

陈默点头，转身离开办公室。

走出公司大楼，陈默才发现自己的后背已经被冷汗浸湿。李明远最后那个眼神，让他想起了系统提示的“潜在威胁”。

那不是上级对下属的眼神，那是猎人盯着猎物的眼神。

陈默没有回公寓，也没有去酒店。他拐进一条小巷，七拐八绕，确认身后没有跟踪后，来到一家网吧。

他开了台机器，登录一个临时邮箱，给老黑发了条加密信息：“情况有变，加快进度。另外，帮我查一个手机号码的来源。”

发完信息，陈默退出邮箱，清空浏览记录。他坐在网吧嘈杂的环境里，盯着屏幕上闪烁的游戏广告，脑子却在飞速运转。

李明远开始怀疑他了。那条神秘短信，很可能就是试探。如果他今晚真的去了那个“老地方”，等着他的，恐怕不会是老朋友。

但问题是，李明远是怎么察觉的？

举报邮件是匿名发送的，经侦支队那边，按照规定，应该不会这么快泄露信息。除非……

陈默突然想到一个可能：李明远在经侦支队有内线。

这个念头让他脊背发凉。如果真是这样，那他的举报，可能从一开始就暴露了。

【系统提示：危机直觉触发。建议宿主立即转移至安全地点。】

陈默猛地站起身，冲出网吧。

他跑到街上，拦了辆出租车，报出一个地址——不是酒店，不是公寓，而是城市另一端的一个城中村。那里鱼龙混杂，外来人口多，是藏身的好地方。

出租车在夜色中穿行，陈默靠在后座上，心跳如鼓。

他知道，从现在开始，他不能再回公司了。李明远既然已经怀疑他，就一定会采取行动。他必须消失，直到经侦支队那边有进展。

但消失，意味着放弃收集更多证据的机会。系统任务要求他在李明远发现举报前收集更多证据，现在看来，时间已经不多了。

出租车停在城中村入口，陈默付了钱下车。狭窄的巷子里，路灯昏黄，空气中弥漫着油烟和潮湿的味道。他凭着记忆，找到一栋老旧的居民楼，爬上三楼，敲响了一扇门。

门开了一条缝，露出一张警惕的脸。

“找谁？”

“我找刘姐。”陈默说，“老周介绍的。”

门里的男人上下打量他，然后侧身让他进去。

屋里很乱，堆满了各种电子设备和线缆。一个四十多岁的女人坐在电脑前，头也不抬地说：“老周的人？他不是已经……”

“他走了，但他留了些东西给我。”陈默说，“我需要一个安全的地方住几天，另外，可能需要一些设备。”

女人——刘姐，终于转过头。她脸上有几道疤痕，眼神锐利：“老周的东西，不是随便什么人都能接手的。你凭什么？”

陈默从口袋里掏出那个U盘，放在桌上：“凭这个。”

刘姐盯着U盘看了几秒，然后点头：“行，房间在最里面，设备随便用。但记住，别给我惹麻烦。”

“放心。”陈默说，“我只是暂时躲躲。”

他拿起U盘，走向里屋。关上门，他靠在门板上，长长地吐出一口气。

暂时安全了。

但陈默知道，这只是开始。李明远不会善罢甘休，经侦支队那边的调查也需要时间。他现在就像走在钢丝上，两边都是深渊。

他走到窗边，拉开窗帘一角。城中村的夜景尽收眼底——密密麻麻的窗户，闪烁的灯光，远处高架桥上流动的车河。

陈默摸出手机，看了一眼系统面板。

【隐藏任务“反击”进度：15%】

【剩余时间：未知】

【风险等级：极高】

他关掉面板，把手机放在桌上。

窗外，夜色正浓。而陈默知道，真正的战斗，才刚刚开始。
