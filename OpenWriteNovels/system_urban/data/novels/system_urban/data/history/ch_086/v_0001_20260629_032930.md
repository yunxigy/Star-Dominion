# 摆烂指数保卫战

周一早晨，陈默踩着点走进公司大门。

前台小妹抬头看了眼墙上的钟——8点59分，冲他竖起大拇指：“陈总，您这时间卡得，比地铁时刻表还准。”

“过奖。”陈默晃了晃手里的咖啡杯，“卡点上班是门艺术。”

电梯门打开，技术部的工位区已经坐满了人。但气氛不太对劲，几个程序员盯着电脑屏幕，表情凝重得像在破解核弹密码。

陈默走到自己工位——没错，升职后他依然没换位置，美其名曰“保持基层视角”——刚放下包，系统提示音就在脑子里响了。

【检测到宿主准时上班，摆烂指数-0.1】

【当前摆烂指数：50.3/100】

陈默心里骂了句，这破系统连准时上班都要扣分。他明明踩着最后一分钟进来的！

“陈总。”张莉抱着一叠文件快步走来，“星海集团的李总刚才又打电话来确认，说想今天见面谈合作。”

“不是说了周二吗？”

“他说周二临时有事，今天下午三点可以。”张莉压低声音，“星海是咱们最大的潜在客户，这次合作要是谈成了，下半年的业绩就稳了。”

陈默看了眼系统面板，任务栏里那个“团队摆烂提升”的任务正闪着红光。

一个月内把团队平均摆烂指数从12.3提升到30，这难度相当于让一群工作狂突然学会躺平。

“今天不行。”陈默摇头，“我有安排。”

张莉愣住了：“什么安排比见星海的李总还重要？”

“晒太阳。”

“……”

陈默没理会张莉错愕的表情，转身走向技术部。小刘正戴着耳机敲代码，黑眼圈重得像被人揍了两拳。

“小刘。”陈默拍了拍他的肩膀。

小刘吓得差点把键盘拍飞：“陈、陈总！”

“昨天几点睡的？”

“呃……凌晨一点。”小刘心虚地移开视线，“就、就优化了一下数据库索引，没干别的。”

陈默眯起眼睛。系统面板上，小刘的个人摆烂指数显示为8.7/100，比昨天的12.3还低了。

“我记得我昨天说过什么？”陈默的声音很平静。

小刘的额头开始冒汗：“您说、说周日强制休息……”

“那你现在在干什么？”

“我、我就是忍不住……”小刘的声音越来越小，“昨晚看到王振华发的朋友圈，他们公司凌晨三点还灯火通明，我怕咱们落后……”

陈默走到投影仪前，打开了一个共享文档。技术部所有人都抬起头。

“各位。”陈默的声音不大，但整个工位区都安静了，“我知道你们在担心什么。王振华的公司天天加班到半夜，客户会觉得他们更专业，对吧？”

几个程序员点了点头。

“那我问你们一个问题。”陈默调出服务器监控数据，“咱们上周修复的那个核心数据库漏洞，用了多久？”

小刘举手：“三天。我们三个工程师轮班，72小时不间断修复。”

“王振华的公司去年遇到类似问题，用了多久？”

“我听说……”另一个程序员推了推眼镜，“他们用了整整两周，而且修复后还出了两次回滚。”

陈默点点头：“三天对两周，谁更专业？”

没人说话。

“专业不是靠加班时长堆出来的。”陈默关掉投影仪，“从今天开始，技术部实行新规：每天下午五点准时下班，周末双休。如果工作做不完，要么是任务分配有问题，要么是效率有问题。这两种情况，都该找我这个负责人，而不是靠你们透支健康。”

工位区一片寂静。

小刘张了张嘴，想说什么，但看到陈默的眼神，又把话咽了回去。

【检测到宿主强制团队休息，团队摆烂指数平均+2.3】

【当前团队平均摆烂指数：14.6/100】

陈默满意地点点头。这才对嘛。

回到自己工位，陈默打开系统商城。经验值攒了1050点，正好够买那个新上架的道具“摆烂光环（初级）”。

【道具：摆烂光环（初级）】
【效果：以宿主为中心，半径十米内的队友摆烂指数自然增长速度+50%】
【持续时间：8小时】
【价格：1000经验值】

陈默毫不犹豫地点击购买。

一道淡金色的光晕从他身上扩散开来，覆盖了整个技术部工位区。正在敲代码的程序员们突然感觉肩膀一松，那种无形的压迫感减轻了不少。

【摆烂光环已激活】

【检测到范围内12名队友，摆烂指数增长速度+50%】

陈默靠在椅背上，喝了口咖啡。阳光从落地窗洒进来，暖洋洋的，让人想打瞌睡。

“陈总。”张莉又凑了过来，“李总那边真的不行吗？他说可以等您到下午四点……”

“不行。”陈默闭上眼睛，“我下午要睡午觉。”

“……”

张莉欲言又止，最后叹了口气，转身离开。

下午两点，陈默准时躺在休息室的沙发上。系统提示音又响了。

【检测到宿主在工作时间午睡，摆烂指数+1】

【当前摆烂指数：51.3/100】

他满意地翻了个身，准备进入梦乡。

就在这时，手机震动起来。陈默眯着眼看了眼屏幕，是个陌生号码。

他按下接听键。

“陈默是吧？”电话那头传来一个傲慢的男声，“我是王振华。”

陈默瞬间清醒了。

王振华，竞争对手公司的老板，那个在朋友圈晒凌晨三点加班照的内卷狂魔。

“王总有何贵干？”陈默的声音懒洋洋的。

“听说你们公司最近在抢星海集团的单子？”王振华冷笑，“我劝你识相点，主动退出。星海的李总是我老同学，这个单子早就内定给我们了。”

陈默坐起身，看了眼系统面板。

【新任务触发：挂断竞争对手的挑衅电话】
【任务奖励：经验值+200，道具“反内卷护盾（一次性）”】

“王总。”陈默的声音依然平静，“如果你是来谈合作的，我们可以约时间。如果你是来放狠话的……”

他顿了顿。

“那我建议你多喝热水，少熬夜。”

说完，陈默直接挂断了电话。

【任务完成！】
【经验值+200】
【获得道具：反内卷护盾（一次性）】
【道具效果：使用后，24小时内所有针对宿主的内卷行为无效】

陈默挑了挑眉。这道具倒是有点意思。

他重新躺下，准备继续午睡。但手机又响了，这次是张莉。

“陈总！”张莉的声音很急，“星海的李总突然说要今天下午来公司参观！三点钟到！”

陈默皱起眉头：“我不是说了今天不见客吗？”

“他说只是参观，不谈合作……”张莉的声音越来越小，“但我总觉得不对劲，会不会是王振华那边搞鬼？”

陈默看了眼时间，两点四十五分。

“让他来。”陈默说，“但告诉所有人，该下班下班，该休息休息。谁要是敢加班，扣奖金。”

“这……”

“执行。”

陈默挂断电话，起身走出休息室。技术部的程序员们已经收拾东西准备下班了，看到陈默出来，都停下脚步。

“陈总，真的要走吗？”小刘小声问，“星海的人要来了……”

“走。”陈默摆摆手，“天塌下来有我顶着。你们该干嘛干嘛。”

程序员们面面相觑，最后还是三三两两地离开了。

三点整，公司门口传来动静。

陈默走到前台，看到一个穿着定制西装的中年男人走进来，身后跟着两个助理。男人扫视了一圈空荡荡的办公区，眉头皱了起来。

“陈总？”男人伸出手，“我是星海集团的李建国。”

陈默和他握了握手：“李总，欢迎参观。不过您可能来得不巧，我们公司五点准时下班，现在大家已经走了。”

李建国愣住了：“现在才三点……”

“是啊。”陈默点点头，“所以您有两个选择：要么现在参观，但只能看到我；要么改天预约，我让全体员工欢迎您。”

李建国的嘴角抽了抽。他身后的助理凑到他耳边说了什么，李建国的表情变得更加微妙。

“陈总。”李建国收回手，语气冷了下来，“我听说你们公司很特别，不加班，不内卷，还强制员工休息？”

“没错。”

“那我想问，如果遇到紧急项目，工期很紧，你们怎么办？”

陈默笑了：“李总，您做企业这么多年，应该明白一个道理：真正紧急的项目，往往是因为前期规划出了问题。我们公司会在项目开始前做好充分准备，避免这种情况发生。”

“如果避免不了呢？”

“那就延期。”陈默说得理所当然，“项目可以延期，员工的健康不能透支。这是我们公司的底线。”

李建国盯着陈默看了足足十秒钟，然后突然笑了。

“有意思。”他转身对助理说，“把合同拿来。”

助理从公文包里取出一份文件，递给李建国。

李建国把文件拍在前台桌上：“陈总，这是星海集团下半年的软件开发合同。本来我是打算给王振华的，但现在我改变主意了。”

陈默挑了挑眉：“为什么？”

“因为我做了二十年企业，见过太多靠压榨员工堆业绩的公司。”李建国说，“但像你们这样，敢在下午三点让员工下班的，我是第一次见。”

他顿了顿，补充道：“而且，我刚才在门口看到你们的技术总监了。他背着钓鱼竿，说要去水库钓夜鱼。一个能在工作日去钓鱼的技术团队，要么是疯子，要么是真正的高手。”

陈默笑了：“李总，您选哪个？”

“我选后者。”李建国伸出手，“合作愉快。”

陈默和他握了握手。系统提示音适时响起。

【检测到宿主在非工作时间谈成重大合作，摆烂指数+3】

【当前摆烂指数：54.3/100】

【团队摆烂指数平均值+5.2，当前平均值：19.8/100】

送走李建国后，陈默回到工位。张莉从角落里冲出来，眼睛瞪得溜圆。

“陈总！您怎么做到的？！”

“什么怎么做到的？”

“三点让员工下班还能谈成合作啊！”张莉激动得语无伦次，“李总刚才出门的时候还说，要把我们公司推荐给其他合作伙伴！”

陈默喝了口咖啡：“很简单，我们只是做了该做的事。”

“该做的事？”

“对。”陈默放下杯子，“尊重员工，尊重时间，尊重专业。这些本来就是企业该做的，只不过现在没多少人记得了。”

张莉若有所思地点点头。

陈默看了眼窗外，夕阳正把天空染成橘红色。他伸了个懒腰，收拾东西准备下班。

【检测到宿主准时下班，摆烂指数+0.5】

【当前摆烂指数：54.8/100】

走出公司大门，陈默深吸一口气。晚风带着初夏的暖意，让人浑身舒坦。

手机震动，是小刘发来的消息。

“陈总！我钓到一条五斤重的鲤鱼！明天带给您尝尝！”

陈默笑着回复：“好，明天中午加菜。”

他收起手机，朝地铁站走去。身后，公司的灯光一盏盏熄灭，整栋大楼陷入黑暗。

但陈默知道，明天太阳升起时，这里会重新亮起灯光。

不是那种为了加班而亮的惨白灯光，而是为了工作而亮的温暖光芒。

这就够了。

【本章结束】
