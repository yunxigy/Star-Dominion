# 真相

U盘插进电脑接口的瞬间，陈默的手指在发抖。

不是害怕，是愤怒。

屏幕亮起，一个加密文件夹跳出来。陈默深吸一口气，点开第一个文件。

“资金流向分析.xlsx”

表格密密麻麻，每一行都是一笔转账记录。陈默的目光死死盯着收款方那一栏——

“鑫海资本”。

这个他从未听过的名字，此刻像一根刺扎进眼睛里。

他继续往下翻。2022年3月，500万。2022年7月，800万。2023年1月，1200万……

最后一行，两周前。

“项目分红，2000万。”

陈默的手指停在鼠标上，指节发白。他想起李明远在会议室里那张永远挂着温和笑容的脸，想起他说“公司正在困难时期，大家要共渡难关”时的表情。

共渡难关。

他点开第二个文件夹。

“风控报告对比.pdf”

两份报告并排放在屏幕上。左边那份是张工的，标题用红色加粗标注：“高风险项目，建议终止”。右边那份是王振华的，标题是：“前景广阔，建议加大投入”。

陈默记得这个项目。去年公司讨论的时候，张工在会上据理力争，说这个项目的数据有问题，风险太高。三天后，张工被调去了后勤部。

而王振华，那个只会拍马屁的废物，接替了张工的位置。

现在陈默知道为什么了。

第三个文件夹里是一段录音。

陈默点开播放键，李明远的声音从音箱里传出来，带着那种他熟悉的、慢条斯理的语调：

“老周这个人，太死板了。”

另一个声音，陈默认出来是老周的直属领导，财务部的王副总：“那怎么办？他手里那些数据……”

“数据可以改。”李明远说，“人也可以换。老周不是一直想提前退休吗？给他办个病退，体体面面的。”

录音到这里戛然而止。

陈默盯着屏幕，眼睛一眨不眨。他想起老周最后一次来公司，收拾东西的时候，对他说的那句话：

“小陈，有些事，不是看不见就不存在。”

当时他以为老周只是感慨。

现在他明白了。

老周早就看见了。

陈默点开最后一个文件，一个Word文档，标题是《给小陈》。

文档很短，只有一页。

“小陈：

如果你看到这个，说明我已经不在了。

密码用的是‘Zhang’，不是因为我喜欢张工，是因为张工是第一个敢说真话的人。我希望你也能成为这样的人。

这三年，我收集了李明远他们所有的证据。他们挪用公款，篡改报告，安插亲信。公司早就烂透了，只是外面那层皮还光鲜。

我知道你在观察，在思考。你比他们都聪明，也比他们都谨慎。但有时候，太谨慎也是一种懦弱。

我把这些交给你，不是要你替我报仇。我是希望你明白：有些事，总要有人去做。

如果你选择把这些交给警方，我支持你。

如果你选择把这些公之于众，我也支持你。

如果你选择把这些删掉，假装什么都没发生，我……也理解。

但我会失望。

老周留”

陈默把这段话看了三遍。

每一遍，他的拳头都握得更紧。

系统提示音在耳边响起：

【情绪分析完成】

【愤怒：73%】

【悲伤：15%】

【其他：12%】

陈默关掉提示框。他不需要系统告诉他现在是什么心情。

他点开系统的任务界面，看着上面那行字：

【主线任务：改变整个职场文化】

【进度：0%】

他想起系统之前说的话：“真正的摆烂，是改变整个职场文化。”

改变。

怎么改变？

陈默看着屏幕上的证据。这些文件像一把刀，可以捅进李明远的心脏。但刀捅出去，他自己也可能被反噬。

系统又跳出一条提示：

【模拟推演中……】

【方案一：交给警方】

【成功率：42%】

【风险：李明远可能通过关系压下案件，或转移证据。陈默可能遭到报复。】

【方案二：交给媒体】

【成功率：31%】

【风险：媒体可能迫于压力不报道，或报道后被公关。陈默可能成为众矢之的。】

【系统建议：宿主当前行为已触发高难度任务，风险指数级上升。是否继续？】

陈默看着那行“是否继续”，手指悬在鼠标上。

继续，意味着和李明远正面对抗。那是一个在公司经营了十几年的老狐狸，手里有资源，有人脉，有手段。

不继续，意味着把U盘拔出来，格式化，然后当什么都没发生过。继续在公司里混日子，等着被裁员，或者被调去边缘部门。

陈默想起老周收拾东西时的背影。

想起张工被调去后勤部时，眼神里的灰暗。

想起那些在会议上沉默的同事，那些明明看见问题却不敢说话的人。

他点开系统对话框，输入：

“如果我选择继续，系统会帮我吗？”

系统回复很快：

【系统只提供任务和奖励，不提供直接帮助。】

【但宿主已完成隐藏任务“真相的代价”，获得奖励：危机直觉+5，可提前0.5秒预感危险。】

【是否接受？】

陈默点了接受。

一股暖流从脊椎升起，扩散到全身。他说不清那是什么感觉，但好像对周围的感知变得更敏锐了。

他听见走廊里有人走过的脚步声，听见隔壁办公室键盘敲击的节奏，甚至听见楼下停车场里汽车发动的声音。

这些声音以前都淹没在背景里，现在却清晰得刺耳。

陈默拔出U盘，握在手心。

金属外壳冰凉，但他握得很紧。

他站起身，走到窗边。楼下是公司的停车场，几辆黑色轿车停在角落里，那是李明远和王副总的车。车窗反着光，看不见里面。

陈默想起系统说的“风险指数级上升”。

他不怕风险。

他怕的是，像老周那样，明明看见了真相，却只能把希望寄托在别人身上。

他不想那样。

陈默转身回到电脑前，打开一个新的加密邮件客户端。这是他之前为了接私活注册的，用的是虚拟身份。

他开始打字。

收件人：市经侦支队公开邮箱

主题：举报材料：XX公司高管涉嫌挪用公款、财务造假

正文：

“您好：

本人实名举报XX公司副总经理李明远、财务部副总王某等人，涉嫌挪用公款、篡改风控报告、安插亲信。证据见附件。

举报人：陈默”

他停顿了一下，把“实名举报”四个字删掉，改成“匿名举报”。

然后又删掉，重新打上“实名举报”。

他盯着那四个字看了很久。

系统提示音又响了：

【检测到宿主情绪波动】

【建议：匿名举报更安全，但实名举报可信度更高。】

【系统不提供选择建议，但宿主需明白：选择即承担。】

陈默点了发送。

邮件发出去的那一刻，他听见自己的心跳声，咚咚咚，像敲鼓。

然后他关掉电脑，把U盘放进口袋，拿起外套。

走出办公室的时候，他看见李明远正好从会议室出来，身边围着一群人。李明远看见他，微微点头，露出那种标准的、温和的笑。

“小陈，这么晚还在加班？”

陈默看着他，第一次没有躲开他的目光。

“嗯，刚忙完。”

“早点回去休息。”李明远拍拍他的肩膀，“公司需要你们这些年轻人。”

陈默点点头，转身走向电梯。

电梯门关上的那一刻，他看见李明远还在看着他，笑容没变，但眼神里好像有什么东西，一闪而过。

陈默按下一楼的按钮。

电梯下行的时候，系统提示音再次响起：

【隐藏任务触发：反击】

【任务内容：在李明远发现举报前，收集更多证据。】

【奖励：未知】

【风险：极高】

【是否接受？】

陈默看着电梯楼层数字不断跳动。

12、11、10……

他点了接受。

电梯到达一楼，门开了。

陈默走出去，外面是夜晚的街道，霓虹灯闪烁，车流不息。

他抬头看了看公司大楼，顶层的灯还亮着，那是李明远的办公室。

然后他转身，走向地铁站。

口袋里，U盘硌着他的大腿。

他走得很快，但很稳。

系统界面在视野角落里闪烁，显示着新的任务详情：

【反击任务第一阶段：获取李明远近三年的行程记录】

【线索：公司车队司机，老刘】

【提示：老刘的女儿下周要高考，他最近很焦虑。】

陈默走出地铁站，夜风吹在脸上，有点凉。

他想起老周文档里的最后一句话：

“有些事，总要有人去做。”

现在，那个人是他了。

陈默加快脚步，走向家的方向。

明天，他要去找老刘聊聊。

关于高考，关于焦虑，也关于——

李明远那些见不得光的行程。
