# 内鬼现形

会议室的空气像凝固了一样。

所有人的目光都聚焦在林小雨身上。她坐在会议桌末端，脸色苍白得像一张纸，手指紧紧攥着笔记本的边缘，指节因为用力而泛白。

“林小雨。”陈默的声音平静得可怕，“去年10月20日凌晨三点，你为什么登录技术文档库？”

林小雨的嘴唇颤抖了一下，没有说话。

技术部老张推了推眼镜，调出服务器日志投影到大屏幕上：“凌晨三点零七分，你的账号访问了‘核心技术架构V2.3’文档，浏览时长四十二分钟。三点四十九分退出系统。”

“我……”林小雨的声音细若蚊蝇，“那天我失眠，想看看文档有没有更新……”

“凌晨三点看文档更新？”法务主管小王皱眉，“林工，你不是技术部的，你是产品经理。那个时间点，你为什么要看技术文档？”

林小雨低下头，不说话了。

陈默站起身，走到她面前。他的影子投在林小雨身上，像一座山。

“王建国给了你什么？”

这句话像一把刀，直接捅破了最后一层窗户纸。

林小雨猛地抬头，眼睛里全是惊恐：“你怎么知道——”

话说到一半，她意识到自己说漏了嘴，立刻捂住了嘴。

会议室里响起倒吸冷气的声音。

陈默从口袋里掏出手机，点开一张截图，放大，放到林小雨面前。那是李正阳律师发来的微信聊天记录截图，时间显示去年10月28日，王建国给一个备注为“星海内部”的人发消息：“初稿拿到了，3月前提交专利申请。”

“这个‘星海内部’，”陈默说，“是你吧？”

林小雨的身体开始发抖。

“我没有……我没有卖公司机密……”她语无伦次，“王总说只是看看，他说只是想了解一下我们的技术方向，不会用的……”

“不会用？”陈默冷笑，“他拿着我们的技术文档，申请了专利，现在反过来告我们侵权。林小雨，你知不知道你做了什么？”

林小雨的眼泪掉了下来：“我真的不知道会这样……王总说只是学术交流，他说不会商用的……”

“学术交流？”老张气得拍桌子，“你把核心技术文档给竞争对手看，这叫学术交流？林小雨，你脑子进水了吗？”

“我……”林小雨泣不成声，“王总说，如果我帮他这个忙，他会推荐我进云海科技，年薪翻倍……我，我家里急需用钱，我妈生病了，手术费要三十万……”

会议室里沉默了。

陈默盯着林小雨看了很久，然后转身回到主位坐下。

“现在不是追究责任的时候，”他说，“现在最重要的是，我们怎么打赢这场官司。”

系统提示音在陈默脑海中响起：

【叮！隐藏任务“证据猎人”进度更新：3/3】

【任务完成！奖励：商业间谍识别技能（初级）】

【技能说明：宿主可通过微表情和肢体语言，初步判断对方是否在说谎。当前准确率：65%】

陈默看了一眼林小雨，她的肩膀在微微发抖，眼神躲闪，不敢与任何人对视。技能反馈的信息是：她说的是真话，但隐瞒了部分细节。

“林小雨，”陈默说，“现在给你一个将功补过的机会。把你知道的所有事情，一字不漏地说出来。王建国是怎么联系你的？你们见过几次面？他还问你要过什么？”

林小雨擦了擦眼泪，开始断断续续地说起来。

原来，去年九月，云海科技的王建国以“行业交流”为名，邀请星海科技的几位核心员工吃饭。林小雨去了，席间王建国对她格外热情，说很欣赏她的产品思维，想挖她去云海。

“他说云海正在筹备新产品线，需要一个懂技术又懂产品的人，”林小雨说，“开的年薪是五十万，是我现在的两倍多。”

“然后呢？”陈默问。

“然后……十月中旬，王总单独约我喝咖啡，”林小雨的声音越来越小，“他说想了解一下我们技术架构的思路，说只是学术参考，不会商用。我……我就把技术文档初稿发给他了。”

“就一次？”陈默问。

林小雨犹豫了一下，点点头。

但陈默的技能反馈告诉她：她在说谎。

“林小雨，”陈默的声音冷了下来，“我再给你一次机会。说实话。”

林小雨的身体僵住了。

“我……”她张了张嘴，最后崩溃地哭了出来，“还有一次……今年一月，王总又找我，说专利申请需要一些技术细节补充，让我把最新的测试数据发给他……我发了……”

会议室里一片死寂。

老张气得浑身发抖：“你！你知不知道那些测试数据是我们花了三个月才做出来的？！”

“我知道……我知道我错了……”林小雨哭得几乎喘不上气，“但我真的没办法……我妈的手术费……王总说只要我帮他，他不仅给我高薪，还先借我二十万……”

“所以你就卖了公司？”小王冷冷地说。

陈默抬手制止了他们。

“现在不是吵架的时候，”他说，“林小雨，你和王建国的所有联系记录，微信、短信、邮件，全部交出来。还有，你们见面的时间、地点、谈话内容，写一份详细的情况说明。现在就写。”

林小雨抹着眼泪点头。

陈默看向李正阳律师的视频窗口：“李律师，这些证据够不够？”

李正阳的表情严肃：“如果这些聊天记录和情况说明属实，我们可以反诉云海科技侵犯商业秘密。但问题是，我们需要证明这些技术信息确实属于商业秘密，而且云海是通过不正当手段获取的。”

“技术文档的密级标注，”老张立刻说，“我们的技术文档从V2.0开始就有密级标注，核心技术架构属于‘绝密’级别，访问需要三级权限。林小雨的产品经理账号只有二级权限，她是越权访问。”

“那她是如何越权的？”李正阳问。

老张调出权限管理系统日志：“去年10月18日，系统管理员周浩给林小雨的账号临时开通了三级权限，理由是‘产品需求评审需要’。但根据项目记录，那段时间根本没有需要三级权限才能参与的产品评审。”

所有人的目光转向坐在角落的周浩。

周浩是技术部的系统管理员，三十出头，戴着黑框眼镜，平时话不多，存在感很低。此刻他脸色发白，双手放在桌下，不知道在做什么。

“周浩，”陈默叫他，“解释一下。”

周浩推了推眼镜：“我……我不记得了。可能是林小雨当时说需要权限看文档，我就给她开了。”

“不记得？”陈默盯着他，“给绝密文档开权限这么大的事，你不记得？”

周浩低下头，不说话。

陈默的技能反馈再次启动：周浩在说谎，而且他非常紧张。

“周浩，”陈默的声音平静得可怕，“你是不是也收了王建国的好处？”

周浩猛地抬头，眼睛里全是惊恐。

“我没有！我就是……就是帮林小雨一个小忙……”

“小忙？”老张气得站起来，“你违规给绝密文档开权限，这叫小忙？周浩，你知不知道这是要负法律责任的？”

周浩的嘴唇哆嗦着，说不出话。

陈默站起身，走到周浩面前。他比周浩高半个头，俯视着他。

“王建国给了你多少？”

周浩的身体开始发抖。

“我……我没有收钱……”他的声音几乎听不见，“王总说，只是让林小雨看看文档，不会外泄……他说这是行业内的正常交流……”

“正常交流需要你违规开权限？”陈默冷笑，“周浩，你觉得我会信吗？”

周浩突然崩溃了：“我没办法啊！王总说他手里有我的把柄！去年我……我挪用了一笔服务器采购款，被他发现了……他说如果我不帮忙，就向公司举报我……”

会议室里再次陷入死寂。

陈默闭上眼睛，深吸一口气。

他没想到，公司内部竟然烂到了这种程度。一个产品经理，一个系统管理员，都被竞争对手策反了。而这一切，都发生在他的眼皮子底下。

“还有谁？”陈默睁开眼，扫视全场，“还有谁和王建国有联系？”

所有人都低下头，不敢与他对视。

陈默知道，现在不是追究的时候。当务之急是打赢官司，保住公司。

“好，”陈默说，“现在情况很清楚了。云海科技通过非法手段获取了我们的商业秘密，并以此申请专利，反过来告我们侵权。我们的应对策略是：第一，反诉云海侵犯商业秘密；第二，申请对方专利无效；第三，追究林小雨和周浩的法律责任。”

他看向李正阳：“李律师，我们需要在45小时内完成诉讼策略方案。你那边能配合吗？”

李正阳点头：“我今晚就飞过来，明天一早和你们团队对接。证据材料越详细越好，尤其是林小雨和王建国的联系记录，以及技术文档的密级证明。”

“老张，”陈默看向技术部主管，“你负责整理技术文档的版本记录、密级标注、访问日志，证明这些信息确实属于商业秘密。”

“小王，”他又看向法务主管，“你负责起草反诉状和专利无效宣告申请，重点是证明对方通过不正当手段获取技术信息。”

“林小雨，周浩，”陈默最后看向那两人，“你们两个，现在立刻写情况说明，把所有事情写清楚。如果你们配合，公司可以考虑从轻处理；如果你们隐瞒任何细节……”

他没有说完，但威胁已经很明显了。

林小雨和周浩拼命点头。

会议结束后，众人陆续离开会议室。陈默站在落地窗前，看着窗外的城市夜景。

系统提示音响起：

【叮！主线任务“硬核应诉”倒计时：43小时15分】

【当前进度：证据收集完毕，诉讼策略制定中】

【额外奖励触发条件：在48小时内成功反诉云海科技，并让对方撤诉】

【奖励预览：法律知识库（中级）、危机公关技能（初级）、公司声誉值+1000】

陈默没有理会系统。他现在满脑子都是林小雨和周浩的脸。

他没想到，自己一手建立的公司，竟然会从内部被腐蚀。如果不是这次专利诉讼，他可能永远都不会发现。

“陈总。”

身后传来声音。陈默转身，看到李正阳律师站在会议室门口。他穿着深灰色西装，提着一个黑色公文包，风尘仆仆的样子。

“李律师？你怎么这么快？”

“我订了最近一班飞机，”李正阳走进来，“事情紧急，耽误不得。”

他走到陈默面前，压低声音：“陈总，有件事我必须提醒你。赵明远这个人，不简单。”

“赵明远？”

“云海科技的法务总监，”李正阳说，“业内人称‘专利屠夫’。他打专利官司，从来没有输过。而且……”

他顿了顿，眼神变得复杂：“五年前，我的一个朋友，也是做技术的，被赵明远用专利诉讼逼到破产。我朋友……最后自杀了。”

陈默皱眉：“所以你接这个案子，是为了……”

“为了报仇，”李正阳毫不掩饰，“赵明远毁了我朋友，我要让他付出代价。陈总，你放心，这个案子我会全力以赴。但你要小心，赵明远手段阴狠，什么事都做得出来。”

陈默点点头：“我会小心的。”

李正阳从公文包里拿出一叠文件：“这是我整理的一些资料，关于赵明远过去打的专利官司。你可以看看，了解一下他的套路。”

陈默接过文件，翻了几页。上面全是专利诉讼的案例，每一个都是云海科技胜诉，而且对手的下场都很惨——破产、被收购、创始人坐牢。

“他最喜欢用的手段，”李正阳说，“就是先申请专利，然后告竞争对手侵权。一旦官司打起来，不管输赢，对手的公司都会元气大伤。很多小公司根本耗不起，只能认输。”

“但我们不一样，”陈默说，“我们有证据证明他们是通过非法手段获取技术的。”

“证据是关键，”李正阳说，“但赵明远一定会想办法销毁证据，或者质疑证据的真实性。我们要做好万全的准备。”

两人又讨论了一个多小时，直到凌晨两点，李正阳才离开。

陈默回到办公室，没有睡觉。他打开电脑，开始整理证据材料。

系统提示音再次响起：

【叮！检测到宿主正在工作，触发隐藏任务“深夜加班”】

【任务要求：连续工作超过4小时】

【任务奖励：精力恢复药剂（小）】

【失败惩罚：明天上班迟到扣工资】

陈默看了一眼任务，苦笑了一下。

系统还是老样子，一边鼓励摆烂，一边又给他发布这种任务。

他继续工作，把林小雨和周浩的情况说明、技术文档的访问日志、微信聊天记录截图，全部整理成文件夹，发给李正阳。

做完这些，已经是凌晨五点。

陈默靠在椅子上，闭上眼睛。他太累了，但脑子里却停不下来。

他想起公司刚成立的时候，只有他和老张两个人，在一个小办公室里，没日没夜地写代码。那时候虽然辛苦，但心里是踏实的。

现在公司做大了，人多了，问题也多了。内部腐败、竞争对手打压、法律纠纷……一件接一件，压得他喘不过气。

“陈总。”

办公室门被敲响。陈默睁开眼，看到老张站在门口。

“老张？你怎么还没走？”

“睡不着，”老张走进来，手里拿着一杯咖啡，“给你。”

陈默接过咖啡，喝了一口。苦涩的味道让他清醒了一些。

“林小雨和周浩的情况说明，我看过了，”老张说，“写得很详细。但我觉得……事情可能没那么简单。”

“什么意思？”

“林小雨说，王建国只找过她两次，”老张说，“但我查了一下，去年十月到今年三月，林小雨的银行账户有五笔大额进账，总共四十万。如果王建国只借了她二十万，那另外二十万是哪来的？”

陈默皱眉：“你查了她的银行流水？”

“我让财务查的，”老张说，“以公司内部调查的名义。陈总，我觉得林小雨可能还有隐瞒。”

陈默沉默了一会儿。

“还有周浩，”老张继续说，“他说王建国用挪用公款的事威胁他，但我查了去年的服务器采购记录，没有发现异常。周浩可能在说谎。”

“你的意思是？”

“我觉得，林小雨和周浩可能都是自愿的，”老张说，“他们可能早就被王建国收买了，这次被发现，才编出那些借口。”

陈默靠在椅背上，揉了揉太阳穴。

“不管真相是什么，”他说，“现在最重要的是打赢官司。等官司打完，再慢慢调查。”

老张点点头：“你说得对。对了，陈总，有件事我一直想问你。”

“什么事？”

“你为什么……突然变得这么厉害？”老张犹豫了一下，“我是说，以前你在公司，虽然能力不错，但也没这么……果断。这次专利诉讼，你处理得简直像个老手。”

陈默笑了笑：“可能是被逼出来的吧。”

他没有提系统的事。有些秘密，最好永远埋在心里。

老张没有追问，拍了拍他的肩膀：“不管怎么样，公司有你在，我就放心了。你早点休息，明天还有一场硬仗要打。”

老张离开后，陈默又在办公室坐了一会儿。

他打开系统界面，看了看自己的属性：

【宿主：陈默】

【当前状态：疲劳（精力值35/100）】

【技能：商业间谍识别（初级）、法律知识库（初级）、危机公关（初级）】

【公司状态：诉讼危机中，声誉值-200】

【摆烂值：1250】

【系统提示：宿主已连续工作6小时，触发“工作狂”负面状态，效率下降20%。建议宿主立即休息，否则可能触发“过劳死”隐藏结局。】

陈默关掉系统界面，站起身。

他走到窗边，看着天边泛起的鱼肚白。

新的一天开始了。

而他的战斗，才刚刚开始。
