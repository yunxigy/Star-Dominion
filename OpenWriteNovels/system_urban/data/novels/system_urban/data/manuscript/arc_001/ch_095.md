# 第九十五章 摆烂连锁

地铁车厢轻微摇晃，陈默靠在门边的扶手上，手里还攥着那个红彤彤的苹果。

【支线任务：老太太的苹果】
任务要求：接受并妥善处理这份善意
奖励：经验值+30，摆烂值+2
状态：已完成

系统提示音在脑海里响起，陈默嘴角微微上扬。这年头，连摆烂都能收到苹果，这世界真是越来越魔幻了。

他低头看了眼手机，母亲的消息已经发过来了。

“儿子，晚上回来吃饭？妈给你炖排骨。”

陈默手指在屏幕上敲了几下：“妈，我晚上回去。对了，刚才在地铁上遇到个老太太，她儿子叫张伟，以前在星耀科技干过，身体不太好。”

消息发出去不到十秒，母亲的电话就打过来了。

“喂？妈？”

“你这孩子，怎么又遇到这种事？”母亲的声音里带着担忧，“那老太太看着多大岁数？”

“六七十吧，头发都白了。”陈默换了个姿势站着，“她说她儿子以前在星耀科技干，天天加班到半夜，身体都熬坏了。”

电话那头沉默了几秒。

“儿子，你那个公司……”母亲欲言又止，“你别太拼了，知道吗？钱够花就行。”

陈默笑了：“妈，我们公司五点下班，双休，不加班。”

“真的？”

“真的。我骗你干嘛？”

母亲这才松了口气：“那就好。对了，你让那小伙子投简历过来，咱们公司不是正招人吗？”

“我刚才已经跟老太太说了。”

“行，那晚上回来，妈给你炖排骨。还有你爸，他昨天还念叨你呢。”

挂了电话，陈默把手机揣回口袋。地铁到站，他随着人流走出车厢。

出站口，那个卖烤红薯的老大爷还在。

陈默走过去，老大爷抬头看见他，笑了：“小伙子，又见面了。”

“大爷，您这红薯怎么卖？”

“十块钱一个。”老大爷用铁钳翻了翻炉子里的红薯，“要哪个？”

陈默指了指最大的那个：“就这个吧。”

老大爷把红薯夹出来，用牛皮纸包好递给他：“送你了。”

“啊？”陈默愣住了，“这怎么好意思？”

“拿着吧。”老大爷摆摆手，“我看你是个好孩子。刚才那老太太，你跟她聊那么久，现在这年头，年轻人愿意跟老人家说话的不多了。”

陈默接过红薯，热乎乎的，烫手。

“大爷，您这……”

“拿着拿着。”老大爷又摆了摆手，“给我妈带回去，她肯定高兴。”

【隐藏任务：孝子的尊严（续）】
任务进度：2/3
任务要求：给母亲带一份礼物
奖励：待完成

系统提示再次响起。陈默看着手里的红薯，又看了看老大爷，突然觉得这世界也没那么糟。

“谢谢您，大爷。”

“客气啥。”老大爷笑了，露出几颗缺了的牙，“快回去吧，别让家里等急了。”

陈默点点头，拎着红薯往公司走。

会议室里瞬间安静了。

林远皱眉：“抵制？怎么抵制？”

林远接过手机，快速浏览了一遍，脸色越来越难看。

“这……这不是胡说八道吗？”他把手机传给旁边的人，“什么叫‘摆烂科技的成功是行业的悲哀’？什么叫‘这种模式不可持续’？”

陈默靠在椅背上，双手抱胸：“他们还找了七家公司联名，准备在峰会上联合声明，说咱们破坏行业规则。”

会议室里炸开了锅。

“这帮人疯了吧？”

“咱们招谁惹谁了？”

“他们自己996把员工身体搞垮了，现在来怪咱们？”

陈默抬手压了压，会议室安静下来。

“我叫大家来，不是让你们吵的。”他说，“我是想问，你们怎么看？”

林远第一个开口：“陈总，我觉得咱们不用理他们。咱们公司什么情况，咱们自己清楚。五点下班，双休，不加班，员工福利好，业绩还比他们强。他们说什么，有用吗？”

“对，咱们用业绩说话。”

“让他们说去呗，咱们又不少块肉。”

陈默点点头，没说话。

林远愣住了。

“让他们说去。”陈默拍了拍他的肩膀，“咱们正好省了广告费。”

“这老大爷，真客气。”母亲把红薯放在桌上，“快去洗手，排骨马上就好。”
