# 第五十三章 桌下的东西

新闻发布会定在下午三点。

星海科技总部大楼的多功能厅里，长枪短炮已经架好。记者们交头接耳，闪光灯此起彼伏。王董站在后台，手指无意识地敲击着桌面。

“股价又跌了两个点。”财务总监低声说。

王董没回头：“意料之中。”

陈默站在角落，看着手机屏幕上跳动的数字。系统面板在眼前浮现，那个“真相挖掘者”的进度条卡在60%，一动不动。

【限时任务：真相挖掘者】
【进度：60%】
【剩余时间：10小时15分】
【任务提示：桌下的东西可能比你想象的更多】

桌下有什么？

陈默盯着那行字，手指在裤缝上轻轻敲击。刚才在王董办公室，他已经分析出匿名爆料的文件是伪造的——创建时间戳对不上，李副总秘书的IP地址出现在不该出现的地方。但系统说“更多”，那就一定不止这些。

“陈默。”王董转过身，“待会儿你坐我右手边。”

“我？”陈默挑眉。

“你是第一个发现问题的人。”王董的眼神很沉，“而且，你跟李副总没有直接利益冲突。”

陈默懂了。王董要他当那个“局外人”的角色，让外界觉得这次危机处理是透明的、公正的。

三点整。

王董走上台，灯光打在他脸上，照出眼角的细纹。他清了清嗓子，台下瞬间安静。

“各位媒体朋友，下午好。”王董的声音很稳，“今天召开这个临时发布会，是针对网上流传的所谓‘匿名爆料’做出回应。”

他顿了顿，目光扫过全场。

“首先，我要明确一点——那份爆料文件是伪造的。”

台下一片哗然。

“伪造？”有记者举手，“王董，您有什么证据？”

“证据很充分。”王董示意助理打开投影仪，“这是爆料文件的元数据截图。大家看这里——文件创建时间是昨天下午四点十七分，但文件内容中提到的‘挪用公款’事件，根据我们的内部记录，发生在昨天下午三点五十分。”

他放大图片，指着时间戳：“也就是说，这份文件是在事件发生后二十七分钟创建的。但爆料者声称，这是‘长期收集的证据’。二十七分钟，怎么收集长期证据？”

台下响起窃窃私语。

“还有，”王董切换到下一张图，“这是文件创建时的IP地址。经过技术部门追踪，这个地址属于……”他停顿了一下，“李副总的秘书，刘婷。”

闪光灯疯狂闪烁。

“王董，这是不是意味着李副总涉嫌……”

“我不做任何没有证据的指控。”王董打断记者，“但我们会对这件事进行彻底调查。同时，我已经向董事会提议，暂停李副总的职务，直到调查结束。”

台下炸开了锅。

陈默坐在侧边，看着王董游刃有余地应对各种尖锐问题。老头子的手很稳，声音很平，但陈默注意到他左手一直插在口袋里——那是紧张时的小动作。

发布会持续了四十分钟。

散场时，陈默被几个记者围住。

“陈总，您作为第一个发现问题的人，能说说当时的情况吗？”

“陈总，您和李副总私下有过接触吗？”

“陈总——”

陈默抬起手，示意安静。

“我只说一句。”他看着镜头，“星海科技是一家透明的公司。任何试图用卑劣手段破坏公司声誉的行为，我们都会追查到底。”

说完，他转身离开。

走廊里，王董等在拐角。

“说得不错。”王董递给他一根烟。

陈默没接：“我不抽烟。”

“年轻人，好习惯。”王董自己点上，深吸一口，“但有时候，人需要点东西来压压惊。”

陈默看着他：“您在紧张？”

“当然紧张。”王董吐出一口烟，“李副总在公司十年了，根基很深。今天这步棋走得太急，打草惊蛇了。”

“就是要打草惊蛇。”陈默说，“蛇不动，我们怎么知道它往哪儿跑？”

王董盯着他看了几秒，忽然笑了：“你小子，胆子比我还大。”

“系统逼的。”陈默心里想，但嘴上没说。

手机震动了一下。

【支线任务“连环套”更新】
【剩余时间：22小时50分】
【新线索：爆料文件中提到的第三方支付公司“速达支付”，与李副总妻子名下的空壳公司存在关联交易】

陈默眯起眼睛。

速达支付。

这个名字他记得。上个月公司财务部提交的报销系统升级方案里，就提到了这家公司。当时他没在意，现在想来……

“王董，”陈默开口，“您知道‘速达支付’吗？”

王董的烟停在半空：“你怎么知道这个名字？”

“爆料文件里提到的。”陈默说，“说是李副总挪用的公款，都通过这家公司洗出去了。”

王董的脸色变了。

“走，回我办公室。”他掐灭烟，脚步很快。

办公室里，王董调出财务系统的后台数据。

“速达支付是我们去年合作的第三方支付平台。”他一边操作一边说，“当时李副总推荐的，说费率低、到账快。董事会讨论过，我也同意了。”

“合作金额多大？”

“每个月流水大概三千万。”王董的手指停在屏幕上，“等等……这里有问题。”

陈默凑过去看。

屏幕上是速达支付的交易明细。大部分交易都很正常，但有几笔大额转账的对手方账户，名字很奇怪——“鑫源商贸”、“宏图实业”、“鼎盛投资”。

“这些公司……”陈默皱眉，“都是空壳公司吧？”

王董没说话，直接打开另一个窗口，输入企业信息查询。

结果出来了。

鑫源商贸，注册资金十万，法人代表张强，注册地址是某小区的三室一厅。

宏图实业，注册资金五万，法人代表李梅，注册地址是某写字楼的虚拟办公室。

鼎盛投资，注册资金八万，法人代表……王董的手指顿住了。

“刘婷。”他念出这个名字，“李副总的秘书。”

陈默倒吸一口凉气。

“所以，李副总通过速达支付，把公司的钱转到这些空壳公司，再通过空壳公司转到自己口袋？”

“不止。”王董的声音很冷，“你看这几笔转账的时间——都是在每个季度末。财务做账的时候，这些钱会被做成‘预付款’或者‘服务费’，平账之后就查不出来了。”

“那现在怎么查？”

“查银行流水。”王董站起来，“我让财务总监去调速达支付的完整流水，包括对手方信息。另外……”

他看向陈默：“你说要打草惊蛇，现在蛇已经动了。今天下午，李副总提交了辞职信。”

“辞职？”陈默一愣，“这么快？”

“他说‘个人原因’。”王董冷笑，“但我们都知道，他是想跑。”

“不能让他跑。”陈默说，“他手里还有东西。”

“什么东西？”

“我不知道。”陈默摇头，“但系统提示说‘桌下的东西比你想象的更多’。李副总在公司十年，经手的项目不止这些。如果只是挪用公款，他没必要这么急着跑。”

王董沉默了很久。

“海外项目。”他忽然说，“三年前，李副总主导了一个东南亚的基建项目。投资额很大，但回报一直不好。董事会质疑过几次，他都用‘当地政策变化’搪塞过去了。”

“项目现在还在进行？”

“还在。”王董打开另一个文件夹，“这是项目资料。你看这里——资金流向很复杂，经过好几个中间公司，最后才到当地合作方手里。”

陈默快速浏览文件，眼睛突然停在某一行。

“这个中间公司……‘星海国际投资有限公司’？”他抬头，“这是我们的子公司？”

“是，注册在开曼群岛。”王董说，“当时李副总说是为了避税，我也没多想。”

“开曼群岛……”陈默喃喃，“洗钱的好地方。”

王董的脸色彻底黑了。

“如果这个项目真的是洗钱通道，”他一字一顿，“那李副总挪用的公款，可能不止我们现在看到的这些。”

办公室的门被敲响了。

财务总监推门进来，脸色很难看：“王董，速达支付的流水调出来了。过去三年，通过这家公司转出去的资金……总共一点二亿。”

一点二亿。

王董的手在发抖。

“还有，”财务总监咽了口唾沫，“我们查了星海国际投资的账目。这家公司三年来没有一分钱收入，但支出……有八千万。”

“八千万花哪儿了？”

“大部分是‘咨询服务费’和‘项目管理费’。”财务总监说，“收款方都是当地的一些小公司，我们查不到具体信息。”

陈默的系统面板突然弹出提示。

【技能“商业嗅觉”（初级）触发】
【直觉：这些小公司可能根本不存在，或者只是壳公司。资金最终流向了某个个人或实体】

“王董，”陈默开口，“我觉得我们应该报警了。”

王董看着他，眼神复杂。

“报警意味着什么，你知道吗？”他问，“李副总会被抓，公司股价会暴跌，董事会会动荡，甚至可能影响到海外项目的正常运营。”

“不报警意味着什么，您知道吗？”陈默反问，“一点二亿的窟窿，八千万的不明支出。如果被监管机构查出来，星海科技可能直接退市。”

两人对视着。

财务总监站在一旁，大气不敢出。

最终，王董叹了口气。

“报警吧。”他说，“但不是现在。”

“为什么？”

“因为我们还不知道，李副总背后还有没有人。”王董走到窗边，看着楼下的车水马龙，“他在公司十年，关系网盘根错节。如果我们只抓他一个，其他人可能会销毁证据，甚至……”

他没说完，但陈默懂了。

“您是说，公司里还有他的同伙？”

“至少审计部有问题。”王董转身，“审计总监是李副总的大学同学，这件事你知道。”

陈默点头。

“所以，我们要先清理内部。”王董的眼神变得锐利，“陈默，我给你一个任务。”

“什么任务？”

“从明天开始，你兼任审计部特别顾问。”王董说，“名义上是协助调查匿名爆料事件，实际上……我要你查清楚审计部这三年的所有账目。”

陈默愣住了。

“我？查账？”他苦笑，“王董，我是做市场的，不是财务出身。”

“但你有直觉。”王董盯着他，“而且，你跟公司里任何人都没有利益牵扯。这是你最大的优势。”

陈默的系统面板再次弹出提示。

【新任务：审计风暴】
【任务内容：担任审计部特别顾问，查清过去三年的账目问题】
【任务奖励：未知】
【任务提示：有时候，最干净的人，反而能看到最脏的东西】

陈默看着那行提示，忽然笑了。

“好。”他说，“我接。”

王董点头：“明天上午九点，审计部开会。你准时到。”

“明白。”

离开王董办公室时，天已经黑了。

陈默站在电梯里，看着镜子里的自己。西装革履，头发梳得一丝不苟，但眼睛里有一种他自己都陌生的锐利。

三年前，他还是个被裁员的普通员工。

现在，他要查一个挪用一点二亿的案子。

电梯门打开，他走出去。

公司大厅里，员工们三三两两往外走，脸上带着下班后的轻松。没人知道，这家公司正在经历一场风暴。

陈默走到门口，忽然停下脚步。

他看见李副总了。

李副总站在停车场入口，正跟一个人说话。那人背对着陈默，看不清脸，但身形很熟悉。

陈默眯起眼睛，悄悄靠近了几步。

“……明天就走，机票已经订好了。”李副总的声音很低，但陈默还是听到了。

“钱呢？”那人问。

“已经转出去了，走的是老渠道。”李副总说，“你放心，查不到的。”

“最好查不到。”那人的声音冷下来，“否则，你知道后果。”

李副总点头哈腰：“明白，明白。”

那人转身离开。

陈默迅速躲到柱子后面，看着那人走向一辆黑色轿车。车门打开的瞬间，他看清了那人的侧脸。

心脏猛地一跳。

那人是……张伟。

张伟，陈默的前同事，三个月前因为挪用公款被开除的张伟。

他怎么会跟李副总在一起？

陈默的系统面板疯狂闪烁。

【警告！警告！】
【检测到关键人物“张伟”与当前事件存在关联】
【支线任务“连环套”更新】
【新线索：张伟可能与李副总存在合作关系，甚至可能是同一利益链条的成员】
【剩余时间：22小时15分】

陈默看着张伟的车消失在夜色中，手指慢慢攥紧。

桌下的东西，果然比他想象的更多。

他掏出手机，拨通了一个号码。

“喂，老周吗？”陈默的声音很平静，“帮我查个人。张伟，三个月前从星海科技离职的那个。对，我要他最近三个月的所有行踪记录，越详细越好。”

挂掉电话，陈默抬头看着星海科技的大楼。

灯火通明，像一座巨大的玻璃棺材。

而他，正在亲手撬开棺材盖。
