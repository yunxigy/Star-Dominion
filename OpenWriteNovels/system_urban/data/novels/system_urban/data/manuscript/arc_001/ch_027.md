# 职场暗战

默摆科技的会议室里，气氛有些凝重。

那封律师函就摆在会议桌中央，白纸黑字，盖着卷王科技的公章。法务部的张律师推了推眼镜，眉头拧成了疙瘩。

“陈总，这封律师函的措辞很专业，指控我们恶意挖角和窃取商业机密，如果走法律程序，即使我们最后赢了，也会消耗大量时间和精力。”

陈默靠在椅背上，手指轻轻敲着桌面。

陈默心里一动，但面上不显。他抬头看向会议室里的众人——赵明远、李姐、还有几个核心员工。

“大家怎么看？”

赵明远第一个开口，语气带着怒意：“这是赤裸裸的威胁！卷王科技自己留不住人，现在反过来告我们？他们挖我们公司的人还少吗？”

李姐冷静一些：“陈总，我查过了。卷王科技最近扩张太快，资金链很紧张。上季度财报不好看，股价跌了百分之十五。他们这时候发律师函，很可能是在转移内部矛盾。”

陈默点点头，心里已经有了判断。

“张律师，这封律师函，你正常处理就行。该回复就回复，该准备材料就准备。不要怕，也不要急。”

张律师松了口气：“明白。”

“赵明远，”陈默看向他，“你下午开个全员会议，把这件事原原本本告诉大家。不要隐瞒，也不要夸大。就说我们正在依法处理，让大家安心工作。”

赵明远愣了一下，随即笑了：“陈总，您这是要打明牌啊？”

“对。”陈默站起身，“我们默摆科技，做事光明正大。他们想玩阴的，我们偏不接招。散会。”

众人离开后，陈默独自坐在会议室里。

就在这时，手机响了。

是一个陌生号码。

陈默接起来，那边传来一个优雅的女声：“陈默先生吗？我是卷王科技的人力资源总监，刘芸。”

“刘总监，有什么事？”

“关于律师函的事，我想和陈先生私下聊聊。卷王科技其实很欣赏陈先生的能力，我们董事长特意让我联系您。”

陈默靠在椅背上，语气平淡：“聊什么？”

“我们想邀请陈先生加入卷王科技，担任副总裁。年薪五百万，外加期权。如果陈先生愿意，律师函的事情，我们可以当面解决。”

陈默笑了。

“刘总监，你们一边发律师函告我，一边又想挖我过去？这是什么操作？”

刘芸的声音依然优雅：“商场如战场，陈先生应该明白。我们只是想给陈先生一个更好的平台。默摆科技虽然发展不错，但毕竟规模有限。卷王科技是上市公司，能给您的，远不止这些。”

“那我要是不去呢？”

“陈先生，律师函的事情，如果您不配合，可能会很麻烦。我们法务部已经准备了充分的材料，如果走法律程序，对您的公司声誉会有影响。”

陈默的笑容更深了。

“刘总监，您这是在威胁我？”

“不敢。我只是陈述事实。”

“那我也陈述一个事实。”陈默的声音冷了下来，“我不会去卷王科技，也不会接受任何威胁。律师函的事，我们法庭上见。”

说完，他直接挂断了电话。

这个技能，倒是挺实用的。

下午三点，公司全员会议。

赵明远站在前面，手里拿着那份律师函的复印件。

“各位同事，我今天要告诉大家一件事。我们公司收到了卷王科技的律师函，指控我们恶意挖角、窃取商业机密。”

“什么？他们凭什么？”

“这不是贼喊捉贼吗？”

“陈总怎么说？”

会议结束后，果然有三个员工找到了赵明远。

“赵总，上周卷王科技的人联系过我，开价是我现在工资的三倍。”

“我也是，他们说只要我带项目过去，直接给我技术总监的职位。”

赵明远把这些信息汇总后，找到了陈默。

“陈总，看来卷王科技挖我们的人不是一天两天了。这次律师函，很可能就是因为他们挖角失败，恼羞成怒。”

陈默点点头：“意料之中。他们越是这样，越说明我们做对了什么。”

“那接下来怎么办？”

“该怎么办就怎么办。”陈默站起身，“公司正常运转，业务照常推进。对了，周明远周总那边，约的是下周三下午三点参观，对吧？”

“对，已经确认了。”

“好，你准备一下接待方案。要体现我们公司的特色。”

赵明远笑了：“明白，咱们公司的特色就是——不加班。”

“没错。”陈默也笑了，“就让周总看看，不加班的公司是怎么创造价值的。”

当天晚上，陈默回到家，刚打开门，手机又响了。

这次是周明远。

“陈总，听说你们收到律师函了？”

消息传得真快。

“周总消息灵通啊。”

“商场就这么大，有点风吹草动都知道。”周明远的声音里带着笑意，“需要帮忙吗？我在法律界有些朋友。”

“谢谢周总，暂时不用。我们能处理。”

“那好。不过陈总，卷王科技那边，你要小心。他们的老板王总，是个不择手段的人。当年我们和他们竞争一个项目，他们直接派人偷我们的标书。”

陈默心里一动：“还有这种事？”

“商场如战场嘛。”周明远叹了口气，“不过你们默摆科技的模式，确实让他们很头疼。你们不加班、不内卷，员工效率反而比他们高。这动了他们的根基啊。”

陈默明白了。

卷王科技的核心竞争力，就是“卷”。他们靠着996、狼性文化，逼着员工拼命干活，以此来降低成本、提高产出。

但现在，默摆科技证明了，不靠压榨员工，也能做出好产品、赢得客户。

这直接动摇了卷王科技的商业模式。

所以他们急了。
