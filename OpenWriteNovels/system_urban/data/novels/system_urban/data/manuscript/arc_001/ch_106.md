# 暗流

时光咖啡馆的玻璃门在身后合拢，陈默捏着那份青云科技王总签过字的意向书，指节微微发白。

陈默没理会系统提示，他盯着手机屏幕上苏晴发来的消息，眉头拧成了疙瘩。

“星耀法务部刚给三家目标公司发了律师函，要求签署星耀公约。另外，他们计划挖走目标公司核心技术骨干，林远在名单上。”

林远。

陈默的手指在屏幕上悬停了两秒。这个名字他太熟了——三个月前，正是林远从星耀法务部辞职，带着那份“技术共享基金”的草案初稿找上了他。那小子当时说：“陈总，我在星耀干了五年，看够了他们用专利大棒打压中小企业的手段。这份草案，是我能想到的唯一解法。”

现在，星耀要把他挖回去。

“狗东西。”陈默低声骂了一句，把手机塞回口袋。

咖啡馆外的阳光刺眼，他眯起眼睛，看见街对面一辆黑色轿车缓缓驶离。车窗摇下一半，露出半张脸——是星耀的人。他们一直在盯着。

陈默没理会，转身走向停车场。

【系统提示：检测到宿主情绪波动。建议：找个地方躺平，喝杯奶茶，奖励摆烂值+5。】

“闭嘴。”陈默拉开车门，发动引擎。

手机又震了。这次是林远。

“陈总，星耀的人找我了。”

林远的声音听起来很平静，平静得有些反常。

“我知道。”陈默把车开出停车场，“开价多少？”

“年薪翻三倍，外加期权。条件是立刻离职，加入星耀法务部，负责处理‘专利纠纷’。”

陈默的手指在方向盘上敲了敲：“你怎么想？”

电话那头沉默了几秒。

“陈总，我当初离开星耀，就是因为受不了他们那套‘用专利绞杀竞争对手’的玩法。现在他们想把我挖回去，让我去对付我们自己人……”林远顿了顿，“我拒绝了。”

陈默松了口气，但紧接着又提了起来。

“他们不会轻易放弃。”陈默说，“星耀的手段，你比我清楚。”

“我知道。”林远的声音低了下去，“所以我想问您，接下来怎么办？”

陈默把车停在路边，看着后视镜里那辆一直跟着的黑色轿车。

“先回公司。”他说，“把所有人都叫上，开个会。”

二十分钟后，陈默推开“摆烂科技”会议室的门。

里面已经坐了七个人。

技术总监林远、运营主管苏晴、产品经理老张、前端组长小王、后端组长李姐、测试主管阿杰，还有刚招进来没多久的实习生小周。

所有人都看着他。

陈默把那份意向书拍在桌上：“青云科技王总签了，但有个条件——要等第二家公司公开表态，他才愿意一起站台。”

苏晴皱眉：“现在星耀已经出手了，那三家目标公司收到律师函，估计撑不了多久。”

“不止律师函。”陈默看向林远，“星耀想挖人。”

会议室里瞬间安静下来。

林远站起身，把手机屏幕亮给大家看。上面是一封邮件，发件人是星耀人力资源总监，内容直截了当——邀请林远加入星耀，年薪、期权、职位，写得清清楚楚。

“我拒绝了。”林远说，“但星耀不会只找我一个人。”

话音刚落，小王的手机也震了。他看了一眼，脸色变了。

“星耀……也找我了。”

李姐的手机紧接着响起。她接起来，听了不到十秒，直接挂断。

“也是星耀。”她说，“开价挺高。”

会议室里的气氛凝重起来。

陈默扫视一圈，发现至少有四个人的手机在刚才那一分钟里亮过。

“看来，星耀是想釜底抽薪。”陈默说，“挖走我们的核心团队，让摆烂科技直接瘫痪。”

老张推了推眼镜：“陈总，我们怎么办？”

陈默没立刻回答。他走到窗边，看着楼下那辆黑色轿车还停在街对面。

李姐简洁地说：“因为尊重。”

阿杰说：“因为能学到东西。”

会议室里响起一阵低笑，气氛稍微松动了些。

陈默点点头：“星耀能给你们更高的薪水，更多的期权，更大的平台。但有一样东西，他们给不了。”

他顿了顿，一字一句地说：

“自由。”

“在摆烂科技，你们不用为了KPI去写垃圾代码，不用为了汇报去编造数据，不用为了站队去勾心斗角。你们只需要做好自己的事，然后准时下班。”

“星耀挖人，是因为他们怕了。”陈默的声音提高了一些，“他们怕我们的技术共享公约真的推行起来，怕他们的专利壁垒被打破，怕他们赖以生存的垄断模式崩塌。”

“所以他们用最下作的手段——挖人、发律师函、搞威胁。”

陈默走到会议桌前，双手撑在桌面上：

“但我不怕。”

“因为摆烂科技的核心，从来不是某一个人，而是我们坚持的理念。就算星耀把你们全挖走，只要这个理念还在，我就能再建一支团队。”

他看着每个人的眼睛：

“所以，选择权在你们手里。想走的，现在就可以走，我绝不阻拦，还会给你们写推荐信。想留的……”

陈默笑了，笑容里带着一股子狠劲：

“那就跟星耀，干到底。”

会议室里安静了足足十秒。

林远第一个站了起来：“我留下。”

苏晴跟着站起来：“我也是。”

老张推了推眼镜，慢悠悠地起身：“我这把老骨头，折腾不动了，就在这儿待着吧。”

小王、李姐、阿杰、小周，一个接一个站了起来。

没有人离开。

陈默看着他们，心里那块石头终于落了地。

林远接过文件，快速翻了几页，脸色越来越凝重。

“这些专利……很多都是在别人已有技术的基础上做的微小改动，然后抢先注册。”林远说，“星耀靠这个手段，逼死了至少十几家小公司。”

“所以，我需要你做一件事。”陈默说，“利用你的专业知识，找出这些专利的漏洞。我们要用他们的方式，反击回去。”

林远抬起头，眼睛里闪着光：“您是说……反诉？”
