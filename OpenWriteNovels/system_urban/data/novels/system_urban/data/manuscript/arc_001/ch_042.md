# 硬核应诉

倒计时46小时58分33秒。

陈默盯着眼前的屏幕，那些原本晦涩难懂的专利文档此刻却变得清晰无比。临时技能“专利分析大师”让他的大脑像加了涡轮增压，每一个技术术语、每一个权利要求都自动拆解成最基础的逻辑单元。

“自适应学习网络...”陈默喃喃自语，手指在键盘上飞快敲击，“核心是通过实时数据反馈动态调整神经网络的拓扑结构，权重变化只是拓扑变化的副产品。”

他调出对方的专利文档：“动态权重分配模型...核心是预设权重分配规则，根据输入数据类型切换不同的权重矩阵...”

法务林律师站在他身后，眉头紧锁：“陈总，这两种算法听起来确实有相似之处，都是‘动态调整’...”

“不。”陈默打断她，转过身，眼睛里闪着光，“林律师，你看这里——我们的算法，拓扑结构变化是连续的、不可预测的，就像生物神经网络的自我重组。而对方的模型，权重矩阵是预设的，只有有限的几种组合模式。”

他调出两张流程图并排放在屏幕上。

“看出来了吗？”陈默指着屏幕，“我们的算法，决策路径是发散的，没有固定模式。对方的算法，决策路径是收敛的，最终都会落到那几个预设的权重矩阵上。”

林律师凑近屏幕，仔细看了半分钟，突然倒吸一口凉气：“陈总，您说得对！这完全是两种不同的技术路径！”

“关键证据就在这里。”陈默调出那份4月12日的测试报告，“这份报告里详细记录了我们的算法在处理异常数据时的拓扑变化过程——看这里，神经元连接重组了17次，每次重组后权重都发生了非线性变化。”

他又调出云海科技专利的说明书：“而对方的专利，在处理类似异常数据时，只是在预设的A、B、C三种权重矩阵之间切换。连重组过程都没有，更别说非线性变化了。”

林律师的眼睛亮了起来：“陈总，如果能证明这一点，对方的‘动态权重分配’和我们的‘自适应学习’根本就不是一回事！”

“不止如此。”陈默继续深挖，“我发现了一个更关键的问题——时间线。”

他调出云海科技的专利申请记录：“对方专利的申请日是今年3月15日，公开日是6月20日。但我们的算法，第一次完整运行测试是4月12日。”

“等等...”林律师皱眉，“如果对方申请在前，我们的测试在后，这对我们很不利...”

“不，你没明白。”陈默调出另一份文件，“这是我们的研发日志。自适应学习网络的理论框架，去年11月就完成了。12月开始编码，今年1月第一版原型机上线。3月份我们已经在内部测试了。”

他顿了顿：“而云海科技的CTO王总，今年2月来我们公司考察过技术。当时我们的算法虽然还不成熟，但核心架构已经成型了。”

林律师倒吸一口凉气：“陈总，您的意思是...”

“我没有任何意思。”陈默打断她，语气平静，“我只是陈述事实。事实是：我们的技术路线在前，对方的专利申请在后。而且，对方申请专利时，我们的技术已经进入实质性测试阶段。”

他调出微信聊天记录：“这是4月12日测试当天，王总发给我的消息——‘陈总，你们的算法逻辑很清晰，特别是异常数据处理部分，很有启发性。’”

林律师盯着那条消息，手指微微发抖：“如果这条消息是真的...”

“当然是真的。”陈默调出手机原始数据，“这是原始聊天记录，有时间戳，有服务器日志。我们可以申请腾讯公司出具数据证明。”

系统提示音突然响起：

【叮！检测到宿主正在深入分析证据链，触发隐藏任务“证据猎人”】

【任务要求：在48小时内找到至少三处可以推翻对方专利有效性的关键证据】

【任务奖励：解锁技能“法律直觉”（被动）——对法律漏洞的感知能力提升300%】

【任务失败：本次应诉胜率下降30%】

陈默深吸一口气。系统这是嫌难度不够，还要加码。

“林律师。”陈默站起身，“我们需要做三件事。”

“第一，立即对所有证据进行公证。4月12日的测试报告、PPT演示记录、微信聊天记录，全部公证。”

“第二，深挖云海科技的专利研发时间线。我要知道他们是什么时候开始研发这个‘动态权重分配模型’的，研发过程中有没有接触过我们的技术。”

“第三，查天宇集团。”陈默的眼神变得锐利，“云海科技是天宇集团的子公司，这次诉讼背后，很可能有天宇集团的影子。”

林律师快速记录着：“陈总，公证需要时间，最快也要明天下午才能拿到公证书。深挖时间线需要调取对方的研发档案，这可能需要法院协助...”

“我知道。”陈默看着倒计时，“所以我们只有46小时。林律师，你现在就去公证处，把所有证据都带上。我在这里继续分析。”

“可是陈总...”

“没有可是。”陈默的语气不容置疑，“这是命令。”

林律师咬了咬牙，抱起那叠文件冲出了办公室。

陈默重新坐回电脑前。技能“专利分析大师”让他能同时处理多线程信息，他的眼睛在屏幕上快速扫视，大脑飞速运转。

突然，他停住了。

云海科技的专利说明书中，有一段关于“权重矩阵切换阈值”的描述。这个描述...怎么这么眼熟？

陈默调出自己公司的内部文档，快速检索。找到了！这是他们今年1月份的一份内部技术讨论记录，当时团队在讨论算法优化时，提出过类似的阈值设定思路。

但这份记录从未公开过。

陈默的手指开始发抖。如果云海科技的专利说明书里，出现了他们未公开的内部讨论内容...这意味着什么？

他立即拨通技术总监老张的电话。

“老张，你现在马上查一下，今年1月15日的技术讨论会，都有谁参加？会议记录有没有外泄的可能？”

电话那头传来键盘敲击声：“陈总，我查一下...1月15日的技术讨论会，参会人员有您、我、还有三个核心程序员。会议记录在内部服务器上，权限设置是仅参会人员可查看。”

“有没有可能被截图或拍照？”

“理论上有可能，但我们的服务器有防截图水印系统，任何截图都会留下隐形水印，记录截图者的工号和时间。”

“好。”陈默松了口气，“你把那次讨论会的完整记录发给我，包括参会人员名单、会议纪要、还有服务器日志。”

挂断电话，陈默继续分析。他的视线落在专利说明书的另一段描述上——“当系统负载超过阈值时，自动触发权重矩阵的重新分配”。

这个描述...和他们4月12日测试报告中的一段记录几乎一模一样！

陈默调出测试报告，找到那段记录：“在模拟高并发场景下，系统负载达到87%时，神经网络拓扑结构发生重组，权重分配模式自动切换...”

相似度超过90%。

陈默的后背开始冒冷汗。如果对方真的是抄袭，那这个抄袭也太明目张胆了。但如果是巧合...世界上哪有这么巧的巧合？

系统提示音再次响起：

【叮！宿主发现关键证据矛盾点】

【触发限时任务“真相挖掘者”】

【任务要求：在24小时内找到证据证明云海科技专利说明书中的技术描述与星海科技未公开技术文档存在实质性相似】

【任务奖励：解锁技能“证据链构建”（主动）——可将零散证据自动串联成完整证据链，持续1小时】

【任务失败：本次应诉胜率下降50%】

陈默盯着屏幕，大脑飞速运转。他必须找到确凿的证据，证明对方抄袭。但问题是，对方是怎么拿到他们未公开的技术文档的？

内鬼？

这个念头刚冒出来，陈默就否定了。参与那次技术讨论的都是公司元老，不可能背叛公司。

那只能是...对方通过某种手段，窃取了他们的技术资料。

陈默调出公司的网络安全日志。今年1月到3月，有没有异常登录记录？有没有数据外传记录？

他快速筛选着日志数据。突然，一个异常记录引起了他的注意——

今年2月28日，凌晨3点17分，有一个IP地址尝试登录公司内部服务器，但被防火墙拦截。这个IP地址...陈默快速查询，发现属于一家名为“天宇信息科技”的公司。

天宇信息科技。天宇集团的子公司。

陈默的心跳开始加速。他继续深挖，发现这个IP地址在2月28日到3月5日期间，尝试了十七次登录，每次都使用了不同的用户名和密码组合，但全部失败。

三月五日之后，这个IP地址就再没出现过。

但就在三月十五日，云海科技提交了专利申请。

时间点吻合得可怕。

陈默立即给老张发消息：“查一下2月28日到3月5日的网络安全日志，重点查IP地址为[具体IP]的所有访问记录。我要知道这个IP都尝试访问了哪些文件，用了什么手段。”

发完消息，陈默靠在椅背上，闭上眼睛。技能“专利分析大师”让他的大脑异常清晰，各种线索在脑海中自动串联，形成一个完整的逻辑链。

云海科技是天宇集团的子公司。天宇集团早就盯上了星海科技的技术。今年2月，王总以考察为名来公司，实际上是为了摸底技术。考察期间，王总可能通过某种手段获取了部分技术信息。

二月底，天宇集团的技术人员开始尝试入侵星海科技的服务器，想要获取完整的技术资料。虽然入侵失败，但他们可能通过其他手段（比如社交工程、内部人员疏忽）获取了部分技术文档。

三月份，云海科技基于窃取到的技术信息，拼凑出了“动态权重分配模型”专利，并在三月十五日提交申请。

四月份，星海科技完成算法测试，云海科技发现自己的专利可能和星海科技的技术重叠，于是先发制人，提起专利诉讼。

逻辑链完整了。

但问题是，证据呢？

陈默睁开眼睛，看向屏幕。系统倒计时显示还有44小时12分。

时间不多了。

他必须找到确凿的证据，证明云海科技的专利是基于窃取的技术信息申请的。否则，就算他能证明两种算法不同，对方也可以咬定是独立研发。

陈默调出王总二月份来公司考察时的所有记录。监控视频、接待记录、技术演示文档...他要找的是，王总在考察期间，有没有机会接触到未公开的技术资料。

监控视频显示，王总在技术演示环节，用手机拍了几张屏幕照片。当时接待人员没有制止，因为演示的是已经公开的技术框架。

但陈默注意到一个细节——在演示过程中，有一份内部技术文档的截图不小心出现在屏幕上，停留了大约三秒钟。

那份文档，正是1月15日技术讨论会的会议纪要！

陈默放大画面，虽然模糊，但能看清文档标题和部分内容。

王总拍到了。

这就是证据链的关键一环。

陈默立即保存这段监控视频，并标注时间点。然后他继续查看王总在公司的其他活动记录。

下午茶时间，王总和几个技术人员聊天。聊天内容被接待人员的录音笔记录下来（这是公司的标准流程，所有商务会谈都要录音）。

陈默调出录音，快速播放。大部分是客套话，但在聊天快结束时，王总问了一个问题：“听说你们的自适应算法很厉害，不知道核心的权重调整机制是怎么设计的？”

技术人员回答：“这个涉及到商业机密，不方便透露。”

王总笑了笑：“理解理解。我就是好奇，动态权重分配这种技术，其实很多公司都在研究，你们有没有考虑过申请专利保护？”

技术人员：“我们正在准备。”

录音结束。

陈默盯着屏幕，手指轻轻敲击桌面。王总这个问题问得很巧妙，看似随口一问，实际上是在试探他们的技术细节和专利布局。

结合之前的监控视频，陈默现在可以确定：王总在考察期间，通过拍照和询问，获取了部分技术信息。虽然信息不完整，但足以让天宇集团的技术人员拼凑出一个相似的专利。

问题是，这些证据够不够？

陈默调出法律数据库，快速检索类似案例。专利侵权诉讼中，如果能证明对方有接触己方技术的机会，并且双方技术高度相似，可以推定对方抄袭。

但“推定”不是“证明”。对方可以辩称是独立研发。

陈默需要更直接的证据——证明对方的技术文档和己方未公开文档存在实质性相似。

他想起刚才发现的那个相似点——专利说明书中的“权重矩阵切换阈值”描述，和己方1月份的技术讨论记录相似度超过90%。

如果能证明这一点...

陈默调出己方的技术讨论记录，和云海科技的专利说明书进行逐字比对。

技能“专利分析大师”让他能瞬间识别文字相似度。比对结果让他倒吸一口凉气——

除了“权重矩阵切换阈值”那段，还有三处描述，相似度都在85%以上。

这不可能是巧合。

陈默立即保存比对结果，并生成详细的分析报告。然后他给林律师打电话。

“林律师，公证进度怎么样？”

“正在排队，预计还要两小时。”

“好。公证完成后，立即申请证据保全。我要保全云海科技的专利申请原始文档，特别是研发过程记录。”

“陈总，这需要法院批准...”

“我知道。你同时准备申请材料，我这边有重大发现。”

陈默挂断电话，继续工作。他必须把所有证据整理成完整的证据链，说服法官。

时间一分一秒过去。倒计时跳到40小时。

陈默的眼睛开始发酸，但他不敢休息。技能“专利分析大师”还剩18小时有效期，他必须在技能消失前完成所有分析。

突然，系统提示音响起：

【警告！宿主发现关键证据可能失效】

【原因：云海科技可能正在销毁或修改相关证据】

【建议：宿主准备备用方案，同时加速证据收集】

陈默的心一沉。他早就该想到，对方既然敢提起诉讼，肯定做好了准备。如果发现自己可能败诉，一定会销毁证据。

他必须抢在对方行动前，固定所有证据。

陈默立即给公司IT部门负责人打电话：“小王，你现在马上做三件事。”

“第一，备份公司所有服务器的完整日志，包括访问记录、操作记录、数据传输记录。备份三份，一份存本地，一份存云端，一份存物理隔离设备。”

“第二，调取今年2月28日到3月5日的所有网络安全日志，特别是那个可疑IP地址的访问记录。生成详细报告，我要知道这个IP都尝试访问了哪些文件，用了什么手段。”

“第三，检查公司所有电脑的USB接口记录、邮件发送记录、文件打印记录。我要知道今年2月到3月，有没有人大量导出或打印技术文档。”

电话那头传来紧张的声音：“陈总，出什么事了？”

“照做就行。半小时内我要看到初步结果。”

挂断电话，陈默继续整理证据。他把所有证据按时间线排列，形成一个完整的逻辑链：

1. 去年11月，星海科技完成自适应学习网络理论框架。
2. 今年1月，算法原型机上线，1月15日召开技术讨论会，产生未公开的会议纪要。
3. 今年2月，云海科技CTO王总来公司考察，期间拍到会议纪要截图，并询问技术细节。
4. 今年2月28日到3月5日，天宇集团IP地址尝试入侵星海科技服务器，未成功。
5. 今年3月15日，云海科技提交“动态权重分配模型”专利申请。
6. 今年4月12日，星海科技完成算法测试，王总发消息称赞。
7. 云海科技专利说明书中的四处技术描述，与星海科技未公开文档高度相似。

逻辑链完整，但还缺一环——直接证明对方抄袭的证据。

陈默盯着屏幕，大脑飞速运转。突然，他想到一个可能性。

如果云海科技真的是基于窃取的技术信息申请专利，那他们的研发文档里，一定会有痕迹。比如，技术讨论记录、草稿、修改记录...

这些文档可能已经被销毁，但如果能申请到证据保全，也许还能找到残骸。

陈默立即给林律师发消息，强调证据保全的紧迫性。然后他继续分析。

时间跳到38小时。

陈默的眼睛布满血丝，但他不敢停。系统任务的惩罚太严重——公司破产，背负三千万债务。他承担不起失败的后果。

突然，IT部门负责人小王打来电话。

“陈总，有重大发现！”

“说。”

“我们查了今年2月到3月的所有文件操作记录，发现一个异常——技术部的李工，在2月20日打印了一份长达50页的技术文档，文档名称是‘自适应学习网络核心算法设计’。”
