# 烤红薯与演讲稿

陈默把烤红薯递到母亲手里的时候，红薯还冒着热气。

“妈，路上买的，趁热吃。”

母亲接过红薯，手指碰到陈默的手背，皱了皱眉：“手这么凉？地铁里没空调？”

“有，就是人多，挤得一身汗出来被风吹的。”陈默换好拖鞋，走进客厅。

父亲正坐在沙发上看电视，财经频道，主持人正用夸张的语调分析某家公司的股价暴跌。陈默瞥了一眼屏幕——是王振华旗下的振华科技。

“爸，我回来了。”

“嗯。”父亲眼睛没离开屏幕，“公司今天不加班？”

“五点准时下班，全员。”陈默在父亲旁边坐下。

父亲终于转过头，看了他一眼：“你这公司，真能做到天天五点下班？”

“双休，节假日正常放假，年假十五天。”陈默掰着手指头数，“入职就交五险一金，没有996，没有大小周。”

母亲把红薯掰开一半，金黄色的瓤冒着甜香。她递给陈默一半：“吃点。你爸昨天还说，现在网上都在传你们公司，说是什么‘反内卷标杆’。”

陈默咬了一口红薯，软糯香甜。他想起下午会议室里林远拍桌子的样子。

“标杆谈不上，就是正常上班而已。”

“正常？”父亲哼了一声，“现在有几个公司能正常？我老同事的儿子，在什么互联网大厂，天天凌晨两点下班，上个月体检，脂肪肝、高血压、颈椎病，二十八岁的人，五十岁的身体。”

电视里，主持人开始采访振华科技的发言人，对方西装革履，表情严肃，正在回应股价下跌的问题：“我们公司始终坚持奋斗者文化，员工自愿加班，这是……”

父亲拿起遥控器换了台：“屁话。”

陈默差点被红薯噎住。

母亲拍了拍他的背：“慢点吃。对了，你上次说的那个老太太的儿子，叫张伟是吧？怎么样了？”

“入职了，今天第一天。”陈默咽下红薯，“在技术部，跟着林远做项目。”

“他不是被裁员了吗？能跟上吗？”

“林远说他基础不错，就是之前在原公司被压榨得太狠，人都麻木了。今天开会的时候，他坐在角落里，一直低着头，我问他有没有什么想法，他愣了半天才说‘都听领导的’。”

陈默想起下午会议时，张伟坐在会议桌最末端，背挺得笔直，像根绷紧的弦。当林远宣布要对抗王振华的抵制时，会议室里其他人都义愤填膺，只有张伟的脸色越来越白。

“慢慢来。”母亲说，“你爸当年从厂里下岗，也是半年没缓过来，天天在家发呆。”

父亲换了台，是个相亲节目。他盯着屏幕，突然说：“你公司现在多少人了？”

“算上今天入职的张伟，四十七个。”

“四十七个人，养得起吗？”

“养得起。”陈默把最后一口红薯塞进嘴里，“我们接了几个长期项目，现金流没问题。而且系统……”

他及时住嘴。

【系统提示：宿主差点说漏嘴，扣除摆烂值1点】

陈默眼前闪过一行半透明的金色小字，只有他能看见。

“系统什么？”父亲问。

“系统……系统工程做得不错，”陈默干笑两声，“我们的项目管理系统很先进。”

父亲没再追问，继续看相亲节目。女嘉宾正在问男嘉宾：“你能接受婚后和公婆同住吗？”

陈默起身去厨房倒水，母亲跟了进来。

“你爸就是嘴硬，其实他挺担心你的。”母亲压低声音，“他昨天还让我问问你，公司缺不缺财务，他有个老同事的女儿，刚考下CPA……”

“妈，我们公司财务是外包的。”

“外包多不靠谱，自己人放心。”

陈默喝了口水，没接话。他知道母亲的意思，但他不想开这个口子。公司里现在全是被裁员的人，每个人都是凭本事进来的，要是搞裙带关系，人心就散了。

“我再想想。”

“行，不急。”母亲拍拍他的肩膀，“你自己心里有数就行。”

回到客厅，父亲已经关了电视，正在翻一本厚厚的相册。

“过来。”父亲朝他招手。

陈默走过去，父亲指着相册里一张黑白照片：“这是你爷爷，1958年，在纺织厂当劳模。那时候讲究‘大干快上’，你爷爷三天三夜没合眼，晕倒在机器旁边。”

照片上的年轻人穿着工装，胸前挂着大红花，笑容灿烂。

“这是你奶奶，”父亲翻到下一页，“1962年，在生产队挣工分，一天干十四个小时，回来还要给一家六口做饭。”

“爸，你给我看这些干什么？”

父亲合上相册：“我想告诉你，你爷爷奶奶那代人，是没办法。你这代人，有选择。你开了公司，就别走老路。”

陈默愣住了。这是父亲第一次这么直接地表达对他的支持。

“我知道。”

“知道就好。”父亲把相册放回书架，“那个王振华，我看了他的采访，满嘴奋斗者文化，其实就是剥削。你不用理他，做好自己的事。”

陈默点点头，心里却想起下午会议室里，林远拍桌子的样子。

“老板！王振华那老东西欺人太甚！”林远把一沓文件摔在桌上，“技术峰会的演讲名单，他居然把我们排在最后，还给了个‘特别案例’的标签！”

会议室里坐着公司所有管理层。技术总监林远，产品经理苏晴，运营主管老周，还有新来的张伟。

张伟坐在最角落，背挺得笔直，脸色发白。

陈默翻了翻文件。王振华联合了七家公司，要在下周的技术峰会上搞一个“行业自律倡议”，主题是抵制摆烂文化。演讲稿都写好了，标题触目惊心——《论摆烂文化的危害：从行业生态到社会责任》。

“他们还邀请了媒体。”苏晴补充道，“我打听过了，至少有三家科技媒体会到场报道。”

老周推了推眼镜：“这是要把我们往死里整啊。技术峰会是行业最大的盛会，这么一搞，我们的名声就臭了。”

林远一拳捶在桌上：“妈的，他们加班猝死的时候怎么不说社会责任？我们准时下班就成了行业毒瘤？”

会议室里群情激愤。只有张伟低着头，手指紧紧攥着笔记本，指节发白。

陈默敲了敲桌子，所有人安静下来。

“他们的演讲稿，谁有？”

苏晴把笔记本电脑转过来：“我搞到了初稿。”

陈默扫了几眼。通篇都是高大上的词汇：行业责任、奋斗精神、可持续发展……但核心就一句话：摆烂科技不加班，所以是行业的害群之马。

“写得不错。”陈默合上电脑，“很有煽动性。”

“老板！”林远急了，“我们得反击啊！要不我们也写一篇，揭露他们压榨员工……”

“不。”

陈默站起身，走到窗边。窗外是城市的夜景，灯火通明。很多写字楼还亮着灯，那些都是在加班的人。

“我们不理会。”

“什么？”林远以为自己听错了。

【叮！系统任务发布】

【任务名称：不要理会】

【任务描述：当竞争对手试图用舆论攻击你时，最好的回应是——不回应。请宿主对王振华等公司的抵制行为采取“不理会”态度，持续到技术峰会结束】

【任务奖励：经验值+100，摆烂值+5】

【失败惩罚：公司股价下跌10%】

陈默眼前闪过系统提示，他转过身，面对众人。

“我说，我们不理会。”他重复道，“他们要演讲，就让他们讲。他们要抵制，就让他们抵制。我们该上班上班，该下班下班，该放假放假。”

“可是……”苏晴欲言又止。

“可是什么？”陈默看着她，“我们开公司，是为了什么？是为了跟王振华吵架吗？”

会议室里安静下来。

“我们是为了让被裁员的人有地方去。”陈默说，“是为了让大家能准时下班，能有周末，能陪家人。王振华要搞我们，那是他的事。我们做好自己的事就行。”

林远张了张嘴，最后叹了口气：“行吧，老板你说了算。”

“散会。”陈默看了看表，“五点了，下班。”

会议室里响起一片欢呼。大家收拾东西，陆续离开。只有张伟还坐在原地，低着头。

陈默走过去：“张伟，下班了。”

张伟抬起头，眼睛里全是血丝：“老板，我……我有点害怕。”

“怕什么？”

“王振华他们人多，我们才四十七个人……”张伟的声音发抖，“我在上一家公司的时候，老板也说要对抗行业潜规则，结果被围剿，公司倒闭，我们都失业了……”

陈默在他旁边坐下：“你上一家公司，加班吗？”

“加，天天加到十一二点，周末也要去。”张伟苦笑，“老板说这是奋斗，是福报。”

“我们公司呢？”

“五点下班，双休……”张伟的声音越来越小，“我今天五点零五分走出公司大门的时候，腿都是软的。我从来没这么早下过班。”

“那就对了。”陈默拍拍他的肩膀，“我们做的事情，和他们不一样。他们用加班来证明自己，我们用效率。他们用围剿来打压对手，我们用产品。走吧，下班了。”

张伟慢慢站起来，收拾好笔记本，跟在陈默后面走出会议室。

走廊里已经空了，只有保洁阿姨在拖地。夕阳从落地窗照进来，把地板染成金色。

“老板，”张伟突然开口，“我觉得……我觉得您说得对。”

“哪句话？”

“做好自己的事。”张伟深吸一口气，“我以前总觉得，不加班就是懒，就是不上进。但今天我五点下班，回家给我妈做了顿饭，她高兴得直哭。她说……她说她三年没吃过我做的饭了。”

陈默没说话，只是拍了拍他的背。

两人一起走出公司大楼。门口的保安朝他们挥手：“陈总，张工，下班啦？”

“下班了。”陈默笑笑，“你也早点收工。”

“没事，我值夜班。”保安咧嘴一笑，“你们公司真好，五点一到，人全走光了。我在这栋楼干了五年，第一次见这种场面。”

陈默和张伟在地铁站分别。张伟要坐三号线，陈默坐一号线。

“明天见。”陈默朝他挥手。

“明天见。”张伟犹豫了一下，又说，“老板，那个……谢谢您。”

陈默摆摆手，转身走进地铁站。

车厢里人不多，陈默找了个位置坐下。他打开系统面板，查看今天的收获。

【宿主：陈默】

【等级：Lv.35】

【经验值：1250/2000】

【摆烂值：87】

【当前任务：不要理会（进行中）】

【今日任务：准时下班（已完成）】

【隐藏任务：孝子的尊严（续）（进度2/3）】

陈默关掉面板，靠在椅背上。地铁在隧道里穿行，窗外是飞速后退的黑暗。

他想起下午会议室里，林远拍桌子的样子，想起张伟发白的脸，想起父亲相册里那些黑白照片。

王振华要抵制就抵制吧。陈默闭上眼睛。反正明天，他还是要五点下班。

到站的时候，陈默的手机响了。是母亲发来的微信。

“红薯好吃吗？我让你爸明天再去买点。”

陈默笑了笑，回复：“好吃。不用买了，明天我给你们带个更好的。”

他走出地铁站，夜风吹在脸上，有点凉。街边的烤红薯摊还亮着灯，老大爷正收拾东西准备收摊。

陈默走过去：“大爷，还有红薯吗？”

“最后一个了。”老大爷从炉子里掏出一个烤得焦黄的红薯，“送你了，小伙子。”

“这怎么好意思……”

“拿着吧。”老大爷把红薯塞到他手里，“我收摊了，明天见。”

陈默拿着热乎乎的红薯，愣在原地。他想起系统提示里那个隐藏任务——孝子的尊严（续），进度2/3，任务要求是给母亲带一份礼物。

一个烤红薯，算礼物吗？

他咬了一口，甜得发腻。

【叮！隐藏任务“孝子的尊严（续）”进度更新：3/3】

【任务完成！奖励经验值+50，摆烂值+3】

【特殊奖励：亲情礼包（内含：母亲的微笑×1，父亲的认可×1）】

陈默看着眼前闪过的系统提示，笑出声来。

他加快脚步，朝家的方向走去。手里的红薯还冒着热气，在夜色里像一盏小小的灯。

明天，技术峰会就要开始了。王振华的演讲排在上午十点，主题是“论摆烂文化的危害”。

而陈默的公司，被安排在下午最后一个，标签是“特别案例”。

但陈默不打算准备任何演讲稿。

他打算五点准时下班，然后去菜市场买条鱼，回家给父母做顿晚饭。

毕竟，系统任务说了：不要理会。

而他，向来是个听话的宿主。
