# 暗流涌动

清晨八点，陈默的手机震动起来。

他瞥了一眼屏幕，是青云科技的王总。

“陈总，新闻稿我看了。”王总的声音里带着压抑不住的兴奋，“评论区已经炸了，星耀那边估计现在焦头烂额。”

陈默靠在办公椅上，手指轻轻敲着桌面：“王总，这只是第一步。”

“我知道。”王总压低声音，“你让我联系的那两家公司，我已经谈妥了。他们手里都有星耀科技‘借鉴’过的专利，苦于对方专利流氓的打法，一直不敢发声。”

“什么时候能提交无效宣告申请？”

“今天下午。”王总顿了顿，“不过陈总，星耀那边已经发了第二份声明，措辞很硬，说要法律追诉。”

陈默轻笑一声：“他们要是真有底气，就不会只发声明了。”

挂断电话，陈默打开系统界面。

【隐藏任务“专利围剿”进度：1/3】

【剩余时间：71小时42分钟】

【当前说服公司：微光科技（赵强）】

【待说服目标：2家】

办公室门被敲响，林薇探进头来：“陈总，赵强到了。”

“请他进来。”

赵强今天穿了件深灰色夹克，手里拎着个黑色公文包。他进门后环顾四周，目光在墙上那幅“摆烂光荣”的书法上停留了两秒。

“陈总。”赵强点头示意。

“坐。”陈默指了指对面的椅子，“咖啡还是茶？”

“不用了。”赵强把公文包放在桌上，拉开拉链，“我直接说正事。”

他从包里取出一个移动硬盘，放在桌上。

“这里面有张伟在链创科技期间的所有项目文档、代码库，以及他和星耀科技法务部往来的邮件。”赵强的声音很平静，“一共47封邮件，时间跨度从三年前到去年十月。”

陈默没有立即去拿硬盘：“怎么拿到的？”

赵强嘴角扯了扯：“张伟这人有个习惯，所有工作文件都同步到私人网盘。他的密码强度……一般。”

“黑进去了？”

“不算黑。”赵强推了推眼镜，“他用的是生日加手机号的组合，我试了三次就进去了。严格来说，这是他自己的安全漏洞。”

陈默看着赵强。这个程序员出身的创业者，眼睛里有种长期熬夜留下的血丝，但眼神很亮。

“这些邮件里有什么？”

“星耀科技法务部的人，在邮件里明确指导张伟如何‘规避’现有专利。”赵强打开笔记本电脑，调出一份文档，“你看这里——‘建议将算法模块拆分为三个子专利，分别申请，这样可以绕过微光科技的核心专利’。”

陈默凑近屏幕。

邮件发送时间是两年前，发件人是星耀科技法务总监李明远。

“还有这个。”赵强又调出另一封邮件，“张伟提交的专利申请草稿，星耀那边直接批注：‘此处描述过于具体，建议模糊化处理，避免与现有专利产生直接冲突’。”

“这是教唆造假。”陈默说。

“不止。”赵强深吸一口气，“张伟在链创科技的最后一个项目，核心代码有30%直接复制自星耀科技三年前的一个未公开项目。那个项目因为技术路线问题被内部叫停了，但代码还在。”

陈默靠回椅背。

办公室里很安静，只有空调运转的轻微嗡鸣。

“你为什么愿意把这些给我？”陈默问。

赵强沉默了几秒。

“因为微光科技差点死掉。”他的声音有些哑，“三年前，星耀用五项专利同时起诉我们，其中三项是明显无效的‘垃圾专利’，但诉讼流程拖了我们整整一年。那一年，我们错过了最好的融资窗口，核心团队走了三分之一。”

他顿了顿：“后来我们虽然赢了官司，但公司已经元气大伤。去年开始，星耀又盯上我们了，这次他们准备了更多专利。”

“所以你要反击。”

“我要让他们付出代价。”赵强的眼神锐利起来，“陈总，你公开揭露他们专利造假，是第一步。但光有舆论不够，我们需要实打实的证据，让专利局、让法院、让所有人都看清楚，星耀科技到底是怎么玩专利游戏的。”

陈默点点头：“这些证据，你愿意公开吗？”

“随时可以。”赵强说，“但我建议分阶段释放。先抛出邮件往来，证明星耀指导造假；再抛出代码抄袭的证据，把事情闹大。这样舆论热度能持续更久。”

陈默笑了：“你比我想的还狠。”

“被逼的。”赵强也笑了，但笑容里没什么温度。

这时，系统提示音响起。

【检测到关键证据获取】

【触发支线任务：证据链完善】

【任务要求：在72小时内，将赵强提供的证据与微光科技、青云科技等公司的专利被侵权证据整合，形成完整证据链】

【任务奖励：技能“逻辑推演”升级至Lv.2，专利分析效率+50%】

【任务惩罚：证据链不完整，宿主名下所有公司未来三年内专利申请通过率降低30%】

陈默看完提示，对赵强说：“今天下午，青云科技那边会有两家公司提交专利无效宣告申请。你的证据，能不能在明天上午十点前整理成可公开的版本？”

“没问题。”赵强合上电脑，“我今晚通宵也要弄出来。”

“别通宵。”陈默摆摆手，“明天上午九点前给我就行。你要是累垮了，谁来跟星耀打这场仗？”

赵强愣了愣，似乎没料到陈默会这么说。

“好。”他站起身，“那我先回去了，整理好发你邮箱。”

“等等。”陈默叫住他，“硬盘留下。”

赵强看了眼桌上的移动硬盘：“你信得过我？”

“你要是想坑我，今天就不会来了。”陈默说，“而且，我们需要互相信任。这场仗，不是一个人能打的。”

赵强点点头，把硬盘推过来。

“陈总，有句话我不知道该不该说。”

“说。”

“你公开揭露星耀，得罪的不只是星耀一家。”赵强压低声音，“整个行业里，用类似手段玩专利游戏的公司，不止他们。你动了太多人的蛋糕。”

陈默靠在椅背上，看着天花板。

“我知道。”他说，“但总得有人站出来。”

赵强没再说什么，转身离开。

办公室里又剩下陈默一个人。

他拿起那个移动硬盘，在手里掂了掂。

很轻，但里面装着的东西，可能压垮一家市值百亿的公司。

系统界面再次弹出。

【摆烂值增加：获取关键证据+30】

【当前总摆烂值：190.5】

【技能“坦荡荡”效果持续中：工作效率+20%，所有公开行动获得额外舆论支持+15%】

陈默关掉界面，拿起手机，给林薇发了条消息：“通知法务部和技术部负责人，十分钟后开会。”

十分钟后，小会议室里坐满了人。

法务总监周明是个四十多岁的中年男人，戴着金丝眼镜，看起来很严肃。技术总监李浩则年轻得多，三十出头，头发乱糟糟的，一看就是长期熬夜的程序员。

陈默把移动硬盘接上投影仪。

“这是赵强提供的证据。”他点开第一封邮件，“星耀科技法务总监李明远，指导张伟如何规避微光科技的专利。”

会议室里响起倒吸冷气的声音。

“这……这是教唆啊。”周明推了推眼镜，“如果属实，星耀科技至少涉嫌不正当竞争。”

“不止。”陈默又点开几封邮件，“这里，星耀指导张伟如何模糊专利描述，避免与现有专利冲突。还有这里，星耀直接提供了他们内部项目的代码片段，让张伟‘参考’。”

李浩凑近屏幕，脸色越来越难看。

“这段代码……”他喃喃道，“我见过。去年微光科技起诉我们专利侵权，其中一项专利的技术方案，和这段代码高度相似。”

“所以星耀是贼喊捉贼。”陈默说，“他们自己抄了自己的代码，然后反过来告别人。”

会议室里一片寂静。

“陈总，”周明开口，“这些证据如果公开，星耀科技可能会反咬我们侵犯隐私。毕竟，这些邮件是私人邮箱里的。”

“证据来源合法吗？”陈默问。

赵强说过，张伟的密码是生日加手机号，试了三次就进去了。严格来说，这不算黑客入侵，只能算……安全意识薄弱。

“法律上有些模糊。”周明谨慎地说，“但我们可以强调，这些证据是内部举报人提供，我们只是接收方。重点是证据内容本身的真实性。”

“技术上能验证吗？”陈默看向李浩。

李浩思考了几秒：“代码部分可以。我们可以做代码相似度分析，出具技术报告。邮件的话……需要看原始邮件头，验证发送时间和IP地址。”

“赵强应该保留了原始数据。”陈默说，“今天下午，你和他对接，把所有证据做技术验证。”

“好。”李浩点头。

“法务这边，”陈默看向周明，“准备两份文件。第一份，向专利局举报星耀科技专利造假，附上证据。第二份，准备应对星耀可能发起的法律诉讼。”

“他们真的会起诉？”周明问。

“一定会。”陈默说，“狗急跳墙。舆论上输了，他们一定会在法律上找回场子。”

会议开了一个小时，任务分配完毕。

散会后，陈默回到办公室，系统提示音又响了。

【隐藏任务“专利围剿”进度更新：1/3】

【新增说服目标：青云科技关联公司“云启智能”】

【云启智能三年前被星耀科技用专利诉讼打压，损失市场份额40%】

【建议接触方式：通过青云科技王总引荐】

陈默拿起手机，给王总发了条消息：“王总，云启智能那边，能帮我引荐一下吗？”

回复很快：“没问题，云启的刘总和我关系不错。他早就想反击星耀了，只是一直没找到机会。”

“约明天下午两点，来我公司谈。”

“好。”

放下手机，陈默走到窗边。

楼下的街道上，行人匆匆。这个城市里，有多少人正在被不合理的规则压榨？有多少公司正在被专利流氓敲诈？

系统界面浮现在眼前。

【当前摆烂值：190.5】

【距离下一阶段解锁还需：209.5摆烂值】

【下一阶段能力预告：可对他人发布“摆烂任务”】

陈默看着那个数字。

190.5。

他想起第一次绑定系统时，那个冰冷的机械音说：“检测到宿主长期处于高压工作状态，精神濒临崩溃。绑定摆烂系统，越摆烂，奖励越高。”

那时候他以为这只是个恶作剧。

但现在，他靠着“摆烂”，开了一家公司，招了一群被裁员的人，现在甚至要挑战行业巨头。

手机震动，是林薇发来的消息：“陈总，星耀科技股价开始下跌了，跌幅3.2%。”

陈默回复：“继续盯着。”

他坐回办公椅，打开电脑。

屏幕上，是赵强刚发来的邮件，标题是：“证据整理初版，请查收。”

陈默点开附件。

文档很厚，足足有八十多页。里面不仅有邮件截图、代码对比，还有赵强做的详细时间线分析，标注了星耀科技每一次专利诉讼的时间点，以及他们“借鉴”他人技术的时间点。

文档最后，赵强写道：“陈总，这些证据足够让星耀伤筋动骨。但你要小心，他们不会坐以待毙。”

陈默关掉文档，靠在椅背上。

办公室的空调还在嗡嗡作响。

窗外，天色渐渐暗下来。

他想起赵强的话：“你动了太多人的蛋糕。”

是啊，太多人了。

但有些蛋糕，本来就不该存在。

系统提示音最后一次响起。

【检测到宿主心态变化】

【触发隐藏状态：破局者】

【效果：未来72小时内，所有对抗性行动成功率+20%，但风险同步提升】

陈默看着那个提示，笑了。

风险提升？

那就来吧。

他拿起手机，给团队所有人发了条消息：“今晚七点，全体加班。不是为了工作，是为了准备一场仗。”

消息发出去三秒，林薇回复：“陈总，你终于舍得让我们加班了？”

陈默回复：“这次不一样。这次是我们主动出击。”

他放下手机，看向窗外渐浓的夜色。

这座城市里，灯光次第亮起。

有些灯是加班的人点亮的，有些灯是回家的人点亮的。

而陈默办公室的灯，今晚会一直亮着。

因为他们要准备的，是一场可能改变整个行业游戏规则的仗。

系统界面在角落里安静地闪烁。

【摆烂值：190.5】

【破局者状态：已激活】

【剩余时间：71小时15分钟】

陈默关掉系统界面，打开赵强发来的证据文档，开始一页一页地仔细阅读。

这场仗，才刚刚开始。
