# 摆烂总监的深层逻辑

王振华盯着会议室白板上那行字，手指无意识地敲着桌面。

“追求效率、尊重与可持续。”他念出声，转头看向陈默，“这听起来……很正确。”

陈默靠在椅背上，手里转着一支笔：“正确的东西往往被当成废话。”

“所以你们公司文化的核心是——”

“反‘烂’。”陈默打断他，“不是反对工作，是反对那些让工作变‘烂’的东西。”

王振华皱眉：“比如？”

“比如无效加班。”陈默起身走到白板前，拿起马克笔，“传统公司喜欢用加班时长衡量态度，但真正高效的人，六小时能干完八小时的活。”

他画了个简单的图表：“我们内部数据，员工平均有效工作时间每天5.8小时。但产出是行业平均的1.3倍。”

“怎么做到的？”

“砍掉所有没意义的会。”陈默写下“会议”两个字，“我们公司规定，超过半小时的会必须提前一天发议程，会上不准跑题，超时自动散会。”

王振华想起自己以前在前公司，每天至少三个小时泡在会议室里，大部分时间在听领导重复说过八百遍的话。

“还有呢？”

“形式主义。”陈默又写下这个词，“周报、月报、季度总结……我们全砍了。”

王振华瞪大眼睛：“那怎么考核？”

“看结果。”陈默转身面对他，“我们只看交付物。代码提交量、项目进度、客户满意度——这些数据系统自动生成，不需要员工花两小时写PPT美化。”

他顿了顿：“你知道前公司一个中层，每周花多少时间在写报告上吗？”

王振华苦笑：“至少十小时。”

“我们公司，零。”陈默说，“省下来的时间，员工可以提前下班，或者学新技能。去年我们内部培训参与率87%，行业平均不到30%。”

会议室安静了几秒。

王振华消化着这些信息。他想起自己在前公司时，明明知道很多流程是浪费时间，却不得不遵守。因为“大家都这样”。

“但这样……不会乱吗？”他问，“没有汇报，管理层怎么掌握情况？”

陈默笑了：“你以为我们没有管理系统？”

他打开手机，调出一个界面递给王振华：“这是我们的项目看板。所有任务实时更新，进度、问题、负责人一目了然。”

王振华接过手机。界面简洁直观，每个任务卡片上都有进度条，颜色区分优先级。他点开一个任务，能看到所有相关文档、讨论记录、甚至代码提交历史。

“这比周报清楚多了。”他承认。

“而且省时间。”陈默收回手机，“一个项目经理，以前每周要花五小时汇总周报，现在只需要每天花十分钟更新看板。”

王振华靠在椅背上，脑子里快速计算。如果真能省下这些时间……

“但你还没说最重要的。”他抬头，“摆烂系统到底是什么？”

陈默的表情微妙起来。

“你觉得，一个公司最‘烂’的是什么？”他反问。

王振华想了想：“官僚主义？内卷？”

“是价值观扭曲。”陈默说，“当员工觉得‘加班=努力’，‘听话=好员工’，‘牺牲健康=敬业’——这个公司就烂到根了。”

他走到窗边，指着楼下：“我们公司六点准时下班。有人提前走，没人会用异样眼光看他。因为大家都知道，工作是为了生活，不是反过来。”

王振华想起自己以前，经常加班到十点，不是因为有活干，而是因为领导没走，同事没走，他不敢走。

“但这样……竞争力不会下降吗？”他问，“行业里大家都在卷。”

陈默转身：“你知道我们去年利润率多少吗？”

王振华摇头。

“38%。”陈默说，“行业平均不到15%。”

王振华愣住了。

“因为效率高，人力成本低，项目周期短。”陈默掰着手指，“同样的项目，我们三个月交付，竞争对手要半年。客户愿意为速度多付30%的钱。”

他坐回椅子上：“而且员工流失率，我们公司去年是5%，行业平均25%。省下来的招聘培训成本，又是几个点。”

王振华沉默了。

他想起张莉接手的那个智慧园区项目。前公司为了赶工，要求三个月出原型，团队已经开始加班。而按照陈默的说法，这种赶工模式反而会拖慢进度。

“你早就知道会这样？”他问。

陈默没有直接回答：“两年前，我还在前公司时，你提过一个‘培育生态’的理念。你说技术应该像种树，不是盖楼。”

王振华瞳孔微缩。那是他职业生涯最得意的想法之一，但在前公司被否决了——“太慢，董事会要短期成果”。

“我记得。”陈默说，“当时我就觉得，你是对的。但前公司的文化，容不下这种理念。”

“所以你离开了？”

“所以我创建了摆烂科技。”陈默说，“我想证明，正确的方式也能赚钱，甚至更赚钱。”

王振华看着眼前这个年轻人。两年前，陈默还只是他团队里一个普通的程序员。现在，对方是估值数十亿的公司创始人。

而他，刚刚被裁员。

“系统提示。”陈默突然说。

王振华一愣：“什么？”

陈默笑了笑：“没什么。只是想告诉你，你理解得很准。”

他站起来：“现在，你该向其他同事解释公司文化了。”

王振华也站起来：“就在这间会议室？”

“不。”陈默走向门口，“在楼下咖啡厅。我们公司没有‘会议室文化’——有事当面说，没事别凑一起。”

两人走出会议室。办公区里，员工们三三两两地聚在一起，有的在讨论代码，有的在喝咖啡聊天。没有那种压抑的安静，也没有假装忙碌的表演。

一个程序员看到陈默，举手打招呼：“陈总，那个支付接口的问题解决了，比预计快两小时。”

“不错。”陈默点头，“早点下班。”

程序员咧嘴一笑，收拾东西准备走。

王振华看着这一幕，心里五味杂陈。在前公司，提前完成任务的人会被分配更多任务，直到忙得喘不过气。

电梯里，王振华忍不住问：“你就不怕员工摸鱼？”

“怕啊。”陈默按下楼层按钮，“所以我们有数据监控。每个人的任务进度、代码质量、客户反馈，全部量化。”

他转头看王振华：“但监控不是为了抓摸鱼，是为了发现问题。如果一个人效率突然下降，我们会主动问他是不是遇到困难了。”

王振华想起前公司的监控——工位摄像头，键盘记录软件，连上厕所时间都被统计。

“这不一样。”陈默仿佛看穿他的想法，“我们监控的是产出，不是过程。只要活干得好，你爱怎么干怎么干。”

电梯门开了。

咖啡厅在公司一楼，装修得像休闲吧。几个员工坐在角落里，对着笔记本电脑讨论，桌上摆着咖啡和点心。

陈默带王振华在靠窗的位置坐下，点了两杯美式。

“现在，”陈默说，“你来告诉他们，我们公司为什么‘摆烂’。”

王振华看着陆续围过来的员工们，深吸一口气。

“我刚来，还在学习。”他开口，“但我想分享一个观察。”

他顿了顿：“以前在前公司，我每天加班到九点，但真正有效的工作时间不到四小时。剩下的时间，我在等领导审批，在写没人看的报告，在参加跑题的会。”

几个员工点头，显然有同感。

“来这里一天，我发现你们六点下班，但产出比前公司高。”王振华继续，“为什么？因为你们砍掉了所有‘烂’的东西。”

他看向陈默：“陈总刚才告诉我，公司文化的核心是反‘烂’。不是反工作，是反那些让工作变质的形式主义、无效加班、官僚主义。”

一个戴眼镜的程序员举手：“王总监，那你觉得我们公司还有什么可以改进的吗？”

王振华愣了一下。在前公司，新人第一天只敢听，不敢问，更别说提意见。

“我觉得……”他思考着，“沟通可以更透明。比如项目风险，应该更早暴露。”

陈默笑了：“说得好。我们正在开发一个风险预警系统，下周上线。”

王振华有些意外。在前公司，提意见会被认为“不懂事”，在这里却被认真对待。

“还有吗？”陈默问。

王振华想了想：“培训体系。新员工入职后，应该有更系统的引导。”

“我们有。”陈默说，“每个新员工配一个导师，不是领导，是同级别的同事。导师不负责考核，只负责解答问题。”

他补充：“而且导师有额外津贴，不是白干。”

王振华想起自己刚入职前公司时，被扔进项目组自生自灭，问问题还被嫌烦。

“最后一个问题。”一个年轻女孩举手，“王总监，你觉得我们公司最大的优势是什么？”

王振华看着周围这些年轻的面孔，突然明白了什么。

“是尊重。”他说，“你们尊重员工的时间，尊重专业，尊重人的基本需求。这听起来简单，但99%的公司做不到。”

陈默带头鼓掌。其他员工也跟着拍手。

王振华有点不好意思。在前公司，他从来没被这样对待过。

“系统提示。”陈默突然又说。

王振华这次真的愣了：“你到底在说什么系统？”

陈默眨眨眼：“公司内部管理系统。提醒我该开会了。”

他站起来：“你们继续聊，我还有个会要开。”

王振华看着陈默离开的背影，心里充满疑问。这个“系统”到底是什么？

咖啡厅里，员工们开始七嘴八舌地讨论起来。王振华听着他们的对话，发现每个人对公司文化都有自己的理解，但核心都是那三个词：效率、尊重、可持续。

一个产品经理坐过来：“王总监，你以前真的每天加班到九点？”

王振华苦笑：“有时候更晚。”

“图啥？”产品经理不解，“我们组有个规矩，活干完了就走。今天我三小时就搞完了需求文档，现在准备去看电影。”

王振华张了张嘴，不知道该说什么。在前公司，提前完成工作会被认为“工作量不饱和”，然后被塞更多活。

“对了，”产品经理压低声音，“陈总刚才说的那个‘系统’，你别太当真。他有时候说话神神叨叨的。”

王振华心里一动：“什么意思？”

“就是……”产品经理犹豫了一下，“陈总总说系统给他发任务，什么‘不要加班’‘挂领导电话’之类的。我们猜他可能有个什么APP，提醒自己别掉进老习惯。”

王振华想起陈默那些奇怪的“系统提示”，若有所思。

“不过陈总确实厉害。”产品经理继续，“两年前他还是普通程序员，现在公司估值几十亿。而且他从来不加班，每天五点准时走。”

“他怎么做到的？”王振华问。

产品经理笑了：“他说他有‘外挂’。我们都当玩笑听。”

王振华却笑不出来。他想起陈默那些精准的判断，对前公司问题的预见，还有今天解释公司文化时那种游刃有余。

这不像一个普通程序员该有的能力。

下午四点，王振华回到工位。他的电脑已经配好，系统账号也开通了。登录内部系统，他看到了陈默说的那个项目看板。

界面比陈默展示的更详细。每个任务都有时间估算、实际耗时、效率评分。他点开几个已完成的任务，发现员工们普遍能在预估时间内完成，甚至更快。

这太反常了。在前公司，项目延期是常态，提前完成是奇迹。

他继续探索系统，发现了更多功能。有一个“文化指数”板块，实时显示公司各项指标：平均下班时间、会议时长、代码质量、员工满意度……

所有数据都在行业平均之上。

王振华想起陈默说的“38%利润率”，突然信了。这样的效率，这样的员工状态，高利润是必然的。

“王总监。”

王振华抬头，看到一个年轻人站在他工位旁。

“我是李浩，你的导师。”年轻人伸出手，“陈总让我带你熟悉环境。”

王振华和他握手：“导师？不是领导？”

李浩笑了：“我们公司没有‘领导’这个说法。只有项目负责人、技术专家、产品负责人……没有上下级。”

“那怎么决策？”

“看数据，看专业。”李浩说，“比如技术方案，技术专家说了算。产品需求，产品经理说了算。陈总只负责大方向。”

王振华想起前公司，一个技术决策要经过五级审批，最后往往被不懂技术的领导拍脑袋否决。

“走，我带你转转。”李浩说，“给你看看我们真正的‘秘密武器’。”

他们来到一个标着“数据中枢”的房间。里面不是服务器，而是一面巨大的屏幕墙，实时显示着各种图表。

“这是公司的‘大脑’。”李浩说，“所有业务数据、项目进度、员工状态，都在这里。”

王振华看着屏幕。其中一个图表显示着“摆烂指数”，旁边有详细说明：数值越高，说明公司文化越健康。

当前数值：87。

“陈总每天看这个？”王振华问。

“每小时。”李浩说，“他说这是公司最重要的指标。比营收、利润都重要。”

王振华想起前公司，老板只看财报，从不关心员工状态。

“为什么叫‘摆烂指数’？”他问。

李浩笑了：“陈总说，真正的‘摆烂’不是不工作，是拒绝所有让工作变‘烂’的东西。这个指数衡量的就是公司‘烂’的程度。”

他指着屏幕：“比如无效加班率、形式主义指数、官僚主义系数……这些越低，摆烂指数越高。”

王振华恍然大悟。原来“摆烂”是这个意思。

“现在你明白公司文化了吧？”李浩问。

王振华点头：“明白了。但还有一个问题——怎么让所有人认同这种文化？”

李浩指了指屏幕：“靠数据，靠结果。当员工发现，在这里工作更轻松、收入更高、成长更快，自然就认同了。”

他补充：“而且我们招人时就筛选过。认同‘摆烂’理念的才进来，不认同的给再多钱也不要。”

王振华想起自己面试时的场景。陈默确实问了很多关于工作理念的问题，当时他以为只是客套。

“最后一个问题。”王振华说，“陈总真的有个‘系统’吗？”

李浩的表情变得微妙：“你问这个干嘛？”

“好奇。”王振华说，“他今天提了好几次‘系统提示’。”

李浩左右看了看，压低声音：“其实我们私下讨论过。陈总可能有个什么习惯养成APP，或者心理暗示工具。他总说系统给他发任务，什么‘明天不要加班’‘挂掉领导电话’之类的。”

“结果呢？”

“结果他真的不加班，真的敢挂领导电话。”李浩笑了，“而且公司越做越大。所以我们都当是陈总的个人风格，不深究。”

王振华若有所思。一个APP，能让一个程序员在两年内创建估值几十亿的公司？这说不通。

除非……那个“系统”是真的。

这个念头一冒出来，王振华自己都吓了一跳。但回想起陈默那些精准的判断，反常的行为，还有今天解释公司文化时那种超乎常人的自信……

“王总监？”李浩的声音打断他的思绪。

王振华回过神：“没事，就是想事情。”

他看了眼时间，下午五点。办公区里，员工们开始收拾东西，三三两两地离开。

“下班了？”王振华问。

“准时下班。”李浩说，“这是公司铁律。除非紧急情况，否则六点后不准工作。”

王振华看着空荡荡的办公区，想起前公司灯火通明到深夜的场景。

“走吧。”李浩拍拍他，“第一天别太累。明天还有更多东西要学。”

王振华跟着李浩走出公司大楼。夕阳西下，街上满是下班的人流。他深吸一口气，感觉胸口那股压了两年的闷气，似乎消散了一些。

手机震动。张莉发来消息：“智慧园区项目组已经开始加班，你确定不回来？机会难得。”

王振华看着这条消息，突然笑了。

他回复：“不用了，谢谢。”

然后拉黑了张莉。

走出大楼时，他回头看了一眼。摆烂科技的招牌在夕阳下闪闪发光。

“系统提示。”他仿佛听到陈默的声音。

王振华摇摇头，走向地铁站。不管那个“系统”是什么，他知道自己找到了正确的地方。

而此刻，在顶楼办公室，陈默看着王振华离开的背影，眼前浮现只有他能看到的界面：

【任务“摆烂总监的深层逻辑”进度：70%】

【隐藏条件触发：理解公司文化真谛】

【额外奖励解锁中……】

陈默笑了。王振华比他想象的更有悟性。

“真正的摆烂，”他自言自语，“是让所有人都能摆烂。”

窗外，城市华灯初上。而在摆烂科技的办公楼里，灯光早已熄灭。

只有数据中枢的屏幕墙，依然闪烁着幽蓝的光。

摆烂指数：88。

比昨天高了一点。
