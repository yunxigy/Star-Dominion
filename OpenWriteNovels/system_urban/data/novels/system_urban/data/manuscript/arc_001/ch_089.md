# 狼性与摆烂

会议室里的空气像是凝固了。

刘强靠在椅背上，手指有节奏地敲着桌面。他盯着王振华，眼神里带着审视，也带着一丝不易察觉的困惑。

“王总，”刘强终于开口，声音比刚才低了几分，“你刚才说的那些，听起来很理想。但现实不是实验室，市场不等人。”

王振华没急着接话。他端起茶杯，慢悠悠地喝了一口，让茶香在舌尖上多停留了几秒。

系统提示音在脑海里响起：

【任务“客户的试探”完成度：80%】

【隐藏任务“摆烂的哲学”进度：2/3】

【剩余：向外部人士证明“摆烂”的价值】

王振华放下茶杯，指尖在杯沿上轻轻划过。

“刘总，”他抬起眼，“你刚才提到三年前那次项目延期，说是人性化管理导致的。我想问个问题——当时项目延期的根本原因是什么？”

刘强愣了一下，显然没料到他会追问这个。

“原因很复杂，”刘强说，“市场环境变化，客户需求临时调整，团队经验不足……”

“这些是客观原因，”王振华打断他，“我想问的是，如果当时团队没有每周工作80小时，如果他们有足够的时间休息和思考，会不会在需求调整的时候反应更快？”

刘强皱眉：“你的意思是，加班反而拖慢了进度？”

“我的意思是，”王振华身体前倾，双手交叉放在桌上，“疲惫的大脑会犯错。犯错就要返工，返工就要花更多时间。这不是管理问题，是生理规律。”

会议室里安静了几秒。

刘强突然笑了，不是客气的那种笑，是真正觉得有意思的笑。

“王总，你很有意思。”他说，“我见过很多创业公司老板，要么是狼性文化的信徒，要么是理想主义的空谈家。你这种……”

他顿了顿，似乎在找一个合适的词。

“你这种‘摆烂哲学’，我还是第一次见。”

王振华也笑了。

“刘总，其实我有个问题一直想问。”他说。

刘强挑眉：“什么问题？”

“你们公司最值得学习的地方是什么？”

这句话一出口，王振华感觉到口袋里的名片微微发热。

系统提示：

【任务触发：询问“你们公司最值得学习的地方是什么”】

【任务状态：进行中】

【奖励：未知】

刘强显然没想到他会问这个。他靠回椅背，手指在扶手上敲了几下，似乎在认真思考。

“最值得学习的地方……”他重复了一遍，“你这个问题问得很有意思。大部分来谈合作的人，要么问我们能给他们什么，要么问他们能给我们什么。问我们‘值得学习的地方’的，你是第一个。”

王振华没说话，只是静静地等着。

刘强沉吟片刻，开口道：“要说最值得学习的，应该是我们的执行力。一旦决定做某件事，整个团队能迅速调动起来，不计代价地去完成。”

“不计代价？”王振华抓住了这个词。

“对，不计代价。”刘强点头，“市场不等人，机会稍纵即逝。有时候你必须牺牲一些东西——休息时间、个人生活，甚至健康——来换取速度和结果。”

王振华身体微微后仰。

“刘总，”他说，“我理解你的意思。但我想问，这种‘不计代价’的执行力，可持续吗？”

刘强沉默了。

会议室里的空调发出轻微的嗡嗡声，像是某种背景音乐。

“可持续？”刘强终于开口，“王总，创业公司哪有可持续的？要么活下来，要么死掉。活下来之后，才有资格谈可持续。”

王振华点头：“你说得对。但问题是，如果一个团队长期‘不计代价’地工作，他们的创造力会下降，犯错率会上升，人员流失会加剧。这些成本，最终会反映在产品和服务上。”

他顿了顿，继续说：“我见过太多公司，靠着狼性文化冲到行业前三，然后因为团队疲惫、人才流失、创新乏力，慢慢掉队。这不是个例，是普遍现象。”

刘强的手指停止了敲击。

他盯着王振华，眼神复杂。

“王总，”他说，“你是在暗示，我们鼎盛科技也会走上那条路？”

“我没有暗示任何事，”王振华摇头，“我只是在陈述一个观察。每个公司都有自己的选择，但每个选择都有代价。”

会议室里再次陷入沉默。

刘强站起身，走到窗边，背对着王振华。窗外是城市的天际线，高楼林立，车流不息。

“王总，”他背对着说，“你知道我为什么想见你吗？”

王振华没回答。

“因为摆烂科技。”刘强转过身，“你们公司成立不到两年，从零做到现在这个规模。没有融资，没有烧钱，没有狼性文化。这在行业里是个奇迹。”

他走回桌边，双手撑在桌面上，身体前倾。

“我想知道，你们是怎么做到的。”

王振华感觉到口袋里的名片又热了一下。

系统提示：

【任务“询问‘你们公司最值得学习的地方是什么’”完成】

【奖励发放中……】

【获得：刘强的深度认可】

【效果：后续合作谈判中，对方信任度+30%】

王振华心里一动，但面上不动声色。

“刘总，”他说，“我们能做到现在，靠的不是奇迹，是方法。”

“什么方法？”

“尊重规律。”王振华说，“人的精力是有限的，创造力是需要休息来恢复的，高效工作需要清晰的头脑。我们只是把这些常识，变成了制度。”

刘强坐回椅子，双手交叉放在胸前。

“具体说说。”

王振华从公文包里拿出一份文件，推到刘强面前。

“这是我们公司的‘摆烂守则’，”他说，“你可以看看。”

刘强拿起文件，快速翻阅。

“每周工作不超过40小时？”他念出来，“连续两周加班超10小时，系统自动预警？主管必须介入？”

“对。”王振华点头。

“员工家里有事，可以带薪休假，不扣工资，不扣绩效？”

“对。”

“禁止无效会议，会议时间不超过30分钟，必须有明确议程和结论？”

“对。”

刘强放下文件，抬头看王振华。

“王总，”他说，“你这套制度，在传统企业眼里，简直是离经叛道。”

“我知道。”王振华说，“但结果呢？我们的人均产出是行业平均的1.5倍，员工流失率是行业平均的三分之一，客户满意度是行业前五。”

刘强沉默了。

他再次拿起那份文件，仔细看了一遍，然后放下。

“王总，”他说，“我承认，你说的有道理。但鼎盛科技不是摆烂科技，我们的规模、业务、市场压力都不一样。你的方法，未必适合我们。”

“我明白。”王振华说，“我不是来推销方法的，我是来谈合作的。但我想让你知道，摆烂科技之所以能走到今天，靠的不是运气，是理念。”

刘强点头：“我理解了。”

他站起身，伸出手。

“王总，今天的会谈很愉快。我会认真考虑合作的事。”

王振华也站起来，握住他的手。

“刘总，期待后续。”

两人握手，力度适中，时间恰到好处。

刘强送王振华到会议室门口，突然开口：“王总，最后问你一个问题。”

“请说。”

“如果有一天，摆烂科技面临生死存亡的危机，你会不会也选择‘不计代价’地工作？”

王振华笑了。

“刘总，”他说，“如果真有那一天，我会选择‘不计代价’地思考，而不是‘不计代价’地工作。”

刘强愣了一下，然后大笑起来。

“有意思，”他说，“真有意思。”

王振华转身离开，走进电梯。

电梯门关上的瞬间，他感觉到口袋里的名片彻底凉了下来。

系统提示：

【任务“客户的试探”完成度：100%】

【隐藏任务“摆烂的哲学”进度：3/3】

【剩余：无】

【奖励发放中……】

【获得：刘强的私人联系方式】

【获得：鼎盛科技“智慧社区”项目优先谈判权】

【获得：摆烂值+500】

【当前摆烂值：2850/10000】

王振华看着系统面板，嘴角微微上扬。

电梯到达一楼，门开了。

他走出电梯，穿过大堂，推开玻璃门。

外面阳光正好，微风拂面。

王振华深吸一口气，掏出手机，给陈默发了条消息：

“谈完了，有进展。”

几秒后，陈默回复：

“回来开会，有新情况。”

王振华皱眉，回复：

“什么情况？”

陈默的回复只有两个字：

“急事。”

王振华收起手机，快步走向停车场。

他发动汽车，驶入车流。

车载广播正在播放新闻：

“近日，多家科技公司宣布调整工作制度，减少加班时间，引发行业热议。有分析人士指出，这可能是职场文化变革的信号……”

王振华关掉广播，踩下油门。

车子汇入主干道，朝着摆烂科技的方向驶去。

他不知道陈默说的“急事”是什么，但他知道，摆烂科技的路，才刚刚开始。

而真正的摆烂，或许才刚刚开始。
