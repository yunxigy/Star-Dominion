# 第十章 书面条件

上午十点前，陈默把证据目录、受理通知书和周律师的邮件打印出来，依次放进文件夹。烤面包机发出轻微的嗡鸣声，蓝莓在白瓷碗里堆成小山，咖啡机正在研磨新鲜的咖啡豆，浓郁的香气弥漫在整个开放式厨房里。

【系统提示：信息归档技能生效，今日重复沟通提醒已开启。】

陈默嘴角微扬，熟练地将煎蛋翻面。进口鸡蛋在平底锅里滋滋作响，蛋黄保持完美的溏心状态。他想起五年前刚入职时，每天早上只能啃着便利店冷掉的包子挤地铁的日子。

“叮：”

手机震动起来，屏幕上显示“刘经理”三个字。

陈默看了眼系统界面，今日任务“拒绝所有非必要社交”正闪烁着淡蓝色的光。他慢条斯理地将煎蛋盛入盘中，淋上少许酱油，然后才不紧不慢地拿起手机。

“喂？”

“陈默！你到底什么意思？”刘经理的声音从听筒里炸开，“公司给你机会你不把握，非要闹到仲裁？你知道仲裁要多久吗？半年！一年！这段时间你靠什么生活？”

陈默咬了口吐司，咀嚼了两下才回应：“刘经理，我现在在吃早餐。”

“吃早餐？你还有心情吃早餐？”刘经理气急败坏，“我告诉你，公司法务部可不是吃素的！你一个普通员工，跟公司打官司，赢面有多大？”

【系统提示：检测到公司再次提出口头和解。建议：只接受可核对的书面条款。】

陈默没有马上回拨。他先把电脑里的证据目录和昨日的受理通知书放进同一个文件夹，再给周律师发了一封邮件。

“陈默？陈默你还在听吗？”刘经理的声音从手机里传出，显得有些失真。

蓝莓的酸甜在口中爆开，陈默舀了一勺酸奶淋上去。咖啡机发出完成的提示音，他起身去倒了杯咖啡。

“陈默！你别以为不说话就能拖过去！”

“我在。”陈默喝了口咖啡，“刘经理，您说的公司法务部，是指上次那个连劳动合同法第三十八条都背不全的实习生吗？”

电话那头突然安静了。

陈默继续吃早餐，叉子轻碰瓷盘的声音在安静的厨房里格外清晰。

“你...你调查过？”刘经理的声音明显弱了下来。

“周律师告诉我的。”陈默放下叉子，“对了，我已经委托周正律师事务所全权代理这个案子。后续所有沟通，请直接联系我的代理律师。”

“周正律师事务所？”刘经理倒吸一口凉气，“那家专门打劳动官司的律所？陈默，你疯了吗？你哪来的钱请他们？”

陈默没有回答。他想起昨天下午在律所里，周律师推了推金丝眼镜，用平静的语气说出的话：“陈先生，这个案子我们接了。按风险代理，前期不收费，胜诉后我们收取赔偿金的15%。”

当时陈默问：“如果败诉呢？”

周律师笑了：“陈先生，这个案子如果败诉，我周正的名字倒过来写。”

【系统提示：整理材料完成，摆烂值+15，当前摆烂值：820点。】

“陈默！你听见我说话没有？”刘经理的声音将陈默拉回现实。

“听见了。”陈默拿起餐巾擦了擦嘴，“刘经理，如果没什么事，我要继续吃早餐了。”

“等等！”刘经理急忙说，“公司愿意让步！赔偿金可以再加一点，11万！11万怎么样？只要你签保密协议，今天下午钱就能到账！”

陈默看了眼系统界面。隐藏任务【仲裁先锋】的进度条静静躺在那里，10%的进度泛着微光。

“刘经理，”陈默的声音很平静，“我的诉求是105,800元，以及解除证明上必须注明‘公司提出解除’。这是我的底线。”

“你...”

“如果公司同意，我们可以庭外和解。”陈默端起咖啡杯，“如果不同意，那就仲裁庭见吧。”

电话那头传来急促的呼吸声，然后是一阵窸窸窣窣的声响。过了大概半分钟，刘经理的声音再次响起，这次带着某种刻意压低的急切：

“陈默，我跟你说实话。公司最近在裁员，如果每个人都像你这样闹，公司受不了的。你就算不为自己想，也为其他同事想想...”

“刘经理，”陈默打断他，“三年前公司第一次裁员时，您也是这么对被裁的同事说的。当时我信了，所以主动降薪20%，还签了那份‘自愿放弃加班费’的协议。”

电话那头彻底沉默了。

陈默放下咖啡杯，声音很轻：“三年了，刘经理。该还的，总要还的。”

他挂断了电话。

【系统提示：今日任务完成，摆烂值+20，当前摆烂值：840点。】

【仲裁节点：等待调解通知。】

陈默收拾好餐具，将它们放进洗碗机。洗碗机开始运转时发出的低沉嗡鸣，让他想起公司里那台永远修不好的打印机。

他走到书房，打开笔记本电脑。屏幕上还停留着昨天周律师发来的《劳动仲裁申请书》电子版。陈默点开，仔细核对每一项诉求：

1. 违法解除劳动合同赔偿金：105,800元（2×5.5个月×10,000元/月）
2. 未休年假工资：8,275元（5天×10,000元/月÷21.75天×300%）
3. 出具解除劳动合同证明，并注明“公司提出解除”

周律师在文件最后用红色字体标注：【重点：公司裁员通知无公章、无签字、未提前30日通知工会，程序严重违法。根据劳动合同法第四十三条，用人单位单方解除劳动合同，应当事先将理由通知工会。】

陈默记得昨天周律师说这段话时的表情，那是一种审阅证据时的冷静与笃定。

“陈先生，你知道为什么很多劳动者仲裁会输吗？”周律师当时问。

陈默摇头。

“因为他们只盯着实体权利，忽略了程序正义。”周律师推了推眼镜，“公司裁员，必须符合劳动合同法第四十一条规定的条件和程序。你的公司既没有证明生产经营发生严重困难，也没有提前30日向工会或全体职工说明情况，更没有听取工会或职工的意见。光是这一条，就够他们喝一壶的。”

陈默当时问：“那为什么公司还敢这么做？”

周律师笑了：“因为他们赌你不懂法，赌你怕麻烦，赌你耗不起。大多数劳动者，听到‘仲裁要半年’就怂了。但陈先生...”他顿了顿，“你不一样。”

是啊，我不一样。

陈默关掉文件，打开系统界面。摆烂值已经累积到595点，距离下一个技能解锁还差5点。

【系统提示：宿主阅读调解通知，触发成就“先看小字”。奖励：摆烂值+25，合同识别能力提升。】

陈默觉得脑子里多了些什么东西。他试着回想劳动合同法第四十一条的具体内容，那些条文竟然清晰地浮现在脑海里：

“有下列情形之一，需要裁减人员二十人以上或者裁减不足二十人但占企业职工总数百分之十以上的，用人单位提前三十日向工会或者全体职工说明情况，听取工会或者职工的意见后，裁减人员方案经向劳动行政部门报告，可以裁减人员...”

他愣住了。

系统连这个都能奖励？

手机再次震动起来，这次是一个陌生号码。

陈默接起电话：“喂？”

“请问是陈默先生吗？”对方的声音很职业化，“这里是星辰科技人力资源部，我是HR总监李薇。”

陈默挑了挑眉。星辰科技，正是他前公司的名字。

“李总监，有什么事？”

“陈先生，关于您与公司的劳动争议，公司高层非常重视。”李薇的声音很平稳，“经过紧急会议，公司决定接受您的全部诉求。赔偿金105,800元，解除证明会按您的要求出具。如果您同意，我们可以立即安排签署和解协议。”

陈默看了眼时间，上午九点四十五分。

“李总监，”他慢悠悠地说，“我记得昨天下午，刘经理还告诉我，公司法务部会‘奉陪到底’。”

电话那头沉默了几秒。

“陈先生，公司确实愿意展现诚意。”李薇的声音依旧平稳，“如果您今天上午能来公司签署协议，我们可以在24小时内完成打款。”

【系统提示：检测到公司书面和解方案，主线节点解锁：核对条款。】

陈默的手指在桌面上轻轻敲击。

他想起五年前入职时，HR总监亲自给他倒茶，笑着说：“陈默是吧？欢迎加入星辰科技，我们公司最重视人才。”

他想起三年前，公司第一次“优化”时，那个被裁的同事在办公室里哭，刘经理拍着他的肩膀说：“公司也是没办法，你要理解。”

他想起一年前，他连续加班一个月赶项目，最后奖金被以“公司效益不好”为由砍掉一半。

“李总监，”陈默开口了，声音很平静，“我的诉求不变。105,800元，解除证明注明‘公司提出解除’。但我有一个额外条件。”

“您说。”

“我要公司向所有被违法裁员的员工，公开书面道歉。”

电话那头传来急促的呼吸声。

“陈先生，这...”

“并且，”陈默继续说，“我要公司承诺，在未来一年内，不再进行任何违法裁员。如果违反，公司需要向每位受影响员工额外支付一个月工资作为赔偿。”

【系统提示：宿主选择逐条核对，没有提前结算。摆烂值+30，当前摆烂值：870点。】

李总监的声音变了：“陈先生，您这是...您知道您在要求什么吗？”

“我知道。”陈默站起身，走到窗前。阳光照在他脸上，有些刺眼，“李总监，我昨天在周律师那里，看到了过去五年星辰科技所有被裁员工的仲裁记录。一共47人，其中43人接受了低于法定标准的赔偿，3人仲裁后败诉，只有1人拿到了法定赔偿。”

他顿了顿：“那个人，是因为公司忘了销毁他加班打卡的记录。”

电话那头彻底安静了。

“李总监，”陈默的声音很轻，“我不只是在为自己争取权益。我在为那43个人，为未来可能被裁的每一个人，争取一个说法。”

漫长的沉默。

然后，李总监的声音再次响起，这次带着某种陈默从未听过的疲惫：

“陈先生，您的条件...我需要请示董事会。”

“请便。”陈默看了眼时间，“我今天下午两点，会准时出现在劳动仲裁委立案窗口。如果两点之前，我没有收到公司的书面答复，我会视为公司拒绝和解，正式提交仲裁申请。”

他挂断了电话。

【系统提示：宿主发现免责条款，主线节点完成：1/2。】

【隐藏任务【仲裁先锋】进度更新：45%】

【成就奖励：合同识别（初级）。】

陈默感觉自己的呼吸变得更加平稳，站姿也不自觉地挺直了。他走到穿衣镜前，看着镜中的自己，还是那张普通的脸，但眼神似乎有些不同。

手机再次震动，这次是周律师。

“陈先生，刚收到星辰科技法务部的邮件。”周律师的声音带着明显的惊讶，“他们回复愿意把公开道歉和未来一年的合规承诺写入和解协议。他们希望今天上午十一点，在公司会议室签署正式和解协议。”

陈默看了眼系统界面。隐藏任务的进度条正在缓慢跳动，从45%跳到了50%。

“周律师，”陈默说，“和解协议里，我要加一条。”

“您说。”

“如果公司违反承诺，每违反一次，需要向受影响员工支付双倍赔偿。这一条，要写进协议里，具有法律效力。”

周律师在电话那头笑了：“陈先生，您这是把星辰科技的承诺逐条写进协议了。”

“是他们自己点的火。”陈默说，“我只是不想让火烧到更多人。”

挂断电话后，陈默开始准备出门。他换上昨天新买的衬衫，料子很好，剪裁也合体，是系统奖励的“生活品质提升包”里那套。

出门前，他看了眼系统界面。摆烂值已经累积到825点，距离解锁下一个技能还差75点。

【系统提示：检测到明日需要签署文件，已将待办事项排序。】

陈默笑了笑，从厨房柜子里拿出一包系统奖励的混合坚果，放进公文包。

电梯下行时，他对着镜面整理了一下衣领。镜中的男人眼神平静，嘴角带着若有若无的弧度。

这不像要去打一场硬仗，倒像是要去赴一个约。

一个迟到了五年的约。
