# 梦回三年前

陈默睁开眼睛的时候，发现自己正坐在一把硬邦邦的塑料椅上。

周围是熟悉的会议室，米白色的墙壁上挂着“天道酬勤”的书法作品，长条会议桌对面坐着人事部的张姐，她正低头翻着一份文件。空调发出低沉的嗡嗡声，窗户外面能看到对面写字楼的玻璃幕墙反射着刺眼的阳光。

三年前的阳光。

陈默低头看自己的手——年轻的、还没被996摧残过的手。他穿着三年前那件洗得发白的格子衬衫，袖口有些磨损，但还扣得整整齐齐。

【当前场景：三年前被裁员当天，公司会议室】

【关键节点1：拒绝签署裁员协议】

【任务要求：用合法合理的方式拒绝签字，并争取应得权益】

【奖励：摆烂值+10，解锁“谈判专家”被动技能】

【惩罚：若签署协议，将永久失去“硬气”属性】

陈默深吸一口气。空气里有打印机墨水和廉价空气清新剂的味道，还有张姐身上那股浓烈的香水味——三年前他闻不习惯，现在还是闻不习惯。

“陈默，这是你的离职协议。”张姐把文件推过来，指甲涂着鲜红的甲油，“签了吧，公司会给你N+1的补偿。”

陈默没动。

他盯着那份文件，白纸黑字写着“自愿离职协议书”。三年前的他确实签了，签完字走出公司大门的时候，甚至觉得松了口气——不用再每天加班到凌晨，不用再面对赵明远那张永远不满意的脸。

但现在不一样了。

“张姐，”陈默开口，声音比三年前沉稳得多，“这份协议有问题。”

张姐抬起头，眉毛挑了一下：“什么问题？”

“第一，”陈默伸出一根手指，“协议标题写的是‘自愿离职协议书’，但根据《劳动合同法》第四十条，公司因经营困难裁员，应该出具‘解除劳动合同通知书’，而不是让员工签自愿离职。”

张姐的表情僵了一瞬。

“第二，”陈默继续说，“协议里写的补偿是N+1，但根据法律规定，经济性裁员应该支付N+1个月工资的经济补偿金，这里的N是指工作年限。我在公司工作了两年零三个月，应该按三年计算。”

会议室里安静了几秒。空调的嗡嗡声突然变得很响。

张姐放下手里的笔，靠向椅背：“陈默，你今天怎么了？以前你不是这样的。”

“以前是以前。”陈默说，“现在我想按法律规定的来。”

【系统提示：节点1完成度70%】

【建议：继续施压，争取更多权益】

陈默心里有了底。他继续说：“第三，我在公司期间累计加班时长超过800小时，其中大部分没有支付加班费。根据《劳动法》第四十四条，工作日加班应支付1.5倍工资，休息日加班应支付2倍工资，法定节假日应支付3倍工资。这部分费用，公司需要结清。”

张姐的脸色变了。她坐直身体，手指在桌面上敲了两下：“陈默，你要想清楚。公司现在经营困难，大家都不容易。你这样闹，对你以后找工作没好处。”

“这不是闹，”陈默说，“这是依法维权。”

“你——”

“如果公司不愿意协商，”陈默打断她，“我可以向劳动仲裁委员会申请仲裁。到时候公司不仅要支付加班费和经济补偿金，还可能面临行政处罚。”

张姐盯着他看了好几秒，然后站起身：“你等一下。”

她走出会议室，高跟鞋敲在地板上发出清脆的响声。陈默听见她在走廊里打电话，声音压得很低，但隐约能听到“难搞”、“懂法”、“要仲裁”这几个词。

陈默靠向椅背，看着墙上那幅“天道酬勤”。三年前他觉得这四个字说得对，现在只觉得讽刺。

会议室的门被推开了。

走进来的是技术总监赵明远，四十岁出头，头发梳得一丝不苟，穿着熨烫平整的衬衫。他手里拿着陈默的离职协议，脸上挂着那种“我是为你好”的表情。

“陈默啊，”赵明远在他对面坐下，“张姐跟我说了。你今天怎么突然这么较真？”

“赵总，”陈默说，“这不是较真，是维护合法权益。”

赵明远笑了笑，把协议放在桌上：“公司有公司的难处。现在市场环境不好，裁员也是没办法的事。你签了协议，拿着补偿金出去，大家好聚好散，对不对？”

“那我的加班费呢？”陈默问。

赵明远的笑容淡了一点：“加班费的事，以后可以再商量。”

“以后是多久？”陈默追问，“一个月？三个月？还是一年？”

“陈默，”赵明远的语气严肃起来，“你这样钻牛角尖，对谁都没好处。公司现在确实困难，但如果你配合，我可以跟HR说，给你多争取一点补偿。”

“多少？”

“N+2，”赵明远说，“这已经是破例了。”

陈默摇头：“不够。我要N+3，加上全部加班费。”

“你——”赵明远深吸一口气，“陈默，你要知道，你现在是在跟公司谈条件。公司愿意给你补偿，已经是仁至义尽了。”

“那咱们就按法律程序走吧。”陈默站起身，“我会去劳动仲裁委员会申请仲裁。如果仲裁结果不满意，我会继续向法院起诉。”

他转身要走。

“等等！”赵明远叫住他。

陈默停下脚步，但没回头。

会议室里安静了十几秒。陈默听见赵明远在身后叹气，然后是纸张翻动的声音。

“好，”赵明远说，“我答应你。N+3，加班费按实际记录结算。但你要签保密协议，不能对外说公司的任何事。”

陈默转过身：“可以。但保密协议要加上一条：如果公司拖欠或克扣补偿，保密协议自动失效。”

赵明远盯着他看了很久，最后点了点头：“行。让张姐重新拟协议。”

陈默坐回椅子上，感觉心脏在胸腔里跳得很快。三年前的他绝对想不到，自己有一天会这样跟赵明远说话。

张姐很快拿着新协议进来了。陈默仔细看了每一条，确认加班费的计算方式、补偿金的支付时间、保密协议的附加条款都没问题，才签下自己的名字。

等他再次看清周围时，发现自己站在公司大楼的门口。

是三年前的那个傍晚，夕阳把玻璃幕墙染成金色。同事们三三两两地走出来，有人在抱怨加班，有人在约晚饭。陈默看见年轻的自己——穿着那件洗得发白的格子衬衫——正低着头走出旋转门，手里捏着那份刚签好的离职协议。

年轻的陈默转过身，脸上带着茫然和疲惫。看见陈默的脸时，他愣了一下：“你是……”

“我是你。”陈默说，“三年后的你。”

年轻的陈默眨了眨眼，然后苦笑：“开什么玩笑。我现在这个样子，三年后能好到哪去？”

“比你想象的好。”陈默说，“你签了离职协议，拿到了应得的补偿。你没有像三年前那样忍气吞声，你维护了自己的权益。”

年轻的陈默低头看手里的协议：“可是……我还是被裁员了。我努力工作，加班到凌晨，结果呢？说裁就裁。”

“那不是你的错。”陈默说，“是公司的问题，是职场文化的问题。你不需要为别人的错误买单。”

年轻的陈默抬起头，眼睛里有什么东西在闪：“那我以后该怎么办？我不知道自己还能做什么。”

陈默看着三年前的自己，想起那时候的焦虑、迷茫、自我怀疑。每天晚上躺在床上，盯着天花板，想着明天要去哪家公司投简历，想着房租怎么办，想着父母打电话来该怎么说。

“你会找到出路的。”陈默说，“你会遇到一些人，做一些事，慢慢找到自己的路。这条路可能跟别人不一样，但那是你自己的路。”

夕阳正在下沉，把他们的影子拉得很长。公司大楼的灯光一盏盏亮起来，加班的人又开始忙碌了。
