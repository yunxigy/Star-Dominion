# 第一章 裁员

陈默盯着办公桌上那封信，白纸黑字，右下角盖着鲜红的公司公章。

"经公司研究决定，因业务调整，您的劳动合同将于本月31日终止……"

他反复读了三遍，每个字都认识，连在一起却像天书。

"陈默，来一下会议室。"

人事部经理张莉站在会议室门口，脸上挂着职业化的微笑。陈默机械地站起身，膝盖撞在桌角上，疼得他倒吸一口凉气，但此刻他顾不上这些。

会议室里坐着部门主管王建国，还有两个陈默叫不上名字的西装男。空调开得很足，冷气顺着脊背往上爬。

"坐吧。"王建国指了指对面的椅子。

陈默坐下，手心全是汗。

"公司最近在优化组织结构，"王建国开口，声音平稳得像在念新闻稿，"你的岗位……被优化了。"

优化。

陈默在心里咀嚼这个词。他在星辰科技干了五年，从实习生做到项目主管，加过的班能绕公司三圈。上个月他还通宵三天赶出了一个大项目，王建国拍着他的肩膀说"好好干，年底给你升职"。

现在，这叫"优化"。

"这是解除劳动合同协议，"张莉把一份文件推到他面前，"你看一下，没问题的话签个字。公司会按照N+1的标准给你补偿。"

N+1。

陈默低头看着协议上的数字。五年，六个月工资。他月薪一万五，算下来是九万。

九万块钱，买断他五年的青春。

他拿起笔，笔尖悬在签名栏上方。

就在这一刻，

"叮："

一个清脆的电子音在脑海里响起。

陈默手一抖，笔尖在纸上划出一道黑线。

"摆烂系统绑定成功。检测到宿主正在被裁员，触发新手任务：拒绝签字，奖励10万元。"

声音直接出现在脑子里，清晰得不像幻觉。

陈默愣住了。

"陈默？"王建国皱起眉，"签啊。"

陈默抬起头，看着会议室里的三个人。他们脸上都写着"快点签完我们好下班"的表情。

脑子里那个声音又响了："任务倒计时：30秒。完成奖励10万元，失败惩罚：无。"

十万。

比协议上的补偿还多一万。

陈默不知道自己是并非疯了。也许是压力太大产生的幻觉。管他呢。

他放下笔。

"我不签。"

会议室里瞬间安静。

王建国脸上的笑容僵住了："你说什么？"

"我说，我不签这个协议。"陈默听见自己的声音，平静得不像话，"根据劳动合同法，公司单方面解除合同需要支付双倍补偿。你们给N+1，不符合规定。"

他根本不知道自己怎么会说出这些话。他只是个普通上班族，并非法律专家。

但系统似乎很欣赏他的表现。

"叮：新手任务完成。奖励10万元已发放至宿主银行账户，请注意查收。"

陈默感觉口袋里的手机震了一下。

王建国的脸色黑了："陈默，你别不识好歹。公司已经仁至义尽了，你要是闹，以后在这个行业里混不下去。"

"王主管，"陈默打断他，"如果公司坚持按N+1解除合同，我会申请劳动仲裁。仲裁不成，我就起诉。"

他说完自己都吓了一跳。

张莉打圆场："陈默，有话好好说嘛。是并非对补偿金额不满意？我们可以再谈。"

"没什么好谈的。"陈默站起身，"要么双倍补偿，要么法庭见。"

他转身走出会议室，心脏在胸腔里狂跳。

走廊里，几个同事投来好奇的目光。陈默面无表情地走回自己的工位，坐下，打开电脑。

屏幕右下角弹出一条银行通知："您尾号3347的账户于15:32收入人民币100,000.00元。"

十万块。

真的到账了。

陈默盯着那串数字，手指开始发抖。这并非幻觉。他真的绑定了一个叫"摆烂系统"的东西。而且，只要他拒绝签字，这种在职场上堪称"自杀"的行为，就真的能换来十万块钱。

"陈默，你没事吧？"隔壁工位的李薇探过头来，小声问，"我看见你从会议室出来，脸色不太好。"

陈默回过神，摇摇头："没事。"

"是并非……裁员的事？"李薇压低声音，"我听说这次要裁掉整个项目二组，我们组也可能……"

陈默没说话。他点开手机银行APP，余额显示：103,247.56元。这是他工作五年攒下的全部积蓄，加上刚刚到账的十万。

十万块。他需要不吃不喝工作半年才能攒到的钱，现在因为一次拒绝签字，轻松到手了。

"叮：新任务发布。"

那个声音又来了。

陈默深吸一口气，集中注意力。

"任务内容：明天不去上班，在家睡到自然醒。任务奖励：市中心公寓首付（价值约50万元）。任务时限：明日上午9:00前。"

市中心公寓的首付。

陈默所在的这座城市，市中心一套一居室的首付至少要五十万。他要不吃不喝干十年，才能攒到这个数。

而现在，只要他明天不去上班，睡到自然醒，就能得到。

这太离谱了。离谱到陈默开始怀疑，这个系统是并非什么新型诈骗。

但十万块钱是真的。

他靠在椅背上，盯着天花板。去，还是不去？

如果去了，他还是那个勤勤恳恳的上班族陈默。明天会被王建国叫去谈话，会被迫签协议，然后拿着九万块钱滚蛋。

如果不去……

陈默想起过去五年。想起无数个加班的深夜，想起错过的朋友聚会，想起因为太忙而分手的女友。想起上个月通宵赶项目时，心脏突然抽痛的那几秒。

他想起王建国刚才的脸。

"优化。"

去他妈的优化。

陈默关掉电脑，拿起背包。

"陈默，你去哪？"李薇惊讶地问，"还没到下班时间呢。"

"回家。"

"可是，王主管还没发话……"

陈默已经走出了办公室。

电梯里，他掏出手机，盯着银行余额。

十万块。够他活一阵子了。

走出公司大楼，下午四点的阳光刺得他眯起眼睛。街上车水马龙，行色匆匆。陈默站在路边，这时不知道该往哪儿走。

回家？他租的房子在城郊，每天通勤要一个半小时。

去哪都行。

陈默拦了辆出租车。

"去哪？"司机问。

陈默想了想："市中心。"

出租车汇入车流。陈默靠着车窗，看着窗外飞速后退的街景，脑子里还是嗡嗡的。

手机又震了一下。他以为是系统任务，低头一看，是银行短信："您尾号3347的账户于16:05支出人民币3,500.00元。"

陈默一愣。他没花钱啊。

仔细一看，交易备注："房租自动扣款"。

哦，对，今天是交房租的日子。他租的那间小单间，月租三千五。

陈默这时笑了。十万块钱，还没捂热，就少了三千五。

这就是生活。

出租车停在市中心最繁华的商业街。陈默下车，看着眼前林立的高楼大厦。这些楼里，多少人正在加班？多少人正在被"优化"？

他走进一家看起来不太贵的连锁咖啡店，点了杯美式，找了个靠窗的位置坐下。

咖啡端上来，热气氤氲。陈默盯着杯子，开始认真思考一个问题：

这个系统，到底是怎么回事？

他尝试在脑海里呼唤："系统？"

没有反应。

"摆烂系统？"

还是寂静。

陈默皱眉，难道刚才的一切真的是幻觉？他拿出手机，又查了一遍银行余额。九万九千七百四十七块五毛六，一分没少。

就在这时，脑海里响起提示音。

【叮：检测到宿主处于相对放松状态，符合任务发布条件。】

陈默手一抖，咖啡差点洒出来。
