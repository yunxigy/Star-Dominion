# 摆烂的艺术

陈默盯着王振华办公室的磨砂玻璃门，能看见里面那个肥胖的身影在来回踱步。

“陈默，你进来一下。”

王振华的声音透过门缝传出来，带着一股压抑的怒气。办公室里其他同事纷纷低下头，假装忙碌，但眼角余光都在往这边瞟。

陈默站起身，慢悠悠地推开门。

王振华的办公室不大，却堆满了各种文件和奖杯。墙上挂着“天道酬勤”四个大字，墨迹已经有些褪色。办公桌上摆着全家福，照片里的王振华比现在瘦二十斤，笑得像个成功人士。

“坐。”王振华指了指对面的椅子。

陈默没动。“站着就行，王主管有什么事？”

王振华的脸色更难看了。他深吸一口气，把一份文件拍在桌上。

“周报。这是你第三次没交了。”

陈默扫了一眼文件，上面确实是他部门的周报汇总表，他的名字后面跟着三个鲜红的“未交”。

“哦，忘了。”陈默说。

“忘了？”王振华的声音拔高了八度，“陈默，公司规定，三次未交周报记过，五次劝退。你已经三次了，知道吗？”

陈默点点头。“知道。”

“那你打算怎么办？”

“下次交。”

王振华气得笑了。“下次？陈默，你最近怎么回事？迟到、早退、不交周报，昨天李总监找你谈话你什么态度？”

陈默想起昨天李明远那张油腻的脸，和他说的那些话——“年轻人要懂得感恩”、“公司给你平台是你的福气”、“不要总想着钱，要看到成长空间”。

系统当时检测到职场PUA话术，弹出了提示：【检测到典型PUA话术，建议应对方案：微笑，点头，然后说“您说得对，但我选择不听”。】

但陈默没那么干。他只是沉默地听完，然后说了句“我知道了”就离开了。

“李总监的话，我听进去了。”陈默说。

王振华愣了一下，显然没料到他会这么回答。“那你——”

“但我选择不执行。”陈默补充道。

办公室里安静了三秒。

王振华的脸从红变紫，再从紫变白。他猛地站起来，指着陈默的鼻子：“陈默！你知不知道自己在说什么？你这是什么态度？”

陈默看着他的手指，距离自己的鼻尖只有五厘米。系统提示音在脑海里响起：

【检测到职场压迫行为，触发被动技能“职场直觉”：对方正在使用权威压迫，建议保持冷静，避免正面冲突。】

【新任务触发：在不被开除的前提下，让王振华说出“你明天不用来了”。】

【任务奖励：摆烂指数+0.5，解锁技能“话术反弹”（可将对方的PUA话术反弹回去，造成双倍精神伤害）。】

陈默心里一动。让王振华说出“你明天不用来了”？这不就是变相开除吗？但任务要求是“不被开除的前提下”，也就是说，得让王振华说出这句话，但又不能真的让他开除自己。

这有点难度。

“王主管，”陈默开口了，声音平静，“您先坐下，别气坏了身子。”

王振华冷哼一声，但还是坐下了。他大概也意识到自己失态了，整理了一下领带。

“陈默，我再给你最后一次机会。”王振华压低声音，“今天下班前，把周报交上来。否则，别怪我不讲情面。”

陈默没说话，而是走到窗边，拉开了百叶窗。

阳光照进来，王振华下意识地眯起眼睛。

“王主管，您看外面。”陈默指着窗外。

王振华顺着他的手指看去，只能看到对面的写字楼和楼下的车流。

“看什么？”

“看那些人。”陈默说，“早上九点，他们挤地铁、挤公交，为了不迟到拼命奔跑。中午十二点，他们挤在快餐店，用十五分钟吃完午饭。晚上九点，他们拖着疲惫的身体回家，可能还要处理工作消息。”

王振华皱眉：“你到底想说什么？”

“我想说，”陈默转过身，“我们都在拼命，但拼命的意义是什么？为了周报？为了KPI？为了您墙上那幅‘天道酬勤’？”

王振华的脸色变了。“陈默，你这是在质疑公司文化？”

“不是质疑，是思考。”陈默说，“我在想，如果我今天交了周报，明天交了月报，后天交了季报，然后呢？升职？加薪？还是继续写更多的报告？”

王振华沉默了。

陈默继续说：“王主管，您在这个位置坐了多久了？五年？七年？您快乐吗？”

这个问题像一把刀，刺中了王振华的要害。他的表情瞬间僵硬了。

“快乐？”王振华重复了一遍这个词，声音有些干涩，“陈默，职场不是讲快乐的地方。职场是讲价值、讲贡献、讲结果的地方。”

“那您觉得，我现在的价值是什么？”陈默问，“是写周报的价值，还是创造价值的价值？”

王振华张了张嘴，没说出话来。

陈默知道，自己的话起作用了。王振华这种中层领导，最怕的就是被下属问到这种根本性问题。他们习惯了用制度和权威压人，一旦遇到不按套路出牌的，就会慌。

“陈默，”王振华终于开口了，声音疲惫，“你到底想怎么样？”

“我想摆烂。”陈默很诚实。

王振华愣住了。“什么？”

“摆烂。”陈默重复了一遍，“不加班，不内卷，不写周报，到点下班，周末双休。您觉得怎么样？”

王振华的脸色彻底黑了。“陈默，你是不是疯了？”

“可能吧。”陈默耸耸肩，“但我觉得，疯子比正常人活得明白。”

王振华猛地拍桌子：“陈默！你明天不用来了！”

话一出口，王振华自己都愣住了。他大概没想到自己会说出这种话。

陈默心里一喜。成了！

【任务完成：让王振华说出“你明天不用来了”。】

【奖励发放：摆烂指数+0.5，当前3.0。】

【解锁技能“话术反弹”：可将对方的PUA话术反弹回去，造成双倍精神伤害。冷却时间：24小时。】

【检测到摆烂指数达到3.0，解锁新技能“危机预判”：可提前感知职场危机，预警时间：1-3天。】

陈默感受着脑海里涌入的信息流，嘴角微微上扬。

“王主管，”陈默说，“您刚才说，我明天不用来了？”

王振华的脸色变了又变，最后憋出一句：“我是气话！”

“但您确实说了。”陈默不依不饶，“按照公司规定，领导说‘不用来了’，应该算口头解除劳动合同吧？”

王振华慌了。“陈默，你别胡搅蛮缠！我那是气话！”

“气话也是话。”陈默说，“王主管，您要为自己说的话负责。”

王振华站起来，指着门口：“你出去！现在就出去！”

陈默没动。“王主管，我觉得我们需要好好谈谈。”

“谈什么？”

“谈谈我的离职补偿。”陈默说，“N+1，按劳动法来，不过分吧？”

王振华气得浑身发抖。“陈默！你这是敲诈！”

“不是敲诈，是维权。”陈默说，“王主管，您是HR出身，应该比我更懂劳动法。”

王振华确实懂。他脸色铁青地坐下，开始翻找文件。

“陈默，你等着。”王振华咬牙切齿，“我会让法务部处理这件事。”

“好。”陈默点点头，“那我先回工位了。对了，王主管，您刚才说的‘明天不用来了’，我录音了。”

他晃了晃手机。其实他根本没录音，但王振华不知道。

王振华的脸色瞬间惨白。

陈默转身离开办公室，关上门的那一刻，听见里面传来砸东西的声音。

回到工位，周围的同事都用惊讶的眼神看着他。刚才办公室的动静不小，大家都听见了。

“陈默，你没事吧？”隔壁工位的程序员小李凑过来问。

“没事。”陈默坐下，打开电脑，“就是跟王主管聊了聊人生。”

小李瞪大眼睛：“聊人生？王主管能跟你聊人生？”

“是啊，他挺有感触的。”陈默说，“还说明天不用我来了。”

小李倒吸一口凉气。“你……你被开除了？”

“没有，他气话。”陈默说，“但我打算当真。”

小李彻底懵了。

陈默没再解释，而是打开系统界面。

【当前摆烂指数：3.0（初级）】

【已解锁技能：职场直觉（被动）、话术反弹（主动）、危机预判（被动）】

【任务“继续摆烂”进度：30%】

【隐藏任务“反击”进行中：风险极高，建议谨慎。】

陈默看着“反击”任务，心里有些犹豫。这个任务是小刘给的U盘触发的，里面的内容如果曝光，足以让李明远进监狱。但风险也很大，李明远不是好惹的。

就在这时，手机震动了一下。

是小刘发来的消息：“陈默，U盘的事，你考虑得怎么样了？”

陈默回复：“还在考虑。你那边安全吗？”

小刘：“安全。李明远最近在忙着应付审计，没空管我。”

陈默：“审计？什么审计？”

小刘：“集团总部派来的，说是要查账。李明远这几天急得像热锅上的蚂蚁。”

陈默心里一动。审计？这是个好机会。

他回复：“U盘先放你那里，等我消息。”

小刘：“好。陈默，我相信你。”

陈默看着这五个字，心里有些复杂。他和小刘其实并不熟，只是同一家公司不同部门的同事。小刘为什么会相信他？就因为他绑定了摆烂系统？

系统提示音响起：

【检测到关键信息：集团审计。】

【建议：利用审计时机，收集更多证据。】

【新任务触发：在不暴露自己的前提下，让审计组发现李明远的问题。】

【任务奖励：摆烂指数+1，解锁技能“证据收集”（可自动整理、分析相关文件）。】

陈默深吸一口气。这个任务难度不小，但奖励很诱人。

他正想着，王振华从办公室出来了。他的脸色很难看，但强装镇定。

“大家注意一下，”王振华拍了拍手，“集团总部派来的审计组今天下午到，各部门准备好相关资料，配合审计工作。”

办公室里一阵骚动。审计？这种事通常提前一个月通知，这次怎么这么突然？

王振华继续说：“特别是财务部、采购部，把近三年的账目都整理好，别出纰漏。”

他说这话时，眼神有意无意地瞟了陈默一眼。

陈默心里明白，王振华这是在警告他。审计组来了，如果陈默敢乱说话，李明远肯定不会放过他。

但陈默不怕。他有系统，有技能，还有小刘给的U盘。

下午两点，审计组到了。

一共三个人，两男一女，穿着正装，表情严肃。领头的是个四十多岁的男人，戴着金丝眼镜，看起来很精明。

王振华和李明远亲自去迎接，点头哈腰的样子让陈默觉得恶心。

审计组在会议室待了一下午，各部门轮流进去汇报。轮到陈默时，已经是下午五点了。

陈默走进会议室，审计组的三个人正低头看文件。领头的男人抬起头，推了推眼镜。

“陈默？”

“是。”

“坐。”男人指了指椅子，“我们看了你的履历，去年才进公司，对吧？”

“对。”

“在公司主要负责什么？”

“项目协调，偶尔写写报告。”陈默说。

男人点点头，翻看手里的文件。“我们注意到，你最近三个月，周报提交率很低。”

陈默心里一紧。这是要找茬？

“是的。”陈默承认，“因为我觉得周报没什么意义。”

男人挑了挑眉。“哦？为什么这么说？”

“周报的内容，无非是重复每天的工作。”陈默说，“真正有价值的信息，都在日常沟通里。写周报只是形式主义。”

会议室里安静了几秒。

男人笑了。“你倒是敢说。”

“实话实说。”陈默说。

男人合上文件，看着陈默。“陈默，我问你个问题，你可以不回答。”

“您问。”

“你觉得，公司里有没有什么……不正常的现象？”

陈默心里一动。这是在试探他？

他想了想，说：“有。”

“比如？”

“比如加班文化。”陈默说，“明明工作做完了，但领导不走，员工也不敢走。明明可以明天做的事，非要今天加班做完。这种文化，不正常。”

男人点点头，示意他继续。

“还有报销制度。”陈默说，“明明可以走正规流程，但非要找关系、走后门。这种风气，也不正常。”

男人的表情严肃起来。“你说的这些，有证据吗？”

陈默摇摇头。“没有证据，只是观察。”

男人沉默了一会儿，说：“陈默，今天的谈话，不要告诉任何人。”

“明白。”

陈默离开会议室，心里有些忐忑。他刚才的话，会不会引起审计组的注意？会不会打草惊蛇？

系统提示音响起：

【任务“让审计组发现李明远的问题”进度：20%。】

【建议：继续观察，等待时机。】

陈默回到工位，发现小刘又发来了消息。

“陈默，审计组的人刚才找我了。”

陈默心里一紧。“问你什么了？”

“问了一些财务上的问题，我按我们之前说的，只说了一部分。”小刘回复，“但他们好像很感兴趣。”

陈默：“你小心点，别暴露自己。”

小刘：“放心，我有分寸。对了，李明远刚才找我了，问我审计组问了什么。”

陈默：“你怎么说的？”

小刘：“我说只问了常规问题。但他好像不信。”

陈默皱眉。李明远起疑心了。

他回复：“最近别联系了，等风头过去。”

小刘：“好。”

陈默关掉手机，靠在椅背上。事情正在往不可控的方向发展。审计组、李明远、王振华，还有隐藏在暗处的其他势力，都搅和在一起了。

他需要一个计划。

系统提示音再次响起：

【检测到复杂局面，建议启动“危机预判”技能。】

【技能启动中……】

【预判结果：未来三天内，李明远可能会采取行动，目标可能是你或小刘。建议提前准备应对方案。】

陈默心里一沉。李明远要动手了？

他必须做点什么。

下班时间到了，同事们陆续离开。陈默没动，他坐在工位上，盯着电脑屏幕发呆。

王振华从办公室出来，看见陈默还在，皱了皱眉。

“陈默，你怎么还不走？”

“加班。”陈默说。

王振华愣住了。“你……加班？”

“是啊。”陈默说，“王主管不是说，要配合审计工作吗？我整理一下资料。”

王振华的表情很复杂，像是欣慰，又像是警惕。

“那你忙吧。”王振华说完，转身离开了。

陈默看着他的背影，嘴角勾起一抹冷笑。

加班？怎么可能。他只是在等。

等所有人都走了，等公司安静下来，等他可以开始真正的行动。

晚上八点，公司彻底空了。陈默站起来，活动了一下筋骨。

他走到李明远的办公室门口，门锁着。

陈默从口袋里掏出一张卡片，这是他之前从系统商城兑换的“万能门卡”，可以打开任何电子门锁。

“滴”的一声，门开了。

陈默走进去，打开手电筒。李明远的办公室很大，装修豪华，比王振华的办公室大三倍。

陈默开始翻找。他要找的，是李明远和供应商之间的往来邮件、合同副本、银行流水记录。小刘给的U盘里有财务数据，但缺乏直接证据。

翻找了半个小时，陈默在书柜的暗格里发现了一个保险箱。

系统提示：

【检测到保险箱，建议使用“万能钥匙”打开。】

【“万能钥匙”已使用，保险箱已打开。】

保险箱里只有三样东西：一个U盘，一份合同，一张照片。

陈默拿起U盘，插进随身携带的笔记本电脑。

里面只有一个文件夹，命名为“备份”。

陈默打开文件夹，里面是密密麻麻的文件：采购合同、银行转账记录、供应商的资质证明……最关键的是，有一份“资金流向图”，清晰地显示了李明远如何通过虚增采购价格，把公司的钱转到自己的口袋里。

陈默倒吸一口凉气。这些证据，足够让李明远坐牢十年。

他又拿起那份合同，是一份股权转让协议。李明远用代持的方式，持有一家供应商30%的股份。

最后是那张照片。照片上是李明远和一个中年男人的合影，背景是某个度假村。中年男人陈默认识，是集团总部的一位副总。

陈默把U盘、合同、照片都拍了照，然后原样放回保险箱，锁好。

他离开李明远的办公室，回到自己的工位。

系统提示音响起：

【任务“让审计组发现李明远的问题”进度：80%。】

【建议：将证据匿名发送给审计组。】

陈默点点头。这是最稳妥的办法。

他打开匿名邮箱，把刚才拍的照片和U盘里的关键文件打包，发送给了审计组领头男人的邮箱。

邮件标题是：“关于李明远贪腐问题的证据。”

发送成功。

陈默关掉电脑，站起来，伸了个懒腰。

该做的都做了。接下来，就看审计组怎么处理了。

他走出公司大楼，夜风吹在脸上，有些凉。

手机震动了一下，是系统消息：

【隐藏任务“反击”进度：50%。】

【风险提示：李明远可能已经察觉，建议提高警惕。】

陈默收起手机，走进地铁站。

地铁里人不多，他找了个位置坐下，闭上眼睛。

今天发生了太多事。王振华的威胁、审计组的到来、李明远的秘密……这一切都像一张大网，把他裹在中间。

但他不怕。

他有系统，有技能，有摆烂的勇气。

摆烂不是放弃，而是换一种方式战斗。

陈默睁开眼睛，看着地铁窗外的黑暗，嘴角露出一丝微笑。

明天，会更有趣。
