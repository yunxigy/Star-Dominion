# 暗流

上午十点，阳光透过落地窗洒进陈默的办公室。

他坐在办公椅上，感受着“商业洞察力+20%”带来的奇妙体验。视野里的一切都变得清晰起来，就像给世界加了一层高分辨率滤镜。

“系统，这buff效果真不错。”陈默在心里说。

【系统提示：临时增益‘商业洞察力+20%’已生效，持续11小时42分。请宿主珍惜使用，过期不候。】

陈默打开电脑，调出星海国际的财务报表。

那些枯燥的数字在+20%的加持下，突然变得生动起来。每一个百分比、每一笔账目，都像活过来一样，向他诉说着背后的秘密。

“有意思。”陈默敲了敲桌面。

两亿贷款，利率3.8%。市场基准利率是4.5%，银行不可能做亏本生意。除非……

他点开贷款协议的扫描件，快速浏览。

商业洞察力让他能瞬间抓住关键条款。那些密密麻麻的小字，在他眼里就像被荧光笔标记过一样显眼。

“找到了。”陈默坐直身体。

协议第37条，附加条款第4款：若借款方发生控制权变更，贷款方有权要求提前偿还全部本息。

“控制权变更……”陈默喃喃道，“张明远持股18%，周家通过鼎盛资本控制现金流。只要张明远不失去控制权，这笔贷款就是安全的。”

他靠在椅背上，手指轻轻敲击扶手。

“所以，他们真正的目的不是利息，而是控制权。”陈默的眼睛眯起来，“两亿贷款，换来的是对星海国际的实际控制。高，真是高。”

手机震动起来。

是刘芳的电话。

“陈总，情况有变。”刘芳的声音有些急促，“我刚联系上那个持股3.2%的小股东，他改口了。”

“怎么改的？”

“他说不卖了。”刘芳压低声音，“我问他原因，他支支吾吾半天，最后说‘有人给了更好的条件’。”

陈默皱眉：“张明远？”

“不确定，但时间点太巧了。”刘芳顿了顿，“而且我打听了一下，另外两个犹豫的小股东，今天上午都接到了神秘电话。”

“看来有人坐不住了。”陈默冷笑一声，“他们报价多少？”

“比我们高20%，而且不要对赌协议。”

“不要对赌……”陈默重复了一遍，突然笑了，“这就有意思了。”

对赌协议是保护收购方的，如果星海国际未来业绩不达标，小股东要赔偿损失。张明远那边不要对赌，说明他们根本不在乎星海国际的未来——他们要的是短期套现。

“陈总，我们怎么办？”刘芳问。

“继续按原计划。”陈默说，“告诉那两个犹豫的小股东，我们的报价提高到比原价高60%，对赌条款可以放宽。”

“60%？”刘芳倒吸一口凉气，“这成本太高了。”

“不高。”陈默看着电脑屏幕，“刘芳，你相信商业直觉吗？”

“啊？”

“我现在有种强烈的预感。”陈默说，“星海国际的真实价值，远超账面数字。60%的溢价，我们赚大了。”

电话那头沉默了几秒。

“好，我去办。”刘芳说，“对了，王律师那边有进展。”

“说。”

“他查到了一些关联交易记录。”刘芳的声音压得更低，“星海国际过去三年，和一家叫‘海天实业’的公司有大量业务往来。金额加起来超过五亿。”

“海天实业？”

“注册地在开曼群岛，实际控制人查不到。”刘芳说，“但王律师发现，这家公司的董事名单里，有个名字很眼熟。”

“谁？”

“周雅琴。”

陈默的手指停住了。

周雅琴，周家的大小姐，鼎盛资本的实际控制人。如果海天实业是她控制的，那五亿的关联交易……

“掏空资产。”陈默一字一顿地说，“他们在掏空星海国际。”

“王律师也是这么说的。”刘芳说，“他正在整理证据，如果属实，我们可以举报。”

“不急。”陈默说，“证据要确凿。告诉王律师，重点查海天实业和星海国际的合同细节，特别是那些看起来利润异常高的项目。”

“明白。”

挂断电话，陈默站起来，走到窗前。

商业洞察力+20%让他能看透很多东西。他现在几乎可以确定，张明远和周家正在上演一出大戏——先通过关联交易掏空星海国际，压低股价，然后低价收购。

而那两亿贷款，就是他们的保险丝。只要控制权不变更，贷款就不会提前收回，星海国际就能继续运转。

“好算盘。”陈默冷笑，“可惜你们遇到了我。”

他转身回到办公桌前，打开一个新文件夹。

里面是王律师发来的星海国际股东名单。陈默一个一个看过去，商业洞察力让他能快速分析每个人的持股比例、背景、可能的态度。

“张明远，18%。”陈默喃喃道，“加上周家通过各种代持的股份，实际控制应该在35%左右。”

他继续往下看。

“散户持股30%，机构持股20%，剩下15%在小股东手里。”

陈默的眼睛亮了。

如果他能收购那15%的小股东股份，加上自己现在持有的5%，总持股将达到20%。虽然还比不上张明远，但已经足以在股东大会上拥有话语权。

更重要的是，他可以联合其他小股东，组建“反对派联盟”。

“就这么办。”陈默拿起手机，拨通了王律师的电话。

“王律师，我需要你帮我做一件事。”

“陈总请说。”

“查一下星海国际最近三年的所有股东大会记录。”陈默说，“特别是那些投票结果接近的议案。我要知道，哪些小股东经常投反对票。”

电话那头传来键盘敲击的声音。

“陈总，您是想……”

“组建联盟。”陈默说，“张明远想掏空公司，肯定有人不满。我要找到那些不满的人，把他们团结起来。”

“明白了，我马上查。”

挂断电话，陈默又拨通了另一个号码。

“李总，我是陈默。”

电话那头是个中年男人的声音：“陈总？稀客啊，怎么想起给我打电话了？”

李总，陈默前公司的客户，也是个精明的生意人。陈默还在前公司时，和他打过几次交道。

“有件好事想和您聊聊。”陈默说，“关于星海国际。”

“星海国际？”李总笑了，“陈总，您不是在开玩笑吧？那家公司现在可是烫手山芋。”

“烫手山芋，有时候也能变成香饽饽。”陈默说，“李总，您对星海国际了解多少？”

电话那头沉默了几秒。

“陈总，您到底想说什么？”

“我想邀请您，参与收购星海国际。”陈默直截了当，“您出资金，我出方案。事成之后，星海国际的海外业务归您。”

又是一阵沉默。

“陈总，您知道星海国际现在的情况吗？”李总的声音严肃起来，“张明远那个人，不好对付。”

“我知道。”陈默说，“但我也知道，星海国际的海外业务，一直没做好。您如果接手，凭您的资源，三年内能翻倍。”

“您怎么知道我对海外业务感兴趣？”

“商业直觉。”陈默笑了笑，“李总，您去年在东南亚考察了三个月，不是白去的吧？”

电话那头传来惊讶的吸气声。

“陈总，您真是……”李总顿了顿，“好，我考虑一下。但丑话说在前面，如果风险太大，我不会参与。”

“当然。”陈默说，“我会把详细的方案发给您。您看完再决定。”

挂断电话，陈默长舒一口气。

商业洞察力+20%的效果还在，他现在能清晰地看到每一步该怎么走。收购星海国际，不是简单的资本游戏，而是一场心理战、信息战、资源战。

他需要盟友，需要资金，需要证据。

而最重要的是，需要时间。

手机又响了。

这次是条短信。

发信人是未知号码，内容只有一句话：

“陈默，收手吧。有些水，你趟不起。”

陈默盯着屏幕，嘴角勾起一抹冷笑。

他没有回复，直接拉黑了这个号码。

然后打开系统界面。

【当前任务：收购星海国际（进行中）】

【任务进度：35%】

【系统提示：检测到宿主情绪波动，焦虑指数上升至50%。建议宿主进行摆烂活动，缓解压力。】

陈默摇摇头。

现在可不是摆烂的时候。

他拿起手机，拨通了刘芳的电话。

“刘芳，下午三点，召开紧急会议。”

“会议主题？”

“战前动员。”陈默说，“我们要打一场硬仗了。”

挂断电话，陈默走到窗前，看着楼下的车水马龙。

商业洞察力+20%让他能看透人心，看透资本，看透那些隐藏在数字背后的阴谋。

但他知道，真正的挑战才刚刚开始。

张明远不会坐以待毙，周家更不会轻易放弃。

他们一定会反击。

而陈默，必须在反击到来之前，做好万全准备。

“系统。”陈默在心里说，“有没有什么任务，能让我快速获得资金？”

【系统提示：检测到宿主需求，发布临时任务——】

【任务内容：在接下来的24小时内，拒绝任何形式的加班。】

【任务奖励：现金1000万，即时到账。】

陈默愣了一下。

拒绝加班？

这算什么任务？

但他没有犹豫，直接点击了接受。

【任务已接受，请宿主遵守。若违反任务，将扣除已获得的全部奖励。】

陈默笑了笑。

拒绝加班，就能获得1000万。

这系统，还真是懂他。

他转身回到办公桌前，开始整理下午会议的资料。

商业洞察力+20%的效果还在持续，他现在能清晰地看到每一步该怎么走。

收购星海国际，不仅仅是为了赚钱。

更是为了证明，在这个扭曲的职场里，还有另一种活法。

一种不用跪着挣钱，不用出卖尊严，不用违背良心的活法。

“张明远，周雅琴……”陈默喃喃道，“你们等着。”

下午三点，会议室。

陈默坐在主位上，看着面前的团队。

刘芳、王律师、还有几个核心员工。

“各位，”陈默开口，“我知道最近大家压力都很大。收购星海国际，不是件容易的事。”

他顿了顿，环视众人。

“但我要告诉你们，这件事，我们必须做。”

刘芳举手：“陈总，能说说原因吗？”

“因为星海国际，不该是现在这个样子。”陈默说，“那是一家好公司，有好的产品，好的员工。但它被蛀虫掏空了，被资本绑架了。”

他站起来，走到白板前。

“我们收购它，不是为了赚钱——虽然肯定能赚钱。”

“我们是为了救它。”

会议室里一片寂静。

“陈总，”王律师推了推眼镜，“您有具体的方案吗？”

“有。”陈默转身，在白板上画了一个简单的架构图。

“第一步，继续收购小股东股份。目标：持股达到20%。”

“第二步，组建股东联盟。目标：联合其他不满的小股东，获得30%的投票权。”

“第三步，收集证据。目标：掌握张明远和周家掏空资产的铁证。”

“第四步，发起股东大会。目标：改组董事会，罢免张明远。”

他画完最后一笔，转身面对众人。

“每一步，都有风险。每一步，都可能失败。”

“但如果我们成功了，”陈默的声音坚定起来，“星海国际，将迎来新生。”

会议室里响起稀稀拉拉的掌声。

刘芳举手：“陈总，资金怎么办？收购需要大量现金。”

“资金的问题，我已经解决了。”陈默说，“具体细节暂时不能透露，但我可以告诉你们，我们有足够的弹药。”

他看了看手表。

“现在，分配任务。”

“刘芳，继续联系小股东。今天下午，我要看到新的进展。”

“王律师，加快证据收集。特别是海天实业的关联交易，我要详细的合同和资金流向。”

“其他人，做好保密工作。今天的会议内容，一个字都不能外泄。”

众人点头。

“散会。”陈默说。

众人离开后，陈默独自坐在会议室里。

商业洞察力+20%的效果开始减弱，他感觉脑子有点发胀。

“系统，”他在心里说，“这buff有副作用吗？”

【系统提示：临时增益‘商业洞察力+20%’使用过度可能导致轻微头痛，属正常现象。建议宿主休息。】

陈默揉了揉太阳穴。

休息？

现在可不是休息的时候。

他拿出手机，拨通了李总的电话。

“李总，方案我发您邮箱了。”

“收到了。”李总的声音有些兴奋，“陈总，您这方案……太详细了。连海外业务的三年规划都有。”

“我说过，我是认真的。”陈默说。

“好。”李总深吸一口气，“我参与。资金方面，我可以出五千万。”

“够了。”陈默说，“李总，欢迎加入。”

挂断电话，陈默长舒一口气。

五千万，加上系统奖励的一千万，还有公司现有的资金……

收购星海国际的弹药，足够了。

他站起来，走到窗前。

夕阳西下，城市的轮廓被染成金色。

陈默知道，真正的战斗，明天才开始。

张明远不会坐以待毙。

周家更不会轻易放弃。

他们一定会反击。

而陈默，必须在反击到来之前，做好万全准备。

“系统，”他在心里说，“还有什么任务吗？”

【系统提示：检测到宿主需求，发布日常任务——】

【任务内容：今晚10点前准时睡觉，不熬夜。】

【任务奖励：‘精力充沛’buff，持续24小时。】

陈默笑了笑。

准时睡觉，就能获得精力充沛buff。

这系统，还真是贴心。

他转身离开会议室，走向电梯。

今晚，他要睡个好觉。

明天，还有一场硬仗要打。

电梯门打开，陈默走进去。

就在门即将关闭的瞬间，他看到走廊尽头，有个熟悉的身影一闪而过。

是张明远的秘书。

陈默的眼睛眯起来。

看来，有人已经坐不住了。

电梯门关闭，开始下行。

陈默靠在电梯壁上，嘴角勾起一抹冷笑。

来吧。

他准备好了。
