# 摆烂总监的觉醒

清晨的阳光穿过落地窗，在王振华的办公桌上铺开一片暖黄。

他盯着便签纸上的字迹看了三分钟，才确认自己没看错。

“观察公司文化，不必做任何实际工作。”

王振华把便签纸翻过来，又翻回去，确认背面没有其他指示。他抬头环顾四周——办公室里静悄悄的，只有键盘敲击声和偶尔的低语。墙上的时钟指向九点四十五分。

他的新同事们，有的在喝咖啡，有的在看书，还有个戴眼镜的姑娘正对着屏幕笑——看的是动画片。

“这真是个公司？”王振华喃喃自语。

他想起昨天陈默带他参观时说的话：“在摆烂科技，我们不打卡，不考核，不加班。你只需要完成手头的工作，剩下的时间——”

陈默当时顿了顿，露出一个意味深长的笑：“随你支配。”

王振华当时以为这是场面话。他在职场混了二十年，见过太多说一套做一套的领导。但今天，他坐在这个靠窗的工位上，看着眼前这片悠闲的景象，心里开始动摇。

“王总监，早啊。”

一个年轻人端着马克杯走过来，杯身上印着“拒绝内卷”四个字。

“早。”王振华下意识挺直腰板，“你是……”

“李明，前端开发。”年轻人拉过旁边的椅子坐下，“陈总让我带你熟悉环境。不过说实话，咱们这儿也没什么好熟悉的。”

王振华看着这个穿着连帽衫、脚踩拖鞋的年轻人，想起自己以前公司里那些西装革履、时刻保持紧张状态的程序员。

“你们……平时都这么……”王振华斟酌着用词，“放松？”

李明喝了口咖啡：“陈总说了，绷紧的弦容易断。我们只在需要紧的时候紧。”

“那什么时候需要紧？”

“项目上线前，或者遇到紧急bug的时候。”李明指了指墙上的白板，“不过那种情况很少。你看，这是我们这个季度的项目进度。”

王振华顺着他的手指看去——白板上画着甘特图，每个项目节点都标注着完成百分比。最右边的项目进度条已经走到85%，而时间才过去一半。

“这……”王振华愣住了。

在他以前的公司，项目进度能到70%就算烧高香了。每次季度汇报，各部门总监都要互相推诿，最后把责任全推到“执行不力”上。

“怎么做到的？”王振华忍不住问。

李明耸耸肩：“专注呗。没有无意义的会议，没有反复修改的需求，没有半夜突然@全体成员的紧急通知。大家把时间花在真正该做的事情上。”

他说着，从口袋里掏出手机：“对了，陈总让我给你看看这个。”

屏幕上是一个聊天群，群名叫“摆烂科技摸鱼小分队”。王振华看到群消息记录：

【陈默：@全体成员 今天天气不错，下午三点集体去楼下咖啡厅喝下午茶。项目进度不用赶，明天再做。】

【李明：收到！我正好想试试新出的燕麦拿铁。】

【财务张姐：我带我家猫来行吗？它最近有点抑郁。】

【陈默：带！公司允许带宠物。】

王振华看着这些对话，感觉自己的世界观正在崩塌。

“这……不影响工作吗？”

“影响什么？”李明笑了，“下午茶时间，大家聊聊生活，反而能碰撞出新点子。上周那个优化方案，就是喝咖啡时聊出来的。”

他收起手机，站起身：“走，我带你转转。虽然陈总说你今天不用工作，但总得知道茶水间在哪儿。”

王振华跟着李明穿过办公区。每经过一个工位，都有人抬头打招呼，笑容自然，眼神放松。没有人在假装忙碌，没有人对着空白的文档发呆，更没有人偷偷刷招聘网站。

“这里是休息区。”李明推开一扇门。

王振华眼前一亮——宽敞的空间里摆着懒人沙发、游戏机、书架，甚至还有一个小型的室内花园。几个员工正躺在沙发上看书，角落里有人在打乒乓球。

“公司鼓励大家休息。”李明说，“陈总说，人不是机器，需要充电。休息好了，工作效率自然高。”

王振华看着墙上的一句话：“休息是为了更好地摆烂。”

他突然觉得，这句话可能不是玩笑。

就在这时，他的眼前浮现出熟悉的光幕：

【任务“摆烂总监的第一天”进度更新：85%】

【提示：宿主开始理解摆烂文化的表层现象。请继续观察，探索其背后的深层逻辑。】

王振华眨了眨眼，光幕消失了。他已经习惯这种突然出现的提示——自从绑定这个离谱的系统后，他的生活就充满了这种超现实的时刻。

“王总监，你没事吧？”李明注意到他的异样。

“没事。”王振华摇摇头，“就是……有点不适应。”

李明笑了：“正常。我刚来的时候也这样。以前在别的公司，我每天工作十二个小时，周末还要加班。结果呢？身体垮了，项目还是延期。来这儿之后，我每天工作六小时，项目反而提前完成。”

“为什么？”

“因为专注。”李明重复这个词，“没有干扰，没有形式主义，没有领导突然塞过来的‘紧急任务’。你只需要做好自己的事。”

他带着王振华走到窗边，指着楼下的街道：“你看，现在是上午十点，别的公司员工都在工位上焦头烂额。而我们这儿，有人已经在规划下午的活动了。”

王振华看着楼下匆匆走过的人群，又回头看看办公室里悠闲的景象，心里涌起一种奇怪的感觉。

那不是羡慕，而是……困惑。

他想起自己二十年的职场生涯——每天早起挤地铁，在打卡机前争分夺秒，开会时假装认真记录，加班时在领导面前表演努力。最后得到了什么？一身的病，破裂的家庭，还有那颗早已麻木的心。

而现在，眼前这群“摆烂”的人，却活得比他轻松，比他高效，甚至比他快乐。

“陈总来了。”李明突然说。

王振华转头，看到陈默从电梯里走出来。他穿着简单的白T恤和牛仔裤，手里拿着一杯豆浆，看起来就像个普通的上班族。

“王总监，怎么样？”陈默走过来，笑着问，“还习惯吗？”

王振华张了张嘴，不知道该怎么回答。说习惯？他到现在还觉得这一切像做梦。说不习惯？那显得他太没见过世面。

“我……在努力理解。”王振华最后说。

陈默点点头：“理解需要时间。我刚开始的时候，也觉得这一切很荒谬。”

他指了指自己的太阳穴：“但后来我想通了。职场文化那些东西——加班、内卷、形式主义——才是真正的荒谬。我们只是把荒谬的东西去掉了，回归正常而已。”

王振华沉默。

陈默拍拍他的肩膀：“今天你的任务就是观察。观察我们的工作方式，观察员工的状态，观察项目的进度。然后，你自己判断。”

他说完就走了，留下王振华一个人站在窗边。

王振华看着陈默的背影，又看看办公室里的一切。他突然想起自己刚入职时的样子——充满干劲，相信努力就能成功。二十年过去了，他变成了自己曾经最讨厌的那种领导：只会压榨员工，用加班掩盖管理无能。

而现在，眼前这个年轻人，用一种完全相反的方式，做出了比他更好的成绩。

“王总监，要不要喝点什么？”李明的声音把他拉回现实。

“咖啡吧。”王振华说，“黑咖啡，不加糖。”

“好嘞。”

李明去茶水间了。王振华独自站在窗边，看着楼下的城市。阳光正好，微风不燥。他突然觉得，自己可能真的需要重新学习怎么工作，怎么生活。

就在这时，他的手机响了。

是前公司的HR总监，张莉。

王振华盯着屏幕看了几秒，还是接了。

“振华啊，听说你去了一家小公司？”张莉的声音带着明显的优越感，“怎么，被裁员后就自暴自弃了？”

王振华皱眉：“有事吗？”

“没什么大事。”张莉笑了，“就是告诉你一声，你以前负责的那个项目，现在由我接手了。领导很重视，让我务必做出成绩。”

王振华心里一沉。那个项目是他花了两年心血做的，因为公司战略调整被搁置。现在他刚离开，就被人捡了现成。

“祝你好运。”王振华说。

“对了，”张莉又说，“你那家公司叫什么来着？摆烂科技？哈哈，这名字真有意思。祝你们摆烂成功啊。”

电话挂断了。

王振华握着手机，指节发白。二十年的职场生涯，他见过太多这种落井下石的人。以前他会愤怒，会不甘，会想着怎么报复。

但现在，他看着眼前这个悠闲的办公室，看着那些快乐工作的年轻人，心里突然平静下来。

“王总监，你的咖啡。”李明端着杯子走过来。

“谢谢。”王振华接过咖啡，喝了一口。苦涩的味道在舌尖蔓延，却让他清醒了不少。

“李明，”他突然问，“你们……就不怕被人看不起吗？”

李明愣了一下，然后笑了：“怕什么？我们用成绩说话。上个季度，我们的项目收益是行业平均的三倍。那些看不起我们的人，现在都在研究我们的模式。”

王振华沉默。

是啊，成绩。在职场，最终还是要看成绩。他以前的公司，天天加班，天天开会，结果呢？项目延期，收益下滑，最后不得不裁员。

而眼前这家“摆烂”公司，却做出了更好的成绩。

这到底是为什么？

王振华想不通。但他知道，自己必须想通。

因为他的任务，就是理解这一切。

【任务“摆烂总监的第一天”进度更新：90%】

【提示：宿主开始质疑传统职场逻辑。请继续深入，寻找摆烂文化的真正核心。】

光幕再次出现，又再次消失。

王振华深吸一口气，把咖啡一饮而尽。

“李明，”他说，“带我去看看你们的项目组吧。我想看看，你们到底是怎么工作的。”

“没问题。”李明笑了，“不过先说好，我们这儿没有‘汇报’这一说。你只是观察，不打扰。”

“我明白。”

两人走向开发部。王振华看着走廊两侧的办公室，每间都布置得温馨舒适。有人养着绿植，有人贴着海报，有人甚至在工位上放了张小床。

“那是给午休用的。”李明解释，“陈总说，午休很重要。睡得好，下午才有精神。”

王振华点点头。他想起自己以前的公司，午休时间只有一个小时，还要扣除吃饭时间。员工们只能趴在桌子上睡，醒来后腰酸背痛。

“到了。”李明推开一扇门。

开发部里，十几个程序员正在工作。但和王振华想象的不同，这里没有紧张的气氛，没有此起彼伏的电话铃声，更没有领导在旁边盯着。

程序员们戴着耳机，专注地盯着屏幕。偶尔有人站起来伸个懒腰，或者去窗边看看风景。

“他们在做什么？”王振华小声问。

“优化算法。”李明说，“这是个技术活，需要高度专注。所以我们规定，工作时间不打扰，不打断。”

王振华看着那些程序员，心里涌起一种敬佩。他以前总觉得程序员是“码农”，是流水线上的工人。但现在他才明白，真正的技术工作，需要的是创造力和专注力，而不是无休止的加班。

“王总监，要不要看看我们的会议记录？”李明问。

“好。”

李明打开电脑，调出一个文档。王振华看到，会议记录只有短短几行字，每一条都直奔主题，没有废话。

“我们开会只讨论必要事项。”李明说，“而且时间控制在十五分钟内。陈总说，长会议是效率的杀手。”

王振华想起自己以前参加的那些动辄两三个小时的会议，大部分时间都在扯皮，最后什么结论都没有。

“那……如果遇到问题呢？”王振华问，“比如项目遇到瓶颈，或者技术难题。”

“那就集中攻关。”李明说，“但攻关时间不超过三小时。三小时后，必须休息。陈总说，疲劳状态下解决问题，只会制造更多问题。”

王振华沉默。这些道理，他其实都懂。但在职场二十年，他早就被那些“狼性文化”“奋斗精神”洗脑了，觉得不加班就是不努力，不熬夜就是不敬业。

现在，眼前这群人用事实告诉他：他错了。

“李明，”王振华突然说，“我想和陈总谈谈。”

“陈总在办公室。”李明指了指走廊尽头，“不过他一般十一点才开始处理工作。现在可能在打游戏。”

王振华愣了一下，还是走了过去。

陈默的办公室门开着。王振华看到，陈默正坐在沙发上，手里拿着游戏手柄，对着电视屏幕操作。屏幕上是一款赛车游戏。

“陈总。”王振华敲了敲门。

陈默头也不回：“进来坐。等我这局结束。”

王振华走进去，在旁边的椅子上坐下。他看着陈默专注地玩游戏，心里五味杂陈。

以前的领导，哪个不是日理万机？开会、审批、应酬，忙得脚不沾地。而眼前这个年轻人，却在上班时间打游戏。

但奇怪的是，公司运转得很好。

“好了。”陈默放下手柄，转过身，“有事？”

王振华深吸一口气：“陈总，我想问一个问题。”

“问。”

“您……为什么选择这种管理方式？”

陈默笑了：“你觉得不好？”

“不，”王振华摇头，“我只是不理解。在我的认知里，管理者应该以身作则，应该比员工更努力。但您……”

“但我在打游戏。”陈默接过话，“你觉得我不负责任，对吗？”

王振华没说话，但表情已经说明了一切。

陈默站起身，走到窗边：“王总监，你知道为什么大多数公司都活不过五年吗？”

“为什么？”

“因为他们的管理者太‘负责’了。”陈默转过身，“他们事必躬亲，恨不得把员工的每一分钟都安排好。结果呢？员工失去了自主性，变成了只会执行的机器。公司失去了创新力，变成了只会跟风的抄手。”

王振华听着，若有所思。

“我的管理方式很简单，”陈默继续说，“只抓方向，不抓细节。我负责制定战略，员工负责执行。我给他们足够的自由和信任，他们给我足够的成果和惊喜。”

“那您怎么保证员工不会偷懒？”

“为什么要保证？”陈默反问，“如果一个人想偷懒，你盯着他也没用。如果一个人不想偷懒，你不需要盯着他。我选择相信人性本善，选择用制度激发人的主动性，而不是用监控压抑人的创造力。”

王振华沉默良久。

他想起自己以前的管理方式——每天盯着员工的考勤，检查他们的工作日志，甚至要求他们每小时汇报进度。结果呢？员工们学会了表演，学会了糊弄，学会了在领导面前假装努力。

而那些真正有能力的人，早就跳槽走了。

“陈总，”王振华终于开口，“我可能……需要重新学习怎么当管理者。”

陈默笑了：“欢迎来到摆烂科技。在这里，你会学到很多以前学校里不教、公司里不让的东西。”

就在这时，王振华的眼前再次浮现出光幕：

【任务“摆烂总监的第一天”进度更新：95%】

【提示：宿主开始理解摆烂文化的管理哲学。请继续探索，找到属于自己的摆烂之道。】

光幕消失。

王振华看着陈默，突然问：“陈总，您绑定的那个系统……到底是什么？”

陈默愣了一下，然后大笑起来：“你也有系统？”

王振华点头：“一个叫‘摆烂系统’的东西。它给我发布任务，让我体验摆烂文化。”

“那我们的系统可能是亲戚。”陈默笑着说，“不过我的系统更离谱。它奖励我摆烂，越摆烂奖励越高。”

“所以您才……”

“所以我才开这家公司。”陈默接过话，“用摆烂的方式，做不摆烂的事。”

王振华若有所思。

“好了，”陈默看看时间，“快十一点了，我该处理点工作了。你也去忙你的吧——哦对了，你今天的工作就是观察。继续观察，直到你想通为止。”

王振华站起身，走到门口时，又回头问：“陈总，如果我想通了，接下来该做什么？”

陈默笑了：“做你自己。在摆烂科技，我们不需要模仿别人，只需要做好自己。”

王振华点点头，走出办公室。

他回到自己的工位，看着窗外的城市。阳光依旧灿烂，微风依旧轻柔。但他心里，有什么东西正在悄悄改变。

他想起张莉的电话，想起前公司的那些勾心斗角，想起自己二十年的职场生涯。那些曾经让他痛苦、愤怒、不甘的东西，现在看来，都那么可笑。

“王总监，要不要一起吃午饭？”李明的声音再次响起。

王振华转过头，看到这个年轻人真诚的笑容。

“好。”他说，“不过我想先完成今天的任务。”

“什么任务？”

王振华笑了：“观察。然后，找到属于我自己的摆烂之道。”
