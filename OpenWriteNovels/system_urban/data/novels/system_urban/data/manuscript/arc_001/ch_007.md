# 第七章 申请立案

陈默把最后一份工资流水装进文件夹，核对完目录上的页码，才发现已经到了出门时间。

桌边还放着昨晚那份和解草案。付款、解除证明、社保转移和保密条款被他分别贴上了便签，任何一项没有写清楚，他都不会签字。

“早安，宿主。”系统的声音在脑海中响起，带着一种机械式的愉悦，“今日摆烂指数评估：睡眠质量95分，自然醒达成，摆烂值+5。”

陈默笑了笑，赤脚踩在温热的木地板上走向厨房。地暖的温度恰到好处，从脚底传来的暖意让他想起小时候冬天赖床的感觉。他打开冰箱，里面整齐地码放着食材：进口鸡蛋、全麦吐司、有机牛奶、新鲜蔬菜，甚至还有一盒价格不菲的和牛牛排，这是昨天系统奖励的“摆烂生活品质提升包”。

煎蛋在平底锅里滋滋作响，吐司机弹出烤好的面包片。陈默一边准备早餐，一边回想昨天的进展。

劳动仲裁委员会的咨询结果很明确：星辰科技的解除程序存在瑕疵，补偿、未结工资和加班记录应当分项核算。他在公司工作五年，月薪一万五，具体金额还要以工资流水和考勤证据为准。

公司行政部刘经理昨天电话里提出的十万零五千八百元，只是一个未经核验的口头方案。

“他们在试探你。”陈默合上文件夹，自言自语道。刘经理主动提出一笔总额，看似诚意十足，但周律师提醒过：星辰科技最近仲裁案子不少，管理层怕的并非单笔赔钱，而是程序问题被公开。

手机震动了一下。

陈默瞥了一眼屏幕，是刘经理的微信消息：“陈先生，昨天说的补偿方案您考虑得怎么样了？公司这边可以尽快安排付款。”

消息发在早上七点二十。行政经理这个点就发工作消息，要么是真着急，要么是在施压。

陈默没有立刻回复。他端着早餐走到客厅的落地窗前，俯瞰着城市晨景。这套位于市中心的公寓是系统奖励的首付，虽然只是首付，但月供由系统自动承担，这是“摆烂值突破500点”时解锁的福利。窗外，早高峰的车流已经开始涌动，而他可以悠闲地坐在温热的地板上吃早餐。

“叮：”系统提示音响起，“检测到宿主正在处理劳动纠纷，触发隐藏任务：仲裁先锋。”

任务描述：正式提交劳动仲裁申请，并在调解阶段坚持不低于双倍补偿的诉求。奖励：摆烂值+300，随机技能升级券×1。

陈默放下叉子。300点摆烂值足够让他向下一个阶段靠近。技能升级券更稀有，但在主线任务结算前，他目前只有一个被动技能：“无效社交免疫”。

“接受任务。”陈默在心中默念。

手机又震动了，这次是电话。屏幕上显示“星辰科技-刘经理”。

陈默等了五秒，接起电话。

“陈先生，早啊。”刘经理的声音带着刻意营造的轻松，“没打扰您休息吧？”

“刚醒。”陈默回答，语气平静。

“那正好，关于补偿方案的事，”刘经理顿了顿，“公司这边讨论了一下，觉得之前说的十万零五千八百这个数字，可以再商量。毕竟您在公司五年，没有功劳也有苦劳嘛。”

陈默没有说话。他走到书房，打开笔记本电脑，屏幕上显示着昨天整理的证据文件夹：劳动合同、工资流水、裁员通知、工作交接记录，还有几段和同事的微信聊天记录截图，证明裁员是突然决定，没有提前通知。

“陈先生？您在听吗？”刘经理的声音提高了些。

“在听。”陈默说，“刘经理，我昨天去劳动仲裁委员会咨询过了。”

电话那头沉默了两秒。

“咨询的结果是，根据法律规定，公司应该支付双倍经济补偿金。”陈默继续说道，“十万零五千八百元，这个数字是正确的。”

又是一阵沉默。陈默能听到刘经理那边有纸张翻动的声音，还有隐约的键盘敲击声。

“陈先生，法律是法律，实际操作是另一回事。”刘经理的语气变了，少了些客套，多了些直接，“您也知道，公司最近业务调整，财务上有点紧张。这样吧，我向上面申请一下，看能不能在双倍补偿的基础上，再加两万，算是公司对您个人的额外补偿。十二万，您看怎么样？”

陈默的手指在桌面上轻轻敲击着。十二万，比法定金额多了一万四千二。如果只看钱，这已经是很不错的条件了，很多被裁员的同事连法定补偿都拿不到。

但他想起了系统任务。想起了律师说的“星辰科技怕你闹大”。想起了那些还在公司里挣扎的前同事。

“刘经理，”陈默说，“我需要考虑一下。明天给你答复，可以吗？”

“这……”刘经理犹豫了，“陈先生，公司这边希望今天就能定下来。您看这样行不行，您说个数，只要在合理范围内，我尽量去争取。”

陈默笑了。这就是谈判的艺术，当对方开始让你“说个数”时，说明他们已经让步了，但还在试探你的底线。

“十万零五千八百元。”陈默重复了一遍法定金额，“这是我的底线。另外，我需要公司出具正式的解除劳动合同证明，并且在证明上注明是‘公司提出解除’，而并非‘协商一致’。”

电话那头传来深吸一口气的声音。

“陈先生，您这是要把事情做绝啊。”刘经理的声音冷了下来。

“我只是在维护自己的合法权益。”陈默说，“刘经理，您是专业的HR，应该知道‘协商一致’和‘公司提出解除’在法律上的区别。前者可能影响我找下一份工作，后者不会。”

长时间的沉默。陈默能想象刘经理现在正皱着眉头，手指在计算器上按来按去，或者正在给上级发消息请示。

“这样吧，陈先生。”刘经理终于开口，语气缓和了些，“您的条件我记下了，需要向王总监汇报。今天下午下班前，我给您最终答复，行吗？”

“可以。”陈默说，“但我要提醒您，如果今天下班前没有答复，我明天上午就会去提交仲裁申请。”

“明白。”刘经理说，“那先这样，下午联系。”

电话挂断了。

陈默放下手机，走到窗前。楼下的车流更加密集了，喇叭声隐约传来。他忽然想起，这个时间，前同事们应该正在挤地铁，或者堵在去公司的路上，开始又一天的996生活。

而他，刚刚和HR经理进行了一场平等的谈判。

“叮：系统提示：宿主在谈判中保持冷静，坚守底线，摆烂值+10。当前摆烂值：515点。”

陈默摇摇头。坚守底线也能算摆烂？不过仔细想想，在职场文化里，敢于对不合理要求说“不”，确实需要一点反惯性的勇气。

他回到餐桌前，吃完已经有些凉的早餐，开始准备今天的行程。

下午一点，陈默出现在城市另一端的律师事务所。这是昨天在劳动仲裁委员会咨询时，工作人员推荐的专攻劳动法的律师，姓周，四十多岁，戴着一副金丝眼镜，办公室里堆满了案卷。

“陈先生，坐。”周律师递过一杯茶，“您电话里说的情况，我初步看了一下材料，胜诉概率很大。”

陈默把整理好的证据文件夹推过去：“这是所有材料。另外，今天上午星辰科技的HR联系我，提出了一笔总额，但要求解除证明上写‘协商一致’。”

周律师快速翻阅文件，眉头时而皱起，时而舒展。当他看到裁员通知时，手指在某一行停了下来。

“这里有问题。”周律师指着文件，“裁员通知是电子版，没有公司公章，也没有法定代表人签字。按照《劳动合同法》第五十条，用人单位应当在解除或者终止劳动合同时出具解除或者终止劳动合同的证明，并在十五日内为劳动者办理档案和社会保险关系转移手续。他们这个通知，在法律上是有瑕疵的。”

陈默眼睛一亮：“这意味着什么？”

“意味着我们可以主张这个解除行为程序违法。”周律师推了推眼镜，“如果程序违法，那么整个解除行为都可能被认定为无效。到时候，要么公司重新走程序，要么支付更高的赔偿。”

“更高的赔偿是多少？”

周律师拿出计算器按了几下：“如果主张违法解除，补偿、未结工资、加班费要分项列明，不能把口头总额直接当成结论。按现有材料，我们可以先按十五万元提出，再根据工资流水和考勤记录调整。”

陈默倒吸一口凉气。这个数字几乎是刘经理提出的十二万的两倍。

“当然，这是理论上的最高值。”周律师补充道，“实际仲裁中，仲裁员会根据具体情况裁量。但有一点是确定的：程序违法这个点，会让公司很被动。”

陈默沉思片刻：“如果我坚持要求公司出具‘公司提出解除’的证明，并且接受双倍补偿，是并非更稳妥？”

“稳妥，但可能少拿钱。”周律师说，“陈先生，我理解您的顾虑。很多劳动者在维权时，首要考虑的是‘拿钱走人，尽快了结’。但您这个案子，证据相对充分，公司又有程序瑕疵，我建议可以争取更多。”

陈默没有立刻回答。他想起系统任务，要求是“坚持不低于双倍补偿的诉求”。如果主张违法解除，那就不能只看一笔口头报价。

“周律师，如果我接受双倍补偿，但要求公司出具‘公司提出解除’的证明，这个方案在法律上可行吗？”

“完全可行。”周律师说，“这是您的权利。而且，如果公司拒绝，反而会成为仲裁时对他们不利的证据。”

陈默点点头：“那我坚持这个方案。如果公司同意，我就接受双倍补偿；如果公司拒绝，或者拖延，我就正式提交仲裁申请，主张违法解除。”

周律师露出赞许的神色：“很理性的策略。陈先生，您比我见过的大多数当事人都冷静。”

“可能是被裁员裁习惯了。”陈默自嘲地笑了笑。

离开律师事务所时，已经是下午四点。陈默站在街边，看着来往的车辆，忽然觉得有些恍惚。一个月前，他还是个每天挤地铁、加班到深夜的普通程序员，现在却坐在律师办公室里讨论劳动仲裁策略。

手机震动，是刘经理的微信：“陈先生，关于您的条件，公司愿意继续谈。补偿暂按十万零五千八百元，解除证明上注明‘公司提出解除’。您看什么时候方便来公司核对协议？”

陈默看着这条消息，没有急着回复。对方愿意把方案写出来，说明周律师的判断是对的，公司确实怕程序问题被公开。

他回复：“明天上午十点，我会带律师一起去核对。”

刘经理的回复几乎是秒回：“好的，明天十点，公司会议室见。”

陈默收起手机，走向地铁站。夕阳把他的影子拉得很长，投在人行道上。他想起系统任务要求提交仲裁申请。既然方案还没有落到纸面上，申请不能停。

“叮：隐藏任务‘仲裁先锋’进入关键阶段。宿主需在调解阶段坚持不低于双倍补偿的诉求，方可完成任务。提示：口头协议不具备法律效力，建议宿主先提交申请并保留书面证据。”

陈默停下脚步。系统说得对，口头承诺不可靠。明天见面时，他要先让律师把每一条条件核清楚。

他走进地铁站，刷码进闸。车厢里人挤人，空气有些浑浊。陈默站在角落，看着窗外飞驰而过的隧道灯光，忽然想起今天还没吃午饭。

“叮：系统提示：检测到宿主错过午餐，触发日常任务‘按时吃饭’。奖励：摆烂值+5。提示：长期不按时吃饭可能导致胃病，影响摆烂生活质量。”

陈默笑了。这系统真是操碎了心。

回到家，陈默煮了一碗简单的面条，加了个荷包蛋。吃完后，他坐在书房里，开始整理明天需要带的文件：身份证复印件、劳动合同原件、工资银行流水、裁员通知截图，以及周律师起草的《协议书》草稿。

晚上九点，手机再次震动。是前同事小李的微信：“默哥，听说你明天要来公司签协议？真的假的？”

陈默回复：“真的。”

小李秒回：“太好了！我们都听说了，你要到了双倍补偿！能不能帮我们也问问？我们几个也被裁了，但公司只肯给N+1。”

陈默皱起眉头。N+1是法定最低标准，很多公司用这个打发员工。星辰科技这次裁员明显存在程序问题，如果走仲裁，应该按证据争取合理结果。

“你们有多少人？”陈默问。

“加上你，一共七个。”小李说，“我们昨天私下建了个群，都在商量这事。但大家都怕麻烦，也怕影响找下一份工作。”

陈默沉思片刻，回复：“明天我签完协议，可以和你们详细聊聊。如果你们想维权，我可以把周律师的联系方式给你们。”

“真的吗？太谢谢了默哥！”小李发来一连串感谢的表情包。

陈默放下手机，靠在椅背上。他忽然意识到，自己正在做的事情，已经超出了“维护个人权益”的范畴。如果明天能帮到其他同事，那系统任务“仲裁先锋”的意义，可能比他想象的更大。

“叮：系统提示：宿主产生利他行为倾向，摆烂值+20。当前摆烂值：540点。提示：摆烂不等于冷漠，真正的摆烂是既维护自身权益，又不损害他人利益。”

陈默看着这条提示，若有所思。系统对“摆烂”的定义，似乎和他最初理解的不太一样。

第二天上午九点四十五分，陈默和周律师出现在星辰科技楼下。

公司所在的写字楼是这一带的地标建筑，玻璃幕墙在阳光下闪闪发亮。陈默抬头看了看，想起自己第一次来这里面试时的紧张心情。五年过去了，他再次站在这里，身份却已经完全不同。

“准备好了吗？”周律师问。

陈默点点头：“准备好了。”

他们走进大楼，乘电梯上到十八楼。前台小姑娘看到陈默，表情有些惊讶：“陈、陈先生？您怎么来了？”

“和刘经理约了十点。”陈默说。

前台连忙打电话确认，然后引导他们去会议室。会议室里已经坐着三个人：刘经理，一个戴眼镜的中年男人，还有一个看起来像法务的年轻女性。

“陈先生，这位是我们公司的王总监，这位是法务部的张律师。”刘经理介绍道，语气比昨天电话里更加正式。

陈默和周律师坐下。王总监打量了陈默几眼，开口道：“陈先生，关于您提出的条件，公司原则上愿意继续谈。这是协议草案，您先看一下。”

他推过来一份文件。陈默接过，和周律师一起仔细阅读。协议条款很详细：补偿金额十万零五千八百元，解除证明注明“公司提出解除”，十五日内办结离职手续，最后一条却写着“双方再无其他争议”。

“这里有问题。”周律师指着最后一行，“‘双方再无其他争议’这一条，需要删除；付款日期也要写清楚。”

王总监皱眉：“为什么？”

“因为根据《劳动合同法》第五十条，用人单位有义务在解除劳动合同后十五日内为劳动者办理档案和社会保险关系转移手续。”周律师说，“这一条是法定义务，不能通过协议排除。如果保留这一条，未来公司可能以此为由拒绝办理相关手续。”

会议室里安静了几秒。王总监和张律师交换了一个眼神。

“周律师说得对。”张律师开口了，“这一条可以删除。另外，我建议增加一条：公司应在协议签订后三个工作日内，向陈先生出具正式的解除劳动合同证明。”

陈默点点头。张律师的补充很关键，有了这一条，公司就不能拖着不办手续。

双方又就几个细节进行了讨论，但公司不愿当场确认付款顺序，也不肯删除保密条款。陈默仔细记下分歧，没有在草案上签字。

“陈先生，补偿金会在三个工作日内打到您的工资卡上。”刘经理说，“另外，您的离职手续，我会安排专人跟进。”

陈默站起身，收回自己的文件。整个过程平静而专业，没有争吵，没有冲突，但协议仍停留在草案阶段。

走出会议室时，陈默停下脚步，转头对刘经理说：“刘经理，还有件事想和您商量。”

刘经理愣了一下：“您说。”

“我有几个前同事，也被这次裁员波及了。”陈默说，“他们的情况和我类似，但公司只愿意给N+1。我想问一下，公司是否愿意对他们也适用双倍补偿的标准？”

刘经理的表情瞬间变得复杂。他看了看王总监，后者面无表情。

“陈先生，每个人的离职情况不同，不能一概而论。”王总监开口了，语气平淡但坚决，“公司会根据每个人的具体情况，依法依规处理。”

陈默点点头，没有再说什么。他和周律师走出公司大门，电梯下行时，周律师轻声说：“你刚才那个问题，问得很好。”

“但没用。”陈默说。

“至少表明了态度。”周律师说，“而且，你那些同事如果想维权，现在有了你的先例，会容易很多。”

陈默走出写字楼，阳光有些刺眼。他掏出手机，给小李发了条消息：“协议还没签，关键分歧我已经记下了。如果你们想维权，我可以把周律师的联系方式和证据清单发给你们参考。”

小李的回复很快：“默哥太够意思了！我们正在开会商量，晚点联系你！”

陈默收起手机，忽然觉得心情轻松了许多。他抬头看了看天空，云朵缓慢地移动着，阳光从云隙中洒下来，照在身上暖洋洋的。

“叮：系统提示：隐藏任务‘仲裁先锋’进入调解阶段。宿主坚持不低于双倍补偿的诉求，但书面协议尚未达成。当前进度：材料待提交。”

陈默愣住了。系统没有发放主线奖励，反而把“待提交”三个字标得很醒目。

“系统，什么时候才算完成？”陈默在心中问道。

“叮：系统提示：主线任务需要书面、可执行的结果。口头承诺、未签协议和未到账款项均不计入完成条件。”

陈默明白过来。系统奖励的并非一句漂亮话，而是能留下证据、真正解决问题的行动。

“那技能升级券呢？”陈默问。

“叮：技能升级券暂未发放。主线任务完成后，才会根据结果结算奖励。”

陈默思考了几秒。高效决策对他目前的状态更有用，毕竟，他可能要开始处理更多类似的事情。

“先不升级。”他在心中默念。

“叮：宿主选择保留资源，等待主线结算。”

陈默深吸一口气。系统没有因为一份草案就发放奖励，反而逼着他把事实、证据和请求分开。这个规则比“越摆烂奖励越高”更值得记住。

下午，陈默回到公寓，开始整理前同事们的情况。小李建的群里有六个人，每个人的情况都略有不同：有的工作年限更长，有的工资更高，有的被裁员的理由更牵强。但有一点是相同的，他们都只拿到了N+1的补偿。

陈默把周律师的联系方式发到群里，又把自己协议的关键条款整理成文档，分享给大家。很快，群里开始热烈讨论起来。

“默哥，你说我们真的能拿到双倍吗？”小李问。

“要看具体情况。”陈默回复，“但有一点是确定的：如果公司裁员程序违法，你们就有权主张更高赔偿。关键是证据。”

“我们有什么证据？”另一个同事问。

陈默想了想，回复：“裁员通知、工作交接记录、和HR的聊天记录、工资条……所有能证明劳动关系和解除过程的东西，都要保存好。明天我可以帮你们整理一下。”

群里一片感谢声。陈默看着手机屏幕，忽然觉得，自己正在做的事情已经不只是维护个人权益。他在帮助一群人保存证据，而这种并肩处理问题的感觉，是他过去五年职场生涯中从未体验过的。

晚上，陈默坐在书房里，看着窗外城市的夜景。灯火璀璨，车流如织，每一盏灯背后，都是一个在职场中挣扎或前行的人。

“系统，”陈默忽然开口，“摆烂的最终目的是什么？”

“叮：系统提示：摆烂是一种生活态度，而非目的。真正的摆烂，是在认清生活真相后，依然选择用最舒适的方式生活。宿主当前行为符合‘高级摆烂’定义：在维护自身权益的同时，不损害他人利益，并可能对社会产生积极影响。”

陈默笑了。高级摆烂，这个说法有意思。

他关掉电脑，走到客厅，从冰箱里拿出一盒进口蓝莓。蓝莓在灯光下泛着深紫色的光泽，像一颗颗微小的宝石。他忽然想起，自己绑定摆烂系统的那一天，正是被裁员的那一天。那时的他，觉得天塌了，未来一片灰暗。

但现在，他坐在系统奖励的公寓里，吃着进口水果，手边是尚未签署的协议草案，群里还有一群等着整理证据的同事。

“叮：系统提示：今日材料整理完成，摆烂值+15，当前摆烂值：555点。主线奖励暂不结算。”

陈默咬了一颗蓝莓，酸甜的汁液在口中爆开。他走到窗前，看着城市的夜空。明天，他还要帮前同事们整理证据，可能还要面对公司的新一轮交锋。但此刻，他只觉得平静。

摆烂系统要求的并非躺平，而是让他学会用更低的消耗，面对这个复杂的世界。

第二天上午，陈默和周律师把仲裁申请、工资流水、录音说明和证据目录递到窗口。工作人员核对材料后，盖章收下申请，给了他一张受理通知书。

【叮：申请已受理，摆烂值+10，当前摆烂值：565点。主线进入调解阶段。】

陈默把通知书夹进文件夹，没有庆祝。他看了一眼手机里还未回复的群消息，转身走出仲裁委。
