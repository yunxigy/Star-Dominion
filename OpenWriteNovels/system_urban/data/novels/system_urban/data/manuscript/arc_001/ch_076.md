# 摆烂之王的复仇

会议室的空调吹出冷风，陈默靠在椅背上，看着对面那个曾经不可一世的男人。

王振华比半年前瘦了一圈，眼袋深重，但眼神里的焦虑已经被某种更复杂的东西取代。他搓了搓手，动作里带着明显的局促。

“陈总。”王振华开口，声音有点哑，“首先，我想为半年前的事道歉。”

陈默没说话，只是抬了抬下巴示意他继续。

“当时我说你‘不知天高地厚’，”王振华苦笑一声，“现在想想，真正不知天高地厚的是我自己。”

【系统提示：检测到关键人物情绪波动，触发隐藏剧情“领导的觉悟”最终阶段】

【任务要求：接受道歉并完成合作签约，过程中保持情绪稳定】

【奖励：技能“情绪共鸣”（被动）】

陈默瞥了眼系统面板，嘴角微微上扬。这系统还真是会挑时候。

“王总，”陈默开口，声音平静，“过去的事就过去了。”

王振华愣了下，似乎没想到这么容易就被原谅。他张了张嘴，又闭上，最后从公文包里抽出一份文件。

“这是我们公司的现状报告，”他把文件推过来，“华振科技，187人，上个季度营收同比下降23%。员工流失率31%，其中技术部流失率最高，47%。”

陈默翻开文件，数据触目惊心。加班时长统计表上，平均每人每月加班86小时，最高纪录是某个项目组连续三周每天工作16小时。

“我们试过所有办法，”王振华的声音越来越低，“团建、奖金、期权……都没用。直到我看到你们公司的案例。”

他抬起头，眼神里有一种陈默很熟悉的东西——那是走投无路时才会出现的孤注一掷。

“我想让华振科技成为‘职场启蒙运动’的合作企业，”王振华说，“第18家。”

陈默合上文件，手指轻轻敲着桌面。

“你知道我们的合作条件吧？”

“知道，”王振华点头，“取消强制加班，实行弹性工作制，管理层带头准点下班。这些我们都愿意做。”

“不只是愿意做，”陈默纠正道，“是要真心认同。如果你只是把这当成救命稻草，那我们没必要合作。”

王振华沉默了几秒，然后站起身，走到窗边。

会议室在28楼，窗外是整个城市的天际线。下午四点的阳光把玻璃幕墙照得发亮，像一面面镜子。

“陈默，”他突然转身，用了陈默的名字而不是“陈总”，“你知道我为什么当初那么针对你吗？”

陈默摇头。

“因为你让我害怕。”王振华的声音很轻，但每个字都清晰，“你辞职那天，我骂你不知天高地厚，其实是因为你做了我想做却不敢做的事。”

他走回座位，坐下，身体前倾。

“我在这家公司干了十五年，从基层员工做到总监。我见过太多人因为加班猝死，见过太多家庭破裂，见过太多年轻人眼里的光一点点熄灭。但我告诉自己，这就是职场规则，要么适应，要么出局。”

王振华深吸一口气。

“直到我看到‘摆烂科技’的案例。你们不加班，不内卷，员工流失率不到5%，营收却每年翻倍。我才明白，不是规则有问题，是我有问题。”

【系统提示：检测到目标人物情绪转变，从焦虑转为放松】

【“情绪共鸣”技能激活中……】

陈默感觉到一种奇怪的连接。他能“感觉”到王振华的情绪，不是读心，而是一种更微妙的东西——就像站在对方的角度，突然理解了那些曾经让他愤怒的行为背后的原因。

“我接受你的道歉。”陈默说。

王振华明显松了口气。

“合作的事，”陈默继续，“我们可以谈。但我有几个条件。”

“你说。”

“第一，取消所有强制加班制度，包括变相强制。第二，管理层必须带头执行，包括你。第三，允许员工匿名反馈，如果发现阳奉阴违，合作立即终止。”

王振华点头：“这些我们都愿意做。”

“最后一点，”陈默看着他，“如果合作成功，我希望你能在行业论坛上公开分享这段经历。不是为了羞辱你，而是让更多人看到改变的可能性。”

王振华愣住了。

陈默能感觉到他的犹豫——那种被扒开伤口展示给所有人看的恐惧。但几秒钟后，恐惧被另一种情绪取代：决心。

“我答应你。”王振华说。

接下来的一个小时，两人敲定了合作协议的所有细节。陈默的法务团队很快拟好了合同，双方签字盖章。

【系统提示：隐藏剧情“领导的觉悟”完成】

【奖励：技能“情绪共鸣”（被动）已解锁】

【效果：能感知周围人的情绪状态，距离越近感知越清晰】

【“职场启蒙运动”合作企业新增1家，当前总数：18家】

【全国知晓率：35% 行业知晓率：70%】

【达成隐藏成就“以德服人”】

陈默看着系统面板上的数字，心里却没有太多喜悦。这些数字背后，是18家公司的数千名员工，他们的生活质量将因此改变。

“陈总，”王振华的声音打断他的思绪，“我能问你一个问题吗？”

“问。”

“你当初辞职的时候，真的预料到会有今天吗？”

陈默笑了。

“王总，”他说，“如果我说我当时只是想睡个懒觉，你信吗？”

王振华愣了下，然后也笑了。那是陈默第一次在他脸上看到真诚的笑容。

“我信。”王振华说，“因为有时候，最简单的选择，反而是最正确的。”

送走王振华后，陈默回到自己的办公室。夕阳把整个房间染成金色，他站在落地窗前，看着楼下车水马龙。

手机震动，是系统的新消息。

【新任务发布：深化变革】

【任务要求：在三个月内，让至少5家合作企业的员工满意度提升20%】

【奖励：解锁“企业管理优化模块”】

【失败惩罚：系统功能降级】

陈默收起手机，眼神变得锐利。

摆烂的终极目标，从来不是什么都不做。而是用最“懒”的方式，做最对的事。

他拿起电话，拨通了助理的号码。

“通知所有合作企业，下周三下午三点，线上会议。主题：如何让员工准时下班，同时提升效率。”

挂断电话，陈默看着窗外渐渐亮起的霓虹灯。

游戏才刚刚开始。

而这一次，他要改变的不是一家公司，而是整个职场的规则。
