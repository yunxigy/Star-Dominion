# 关键事件时间线

| 时间/章节 | 事件 | 影响 |
|---|---|---|
| 第1—10章 | 陈默被星辰科技裁员，绑定系统，获得现金与滨江花园公寓首付，提交仲裁材料并提出书面和解条件 | 个人从被动失业进入主动谈判，摆烂科技只有名字和计划 |
| 第11—18章 | 和解签署、赔偿到账、公司注册、预算与写字楼筹备 | 陈默拥有合法创业主体和有限现金，但必须尽快获得业务 |
| 第19—30章 | 建立准时下班制度，招募第一批员工，陆野加入，完成第一份可复制产品和正式订单 | 摆烂科技从理念变成能交付的小公司 |
| 第31—46章 | 用工时、返工和交付数据证明效率，陆野把点子做成协作产品 | 反内卷从口号变成可验证的产品方法 |
| 第47—60章 | 面对同行模仿、挖人、抢客户和资本投资，拒绝不适合的融资并建立初步行业公约 | 公司获得口碑，但仍面临规模和现金流限制 |
| 第61—76章 | 组织扩张、进入制造业试点、经历现场故障，建立工业软件和供应链能力 | 摆烂科技从软件服务进入真实产业 |
| 第77—90章 | 并购团队、成立子公司、投入边缘计算研发，经历断供和样机失败 | 摆烂科技完成集团化，开始面对核心技术与供应链风险 |
| 第91—106章 | 关键器件断供，集团建立轮值应急机制，联合国内供应商做替代方案 | 反内卷制度经受真正危机，国产替代从口号进入现场 |
| 第107—114章 | 推动交付、值守、数据和安全标准，面对对手舆论与集团内部反对 | 集团成为行业规则的参与者，而不是单纯卖产品 |
| 第115—120章 | 完成跨区域技术交付，陈默不再亲自审批，系统最终任务结算 | 集团能脱离个人监工运行，摆烂被证明为可持续生产力 |
