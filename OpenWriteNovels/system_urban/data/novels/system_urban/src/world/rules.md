# 世界底层规则

## 系统规则

- 系统奖励“拒绝无意义消耗、保留判断力、建立可持续机制”的选择，不直接生成客户、专利或成熟技术。
- 任务可以要求陈默拒绝无偿加班、停止无效会议、拒绝口头承诺、把责任写进流程，但不能要求他逃避安全事故、客户故障或法律责任。
- 奖励有即时和链式两类。链式奖励必须等事件闭环后结算，不能每章自动发放。
- 系统提供的资源要有现实落点：资金有用途限制，房产和场地涉及合同与维护，设备需要人员使用，信息只能减少搜索成本。
- 任务失败会带来摆烂值扣除、奖励冻结、现金流压力或公开声誉损失，不使用随机抹除角色能力的惩罚。

## 职场规则

- 准时下班不是不负责。紧急事项用轮值、明确授权、加班费和补休解决，不能让全员陪同。
- 目标、责任、验收标准和风险必须在工作时间内尽量写清楚；临时变更会带来成本，成本由提出变更的一方承担或重新谈合同。
- 员工可以离职、拒绝任务或选择不加入公司。陈默不能用道德压力替代薪酬、成长和制度。
- 反内卷的效果通过返工率、交付可预测性、离职率、客户续约和产品质量体现，不用“大家都很努力”证明。

## 经营规则

- 摆烂科技先靠服务和小产品活下来，再形成可复制产品，随后才进入产业技术和集团化扩张。
- 每次扩张都要回答现金流、人才、交付责任和组织授权四个问题。
- 融资、并购、开放接口和行业联盟都有收益与代价，不能由系统替陈默自动选出正确答案。
- 公司可以失败、延期、赔钱和失去客户；失败必须留下经验、关系变化或新的约束。

## 技术规则

- 软件产品先解决内部重复工作，再服务客户，再进入真实工厂和产业链。
- 工业技术必须经过实验室、试点、现场连续运行和供应链验证，单次演示不能视为成功。
- 国产替代不是喊口号，需要器件、认证、数据归属、产能和客户共同承担成本。
- 点子王负责提出方向，但方向必须经过原型、测试、交付和复盘，才能成为集团能力。
