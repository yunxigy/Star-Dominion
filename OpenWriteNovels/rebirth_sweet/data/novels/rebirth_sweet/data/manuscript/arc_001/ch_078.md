# 图书馆的秘密

图书馆的玻璃门被推开时，苏念一眼就看到了站在台阶下的顾行舟。

他穿着深蓝色的校服外套，手里拎着两个塑料袋，晨光打在他侧脸上，睫毛投下一小片阴影。听到动静，他抬起头，嘴角微微扬起一个弧度。

“来了。”顾行舟把其中一个袋子递过来，“豆浆，肉包子。”

苏念接过来，塑料袋还温热着。她低头看了一眼，两个肉包子，一袋豆浆，吸管已经插好了。

“你怎么知道我没吃早饭？”她问。

顾行舟顿了顿：“猜的。”

苏念没拆穿他。上辈子她高三时经常不吃早饭，胃病就是那时候落下的。这辈子重生回来，她倒是记得吃，但顾行舟不知道这些。

两人走进图书馆。周末早上八点，阅览室里人不多，只有几个考研的学生埋头在书堆里。空气里有旧书纸和消毒水的味道，阳光从高大的窗户斜射进来，在地板上拉出长长的光斑。

顾行舟选了个靠窗的位置，放下书包，从里面掏出一叠卷子。

“你上次月考的数学卷子我看了。”他翻开其中一张，用笔尖点了点最后一道大题，“这里，你的解题思路没问题，但公式用错了。”

苏念凑过去看。那道题她记得，上辈子高考时考过类似的变形题，当时她没做出来。这辈子她凭着模糊的记忆写了步骤，结果还是错了。

“这个公式不是这样用的。”顾行舟从书包里又掏出一本笔记本，翻到某一页，“你看，这里有个前提条件。”

苏念盯着他笔记本上工整的字迹。不是打印体，是一笔一划手写的，每个公式的推导过程都写得清清楚楚，旁边还有用红笔标注的重点。

“你什么时候整理的？”她问。

顾行舟的笔尖停了一下：“高二暑假。”

苏念抬起头看他。高二暑假，那时候他们还不熟，甚至没说过几句话。顾行舟就已经在整理这些了？

“你……”她犹豫了一下，“你那时候就开始准备高考了？”

顾行舟没直接回答，而是把笔记本推到她面前：“先看这道题。”

苏念没再追问。她低头看笔记本，顾行舟开始讲解。他的声音很轻，但每个字都清晰，逻辑链条严丝合缝。从最基础的公式推导开始，一步步延伸到题目的变形应用。

苏念听着，忽然想起上辈子高三时，她数学烂得一塌糊涂，每次考试都在及格线边缘挣扎。那时候她满脑子都是周宇航，根本没心思学习。直到高考失利，她才后悔莫及。

“这里懂了吗？”顾行舟问。

苏念回过神，点点头：“懂了。”

顾行舟又翻到下一页：“那看这道。这是上次月考的附加题，全班只有三个人做出来。”

苏念看了一眼题目，眉头皱起来。这道题她有印象，上辈子高考时出过类似的，但难度更高。她当时在考场上对着这道题发了十分钟呆，最后只能空着。

“这道题的关键在于换元。”顾行舟在草稿纸上写下一串步骤，“你看，如果设t等于这个，然后代入……”

他讲得很慢，每一步都等苏念点头确认后才继续。苏念发现自己竟然能跟上他的思路，甚至能在某些地方提出自己的疑问。

“等一下，”她打断他，“这里为什么要用这个公式？”

顾行舟愣了一下，随即笑了：“你发现了。”

他指着草稿纸上的某一步：“其实这里可以用另一种方法，但比较复杂。用这个公式更直接。”

苏念盯着那行公式看了几秒，忽然说：“这个公式我好像在哪见过。”

顾行舟的笔尖停在半空。

苏念抬起头：“你是不是……给我讲过？”

顾行舟没说话，但耳根有点红。

苏念忽然想起一件事。上辈子高三下学期，有一次她收到一个匿名包裹，里面是一本手写的数学笔记。当时她以为是哪个暗恋她的男生送的，随手就塞进了抽屉里，再也没看过。

直到高考前收拾东西时，她才翻出来，发现笔记里不仅有数学，还有物理、化学的重点整理。字迹工整，逻辑清晰，每一页都写得密密麻麻。

但那时候已经太晚了。

“那本笔记……”苏念的声音有点哑，“是你写的？”

顾行舟沉默了几秒，然后轻轻点头。

苏念感觉喉咙发紧。上辈子她收到那本笔记时，正满脑子想着怎么追周宇航，根本没心思看。她甚至在心里嘲笑过那个送笔记的人——写得这么认真有什么用？我又不会看。

现在她知道了，那个人就坐在她对面。

“为什么？”她问。

顾行舟抬起头，眼神很认真：“因为你需要。”

苏念愣住了。

“高二那年军训，”顾行舟的声音很轻，“你中暑晕倒，我背你去医务室。你趴在我背上，迷迷糊糊地说了一句‘要是数学能及格就好了’。”

苏念完全不记得这件事。上辈子军训时她确实在中暑过，但醒来后只记得自己躺在医务室，旁边坐着周宇航。

“还有开学第一天，”顾行舟继续说，“你在讲台上做自我介绍，说你的目标是考上一本，让妈妈过上好日子。”

苏念想起来了。那天她紧张得手都在抖，声音小得像蚊子叫。讲台下有人笑，她恨不得找个地缝钻进去。

“所以你就开始帮我？”她问。

顾行舟摇头：“不是帮。是……”

他顿了顿，似乎在找合适的词。

“是觉得你值得。”他说。

苏念盯着他看了很久。图书馆的窗户开着，有风吹进来，吹动了桌上的草稿纸。阳光从侧面打过来，顾行舟的睫毛在眼睑下投出细密的阴影。

她忽然想起上辈子收到的那些匿名贺卡。每年生日、每个节日，她都会收到一张，上面写着简短的祝福。字迹和那本笔记一模一样。

“那些贺卡，”她说，“也是你寄的？”

顾行舟的耳根更红了，但这次他没躲闪：“嗯。”

苏念感觉心脏被什么东西轻轻撞了一下。上辈子她收到那些贺卡时，以为是周宇航寄的，还为此高兴了好久。直到后来她才知道，周宇航根本不知道她的生日。

“为什么不说？”她问。

顾行舟低下头，看着桌上的卷子：“那时候……你眼里只有别人。”

苏念说不出话来。

是啊，上辈子她满脑子都是周宇航，根本没注意过身边还有一个人，默默为她做了这么多。

“对不起。”她忽然说。

顾行舟抬起头，眼神有些惊讶。

“上辈子，”苏念的声音很轻，“我太蠢了。”

顾行舟看着她，忽然笑了：“这辈子不蠢就行。”

苏念也笑了。两人对视了几秒，然后同时移开视线。

“继续讲题吧。”顾行舟重新拿起笔。

苏念点头，低头看卷子。但这一次，她发现自己很难集中注意力。顾行舟的声音就在耳边，很近，近得能闻到他身上淡淡的洗衣液味道。

她偷偷抬眼看他。顾行舟正专注地在草稿纸上写步骤，侧脸的线条很干净，喉结随着说话轻轻滚动。

苏念忽然想起上辈子最后一次见到顾行舟，是在高中同学聚会上。那时候她刚离婚，带着孩子，日子过得很艰难。顾行舟西装革履，已经是某家投行的高管。

聚会结束时，他送她回家。车停在她家楼下，他忽然说：“如果当初……”

话没说完，他就停住了。

苏念当时没在意，只当他是客套。现在想想，那句话后面可能藏着很多东西。

“这里懂了吗？”顾行舟问。

苏念回过神，连忙点头：“懂了。”

顾行舟看了她一眼，没说什么，继续讲下一道题。

时间过得很快。等苏念做完最后一道练习题，抬头看墙上的钟，已经十一点半了。

“先休息一下。”顾行舟合上笔记本，“我去买水。”

苏念看着他起身走向图书馆的小卖部，背影挺拔，校服外套的下摆随着走动轻轻晃动。

她忽然意识到，自己已经很久没有这样仔细地看过一个人了。上辈子离婚后，她对感情彻底死心，觉得这辈子大概就这样了。没想到重生回来，反而遇到了上辈子错过的人。

顾行舟很快回来，手里拿着两瓶矿泉水。他把其中一瓶递给苏念，然后坐回座位。

“下午还继续吗？”他问。

苏念想了想：“下午我有点事，明天可以吗？”

顾行舟点头：“好。”

两人收拾东西准备离开。苏念把笔记本和卷子塞进书包，忽然想起一件事。

“顾行舟，”她叫住他，“你下午有空吗？”

顾行舟正在拉书包拉链的手顿了顿：“怎么了？”

“我想请你吃饭。”苏念说，“谢谢你帮我补课。”

顾行舟看着她，眼神有些复杂。过了几秒，他说：“不用，顺手的事。”

“那不一样。”苏念坚持，“你花了这么多时间帮我，我总得表示一下。”

顾行舟没说话，但耳根又开始泛红。

苏念忽然发现，这个人好像很容易脸红。平时看着挺冷淡的，一到这种时候就破功。

“就去学校后面那家小餐馆，”她说，“我请客。”

顾行舟犹豫了几秒，最终点头：“好。”

两人走出图书馆。周末的校园很安静，只有零星几个学生在操场上打球。阳光很好，晒在身上暖洋洋的。

苏念走在顾行舟旁边，两人之间隔着半步的距离。她忽然想起上辈子，她和周宇航也这样走过，但那时候她满心欢喜，现在回想起来只觉得可笑。

“顾行舟，”她忽然问，“你为什么喜欢我？”

这个问题她憋了很久，终于问出口。

顾行舟的脚步顿了顿，然后继续往前走。

“刚才不是说了吗？”他说。

“那只是原因，”苏念说，“我想知道为什么。”

顾行舟沉默了很久。两人走过操场，走过教学楼，一直走到校门口，他才开口。

“因为你很认真。”他说。

苏念愣了。

“军训时中暑，你明明很难受，但还是坚持走完了全程。”顾行舟的声音很轻，“开学自我介绍，你紧张得声音都在抖，但还是把话说完了。”

他停下脚步，转身看着苏念。

“你总是很认真地对待每一件事，”他说，“哪怕结果不好，你也从不敷衍。”

苏念怔怔地看着他。阳光从他身后照过来，在他周身镀上一层金边。

她忽然想起上辈子，她确实很认真——认真地喜欢周宇航，认真地为他付出一切，最后认真地被甩掉。

“但上辈子我认真错了方向。”她说。

顾行舟点头：“所以这辈子，要认真对的事。”

苏念忽然笑了。她发现自己好像有点明白顾行舟的意思了。

“那你觉得，”她问，“什么是‘对的事’？”

顾行舟看着她，眼神很认真：“高考，未来，还有……”

他顿了顿，没说完。

苏念等着他继续说，但他只是转过身，继续往前走。

“先去吃饭吧。”他说。

苏念跟上去，心里有点失落，但更多的是好奇。她发现自己越来越想了解这个人，了解他藏在平静表面下的所有心思。

两人走到学校后面的小餐馆。这是家开了十几年的老店，招牌菜是红烧肉和糖醋鱼。周末中午人不多，只有几桌学生在吃饭。

苏念点了三个菜，把菜单递给顾行舟：“你看看还要什么。”

顾行舟没接：“你点就行。”

苏念没坚持，又加了个汤。

等菜的时候，两人相对坐着，一时有点沉默。餐馆里很吵，隔壁桌的男生在大声讨论游戏，后厨传来炒菜的滋滋声。

苏念忽然开口：“顾行舟，你有没有想过以后要做什么？”

顾行舟正在倒水，闻言手顿了顿：“金融。”

“投行？”苏念问。

顾行舟点头。

苏念想起上辈子，顾行舟确实进了投行，而且做得很好。同学聚会上，他是混得最好的那一个。

“那你高考志愿打算填哪里？”她问。

顾行舟报了一所顶尖财经大学的名字。苏念记得，那所大学的录取分数线高得吓人，全省前一百名才有希望。

“你能考上吗？”她问。

顾行舟看了她一眼：“能。”

苏念忽然发现，这个人说话时有种不容置疑的笃定。不是自大，是那种基于实力的自信。

“那你呢？”顾行舟反问。

苏念想了想：“我想学计算机。”

顾行舟有些惊讶：“为什么？”

“因为未来是互联网的时代。”苏念说，“计算机是基础。”

她说这话时，脑子里闪过上辈子的记忆。那些年她见过太多风口，也见过太多人因为抓住风口而翻身。她知道自己错过了太多，这辈子不想再错过。

“而且，”她补充道，“我想创业。”

顾行舟看着她，眼神里多了些东西：“什么方向？”

“现在还没想好，”苏念说，“但肯定和互联网有关。”

顾行舟没再追问。这时菜上来了，红烧肉冒着热气，糖醋鱼的酱汁还在滋滋作响。

“吃饭吧。”顾行舟把筷子递给她。

苏念接过筷子，夹了一块红烧肉。肉炖得很烂，入口即化，咸香中带着一丝甜味。

她忽然想起上辈子，她很少有机会来这种小餐馆吃饭。离婚后她要养孩子，要还房贷，每一分钱都得精打细算。

“好吃吗？”顾行舟问。

苏念点头：“好吃。”

顾行舟也夹了一块肉，但没吃，只是看着。

“怎么了？”苏念问。

“没什么，”顾行舟说，“就是觉得……这样挺好。”

苏念愣了愣，然后笑了。

是啊，这样挺好。没有周宇航，没有那些乱七八糟的事，只有她和顾行舟，坐在一家小餐馆里，吃着简单的饭菜，聊着未来的打算。

上辈子她求而不得的东西，这辈子好像正在慢慢实现。

吃完饭，顾行舟坚持付了钱。苏念和他争了半天，最后还是没争过。

“说好我请客的。”走出餐馆时，苏念有点不好意思。

“下次吧。”顾行舟说。

苏念抬头看他：“还有下次？”

顾行舟的耳根又红了：“你不是说明天继续补课吗？”

苏念这才反应过来，自己刚才说的“下次”好像有点歧义。她张了张嘴，想解释，但最后只是点点头。

“那明天见。”她说。

顾行舟点头：“明天见。”

两人在校门口分开。苏念看着顾行舟的背影渐渐走远，心里忽然涌起一种奇怪的感觉。

上辈子她追了周宇航三年，最后只换来一句“你配不上我”。这辈子她重生回来，本来只想好好高考，改变命运，没想到却遇到了顾行舟。

这个上辈子默默喜欢了她十年，这辈子依然在默默付出的人。

苏念转身往教学楼走。下午她要去图书馆还书，然后回家复习。时间很紧，距离高考只剩下不到三个月。

但她心里却前所未有的平静。

因为她知道，这一次，她不会再错过对的人。

走到教学楼门口时，苏念忽然听到有人叫她的名字。

“苏念！”

她转身，看到周宇航正从篮球场那边跑过来。他穿着球衣，额头上全是汗，手里拿着一瓶水。

“下午有空吗？”他气喘吁吁地问，“我们队和隔壁班打比赛，来看吗？”

苏念看着他。阳光下，周宇航的脸很年轻，笑容灿烂得像上辈子她第一次见他时那样。

但这一次，她心里没有任何波澜。

“不了，”她说，“我下午有事。”

周宇航愣了愣，显然没想到她会拒绝。上辈子苏念从不会拒绝他的任何邀请，哪怕是逃课。

“什么事啊？”他问，“比看我打球还重要？”

苏念忽然觉得有点好笑。这个人，永远觉得自己是世界的中心。

“比看你打球重要。”她说。

周宇航的脸色变了变。他盯着苏念看了几秒，忽然笑了：“行吧，那下次。”

苏念点点头，转身走进教学楼。她没回头，但能感觉到周宇航的目光一直追着她。

走到楼梯拐角时，她松了口气。

上辈子她为了这个人，浪费了太多时间和感情。这辈子，她不会再犯同样的错误。

回到教室，苏念从书包里掏出顾行舟的笔记本。她翻开第一页，看着上面工整的字迹，忽然发现角落里有一行很小的字。

她凑近看，那行字写着：

“希望你一切都好。——顾行舟”

苏念的心脏猛地跳了一下。

她想起上辈子收到的那些贺卡，每一张的角落里，都有同样的一行字。

原来从那么早开始，他就已经在为她祝福了。

苏念把笔记本抱在怀里，闭上眼睛。

窗外传来篮球场的喧闹声，但她心里一片宁静。

她知道，从这一刻起，她的人生终于走上了正确的轨道。

而那个默默喜欢了她十年的人，这一次，她不会再错过。
