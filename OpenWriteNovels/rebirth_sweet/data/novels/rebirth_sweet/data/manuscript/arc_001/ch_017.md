# 第十七章 室友

苏念在312宿舍的第一个早晨，是被林薇的闹钟吵醒的。

那手机闹铃声尖锐得能刺穿耳膜，响了足足三十秒才被慌乱按掉。苏念睁开眼，上铺的床板近在咫尺，晨光从浅蓝色窗帘缝隙里漏进来，在水泥地上划出一道亮痕。

“完了完了，八点有课！”林薇从上铺探出头，头发乱得像鸟窝。

对面下铺的陈雪翻了个身，声音闷在枕头里：“你中文系第一节不是十点吗？”

“是十点，但我得去占座啊！”林薇已经手忙脚乱地爬下梯子，“上次坐最后一排，教授讲《诗经》我一个字没听清。”

苏念看了眼手机——七点二十。

她坐起身，被子滑到腰间。昨晚整理行李到凌晨，此刻肩膀还有些酸。宿舍是四人间，靠门那张床空着，听说那个女生要下周才来报到。

“苏念你起这么早？”林薇一边套T恤一边问。

“习惯了。”苏念说。

上辈子在广告公司做策划，常年九九六，生物钟早就定型了。哪怕重生回高三，她也没睡过懒觉。

陈雪终于坐起来，揉着眼睛：“你们俩都别吵，让我再眯五分钟……”

“不行！”林薇一把掀开她的被子，“说好今天一起去办校园卡的！”

苏念看着她们闹，嘴角不自觉弯了弯。

年轻真好。

她起身去洗漱。公共洗手间在走廊尽头，水龙头有点漏水，滴答滴答的声响在清晨的宿舍楼里格外清晰。苏念用冷水拍了拍脸，镜子里的自己十八岁，皮肤饱满，眼睛亮亮的，没有黑眼圈，没有法令纹。

真好。

她想起上辈子第一次来江城大学报到，是一个人拖着行李箱，找宿舍找了半小时，室友们早就熟络了，只有她格格不入。那时候周宇航考到了隔壁的财经大学，她满脑子想的都是怎么偶遇他，根本没心思交朋友。

这辈子不一样了。

苏念回到宿舍时，林薇已经化好了妆——眉毛画得有点歪，口红颜色太艳，但青春的脸庞撑得住任何夸张的色彩。陈雪还在慢吞吞地穿袜子。

“苏念你用什么护肤品啊？”林薇凑过来，“皮肤也太好了吧，毛孔都看不见。”

“就……大宝。”苏念说。

这是实话。高三那年她忙着高考，根本没心思护肤，洗完脸随便抹点东西就完事。

“天生丽质啊！”林薇夸张地叹气，“我就不行，昨晚熬夜追剧，今天脸又油又黄。”

陈雪终于收拾好了，背着帆布包：“走吧走吧，再不走食堂没位置了。”

三个人一起出门。九月的江城还有些热，梧桐树的叶子还是深绿色的，阳光穿过枝叶在地上投下斑驳的光影。路上都是拖着行李箱的新生，家长跟在后面，手里拎着脸盆和暖水壶。

“我们先去二食堂？”陈雪问，“听说那里的小笼包好吃。”

“行。”苏念点头。

她记得二食堂。上辈子她很少去那里，因为离宿舍远，她总是就近解决。但顾行舟昨天带她去的就是二食堂，他说那里的早餐种类多。

想到顾行舟，苏念的心跳快了半拍。

昨天他送她到宿舍楼下，临走前说：“明天早上我来接你，带你去办校园卡。”

“不用这么麻烦……”

“不麻烦。”顾行舟打断她，语气很认真，“我想来接你。”

苏念没再拒绝。

二食堂已经人满为患。每个窗口前都排着长队，空气里弥漫着包子、油条、豆浆混合的香气。林薇踮着脚尖张望：“天哪，这得排到什么时候？”

“我去买小笼包，你们去占座？”陈雪提议。

“行！”林薇拉着苏念，“我们去找位置。”

她们在角落找到一张空桌。苏念刚坐下，手机就响了。

是顾行舟的消息：“起了吗？我在二食堂门口。”

苏念的心跳漏了一拍。她抬起头，透过攒动的人头，看见食堂玻璃门外站着一个高瘦的身影。白衬衫，黑裤子，背挺得很直，手里拿着两杯豆浆。

“我朋友来了。”苏念对林薇说。

“男朋友？”林薇眼睛一亮。

“不是……”苏念脸有点热，“高中同学。”

她起身朝门口走去。顾行舟看见她，眼睛弯了弯，举起手里的豆浆：“给你买的，甜的。”

“谢谢。”苏念接过，指尖碰到他的手背，触感温热。

“校园卡办完了吗？”顾行舟问。

“还没，打算吃完早饭去。”

“我陪你。”他说得自然，好像这是天经地义的事。

苏念点点头。两人一起走向餐桌，林薇已经买好了小笼包，正瞪大眼睛看着他们。

“介绍一下，”苏念说，“这是我室友林薇，这是……顾行舟。”

“你好。”顾行舟点点头。

“你好你好！”林薇热情得过分，“苏念你藏着这么帅的高中同学不早说！”

苏念的脸更热了。

陈雪端着豆浆回来，看见顾行舟也愣了一下。苏念又介绍了一遍，陈雪推了推眼镜，很文静地点头：“你好。”

四个人坐下吃早饭。林薇话多，一直问顾行舟是哪个系的，高考考了多少分，怎么认识苏念的。顾行舟话少，但问什么都答，态度很耐心。

“我们是高中同桌。”顾行舟说。

“哇，同桌！”林薇起哄，“那不是近水楼台先得月——”

“林薇！”苏念打断她。

顾行舟看了苏念一眼，嘴角有很淡的笑意。

吃完早饭，林薇和陈雪先去办校园卡，苏念和顾行舟走在后面。九月的校园很热闹，到处都是社团招新的海报，音响里放着吵闹的音乐。

“你室友们挺有意思。”顾行舟说。

“林薇是话痨，陈雪比较安静。”苏念说，“你呢？室友怎么样？”

“还行。”顾行舟顿了顿，“三个都是理工科的，整天聊代码和算法，我插不上话。”

苏念想象了一下那个画面，忍不住笑了：“那你岂不是很无聊？”

“不会。”顾行舟看着她，“我可以找你。”

苏念的心跳又快了。

她低下头，假装整理背包的肩带。阳光有点刺眼，梧桐树的影子在她脸上晃动。

办校园卡的地方在行政楼一楼，已经排了很长的队。顾行舟很自然地站到她身后，替她挡住一部分阳光。

“热吗？”他问。

“还好。”

“我去买瓶水？”

“不用，我有。”苏念从包里掏出水壶。

队伍慢慢往前挪。前面有家长在和工作人员争论什么，声音很大。苏念听着有点烦，往顾行舟那边靠了靠。

“累了？”顾行舟问。

“有点。”苏念承认。昨晚没睡好，早上又起得早，现在站着确实腿酸。

“再坚持一下。”顾行舟说，“办完卡我带你去图书馆，那里凉快。”

苏念点点头。

办卡过程很顺利，拍照、填表、交钱，十分钟搞定。新校园卡上印着苏念的照片，十八岁，扎着马尾，眼睛很亮。

“挺好看。”顾行舟说。

苏念把卡收好：“走吧，去图书馆。”

江城大学的图书馆是新建的，五层楼，玻璃幕墙，阳光透进来很亮堂。顾行舟显然已经来过，很熟地带她上到三楼，在靠窗的位置坐下。

“这里安静，适合看书。”他说。

苏念环顾四周。书架一排排立着，空气里有纸张和旧书的味道。有几个学生在看书，很安静，只有翻页的沙沙声。

“你常来？”苏念问。

“昨天来过一次。”顾行舟从背包里拿出一本书，“借了本书。”

苏念瞥了一眼封面——《经济学原理》。

“你不是学计算机的吗？”她问。

“辅修金融。”顾行舟说，“多学点没坏处。”

苏念想起上辈子，顾行舟后来确实进了投行，做得风生水起。他本来就聪明，学什么都快。

“你呢？”顾行舟问，“打算怎么安排大学生活？”

苏念想了想：“先把专业课学好，然后……看看有没有机会做点兼职。”

“兼职？”

“嗯。”苏念点头，“我想早点经济独立。”

上辈子她家境不好，大学四年都是靠助学贷款和兼职撑过来的。这辈子她有前世记忆，知道哪些兼职赚钱多，哪些行业未来有前景。

顾行舟看着她，眼神有些复杂：“你好像……比以前想得更远了。”

苏念心里一紧。

她差点忘了，顾行舟很敏锐。高三那次月考，她用前世记忆写出超纲答案，他就看出不对劲了。后来她编了个“做了一个很长的梦”的借口，他好像信了，又好像没全信。

“人总要长大的。”苏念含糊地说。

顾行舟没再追问。他翻开书，开始看。苏念也拿出专业书，但看了几行就走神了。

阳光从窗户照进来，落在顾行舟的侧脸上。他的睫毛很长，鼻梁很挺，手指修长，翻书的动作很轻。苏念忽然想起高三那个雨天，他们共撑一把伞，他的耳朵红了一路。

那时候她只觉得感激，现在心跳得厉害。

“看什么？”顾行舟忽然抬头。

苏念慌忙移开视线：“没什么……在想事情。”

“想什么？”

“想……”苏念顿了顿，“想上辈子的事。”

顾行舟放下书，认真地看着她：“你经常想上辈子的事吗？”

“有时候。”苏念说，“会想如果重来一次，会怎么选择。”

“那现在呢？”顾行舟问，“重来一次，你觉得选择对了吗？”

苏念看着他，忽然笑了：“目前为止，还不错。”

顾行舟也笑了。他伸出手，轻轻碰了碰苏念的手背：“那就好。”

他的手指很凉，但触感很清晰。苏念没有躲开。

两人在图书馆待到中午。顾行舟带她去吃了麻辣香锅，然后送她回宿舍。下午苏念有开学典礼，顾行舟也有班会。

“晚上一起吃饭？”顾行舟问。

“好。”苏念点头。

回到宿舍，林薇和陈雪都在。林薇一看见苏念就扑过来：“快从实招来！你和那个顾行舟到底什么关系？”

“就是高中同学……”苏念说。

“骗鬼呢！”林薇翻白眼，“他看你的眼神都快拉丝了！”

陈雪推了推眼镜：“确实，他对你很特别。”

苏念的脸又热了。她走到自己床边坐下，把背包放好：“我们……就是关系比较好。”

“多好？”林薇凑过来，“有没有发展可能？”

苏念没回答。

林薇当她是默认，兴奋地拍手：“我就说嘛！你俩站一起特别配！”

“别乱说……”苏念无奈。

“我哪有乱说！”林薇掰着手指头数，“你看啊，他长得帅，成绩好，对你又温柔，这种男人现在打着灯笼都找不着！”

陈雪也点头：“确实，现在很少有男生这么细心了。”

苏念听着她们议论，心里有点乱。

她对顾行舟是什么感觉？感激肯定是有的，高中那年他帮了她很多。心动……好像也有。昨天他表白的时候，她心跳快得不像话。

但那是喜欢吗？

苏念不知道。上辈子她追了周宇航三年，最后被甩得很难看。从那以后她就不敢轻易动心了，怕重蹈覆辙。

“想什么呢？”林薇戳她肩膀。

“没什么。”苏念回过神，“下午开学典礼几点？”

“两点。”陈雪看了眼时间，“还有一个小时，你可以先睡会儿。”

苏念确实有点困。她躺下来，闭上眼睛，脑子里却很乱。

顾行舟的脸，周宇航的脸，上辈子的事，这辈子的选择……全都搅在一起。

她翻了个身，把脸埋进枕头里。

算了，不想了。

走一步看一步吧。

下午的开学典礼在体育馆举行。几千个新生坐在下面，台上领导讲话，声音通过音响传出来，嗡嗡的，听不太清。林薇一直在玩手机，陈雪在记笔记，苏念则盯着前面发呆。

“下面请新生代表发言。”主持人说。

一个男生走上台。苏念没在意，直到那个声音响起——

“大家好，我是计算机科学与技术专业的顾行舟。”

苏念猛地抬头。

台上的人穿着白衬衫，站得笔直，声音清晰平稳。他代表全体新生发言，讲了对大学的期待，对未来的规划，最后说：“希望我们都能不负韶华，成为想成为的人。”

掌声响起。

林薇激动地摇苏念手臂：“快看快看！是你家顾行舟！”

“他不是我家的……”苏念小声说，但眼睛一直盯着台上。

顾行舟下台时，目光扫过观众席，好像在找什么人。苏念下意识低下头，心跳得很快。

“他肯定在找你。”林薇说。

苏念没说话。

典礼结束后，人群开始往外涌。苏念和室友走散了，正四处张望时，手机响了。

顾行舟的消息：“你在哪？”

“体育馆东门。”苏念回复。

“站着别动，我来找你。”

苏念站在原地等。周围都是人，吵吵嚷嚷的，但她一眼就看见了顾行舟。他个子高，走过来时很显眼。

“刚才讲得怎么样？”他走到她面前，问。

“很好。”苏念说，“代表新生发言，很厉害。”

顾行舟笑了笑：“老师临时让我去的，稿子都是昨晚写的。”

“那也很厉害。”苏念真心实意地说。

上辈子她就知道顾行舟优秀，但那时候她满脑子都是周宇航，根本没注意过他。现在才发现，这个人简直浑身都在发光。

“走吧，吃饭。”顾行舟很自然地接过她的背包，“想吃什么？”

“都行。”

“那去三食堂？听说那里新开了个窗口，做煲仔饭的。”

“好。”

两人并肩往外走。夕阳把他们的影子拉得很长，交叠在一起。苏念忽然想起高三那个傍晚，也是这样的夕阳，她追着周宇航的背影跑，摔了一跤，膝盖磕破了皮。

那时候顾行舟在哪儿呢？

她好像……完全不记得了。

“怎么了？”顾行舟察觉到她的走神。

“没什么。”苏念摇摇头，“在想事情。”

“又想上辈子的事？”

“嗯。”苏念承认，“在想……如果早点遇见你就好了。”

顾行舟的脚步顿了一下。

他转过头，看着苏念，眼神很深：“现在也不晚。”

苏念的心跳漏了一拍。

她张了张嘴，想说什么，但最终只是点点头：“嗯，不晚。”

两人继续往前走。夕阳西下，校园里的广播开始放歌，是首很老的情歌，旋律悠扬。

苏念忽然觉得，这辈子，好像真的不一样了。

至少这一次，她没有错过对的人。
