# 数学考场

公交车摇摇晃晃地穿过早高峰的车流。

苏念坐在靠窗的位置，手指无意识地摩挲着校牌边缘。塑料壳子被磨得有些发白，上面的照片还是高一入学时拍的，齐刘海，圆脸，笑得傻乎乎。

她盯着那张照片看了几秒，忽然想笑。

十八岁的自己，真够天真的。

“市一中站到了——”

广播里的女声机械地报站。苏念拎起书包，跟着人群挤下车。

五月的阳光已经有些毒辣，晒得柏油路面发软。校门口拉起了红色横幅——“沉着冷静，诚信应考”，两边站着穿制服的保安，正检查准考证。

苏念摸了摸书包侧袋，指尖碰到那张硬卡纸。

准考证还在。

她松了口气，又觉得自己可笑。明明记得清清楚楚，上辈子差点迟到，慌慌张张跑进考场，结果发现准考证忘在宿舍床头。最后是班主任骑着电动车帮她回去取的，差点没赶上听力。

这辈子，她提前一晚就把所有东西塞进了书包。

包括顾行舟塞给她的那个文件袋。

苏念走到树荫下，从书包里掏出那个牛皮纸袋。封口处用透明胶带粘得很整齐，她撕开，里面是一沓A4纸，最上面那张写着：

“备用准考证、2B铅笔、橡皮、黑色签字笔×3、尺子、圆规。都检查过了，没问题。”

字迹工整，一笔一划。

苏念盯着那行字看了几秒，忽然鼻子有点酸。

她把文件袋塞回书包，深吸一口气，朝考场走去。

教学楼前已经挤满了人。有人捧着笔记在临阵磨枪，有人三三两两聚在一起说话，还有家长隔着栏杆往里张望，手里举着矿泉水和巧克力。

苏念穿过人群，找到自己的考场——三楼，307教室。

门口贴着座位表，她扫了一眼，找到自己的名字。第三列，第五排，靠窗。

她走进去，找到位置坐下。

桌面是老式的木头课桌，上面刻满了密密麻麻的字迹。有人写“高考必胜”，有人写“XXX我爱你”，还有人画了个歪歪扭扭的乌龟。

苏念摸了摸那些刻痕，忽然想起自己高三时也在桌肚里刻过字。

写的是周宇航的名字。

她当时觉得这是世界上最浪漫的事。

现在想想，真是傻透了。

“同学，麻烦让一下。”

苏念抬头，看见一个戴眼镜的男生站在过道里，手里拎着文具袋。她往里挪了挪椅子，男生道了声谢，坐到她后面。

教室里渐渐坐满了人。监考老师抱着密封袋走进来，开始宣读考场纪律。

苏念把文具一样样摆好——两支黑色签字笔，一支备用；2B铅笔，橡皮，尺子，圆规。全部是顾行舟准备的那套。

她拿起铅笔，在草稿纸上划了两道。

笔芯很顺，削得尖尖的。

“现在分发试卷。”

监考老师撕开密封袋，把试卷一份份传下来。苏念接过卷子，先翻到最后一页，看了看题目数量。

选择题12道，填空题4道，解答题5道，还有一道选做题。

和上辈子一样。

她闭上眼睛，深呼吸。

没关系。

她已经不是那个连三角函数都搞不懂的苏念了。

“考试开始。”

广播里的女声落下，教室里只剩下翻卷子的沙沙声。

苏念拿起笔，从第一题开始看。

集合、复数、概率……都是基础题。她几乎没怎么想，直接写下答案。

前三道题，三分钟搞定。

第四题是三角函数图像变换。苏念盯着题目看了几秒，脑子里忽然浮现出顾行舟的脸。

那是在图书馆，下午四点，阳光从窗户斜斜照进来。他坐在她对面，手里拿着铅笔，在草稿纸上画坐标系。

“你看，这个函数，先平移，再伸缩，顺序不能错。”他的声音很低，像怕吵到旁边的人，“你记住口诀：左加右减，上加下减。”

“哦……”苏念当时其实没太听懂，但看着他认真的侧脸，莫名其妙就点了头。

“懂了？”

“懂了。”

“那你做一遍。”

苏念拿起笔，在草稿纸上乱画一气。顾行舟看着她的步骤，眉头皱起来。

“这里，符号反了。”

“啊？”

“应该是加，不是减。”

“哦……”

“还有这里，周期算错了。”

“哦……”

“你到底听没听？”

“听了听了……”

顾行舟叹了口气，把草稿纸抽过去，重新写了一遍。字迹工整，步骤清晰，每一步都标了注释。

“再看一遍。”

苏念盯着那张纸，忽然觉得那些符号没那么可怕了。

“现在会了？”

“嗯。”

“那你再做一遍。”

苏念拿起笔，这次没出错。顾行舟看着她的答案，嘴角微微扬了一下。

“不错。”

那是苏念第一次看见他笑。

不是那种礼貌的、客套的笑，是真的觉得高兴。眼睛弯起来，嘴角有小小的弧度，整个人都柔和了。

苏念当时愣了一下，心跳漏了一拍。

现在想起来，那大概就是心动的开始。

“同学，请保持安静。”

监考老师的声音把苏念拉回现实。她回过神，发现自己不知什么时候停下了笔，正对着草稿纸发呆。

她摇摇头，把那些乱七八糟的念头甩出去。

现在不是想这些的时候。

她低头，继续做题。

选择题很快做完，填空题也顺利解决。苏念翻到解答题，第一道是立体几何。

建系，设坐标，求向量，列方程。

她写得很快，笔尖在纸上划出沙沙的声响。脑子里自动浮现出顾行舟教她的方法——

“立体几何，第一反应就是建系。找三条互相垂直的棱，设成坐标轴。”

“要是找不到呢？”

“那就找两条垂直的，第三条自己补。”

“怎么补？”

“用向量叉乘。”

“什么？”

“……算了，这个超纲了。你记住，找不到就画辅助线，把图形补成正方体或者长方体。”

“哦……”

“听懂了？”

“大概……”

“那你做这道题试试。”

苏念看着题目，脑子里一片空白。顾行舟等了半分钟，见她没动笔，把卷子抽过去，三两下画好辅助线，标好坐标。

“现在呢？”

“哦……我会了。”

“真会了？”

“嗯。”

“那你做。”

苏念拿起笔，这次真的做出来了。顾行舟看着她的步骤，点了点头。

“不错，有进步。”

苏念当时心里美滋滋的，觉得自己终于开窍了。

现在想想，那哪是开窍，分明是有人手把手教。

她写着写着，忽然笑了一下。

监考老师正好走过来，看见她对着卷子笑，眼神里带着疑惑。苏念赶紧低下头，假装在检查答案。

时间一分一秒过去。

解答题做到第三道时，苏念卡住了。

是数列题，给了一个递推公式，求通项。她看了半天，脑子里乱糟糟的，怎么都理不清思路。

手心开始出汗。

她放下笔，闭上眼睛。

深呼吸。

没关系。

她想起顾行舟说过的话——

“数列题，第一步，先看递推公式的结构。是线性的，还是非线性的？”

“线性的怎么了？”

“线性的就好办，直接用特征根法。”

“非线性呢？”

“非线性就麻烦点，得构造新数列。”

“怎么构造？”

“看情况。有时候取倒数，有时候取对数，有时候两边同时除以某个东西。”

“听着好复杂……”

“不复杂，多做几道就会了。”

“那你给我多出几道。”

“行。”

顾行舟真的给她出了十几道数列题，从简单到难，一道道讲。苏念当时听得头昏脑涨，但硬着头皮做完了。

现在，那些题目一道道浮现在脑子里。

她拿起笔，开始在草稿纸上试。

取倒数……不对。

取对数……也不对。

两边同时除以an……还是不对。

苏念咬着笔帽，盯着草稿纸上的式子。时间已经过去二十分钟，她还卡在这道题上。

额角渗出细密的汗珠。

她想起上辈子的自己，数学考了89分，全班倒数。出考场时，她看见周宇航和几个男生在对答案，笑得很开心。

她走过去，想问自己做得对不对。

周宇航看了她一眼，说：“你就算了吧，问了也听不懂。”

周围的人都笑了。

苏念站在原地，脸烧得通红。

那种羞耻感，她记了十年。

“还有最后十五分钟。”

监考老师的提醒让苏念回过神。她看了看卷子，解答题还剩两道没做，选做题也没碰。

时间不够了。

她深吸一口气，决定先跳过这道数列题，把后面能拿的分先拿到。

第四道是导数题，求极值。苏念记得顾行舟讲过这类题的套路——求导，找零点，列表判断单调性。

她写得很快，步骤清晰，没出什么差错。

第五道是概率统计，给了一个实际背景，求期望和方差。苏念看了两遍题目，理清思路，开始列式。

写完最后一笔，她看了看时间，还剩八分钟。

够了。

她翻回那道数列题，盯着草稿纸上的式子。

忽然，脑子里灵光一闪。

她想起顾行舟讲过的一道例题——

“你看这道题，递推公式是an+1 = 2an + 1，你试试两边同时加1。”

“为什么？”

“构造等比数列。an+1 + 1 = 2(an + 1)，这样bn = an + 1就是等比数列了。”

“哦……”

“懂了？”

“懂了！”

苏念拿起笔，在草稿纸上重新演算。

两边同时加1……构造新数列……求通项……

三分钟后，答案出来了。

她长舒一口气，把步骤工工整整地写在卷子上。

“考试结束，请立即停笔。”

广播里的女声响起，监考老师开始收卷。苏念放下笔，看着自己的卷子被收走，心里忽然空落落的。

她趴在桌上，闭上眼睛。

数学考完了。

接下来，还有英语、理综。

但她已经不那么怕了。

“同学，交卷了。”

监考老师拍了拍她的肩膀。苏念抬起头，收拾好东西，跟着人群走出教室。

走廊里挤满了人，有人在对答案，有人在哀嚎，有人已经哭了出来。

苏念避开人群，走到楼梯口。

她摸出手机，看了一眼时间。

11:47。

离下午的英语考试还有两个多小时。

她正想着去哪儿吃饭，手机忽然震了一下。

是顾行舟发来的消息。

“考完了？”

苏念盯着那三个字看了几秒，忽然笑了。

她按下语音键，说：“考完了。”

那边很快回复：“感觉怎么样？”

苏念想了想，说：“还行。有道数列题卡住了，后来做出来了。”

“哪道？”

“an+1 = 2an + n + 1那道。”

“哦，那道。你用的什么方法？”

“两边同时加n+2，构造等比数列。”

“对，就是这个方法。我教过你的。”

苏念愣了一下。

她忽然想起，那道例题，顾行舟确实讲过。

就在上周，在图书馆，下午四点，阳光从窗户斜斜照进来。

他坐在她对面，手里拿着铅笔，在草稿纸上写写画画。

“你看这道题，递推公式里带n，你试试两边同时加个东西，把n消掉。”

“加什么？”

“你猜。”

“猜不出来……”

“那我提示你，加一个关于n的一次函数。”

“an+1 + (an + b) = 2(an + (an + b))？”

“对，然后呢？”

“然后……解出a和b？”

“聪明。”

苏念当时没完全听懂，但硬着头皮记下了方法。

没想到，真的用上了。

她对着手机屏幕，忽然不知道该说什么。

那边又发来一条消息：“出来吧，我在校门口等你。”

苏念盯着那行字，心跳忽然快了起来。

她收起手机，快步朝楼下走去。

校门口人山人海，家长、学生、老师挤成一团。苏念踮着脚张望，在人群里找了半天，终于看见那个熟悉的身影。

顾行舟站在梧桐树下，手里拎着一个塑料袋。

他穿着白衬衫，袖子挽到手肘，露出小臂流畅的线条。阳光透过树叶的缝隙落在他身上，斑斑驳驳。

苏念穿过人群，走到他面前。

“你等多久了？”

“没多久。”顾行舟把塑料袋递给她，“先吃饭。”

苏念接过来，打开一看——是两个饭团，一盒牛奶，还有一小盒切好的水果。

她愣了一下：“你什么时候准备的？”

“早上。”

“你不是也要考试吗？”

“我考场就在隔壁，出来得早。”

苏念看着手里的饭团，忽然不知道该说什么。

她想起上辈子的高考。

那时候，她是一个人。

考完数学，她走出考场，看见周宇航被一群女生围着，叽叽喳喳地对答案。她站在人群外，看了很久，最后转身走了。

食堂里全是人，她排了半小时队，才买到一份冷掉的盒饭。坐在操场边的台阶上，一个人吃完。

那天下午考英语，她听力没听进去，满脑子都是周宇航的笑脸。

最后，英语考砸了。

总分只够上个三本。

“发什么呆？”

顾行舟的声音把苏念拉回现实。她回过神，发现他正看着自己，眼神里带着疑惑。

“没、没什么。”苏念低下头，撕开饭团的包装，“谢谢。”

“不客气。”

两人走到树荫下的长椅坐下。苏念咬了一口饭团，是肉松的，米饭软硬适中，还带着一点温热。

她忽然鼻子有点酸。

“怎么了？”顾行舟问。

“没事。”苏念摇摇头，使劲眨了眨眼睛，“饭团好吃。”

“嗯。”

“你做的？”

“嗯。”

“你还会做饭？”

“会一点。”

苏念又咬了一口，忽然问：“你为什么对我这么好？”

顾行舟愣了一下，没说话。

苏念看着他，等了很久，才听见他开口。

“因为你值得。”

三个字，轻飘飘的，却像石头一样砸在苏念心口。

她张了张嘴，想说什么，最后只是低下头，继续吃饭团。

阳光透过树叶的缝隙，在地上投下斑驳的光影。远处传来人群的喧哗，近处只有树叶沙沙的声响。

苏念吃完饭团，把包装纸捏成一团，扔进垃圾桶。

“下午考英语，你复习了吗？”顾行舟问。

“复习了一点。”

“听力多听几遍，阅读注意时间分配，作文背几个模板。”

“嗯。”

“别紧张。”

“嗯。”

“你这次能考好。”

苏念抬头，看见顾行舟正看着自己。他的眼神很认真，没有一点敷衍。

她忽然笑了。

“你怎么知道？”

“我猜的。”

“猜得准吗？”

“准。”

苏念看着他，忽然说：“顾行舟，谢谢你。”

顾行舟愣了一下，耳朵尖忽然红了。

“不用谢。”

“不是客气。”苏念认真地说，“是真的谢谢你。从高三开始，你一直在帮我。补课，讲题，准备文具，现在还给我送饭……我不知道该怎么报答你。”

顾行舟看着她，忽然笑了。

“不用报答。”

“那怎么行？”

“你考上好大学，就是最好的报答。”

苏念愣住了。

她想起上辈子，自己只考了个三本，毕业后在小公司做文员，月薪三千，每天加班到十点。后来公司倒闭，她失业，找不到工作，穷得连房租都交不起。

最后，在出租屋里猝死。

如果那时候，有人对她说“你考上好大学，就是最好的报答”，她大概会笑出来。

大学有什么用？学历有什么用？最后还不是一样穷困潦倒？

但现在，她不这么想了。

这辈子，她要抓住每一个机会。

“我会的。”苏念说，“我会考上好大学。”

顾行舟点点头：“我相信你。”

两人又坐了一会儿，直到人群渐渐散去，苏念才站起来。

“我得回去复习英语了。”

“嗯。”

“你呢？”

“我也回去。”

“那……下午见？”

“下午见。”

苏念转身，朝教学楼走去。走了几步，她忽然停下来，回头看了一眼。

顾行舟还站在原地，正看着她。

阳光落在他身上，白衬衫被风吹得微微鼓起。

苏念的心跳忽然漏了一拍。

她赶紧转过头，快步走进教学楼。

直到走到楼梯口，她才敢停下脚步，捂住狂跳的心脏。

完了。

她好像，真的喜欢上顾行舟了。
