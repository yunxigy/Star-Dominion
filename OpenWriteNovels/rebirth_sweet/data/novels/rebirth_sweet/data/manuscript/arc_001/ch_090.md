# 两个笔记本

梧桐树的叶子在头顶沙沙作响，阳光透过缝隙洒下来，在顾行舟的肩膀上跳动。苏念盯着他校服外套上那道浅浅的褶皱，突然觉得喉咙发紧。

“你……”她张了张嘴，声音哑得厉害，“你从高一就开始记了？”

顾行舟点了点头，没说话。他垂着眼睛，睫毛在眼下投出一小片阴影。苏念这才发现，他的睫毛很长，比班上大部分女生都要长。

“为什么？”苏念又问。

这次顾行舟抬起了头。他看着苏念，眼神很认真，认真到苏念几乎要避开他的目光。

“因为你值得。”他说。

苏念的手指无意识地攥紧了那两个笔记本。牛皮纸的封面有些粗糙，深蓝色的硬壳边缘已经磨得发白。她突然想起高一那年，自己确实有一阵子没吃早餐——不是为了省钱，而是因为妈妈那阵子生病住院，她每天早起要去医院送饭，根本来不及吃。

她以为没人知道。

“你……”苏念深吸一口气，“你扶我去医务室那次，是故意的？”

顾行舟愣了一下，似乎在回忆。然后他轻轻摇头：“不是故意的。你体育课扭到脚，我刚好在操场边上背单词。”

“那后来呢？你为什么没走？”

“你疼得脸都白了。”顾行舟的声音很轻，“医务室老师不在，我……我不放心。”

苏念的鼻子突然一酸。她想起那天下午，自己坐在医务室的床上，脚踝肿得老高，眼泪啪嗒啪嗒往下掉。她以为医务室里只有自己一个人，原来门口一直站着个人。

“还有高三那次。”苏念的声音开始发抖，“我在天台哭的时候，你也在？”

顾行舟这次沉默了很久。梧桐树的影子在他脸上晃动，苏念看见他的喉结动了动。

“在。”他说，“你在天台哭了四十七分钟。我在楼梯口站着，数着时间。”

四十七分钟。

苏念的眼泪一下子涌了出来。她想起那天下午，自己刚被周宇航当众拒绝，躲在天台上哭得喘不过气。她以为全世界都抛弃了她，原来有人一直在数着她的眼泪。

“为什么……”苏念哽咽着问，“为什么不告诉我？”

顾行舟看着她，眼神里有一种苏念看不懂的情绪。那情绪太复杂，太深，深得像一口井。

“因为你那时候喜欢周宇航。”他说，“那是你自己的选择。”

苏念的哭声戛然而止。

她突然想起上辈子的自己，想起那个为了周宇航要死要活的十八岁。她想起自己曾经在顾行舟面前，兴高采烈地讨论周宇航今天穿了什么衣服，打了什么球，甚至为了引起周宇航注意，故意在顾行舟面前大声说：“我觉得周宇航肯定喜欢我！”

那时候顾行舟在做什么？

他在做题。

苏念记得很清楚，那时候顾行舟正低着头，笔尖在草稿纸上划得沙沙响。她以为他没听见，现在想来，他怎么可能没听见？

“对不起……”苏念的声音低得几乎听不见，“我上辈子……我上辈子真的……”

“不用道歉。”顾行舟打断她，“我说了，那是你自己的选择。”

“可是我——”

“苏念。”顾行舟突然叫她的名字，声音很轻，却带着一种不容置疑的坚定，“你听我说。”

苏念抬起头，泪眼朦胧地看着他。

“上辈子的事，已经过去了。”顾行舟一字一句地说，“这辈子，你重新来过了。你不再是那个为了别人要死要活的苏念，你是现在的苏念。”

现在的苏念。

苏念愣住了。她低头看着手里的两个笔记本，牛皮纸的封面被泪水打湿了一小块，深蓝色的硬壳在阳光下泛着柔和的光。

“这个……”她举起那个深蓝色的笔记本，“真的是错题本？”

顾行舟点头：“你高三上学期的数学错题，我全整理了一遍。”

苏念翻开本子。熟悉的字迹映入眼帘——不是她的字，是顾行舟的。他的字很工整，一笔一划都写得很认真。每一道错题下面，都用红笔标注了错误原因，还附上了解题思路。

有些题旁边还画了小小的箭头，指向某个步骤，旁边写着：“这里容易粗心，再检查一遍。”

苏念的手指抚过那些字迹，突然想起高三那年，自己的数学成绩确实突飞猛进。她一直以为是自己开窍了，现在才知道，原来有人在背后默默帮她。

“那这个呢？”苏念又举起那个牛皮纸本子。

顾行舟的耳朵突然红了。

“这个……”他移开目光，看向远处的操场，“是……是记录。”

“记录什么？”

“记录你。”顾行舟的声音更轻了，“记录你每天的样子。”

苏念的心跳漏了一拍。她翻开牛皮纸本子，第一页的日期是高一开学第一天。

“九月一日，晴。苏念穿了一件浅蓝色的连衣裙，马尾扎得很高。她笑起来的时候，眼睛会弯成月牙。”

第二页：“九月三日，多云。苏念数学课走神了，被老师点名回答问题。她站起来的时候，脸红得像番茄。”

第三页：“九月五日，小雨。苏念没带伞，站在教学楼门口等了十分钟。最后她把书包顶在头上，跑进了雨里。”

一页，两页，三页……

苏念一页一页地翻着，眼泪又掉了下来。她看见自己高一第一次月考，数学只考了62分，躲在楼梯间哭。她看见自己高二运动会，报名了八百米，跑到一半摔了一跤，膝盖磕破了皮。她看见自己高三生日，一个人坐在教室里，对着窗外的夕阳发呆。

每一天，每一个细节，都被这个叫顾行舟的男生，用这样工整的字迹，记录了下来。

“你……”苏念哽咽着问，“你记了多久？”

“三年。”顾行舟说，“从高一第一天，到高三最后一天。”

“为什么……为什么记这些？”

顾行舟终于转回头，看着苏念。他的眼睛在阳光下很亮，亮得像星星。

“因为我想记住你。”他说，“记住你每一个样子。”

苏念的呼吸一窒。

她突然想起上辈子，自己三十岁那年，在出租屋里翻到高中同学录。那时候她已经和周宇航分手五年，穷困潦倒，一事无成。她翻到顾行舟那一页，看见他在留言栏里写：“祝你前程似锦。”

那时候她只觉得这句话客套，现在才知道，这四个字里，藏了多少说不出口的话。

“顾行舟。”苏念轻声叫他的名字。

“嗯？”

“你等了多久？”

顾行舟沉默了很久。梧桐树的叶子又开始沙沙作响，一片叶子飘下来，落在他的肩膀上。

“十年。”他说，“从高一第一天，到现在。”

十年。

苏念的眼泪彻底决堤了。她想起上辈子的自己，想起那个为了周宇航要死要活的十八岁，想起那个穷困潦倒的三十岁。她想起自己曾经无数次在顾行舟面前，兴高采烈地讨论别的男生，却从来没有认真看过他一眼。

“对不起……”她泣不成声，“真的对不起……”

顾行舟看着她，眼神里没有责备，只有一种深沉的温柔。他伸出手，似乎想擦掉苏念的眼泪，但手伸到一半，又缩了回去。

“我说了，不用道歉。”他说，“那是你自己的选择。”

“可是我——”

“苏念。”顾行舟又打断她，“你听我说。”

苏念抬起泪眼，看着他。

“这辈子，你重新来过了。”顾行舟一字一句地说，“你不再是那个为了别人要死要活的苏念。你是现在的苏念，是考上了理想大学的苏念，是创业成功的苏念，是……”

他顿了顿，声音更轻了。

“是让我等了十年的苏念。”

苏念的哭声戛然而止。

她突然想起这辈子的一切。想起高三那年，顾行舟帮她补数学，陪她去图书馆，在雨天给她撑伞。想起大学时，顾行舟和她考到同一座城市，默默关注她的生活。想起创业初期，顾行舟暗中帮她拉投资，给她介绍人脉。

原来这一切，都不是巧合。

“你……”苏念深吸一口气，“你这辈子，也一直在帮我？”

顾行舟点头：“你创业的时候，我帮你联系了第一个投资人。你公司遇到危机的时候，我……”

他突然停住了。

苏念的心脏猛地一缩：“你什么？”

顾行舟移开目光，看向远处的教学楼。阳光照在他的侧脸上，苏念看见他的睫毛在微微颤抖。

“我放弃了出国的机会。”他说，“留下来帮你。”

苏念的呼吸一窒。

她突然想起三年前，公司遭遇重大危机，几乎破产。那时候她焦头烂额，四处求人，却处处碰壁。就在她快要绝望的时候，突然有一笔资金注入，帮她渡过了难关。

她一直以为那是运气好，现在才知道，那是顾行舟放弃了出国深造的机会，把准备留学的钱，全部投给了她。

“你……”苏念的声音发抖，“你为什么要这么做？”

顾行舟转回头，看着她。他的眼神很平静，平静得像一潭深水。

“因为你值得。”他说。

又是这句话。

苏念的眼泪又涌了出来。她想起上辈子，自己穷困潦倒的时候，曾经在街头遇见顾行舟。那时候他已经是金融界的新星，西装革履，意气风发。她躲躲闪闪地想避开，却被他叫住了。

“苏念。”他当时说，“你还好吗？”

她当时说了什么？

她说：“我很好，不用你管。”

然后转身就跑。

现在想来，那时候顾行舟的眼神，一定很难过吧。

“顾行舟。”苏念轻声叫他。

“嗯？”

“你……”苏念深吸一口气，“你这辈子，还愿意等吗？”

顾行舟愣住了。

梧桐树的叶子在头顶沙沙作响，阳光透过缝隙洒下来，在两人之间投下斑驳的光影。苏念看见顾行舟的喉结动了动，看见他的手指微微蜷缩，看见他的耳朵又红了。

然后，他笑了。

那是苏念第一次看见顾行舟笑得这么开心。他的眼睛弯起来，嘴角上扬，整个人在阳光下闪闪发光。

“我等了十年。”他说，“不差这一会儿。”

苏念也笑了。她擦掉眼泪，把两个笔记本紧紧抱在怀里。

“那……”她小声说，“那我请你吃饭吧。”

顾行舟愣了一下：“吃饭？”

“嗯。”苏念点头，“你帮我补了那么久数学，又……又记了我三年，我总得谢谢你吧。”

顾行舟看着她，眼神里有一种苏念看不懂的情绪。那情绪太复杂，太深，深得像一口井。

“好。”他说，“你想吃什么？”

苏念想了想：“学校门口那家麻辣烫吧。”

顾行舟笑了：“好。”

两人并肩往校门口走。梧桐树的影子在脚下拉得很长，阳光暖暖地照在身上。苏念抱着两个笔记本，突然觉得心里有什么东西，悄悄融化了。

“顾行舟。”她突然开口。

“嗯？”

“你……”苏念犹豫了一下，“你记了我三年，有没有发现什么……什么特别的事？”

顾行舟想了想：“有。”

“什么？”

“你每个月都会去一次图书馆的角落，借同一本书。”他说，“《小王子》。”

苏念的心跳漏了一拍。

“你……你怎么知道？”

“因为我每次都坐在你后面三排。”顾行舟说，“你每次看书的时候，都会翻到最后一页，看那句话。”

苏念的眼眶又热了。

她想起《小王子》最后一页的那句话：“如果你爱上了某个星球的一朵花。那么，只要在夜晚仰望星空，就会觉得漫天的繁星就像一朵朵盛开的花。”

上辈子，她每次看这句话，都会想起周宇航。

这辈子，她突然觉得，这句话应该送给另一个人。

“顾行舟。”苏念轻声说。

“嗯？”

“谢谢你。”苏念说，“谢谢你等了我十年。”

顾行舟的脚步顿了一下。他转过头，看着苏念，眼神里有一种深沉的温柔。

“不用谢。”他说，“因为你值得。”

苏念笑了。她抱紧怀里的两个笔记本，和顾行舟一起，走进了校门口那家麻辣烫店。

店里的热气扑面而来，老板娘热情地招呼他们坐下。苏念点了微辣，顾行舟点了不辣。两人坐在靠窗的位置，阳光透过玻璃照进来，暖洋洋的。

“顾行舟。”苏念突然开口。

“嗯？”

“你……”苏念犹豫了一下，“你以后，还会继续记吗？”

顾行舟愣了一下，然后笑了。

“会。”他说，“只要你愿意。”

苏念的脸突然红了。她低下头，假装看菜单，心跳却快得厉害。

“那……”她小声说，“那你要记仔细点。”

顾行舟的笑声在耳边响起，低沉而温柔。

“好。”他说，“我记仔细点。”

麻辣烫端上来了，热气腾腾的。苏念拿起筷子，突然想起一件事。

“顾行舟。”

“嗯？”

“你……”苏念深吸一口气，“你上辈子，最后怎么样了？”

顾行舟的动作顿了一下。他放下筷子，看着苏念，眼神里有一种复杂的情绪。

“我去了国外。”他说，“读完博士，进了投行。三十五岁那年，做到了亚太区总裁。”

苏念的心脏猛地一缩。

她想起上辈子，自己三十岁那年，在街头遇见顾行舟。那时候他西装革履，意气风发，她却躲躲闪闪地想避开。

原来那时候，他已经那么成功了。

“然后呢？”苏念轻声问。

顾行舟沉默了很久。窗外的阳光照进来，在他的脸上投下斑驳的光影。

“然后……”他终于开口，“我回国找你。”

苏念的呼吸一窒。

“找我？”

“嗯。”顾行舟点头，“我回国第一件事，就是去找你。可是你已经……”

他突然停住了。

苏念的心脏狂跳起来：“我已经什么？”

顾行舟看着她，眼神里有一种深沉的悲伤。

“你已经结婚了。”他说，“和周宇航。”

苏念的脑子嗡的一声。

她想起上辈子，自己确实和周宇航结过婚。那是在她二十八岁的时候，周宇航突然回头找她，说想和她在一起。那时候她穷困潦倒，一事无成，突然听见曾经喜欢的人说这种话，想都没想就答应了。

可是那场婚姻，只维持了两年。

“你……”苏念的声音发抖，“你去找我的时候，我已经结婚了？”

顾行舟点头：“我在你家楼下站了一夜。第二天早上，看见你和周宇航一起出门。你笑得很开心，我就……”

他深吸一口气。

“我就走了。”

苏念的眼泪又涌了出来。她想起上辈子，自己二十八岁那年，确实有一阵子特别开心。那时候周宇航刚回头找她，她以为自己终于等到了爱情，每天笑得像个傻子。

原来那时候，顾行舟就站在她家楼下。

“对不起……”苏念泣不成声，“真的对不起……”

顾行舟看着她，眼神里没有责备，只有一种深沉的温柔。

“我说了，不用道歉。”他说，“那是你自己的选择。”

“可是我——”

“苏念。”顾行舟打断她，“你听我说。”

苏念抬起泪眼，看着他。

“这辈子，你重新来过了。”顾行舟一字一句地说，“你不再是那个为了别人要死要活的苏念。你是现在的苏念，是考上了理想大学的苏念，是创业成功的苏念，是……”

他顿了顿，声音更轻了。

“是让我等了十年的苏念。”

苏念的哭声戛然而止。

她突然想起这辈子的一切。想起高三那年，顾行舟帮她补数学，陪她去图书馆，在雨天给她撑伞。想起大学时，顾行舟和她考到同一座城市，默默关注她的生活。想起创业初期，顾行舟暗中帮她拉投资，给她介绍人脉。

原来这一切，都不是巧合。

“顾行舟。”苏念轻声叫他。

“嗯？”

“这辈子……”苏念深吸一口气，“这辈子，我不会再错过了。”

顾行舟愣住了。

然后，他笑了。那是苏念第一次看见顾行舟笑得这么开心。他的眼睛弯起来，嘴角上扬，整个人在阳光下闪闪发光。

“好。”他说，“我等你。”

麻辣烫的热气在两人之间升腾，阳光透过玻璃窗洒进来，暖洋洋的。苏念看着顾行舟的笑脸，突然觉得，这辈子，一切都刚刚好。

她不会再错过了。
