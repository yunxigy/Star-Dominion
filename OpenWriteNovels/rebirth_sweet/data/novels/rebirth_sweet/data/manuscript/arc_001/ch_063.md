# 第六十三章 面谈

顾氏集团总部大楼的玻璃幕墙在阳光下反射出刺眼的光芒。

苏念站在旋转门前，仰头看着这栋三十二层的建筑，手指不自觉地攥紧了背包带子。她今天穿了一件白色衬衫，外面套着黑色西装外套，是她衣柜里最正式的一套——但站在这个入口处，她觉得自己像误入奢侈品店的流浪汉。

“发什么呆？”

顾行舟的声音从身后传来。苏念回头，看见他今天也穿了正装，深灰色西装剪裁得体，衬得他肩宽腰窄。他手里拿着两杯咖啡，递了一杯给她。

“给，美式，不加糖。”

苏念接过来，咖啡的温度透过纸杯传到掌心。她抿了一口，苦涩的味道在舌尖散开，让她稍微清醒了一点。

“我昨晚几乎没睡。”她老实交代，“把能想到的问题全准备了一遍，但越准备越觉得没底。”

顾行舟看了她一眼：“你紧张什么？”

“我能不紧张吗？”苏念压低声音，“那是你爸！顾氏集团的掌舵人！我这种小公司，人家动动手指就能碾死。”

“他要是想碾死你，就不会约面谈了。”顾行舟推开旋转门，“走吧，电梯在左手边。”

大堂里冷气开得很足，苏念踩在光可鉴人的大理石地面上，听见自己的高跟鞋发出清脆的声响。前台几个姑娘抬头看了她一眼，又低头继续工作。

电梯门打开，顾行舟按了32层。

“等一下。”苏念突然抓住他的袖子，“你爸……他有什么忌讳吗？比如不喜欢听什么话，或者特别讨厌什么样的人？”

顾行舟低头看着她抓着自己袖子的手，嘴角动了动：“他讨厌说废话的人。”

“那什么是废话？”

“就是你现在问的这些。”

苏念松开手，瞪了他一眼。顾行舟没躲，反而笑了一下：“别怕，如实回答就行。他问什么，你就说什么，别绕弯子。”

电梯匀速上升，苏念看着数字跳动，心跳也越来越快。她想起上辈子，自己连顾行舟家的门都没进过。那时候她追着周宇航跑，根本不知道身边坐着个家里有矿的。

“到了。”

门打开，走廊铺着深色地毯，踩上去悄无声息。顾行舟走在前面，苏念跟在后面，感觉自己像被押送的犯人。

会议室的门虚掩着，顾行舟敲了两下，里面传来一个低沉的男声：“进。”

推开门，苏念第一眼看见的是落地窗。三十二层的视野毫无遮挡，整个城市的天际线尽收眼底。然后她才注意到坐在长桌主位的男人。

顾明远看起来五十出头，头发梳得一丝不苟，两鬓有些灰白。他穿着深蓝色西装，没打领带，领口解开一颗扣子。手里拿着一份文件，正低头看，听见动静才抬眼。

那眼神很锐利，像手术刀，把苏念从头到脚剖开看了一遍。

“爸，这是苏念。”顾行舟侧身让开。

苏念深吸一口气，往前走了两步：“顾总好，我是苏念，念念科技的创始人。”

顾明远放下文件，靠在椅背上：“坐。”

苏念在长桌另一端坐下，距离有点远，她得稍微提高音量。顾行舟在她旁边坐下，但没说话，只是安静地坐着。

“行舟跟我提过你。”顾明远开口，声音不高，但每个字都清晰，“他说你很特别。”

苏念心里咯噔一下，不知道顾行舟到底说了什么。她侧头看了他一眼，顾行舟面无表情，只是微微点了下头。

“他可能说得太夸张了。”苏念扯出一个笑，“我就是个普通创业者。”

“普通创业者不会让行舟专门来打招呼。”顾明远的手指在桌面上敲了敲，“说说吧，你为什么选农产品电商？”

这个问题苏念准备过，她立刻回答：“因为市场大，痛点明显，而且——”

“停。”顾明远抬手打断她，“我让你说见解，不是让你背商业计划书。”

苏念的话卡在喉咙里。她看着顾明远，对方正用那种审视的目光看着她，等着她说点不一样的。

会议室里安静了几秒。

苏念突然想起上辈子，她最后一次见顾行舟是在医院。那时候她公司破产，债主堵门，她躲到顾行舟的公寓里。他什么都没问，只是给她煮了一碗面。

那天晚上，顾行舟说：“你总是想太多，做太少。”

苏念闭了闭眼，再睁开时，眼神变了。

“因为我饿过。”她说。

顾明远挑眉：“什么？”

“我小时候，家里穷，经常吃不饱。”苏念的声音很平静，“有年冬天，我妈跑了，我爸在工地摔断腿，家里只剩半袋米。我每天就煮一锅粥，早上喝稀的，晚上喝稠的，喝了整整两个月。”

她停顿了一下，继续说：“后来我考上大学，拼命打工，就是为了不再饿肚子。但我发现，像我这样的人很多，他们种地、养猪、养鱼，辛辛苦苦一年，东西卖不出去，烂在地里，或者被中间商压价，最后还是穷。”

顾明远没说话，只是看着她。

“农产品电商不是什么新概念，很多人做过，但大多数都死了。”苏念说，“因为他们只想着把东西搬到网上卖，没想过怎么解决根本问题。”

“什么根本问题？”

“信任。”苏念说，“城里人不相信农民种的菜没打药，农民不相信城里人愿意出高价。中间隔着一道墙，电商只是把墙搬到了网上，墙还在。”

顾行舟突然开口：“所以你打算怎么做？”

苏念看了他一眼，又转向顾明远：“我想建一个透明系统。从种子下地开始，全程监控，施肥、打药、采摘、运输，所有环节都公开。消费者扫码就能看见这颗白菜是怎么长大的，甚至能看见种它的人长什么样。”

顾明远身体前倾：“成本呢？”

“很高。”苏念老实说，“所以前期只能做小规模，选几个试点，跑通模式再复制。”

“小规模怎么做大？”

“靠口碑。”苏念说，“第一批用户如果觉得好，会自发传播。农产品不是快消品，复购率高，一个家庭如果认准了某个牌子，可能一买就是十年。”

会议室里又安静下来。顾明远靠回椅背，手指无意识地敲着桌面。苏念的心提到了嗓子眼，她不知道自己说得对不对，但至少是真话。

“行舟。”顾明远突然转向儿子，“你觉得呢？”

顾行舟坐直身体：“她的想法有风险，但逻辑成立。现在市场同质化严重，要么拼价格，要么拼差异化。她选的路难走，但如果走通了，壁垒很高。”

顾明远哼了一声：“你倒是会护着她。”

顾行舟没接话，只是低头整理了一下袖口。苏念注意到他耳根有点红。

“苏念。”顾明远重新看向她，“如果我投你，你要多少？”

苏念愣住了。她没想到这么直接。

“我……”她脑子飞快转着，“五百万。”

“五百万？”顾明远笑了，不是嘲笑，但也没多少温度，“你知道行舟上次投你多少吗？”

苏念心里一紧。她知道顾行舟给了她二十万，但没想到他爸会直接问这个。

“二十万。”她老实回答。

“二十万能干什么？”顾明远问，“付个办公室租金？还是发两个月工资？”

苏念握紧拳头。她想起自己租的那个民房，想起每天挤公交跑市场，想起为了省钱吃泡面的日子。

“二十万能活三个月。”她说，“够我验证模式，做出第一批样品，找到愿意合作的农户。”

“然后呢？”

“然后如果验证成功，我就能用数据说话，去找下一轮投资。”苏念说，“如果失败，我就认栽，回去打工还钱。”

顾明远盯着她看了很久，久到苏念以为他要下逐客令了。

“你知道我为什么愿意见你吗？”他突然问。

苏念摇头。

“因为行舟。”顾明远说，“他从小到大，没为任何事求过我。除了这次。”

苏念猛地转头看顾行舟。顾行舟避开她的目光，只是看着窗外。

“他跟我说，有个女孩很特别，值得一看。”顾明远继续说，“我问他特别在哪里，他说，她知道自己要什么，而且愿意为它拼命。”

会议室里很安静，只有空调运转的微弱声响。

苏念鼻子突然有点酸。她想起上辈子，顾行舟也是这样，默默看着她，默默帮她，却从来不说。

“顾总。”她深吸一口气，“我不会让你们失望的。”

顾明远没接话，只是站起身，走到落地窗前。苏念和顾行舟也跟着站起来。

“你知道这栋楼建了多少年吗？”顾明远突然问。

苏念摇头。

“二十三年。”顾明远说，“我父亲那辈开始做，传到我手里。中间经历三次经济危机，两次差点破产。”

他转过身，看着苏念：“创业不是请客吃饭，是九死一生。你今天说的这些，听起来很漂亮，但做起来可能完全不是那么回事。”

“我知道。”苏念说。

“你知道？”顾明远挑眉，“你连账上有多少钱都算不清楚，你知道什么？”

苏念脸一下子红了。她确实没算过，顾行舟那二十万她一直没动，公司账上就剩几千块。

“行舟。”顾明远突然叫儿子，“你卡里还有多少？”

顾行舟顿了一下：“三百多万。”

“转给她。”顾明远说，“算我投的。”

苏念和顾行舟同时愣住。

“爸？”顾行舟皱眉。

“怎么？舍不得？”顾明远看着儿子，“你不是说她值得吗？”

顾行舟沉默了几秒，然后掏出手机，操作了几下。苏念手机震了一下，她低头一看，银行到账通知：3,000,000.00元。

“这……”苏念抬头，不知道该说什么。

“别高兴太早。”顾明远走回桌边，拿起那份文件，“这是投资协议，你看看。股份、对赌、退出机制，都在里面。看完觉得能接受，明天来签。”

他把文件递给苏念，然后走向门口。走到一半，又停下来，回头看着她。

“还有。”他说，“别辜负行舟。”

门关上了，会议室里只剩下苏念和顾行舟。

苏念站在原地，手里捏着那份文件，感觉像做梦。三百万，她上辈子公司最鼎盛的时候，账上也没这么多现金。

“你……”她转向顾行舟，“你为什么不早说？”

顾行舟走到窗边，背对着她：“说什么？”

“说你爸是顾氏集团的老板。”苏念声音有点抖，“说你家里这么有钱。”

“说了又怎样？”顾行舟转过身，“你会因为这个跟我做朋友吗？”

苏念愣住。

她想起上辈子，她确实不知道顾行舟的家世。那时候她只觉得他成绩好，人安静，坐在她旁边三年，话都没说过几句。

“我……”她张了张嘴，不知道该怎么回答。

顾行舟走过来，从她手里抽走那份文件，翻到最后一页：“这里，签字栏。你想清楚再签。”

苏念看着他，突然问：“你为什么帮我？”

顾行舟动作一顿。

“从高三开始，你就一直帮我。”苏念说，“补课、挡周宇航、送笔记、现在又……你图什么？”

会议室里安静得能听见彼此的呼吸声。

顾行舟合上文件，放在桌上。他抬头看着苏念，眼神很深，像藏着很多话。

“图你。”他说。

苏念心跳漏了一拍。

“图你以后能成功。”顾行舟补充道，语气平淡，但耳根又红了，“这样我就能收回投资，赚一笔。”

苏念盯着他看了几秒，突然笑了。

“行。”她说，“那我一定努力，让你赚个盆满钵满。”

顾行舟也笑了，很淡，但眼睛里有光。

“走吧。”他拿起外套，“带你去吃饭，庆祝一下。”

“等等。”苏念拉住他，“你刚转给我的三百万……”

“那是我爸的钱，不是我的。”顾行舟说，“我的钱还在卡里，留着以后娶媳妇。”

苏念脸一下子红了：“谁、谁要嫁给你！”

顾行舟没接话，只是推开会议室的门。走廊里空无一人，地毯吸收了所有脚步声。

电梯门打开，苏念走进去，顾行舟跟在后面。门关上的瞬间，她突然听见他说：

“苏念。”

“嗯？”

“这次，别再错过了。”

苏念猛地抬头，但顾行舟已经按下了一楼的按钮，看着跳动的数字，侧脸线条在灯光下显得格外清晰。

她张了张嘴，最终什么也没说。

但心里某个地方，好像有什么东西，悄悄裂开了一道缝。
