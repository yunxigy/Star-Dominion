# 牛奶与旧伤疤

凌晨三点的办公室，只剩下键盘敲击声和服务器低沉的嗡鸣。

苏念揉了揉酸胀的眼睛，视线在屏幕上那些密密麻麻的代码间模糊了一瞬。她已经连续工作了十六个小时，大脑像生锈的齿轮，转动时发出吱呀的声响。

“先吃饭。”

顾行舟的声音从旁边传来，沙哑得厉害。他把一份外卖推到她面前，塑料袋上凝着水汽，是温热的。

苏念抬头看他。

顾行舟眼下是浓重的青黑，眼睛里布满血丝，但眼神还是清亮的。他右手小指上那道旧伤疤在屏幕光里泛着淡白色，像一条细小的蜈蚣。

“你什么时候买的？”苏念问。

“让小周送来的。”顾行舟打开饭盒，烧鹅的香气立刻弥漫开来，“半小时前就到了，看你一直在敲代码，没叫你。”

苏念这才发现，自己已经饿得胃隐隐发疼。她拿起筷子，夹了一块烧鹅，肉质酥软，酱汁浓郁。她吃得很快，几乎是狼吞虎咽。

“慢点。”顾行舟皱眉。

“饿。”苏念含糊地说。

顾行舟没再说话，只是从旁边拿过一盒纯牛奶，插好吸管递给她。温热的，他用热水袋焐过。

苏念接过来喝了一口，甜味在舌尖化开。她突然想起什么，动作顿了顿。

“你怎么知道我低血糖？”

顾行舟的手指在键盘上停住。

办公室里安静了几秒，只有服务器风扇转动的声音。

“你大学时和室友提过。”他说。

苏念盯着他：“我大学时和室友说的话，你怎么知道？”

顾行舟没回答，而是转过身继续敲代码。屏幕光映在他侧脸上，下颌线绷得很紧。

“顾行舟。”苏念叫他名字。

“吃饭。”他说，“半小时内吃完，我会打电话检查。”

苏念看着他的背影，突然发现一件事——顾行舟的右手小指，在敲键盘时会微微弯曲，像是用不上力。那道伤疤比她想象的要深，一直延伸到指根。

“你这伤，”她指着他的手，“不是大学实验划的吧？”

顾行舟的动作彻底停了。

他转过头，眼睛里有什么东西一闪而过，快得苏念抓不住。

“吃你的饭。”他说。

苏念没动。她放下筷子，认真地看着他：“顾行舟，你是不是有什么事瞒着我？”

办公室的灯光是冷白色的，照得两个人脸色都有些苍白。窗外是漆黑的夜，远处城市的灯火像撒了一地的碎钻。

顾行舟沉默了很久。

久到苏念以为他不会回答了。

“有些事，”他终于开口，声音很低，“我欠了你十年。”

苏念的心脏猛地一跳。

十年。

十年前，他们十八岁，在高三的教室里。她是追着校草跑的普通女生，他是坐在角落里、永远考满分的沉默同桌。

“什么意思？”她问。

顾行舟看着她，眼神复杂得让她看不懂。

“字面意思。”他说，“所以现在，你的事就是我的事。”

“可你说过，我们是合伙人。”

“是。”顾行舟点头，“但合伙人不会记得你低血糖，不会知道你大学时和室友说过什么。”

苏念愣住了。

她突然想起很多事。

想起高三那年，图书馆里永远坐在她对面的顾行舟。想起下雨天，他撑着伞送她回家，耳朵红了一路。想起毕业时，他送她的那本手写笔记，里面是密密麻麻的高考重点，字迹工整得像印刷体。

想起上辈子，她穷困潦倒时，曾经在同学聚会上见过顾行舟一次。那时他已经是很成功的投资人，被一群人围着敬酒。她躲在角落里，没敢上前打招呼。

后来她听说，顾行舟一直单身。

“你……”苏念的声音有些发抖，“你上辈子……”

“没有上辈子。”顾行舟打断她，“只有这辈子。”

苏念看着他。顾行舟的眼睛很亮，亮得让她不敢直视。

“那这伤疤，”她指着他的小指，“到底是怎么来的？”

顾行舟低头看了看自己的手。

“高三那年，”他说，“你追周宇航，被他朋友堵在巷子里。我去拦，被人用刀划的。”

苏念的呼吸停了。

她完全没有这段记忆。上辈子的她，眼里只有周宇航，根本不知道有人为她挡过刀。

“为什么……为什么不告诉我？”她问。

顾行舟笑了笑，那笑容里有很多苏念看不懂的东西。

“告诉你，然后呢？”他说，“你会因此喜欢我吗？”

苏念张了张嘴，说不出话。

不会。

上辈子的她不会。那时的她满心都是周宇航，顾行舟对她来说，只是一个沉默的、成绩很好的同桌。

“所以，”顾行舟说，“有些事，没必要让你知道。”

苏念的眼眶突然有点热。

她想起自己重生后的种种。想起她拒绝周宇航时，顾行舟默默关注的眼神。想起她找他补课时，他讲题很细但话很少。想起运动会，他在终点等她。想起生日，他送她手写笔记。

想起她误会他和校花说话时，心里那种不舒服的感觉。

原来那些感觉不是错觉。

原来有些事，她早就该发现。

“顾行舟。”她叫他。

“嗯？”

“牛奶很好喝。”苏念说。

顾行舟愣了一下，然后笑了。这次是真的笑，眼睛弯起来，眼角的细纹在灯光下清晰可见。

“那就好。”他说。

苏念继续吃饭，这次吃得慢了些。烧鹅饭已经有点凉了，但她觉得，这是她吃过最好吃的一顿。

顾行舟转回身继续敲代码。键盘声重新响起，但节奏比之前慢了一些。

苏念吃到最后，突然发现饭盒底下压着一张纸条。她抽出来，上面是顾行舟的字迹：

“代码可以重写，身体不能重来。——你的合伙人”

苏念看着那张纸条，看了很久。

然后她把它折好，放进口袋里。

“顾行舟。”她又叫他。

“嗯？”

“我们……”苏念斟酌着措辞，“我们以前，是不是发生过很多我不知道的事？”

顾行舟的手指在键盘上悬停。

“是。”他说。

“比如？”

“比如，”顾行舟转过头，认真地看着她，“高三那年，你感冒发烧，我翘了晚自习去给你买药。你烧得迷迷糊糊，把我认成了周宇航，拉着我的手说‘宇航你真好’。”

苏念的脸瞬间红了。

“比如，”顾行舟继续说，“大学时，你参加辩论赛，我在台下看了全程。你最后结辩的时候，引用了一个很冷门的案例，全场只有我听懂了，鼓掌鼓得最大声。”

“比如，你毕业找工作，投了三十七份简历，我帮你改了三十五份。你不知道，你收到的那些面试通知，有一半是我托人递的。”

苏念的眼泪终于掉了下来。

她想起上辈子，自己过得那么辛苦，找工作处处碰壁，最后只能去小公司做最底层的工作。她以为那是命运，原来不是。

“为什么？”她问，声音哽咽，“为什么要做这些？”

顾行舟看着她，眼神温柔得让她心碎。

“因为，”他说，“我喜欢你啊，苏念。”

“从十八岁开始，到现在，整整十年。”

办公室里安静得可怕。

苏念能听到自己的心跳声，一下，又一下，重得像擂鼓。

她想起自己重生后的初衷——好好高考，避开周宇航，利用前世记忆赚钱。她以为这辈子会完全不同，却没想到，最大的不同，是身边一直有这个人。

“我……”她开口，却不知道该说什么。

顾行舟站起来，走到她面前。他很高，苏念坐着，需要仰头才能看到他的脸。

“不用现在回答我。”他说，“先把代码写完，先把公司撑过去。其他的，我们有的是时间。”

苏念点点头，眼泪还在掉。

顾行舟抬手，用拇指擦掉她脸上的泪。他的手指有些凉，指腹有薄茧，擦过皮肤时有点痒。

“别哭了，”他说，“哭花了脸，明天怎么见投资人？”

苏念破涕为笑。

她抓住顾行舟的手，看着他小指上那道伤疤。

“还疼吗？”她问。

“早就不疼了。”顾行舟说，“但有时候会想起来。”

“想起什么？”

“想起你十八岁时的样子。”顾行舟的眼神飘向远处，“马尾辫，校服，笑起来眼睛弯弯的。追着周宇航跑，跑得那么认真，那么傻。”

苏念的脸又红了。

“我那时是不是很蠢？”她问。

“是。”顾行舟点头，“但很可爱。”

苏念松开他的手，推了他一下：“去写你的代码。”

顾行舟笑了，转身回到自己的位置。

办公室里重新安静下来，但气氛和之前完全不同了。键盘声还在响，服务器还在嗡鸣，但有什么东西变了。

苏念喝完最后一口牛奶，把空盒子扔进垃圾桶。她摸了摸口袋里的纸条，纸张的触感很真实。

她重新看向屏幕，代码还是那些代码，问题还是那些问题。但她的心态不一样了。

“顾行舟。”她突然说。

“嗯？”

“GPL协议的事，你打算怎么解决？”

顾行舟敲键盘的手停了一下。

“我已经联系了NeuralCore的维护者，”他说，“对方同意给我们特殊许可，但需要支付一笔授权费。”

“多少？”

“二十万。”

苏念倒吸一口凉气。公司账上只有四十二万，这一下就去了一半。

“我来想办法。”顾行舟说，“你专心重写代码。”

“你有什么办法？”

顾行舟没直接回答，而是说：“还记得高三那年，我送你的生日礼物吗？”

“那本手写笔记？”

“嗯。”顾行舟点头，“那本笔记里，除了高考重点，还有一页，写着一串数字。”

苏念愣住了。她完全不记得这件事。

“那串数字，”顾行舟说，“是一个银行账户的密码。”

“什么银行账户？”

“我从十八岁开始，每个月往里面存钱。”顾行舟看着她，“存了十年，本来是打算……”

他顿了顿，没说下去。

苏念突然明白了。

那笔钱，是他存了十年的。本来可能是打算用在别的地方，比如求婚，比如买房，比如他们的未来。

“不行，”苏念立刻说，“那是你的钱，我不能用。”

“现在是公司需要。”顾行舟说，“而且，我说了，你的事就是我的事。”

“可那是你十年……”

“苏念。”顾行舟打断她，声音很严肃，“公司现在是生死关头。代码要重写，授权费要付，服务器要续费，员工工资要发。账上那点钱，撑不了三个月。”

苏念沉默了。

她知道顾行舟说得对。公司现在就像走在钢丝上，一步走错，就是万丈深渊。

“那……算我借你的。”苏念说，“等公司赚钱了，我连本带利还你。”

“好。”顾行舟点头，“按银行利息算。”

苏念看着他，突然笑了：“你还挺会做生意。”

“不然怎么当你的合伙人？”顾行舟也笑了。

两人相视一笑，气氛轻松了些。

苏念重新看向屏幕，开始重写代码。这次她写得很快，思路清晰，手指在键盘上飞舞。顾行舟在旁边，偶尔会指出她代码里的问题，两人讨论几句，然后继续。

时间一分一秒过去。

窗外的天色开始泛白，从漆黑变成深蓝，再变成灰白。晨光透过百叶窗的缝隙照进来，在地板上投下一道道光斑。

苏念写完最后一行代码，长长地舒了一口气。

“完成了。”她说。

顾行舟凑过来看了看，点点头：“没问题。我这边授权费也谈好了，下午就能签合同。”

苏念靠在椅背上，感觉全身的力气都被抽空了。但她心里是轻松的，像卸下了一块大石头。

“去睡一会儿吧。”顾行舟说，“我让小周给你订了酒店，就在公司隔壁。”

“你呢？”

“我还有点事要处理。”顾行舟说，“处理完就去。”

苏念看着他布满血丝的眼睛，知道他在说谎。他肯定又要通宵。

“顾行舟。”她叫他。

“嗯？”

“谢谢。”苏念说，“不只是为了钱，为了所有的事。”

顾行舟看着她，眼神很深。

“不用谢。”他说，“这是我欠你的。”

“你不欠我。”苏念摇头，“是我上辈子……”

“没有上辈子。”顾行舟再次打断她，“我说了，只有这辈子。”

苏念看着他，突然很想问：那你上辈子呢？你上辈子过得怎么样？

但她没问出口。

有些事，也许现在还不是时候。

“那我先去睡了。”苏念站起来，走到门口时，又回头看了一眼。

顾行舟已经转回身，继续对着屏幕工作。晨光落在他身上，给他镀了一层淡淡的金色。

苏念突然想起，高三那年，顾行舟也是这样。她追着周宇航跑的时候，他永远坐在角落里，安静地看着她。

原来，他看了她十年。

苏念轻轻关上门，走出公司。

清晨的街道很安静，只有环卫工人在扫地。她深吸一口气，空气里有青草和灰尘的味道。

她摸了摸口袋里的纸条，那张写着“你的合伙人”的纸条。

然后她笑了。

这辈子，也许真的不一样了。
