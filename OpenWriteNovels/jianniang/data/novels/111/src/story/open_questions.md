# 待确认问题

以下内容来自用户设定中的不同表述或尚未落地的规划。本文件用于防止写作 agent 自行补全成硬事实。

| 问题 | 当前可用事实 | 写作处理 |
|---|---|---|
| 新手阶段的时间规则 | 第二章正文明确写出新手保护罩持续 7 天；其他限制细节尚未在正文中固定 | 先按 7 天保护罩写，离开/战斗/保护边界另行确认 |
| 领主等级与等级 40 | 设定写出“等级达到 40/镇级解锁概念之海”，但没有给出完整经验表 | 只写“达到门槛后解锁”，不提前给出数字换算 |
| 领主世界四年与王城级转移 | 两者都被设定为可以把领地转入现实的条件，先后关系未定 | 在王城篇前保留两条路线，不声明谁优先 |
| 现实与领主世界的时间比 | 高考实战、大学阶段和现实返回均有规划，但具体周期未固定 | 只在需要时写当前阶段，避免连续报出未经确认的月份 |
| 舰娘解锁顺序 | 拉菲是第一位明确召唤的舰娘，其余舰娘只在未来规划中出现 | 未来舰娘只作为候选，不提前写成已拥有 |
| 初始资源与燃油消耗 | 第二章给出物资 600、心智魔方 1、快速建造工具 1、石油 0；后续消耗表未完整确定 | 后续新增数值必须在章节内说明来源和用途 |
| 心智魔方与观察者 | 黑色方块与父母、舰娘心智和观察者有关，但真相属于长线伏笔 | 第一卷只写感应、共鸣和异常，不直接揭底 |
| 领地建筑解锁 | 已明确建造台、栅栏、深水之井及一批规划建筑 | 未建成的建筑只写为图纸、研究方向或未来计划 |
