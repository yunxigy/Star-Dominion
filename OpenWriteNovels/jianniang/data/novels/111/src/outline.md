# 《领主纪元：舰娘枢纽》总纲

> 核心主题: 当一个被世界判定为“无用”的天赋获得真正的规则解释权，灵汐要用领地、舰娘和自己的判断力，为人类在万族争霸中建立一条能活下去的路。
> 故事简介: 蓝星被拉入万族争霸，异族可以挑战并瓜分人类领土。孤儿灵汐在十八岁领主觉醒仪式上，以父母留下的黑色方块觉醒稀有 S 级天赋“碧蓝舰枢”。所有人都认为战舰只能困在海上，她却在荒芜戈壁召唤出第一位舰娘拉菲，从一口水井、一块领地和一笔燃油账开始，逐步把舰娘体系变成领主世界里一座能生产、能防守、能与人共同生活的枢纽。
> 目标字数: 100000
> 正典来源: 用户提供的核心设定文档与第一、二章正文；未明确内容不得提前写成硬事实。

## 第一卷：荒原上的第一座港口（规划 ch_001-ch_020）

> 篇情感弧线: 被误解的觉醒 → 缺水缺油的生存压力 → 建立第一套资源循环 → 证明舰娘能够在陆地作战
> 核心结果: 灵汐从“拥有一个奇怪天赋”走到“拥有一座能让自己和拉菲活下来的领地”。第一卷不急着完成大规模升级，先把水、燃油、体力、维修、警戒和领地边界写实。

### 第一阶段：觉醒与落地（ch_001-ch_002，已完成）

- 第一章《觉醒S级：那是……船？》：灵汐在魔都二中觉醒“碧蓝舰枢”，获得“心智感应”和“魔方感应”两条被动能力，承受外界对舰船天赋的误判，得到朋友与老师的支持。

## 第二卷：学院争霸与双重生活（规划 ch_021-ch_060）

> 篇情感弧线: 新人脱离保护 → 学院竞争与现实身份压力 → 领地基建扩张 → 碧蓝舰枢被迫接受公开检验

- 领主世界与现实世界形成周期性切换，灵汐要同时处理学习、训练、资源、同伴和舰娘日常。
- 学院提供图纸和资源，但每次扩张都带来油耗、维护和领地管理成本。
- 通过心智钻井平台、科研中心、机械厂、食堂、浴场和维修港等规划中的专属建筑，建立“战争机器与生活秩序并存”的领地气质。
- 领主之间的高校比拼不是单纯擂台赛，还包含侦察、补给、协作、地形和规则理解。
- 领地达到文本所说的等级 40/镇级门槛后，概念之海开始显现；具体等级对应关系保留待确认。

## 第三卷：万族博弈与高维真相（规划 ch_061-ch_090）

> 篇情感弧线: 以为自己在参加竞争 → 发现竞争规则本身有问题 → 看到观察者的注视 → 决定把舰娘和人类都当作有选择权的存在

- 万族战场从资源争夺扩展为势力博弈，灵汐要面对异族领主、同族竞争者和人类内部的利益分配。
- 心智魔方、父母意外、舰娘心智与高维观察者逐步互相指向，但每次揭示只解决一个局部问题。
- 舰娘的优势不只靠火力，还靠后勤、科研、维修、情报和对领地生活的参与。
- 观察者不作为早期章节的万能解释；只有出现足够证据后，才让其进入现实冲突。

## 第四卷：具象化与国门守护（规划 ch_091-ch_120）

> 篇情感弧线: 领地必须回到蓝星 → 个人力量转化为国家防线 → 舰体具象化付出巨大代价 → 人类选择自己的未来

- 灵汐的领地达到王城级或满足领主世界四年条件后，具备转移至现实世界的可能；两者关系仍待确认。
- 现实世界防线遭遇大规模异族压力，碧蓝王城不只是降临场面，也要承担人口、能源、工业和协同治理。
- 舰体具象化作为需要燃烧海量石油资源的终极底牌，不在前期当作普通技能反复使用。
- 结局回收黑色方块、父母、观察者和舰娘“人心”的主线，同时保留灵汐和舰娘共同生活的日常质感。

### 统一写作约束

- 每章写清楚资源、体力、伤势、信息和关系中的至少两项变化。
- 每次能力展示都要说明条件、代价或后续影响。
- 系统消息只承载规则确认，不代替人物行动和场景。
- 相邻章节不重复使用同一种开头意象或结尾宣言。
- 第一卷的核心爽点是“把看似不适合陆地的天赋做成可靠体系”，不是连续抽卡和连续升级。
