# 世界底层规则

## 世界层级

| 层级 | 当前规则 |
|---|---|
| 蓝星现实 | 人类依托灵能堡垒存续，城市是相对安全区；异族已占领部分大陆领土 |
| 领主世界 | 觉醒者被传送到各类试炼区和战场，开拓、占领、战斗与建设都能影响领地成长 |
| 万族争霸 | 异族可以挑战蓝星并瓜分领土；青年/高校比拼与常态化战场是设定中规划的两类竞争场景 |
| 高维观察层 | 观察者可能把万族争霸当作兵棋，心智魔方可能是其中的异常变量；这属于长线真相 |

## 觉醒与领地

1. 十八岁公民强制参加领主觉醒仪式。
2. 觉醒者获得领地契约、领主天赋和进入领主世界的资格。
3. 领主核心可以展开初始领地与领主木屋；初始领地是人物生存与建筑的边界。
4. 领地规划等级为村级、镇级、城级、王城级、永恒之都级。具体经验与建筑数量表尚未确定。
5. 领地升级应同时带来生产、防御、人口/单位容量和治理压力，不能只增加面板数值。

## 资源规则

- 物资/金币用于建造与日常交易。
- 木材、石材等基础材料需要采集或交换；采集会消耗时间和体力。
- 心智魔方用于舰娘召唤或相关研究，属于稀缺资源。
- 石油/灵能燃油是舰娘具象化舰装、作战和大型建筑运行的重要资源。没有燃油时，舰娘可以依靠肉身和舰装物理形态行动，但战斗能力与可用技能受限。
- 水是荒漠生存和舰娘散热、休息的重要基础资源；深水之井可以无视地形强制开采地下水源，但井本身仍需要被保护和管理。
- 魔核等战利品可以作为后续建筑、研究或交易资源，具体兑换关系在发生时确定。
- 一次性防御护盾是林北赠送给灵汐的单次保命道具；宿主遭遇致命威胁或主动激活后，卡片立即消失，随后获得 5 秒无敌，不能重复触发。

## 碧蓝舰枢

- 可以使用碧蓝航线专属建筑并解锁舰娘分支。
- 舰娘实力受领地等级、燃油、装备、维修状态、战术环境和指挥质量共同影响。
- 舰娘可以入驻建筑，承担后勤、防御、科研等专属基建职能；入驻意味着时间与功能分配，不是凭空复制单位。
- 领地达到设定中的等级 40/镇级门槛后，解锁概念之海；对应关系和解锁条件保持开放。

## 战斗规则

- 战斗先由侦察、地形、距离、资源和目标优先级决定，火力只是解决方案的一部分。
- 驱逐舰偏向机动、侦察和近距离打击；战列舰偏向远距离重火力；航母偏向制空和航空支援。这些是规划中的兵种逻辑，未获得的舰娘不能提前使用。
- 伤势、体力、燃油和维修会延续到战后，不能由结算界面自动抹除。
- 舰体具象化是终局级底牌，需要燃烧海量石油资源，不能在前期当作普通攻击。

## 叙事中的规则校验

- 新章节出现新数值时，必须说明来源、消耗和结余。
- 新建筑至少要有材料、时间、位置或人员中的一项限制。
- 新技能必须说明触发条件和代价。
