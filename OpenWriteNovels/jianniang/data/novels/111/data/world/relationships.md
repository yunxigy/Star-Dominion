# 关系状态

- 灵汐—拉菲：指挥官与第一位舰娘。关系从召唤后的心声和共同生存开始，灵汐负责资源与判断，拉菲负责行动与战斗；信任仍在形成。
- 灵汐—叶冰瑶：从小一起长大的朋友。叶冰瑶用“背船、挖河、我养你”的夸张承诺表达保护，现实能力和试炼距离仍未验证。
- 灵汐—林北：发小与互相较劲的朋友。林北用嘲讽掩饰担心，赠送一次性防御护盾；两人以炮火和炎魔互相放话。
- 灵汐—老李：学生与班主任。老李无法控制灵汐的出生地，却赠送深水之井图纸；灵汐把这份支持转化为第一天的生存基础。
- 拉菲—荒芜戈壁：环境关系。她拥有舰装和战斗本能，但当前没有油料，水、散热和休息决定她能否继续行动。
