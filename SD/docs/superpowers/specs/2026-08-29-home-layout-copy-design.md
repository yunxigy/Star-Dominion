# 首页右侧间距与广告词调整设计

## 目标

- 消除首页右侧卡片中时钟与分类入口之间被强制拉开的大片空白。
- 将首页轮播广告词从“100+ 免费在线工具”更新为“200+ 免费在线工具，助力高效工作”。

## 方案

1. 保留首页现有两列响应式结构、卡片样式和分类入口。
2. 将右侧卡片从 `justify-between` 改为自然的纵向排列，并保留明确的垂直间距，使时钟和分类网格在各个断点下紧凑衔接。
3. 仅更新 `TypewriterText` 的首条文案；工具数量徽章继续使用注册表的动态数量，避免未来再次过期。

## 验收

- 首页右侧卡片不再出现由弹性布局产生的大段垂直空白。
- 首页动态广告词首条显示为“200+ 免费在线工具，助力高效工作”。
- 首页其它导航、搜索、项目作品和分类卡片行为保持不变。
- 现有测试、lint 与生产构建通过。
