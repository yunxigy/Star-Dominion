> 目标：整套牌在视觉语言、卡面比例、光影、材质和神秘学符号上保持统一，同时每张牌拥有独立、可辨识的核心画面。

## 1. 整套牌统一视觉规范

### 1.1 核心美术方向

**主题关键词：**

`dark gold tarot, occult mysticism, gothic elegance, antique engraving feeling, black obsidian, aged gold, deep burgundy, midnight blue, ritual candlelight, celestial symbols, alchemy geometry, mysterious sacred atmosphere`

整套牌统一采用：

- **暗金神秘风**，主色为黑曜石黑、古旧暗金、午夜蓝、深酒红、墨绿。
- 金色不是明亮土豪金，而是 **aged gold / antique gold / muted metallic gold**。
- 画面整体偏暗，但主体必须清晰，关键符号通过金色边缘光、烛火、月光或日蚀光强调。
- 质感介于 **古典塔罗 + 黑暗奇幻 + 哥特神秘学 + 高级收藏卡牌插画** 之间。
- 有宗教感、仪式感、命运感，但避免直接复制任何现成塔罗牌画风。
- 允许使用：星盘、月相、日蚀、炼金术圆环、古代几何、黑色石柱、祭坛、烛火、星尘、薄雾、古老花纹。
- 不要赛博朋克，不要霓虹，不要现代街景，不要动漫大眼，不要Q版，不要廉价手游特效。

### 1.2 统一卡面构图

建议所有牌使用同一套基础构图参数：

- **竖版 2:3**
- 主体位于画面中央或中央略偏下
- 上方保留少量呼吸空间，便于后续网站叠加牌名 / 编号
- 四周可以有极细暗金装饰边框，但不要抢主体
- 画面必须有明确前景、中景、背景
- 光源数量控制在 1–2 个
- 强调纵深、体积光、薄雾、暗部层次
- 每张牌至少保留 1 个“远看就能认出”的核心符号

### 1.3 推荐统一前缀 Prompt

以下内容可以作为所有 78 张牌的统一前缀，由程序自动拼到每张牌专属提示词前：

```text
vertical tarot card illustration, dark gold occult aesthetic, mysterious gothic fantasy, antique black and aged gold color palette, deep burgundy and midnight blue accents, cinematic low-key lighting, sacred ritual atmosphere, subtle volumetric fog, fine antique gold linework, celestial and alchemical symbols, elegant composition, highly detailed painterly illustration, refined materials, obsidian stone, antique metal, velvet fabric, candlelight, moonlight, dramatic but restrained contrast, premium collectible tarot card art, symmetrical visual balance when appropriate, mystical, solemn, poetic, no modern objects, no cyberpunk, no neon, no cartoon style
```

### 1.4 推荐统一后缀 Prompt

```text
ultra detailed, coherent anatomy, elegant hands, realistic fabric folds, realistic metal reflections, controlled highlights, deep shadows, sophisticated composition, premium fantasy illustration, 2:3 vertical composition, no readable text inside the artwork
```

### 1.5 统一 Negative Prompt

```text
low quality, low resolution, blurry, noisy, oversaturated, neon colors, cyberpunk, sci-fi city, modern clothing, modern props, cartoon, chibi, childish, cute style, exaggerated anime face, deformed body, extra limbs, extra fingers, malformed hands, bad anatomy, duplicate characters, duplicate objects, floating random symbols, cluttered composition, flat lighting, plastic texture, cheap mobile game UI, watermark, logo, QR code, readable text, subtitles, random letters, frame text
```

### 1.6 网站实现建议

为避免 AI 在卡图里生成乱码文字，**卡面图本身不要让模型生成牌名**。建议：

1. AI 只负责纯插画；
2. 前端统一叠加：
   - 罗马数字 / 序号；
   - 中文牌名；
   - 英文牌名；
3. 正位 / 逆位不要生成两套图，直接在前端旋转 180°；
4. 同一张牌在每日塔罗、三牌阵、爱情、事业、是/否模式下应复用同一张卡面。

# 8. 给代码生成工具的调用规则建议

如果你的网站通过 AI 批量生成卡图，可以把提示词拆成三个字段：

```ts
type TarotCardPrompt = {
  id: string
  nameZh: string
  nameEn: string
  arcana: "major" | "minor"
  suit?: "cups" | "pentacles" | "swords" | "wands"
  keywords: string[]
  scenePrompt: string
}
```

运行时：

```ts
const finalPrompt = [
  GLOBAL_STYLE_PROMPT,
  card.scenePrompt,
  GLOBAL_SUFFIX_PROMPT,
  NEGATIVE_PROMPT
].join("\n");
```

# 9. 整套牌最终统一要求

无论使用哪一种模型，最终人工筛图时建议统一检查：

- 人物脸部风格是否一致；
- 金色是否统一为暗金 / 古金，而不是亮黄色；
- 是否混入现代服装、建筑、电器；
- 是否出现多余手指、多余人物；
- 每张牌的核心符号数量是否正确；
- 宝剑、圣杯、金币、权杖数量是否与牌面数字一致；
- 大阿卡纳最重要的经典象征是否保留；
- 画面里不要出现乱码牌名；
- 不要让不同牌之间背景完全一样；
- 逆位由前端旋转，不再单独出图；
- 保持同一尺寸、同一边框、同一暗部密度与金色高光强度。
