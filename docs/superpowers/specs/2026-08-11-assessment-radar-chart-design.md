# 测评结果雷达图设计

## 目标

在现有测评结果页增加一张可快速理解整体轮廓的雷达图，同时保留目前的横向柱状图，以便查看准确百分比和维度说明。

## 方案选择

考虑过三种实现：

1. 原生 SVG：体积小、可完全控制视觉与无障碍语义，不增加运行依赖；采用此方案。
2. 引入 Recharts 等图表库：开发较快，但会为单张简单图表增加较多依赖和产物体积。
3. 仅使用 CSS 绘制：适合柱状图，不适合维度数量可变的多边形坐标计算。

## 展示规则

- `dominant` 和 `dimensions` 模式展示雷达图，维度数量可以是 4–6 个。
- `mbti` 模式不展示雷达图，继续使用 E/I、S/N、T/F、J/P 四组双向比例条。
- 雷达图位于“维度地图”标题和柱状图之间；柱状图、百分比、维度说明全部保留。
- 图表数据直接使用 `score.dimensionScores` 中的 0–100 分数，不改变计分算法。
- 信息不足的维度按 0 绘制，但使用虚线轴和“信息不足”文字说明，不能把 0 误解成有效低分。
- 图表下方明确说明：百分比表示本次回答中的相对倾向，不是人群百分位。

## 组件边界

新增独立 `AssessmentRadarChart` 组件，输入为维度定义和维度分数：

- 负责极坐标换算、网格、轴线、数据多边形、圆点和标签。
- 不读取测评定义、不重新计分，也不决定是否展示。
- `AssessmentResult` 仅负责在非 MBTI 模式中调用组件。

极坐标从正上方开始顺时针排列。图表使用固定 `viewBox` 和 `width: 100%` 自适应，桌面最大宽度约 520px，390px 移动端不得产生横向滚动。

## 视觉与交互

- 使用现有暖色结果页：米白网格、棕色轴线、当前测评分组对应的强调色。
- 数据区域为半透明填充，边线和数据点保持足够对比度。
- 不增加悬浮提示或动画依赖；使用轻量 CSS 过渡，并遵守 `prefers-reduced-motion`。
- 标签展示维度名称与整数百分比；过长名称允许两行或缩小字号。

## 无障碍

- SVG 使用 `role="img"`，包含可读标题与描述。
- 描述按顺序列出每个维度的百分比或“信息不足”，屏幕阅读器不依赖图形理解结果。
- 雷达图不是唯一信息来源，后方柱状图继续提供文本和数值。

## 测试

- 单元测试覆盖点坐标、100/50/0 分映射、维度数量变化和信息不足。
- 渲染测试确认非 MBTI 显示雷达图、MBTI 不显示雷达图，并包含可访问名称。
- 运行完整 Vitest、TypeScript、注册表校验和生产构建。
- 在桌面与约 390px 移动宽度检查无横向溢出。

## 范围外

- 不改变测评题目、计分、结果类型或注册表。
- 不加入人群常模、排行榜、历史结果保存或结果分享图片。
- 不替换现有柱状图。
