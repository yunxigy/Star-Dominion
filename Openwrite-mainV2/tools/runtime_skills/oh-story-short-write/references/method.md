# 短篇方法

## 单一情绪任务

先回答读者读完最强烈的感觉是什么，哪一个关系或事件负责交付它。副线必须强化主线，否则删除或合并。开头尽快进入不稳定状态，但要让钩子与最终冲突属于同一条因果链。

## 场景链

每个场景记录：进入时人物相信什么、当下目标、阻力、关键选择、离开时发生了什么不可逆变化。后一场由前一场的结果触发，避免并列堆叠事件。

可用的基础节奏是建立期待、第一次受阻、信息或关系转向、压力集中、核心选择、结算与余韵。场数按篇幅调整，不为满足公式硬造转折。

## 反转与信息

反转至少满足：前文存在可回看线索；新解释比旧解释更完整；它改变人物选择或读者情绪；结局不依赖突然加入的规则。无反转的甜宠、喜剧、成长或报应故事也可以靠关系变化与情绪结算成立。

把信息分为立即需要的条件、延迟揭示的答案和可由细节推断的关系。延迟答案时仍给足问题和证据，不能只写含糊暗示。

## 人物与精修

优先保留能制造选择的人物，合并只负责解释、传话或围观的角色。通过重复但有变化的行动、口吻和选择建立人物，不用长段背景替代戏剧现场。

精修时从结尾反查：每个场景是否提供因果或情绪准备；中段是否至少改变过局面；高潮是否来自人物选择；关键线索能否回看；结尾是否兑现开头承诺并保留适当余韵。
