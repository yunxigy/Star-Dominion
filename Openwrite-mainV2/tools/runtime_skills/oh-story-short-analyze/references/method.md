# 短篇拆解方法

## 分段

按场景变化而不是固定字数分段。每个场景记录进入信念、即时目标、阻力、关键选择、信息变化、情绪变化和离开状态。检查后一场是否由前一场结果触发；并列事件要标为因果薄弱。

## 六个维度

1. 开头：异常或损失是什么，向读者承诺哪种体验，是否真正进入主线。
2. 人物：谁制造选择，谁提供阻力，谁只承担解释或见证功能，角色能否合并。
3. 信息：哪些条件立即公开，哪些答案延迟，读者凭什么形成旧解释。
4. 情绪：铺垫、加压、释放和余波如何分布，中段是否改变局面。
5. 反转：是否有可回看线索，新解释是否更完整，是否改变选择或情绪，是否突然引入规则。
6. 结尾：高潮是否来自人物选择，是否兑现开头承诺，余韵是否服务核心情绪。

无反转作品不要判为结构缺失。甜宠、喜剧、成长和报应型短篇可以通过关系变化与情绪结算成立。

## 输出

先给一句话故事机制和场景链，再给情绪曲线、信息释放表、反转或结算审计、人物功能表和可迁移模块。每个模块写明原作证据、有效机制、适用前提、失效风险以及换用当前项目素材的候选变体。

不要大段引用原文。专名、独特设定和标志性场面只用于定位证据，不进入迁移方案。
