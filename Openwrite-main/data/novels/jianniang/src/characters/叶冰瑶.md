# 叶冰瑶

## 背景

灵汐的死党/发小，魔都二中甜美系校花，从小一起长大。小鹿般的眼睛，甜美可人。性格单纯善良，容易紧张焦虑（觉醒前查星象运势、撕《荒野求生指南》），但对灵汐极度保护。觉醒A级天赋【自然亲和】+A级【精灵之心】，天生精灵女王模板，森林地形绝对霸主。经典台词："我用我的精灵射手背着你的船走！或者我给你挖人工河！总之我养你！"
