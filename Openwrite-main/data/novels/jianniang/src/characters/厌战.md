# 厌战

## 背景

战列舰娘，沉稳可靠的大姐姐型角色。406mm主炮可进行超视距远程打击，是领地的远程火力支柱。油耗恐怖，是灵汐"账单噩梦"的来源之一。战斗风格：站在数公里外，用校射雷达锁定后降下毁灭火雨。
