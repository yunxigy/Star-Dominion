# 王叔

## 背景

城西七号楼房东，60多岁，退休工人。面容沧桑，说话慢条斯理。1987年事件的知情者，当年是林深父亲的工友。暗中保护林深多年，手中保管着林深父亲的"遗物"（暗红色碎片）。知道封印阵的存在。
