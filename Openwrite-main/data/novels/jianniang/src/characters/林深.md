# 林深

## 背景

男主，26岁，便利店夜班店员。沉默寡言，眼神疲惫但警觉。幼年丧母，由外婆抚养长大，对童年记忆模糊。身上有暗红色胎记（实为"标记"）。父亲1987年失踪，母亲在他五岁时"病逝"（实为保护他逃离"娘娘"而牺牲）。
