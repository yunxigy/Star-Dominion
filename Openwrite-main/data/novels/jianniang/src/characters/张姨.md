# 张姨

## 背景

七号楼三楼原住户，三年前因目睹"它们"而失踪。实为自愿成为"容器"但失败，变成半人半碎片的存在（红裙女人）。瞳孔泛暗红光，赤脚，动作僵硬。在便利店用五角硬币警告林深。最终在林深帮助下恢复人形。
