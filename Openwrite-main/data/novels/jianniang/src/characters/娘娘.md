# 娘娘

## 背景

被封印在裂缝中的古老存在，由暗红色碎片凝聚的巨大人形轮廓，面容模糊但穿着红裙。声音像无数人同时低语。并非邪恶——是被困数百年的悲伤灵魂，只想"回家"。"它们"是封印泄漏的碎片。最终被林深释放灵魂。
