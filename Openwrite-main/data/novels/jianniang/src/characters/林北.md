# 林北

## 背景

魔都林氏集团少东家，高三（2）班刺头，灵汐的发小/傲娇竹马。嚣张红发，穿限量版防护服、几十万战术手表、战术靴。嘴毒心善，明明关心灵汐却非要摆臭脸。觉醒A级天赋【炎魔召唤】。口头禅"切"，习惯用脚踢椅子。曾想给灵汐送东西被老李砸黑板擦制止，觉醒后赠送200单位材料卡还嘴硬说"给船多买点润滑油"。经典台词："要是你在新手区就被淘汰了，以后出去别说认识本少爷。"
