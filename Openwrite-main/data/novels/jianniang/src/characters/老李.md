# 老李

## 背景

魔都第二中学高三（2）班班主任，退役老兵。眼眶深陷，声音沙哑如砂纸磨过，外表严厉内心柔软。教鞭抽黑板、砸黑板擦是常态。为灵汐申请定向觉醒石（被拒），又私下赠送绿色稀有图纸【深水之井】。最后一课哽咽说"活着回来"。经典台词："不想变成两脚羊，就给我咬碎了牙活下去！"
