# 灵汐

## 背景

【主角】女，18岁，魔都第二中学高三（2）班年级第一，理论课满分怪物。银色长发，穿洗得发白的校服，领口扣子系到最上面一颗，禁欲而严谨。性格清冷沉稳，与年龄不符的静气。父母十年前"意外"身亡，是孤儿，住四十平米老旧公寓。拥有"魔方感应"能力，能感知他人情绪光晕（如林北的焦躁橙色）。觉醒S级（唯一）天赋【碧蓝舰枢】——召唤系·舰船。父母遗物黑色方块实为心智魔方，窃取自高维文明"观察者"的作弊码。口头禅/标志性台词："真理，往往只在射程之内。"
